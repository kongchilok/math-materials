## 練習題

1．（a）√50　（b）√75　（c）三邊為 √50、√25、√75 的三角形周長。

- (a) 50 = 25 × 2（25 是完全平方）→ √50 = 5√2。
- (b) 75 = 25 × 3 → √75 = 5√3。
- (c) √25 = 5（整數，沒有根號）。
  三項的根號內分別是 2、無、3，兩兩不同類，不能合併。
  周長 = 5√2 + 5 + 5√3（厘米）。
- 檢核（近似值）：√50 ≈ 7.0711、√25 = 5、√75 ≈ 8.6603，和 ≈ 20.7314；
  5√2 ≈ 7.0711、5√3 ≈ 8.6603，5√2 + 5 + 5√3 ≈ 20.7314 ✔
- 最簡性檢核：2 與 3 都沒有完全平方因數 ✔
- **文件答案：(a) 5√2　(b) 5√3　(c) 5√2 + 5 + 5√3 — 一致。**

2．計算 √48 − √27 + √12。

- 48 = 16 × 3 → √48 = 4√3；27 = 9 × 3 → √27 = 3√3；12 = 4 × 3 → √12 = 2√3。
- 三項同類（根號內都是 3），係數 4 − 3 + 2 = 3 → 3√3。
- 檢核（近似值）：6.9282 − 5.1962 + 3.4641 = 5.1961；3√3 ≈ 5.1962 ✔
- 形式檢核：三項化簡後都是 √3 的倍數，答案必然也是 √3 的倍數 ✔
- **文件答案：3√3 — 一致。**

3．（a）4 + √3 與 13 − √2 的有理化因式及乘積。（b）化簡 1/(2 + √3)。

- (a) 共軛只調中間符號：4 + √3 → 4 − √3；乘積 = 4² − 3 = 16 − 3 = 13。
  13 − √2 → 13 + √2；乘積 = 13² − 2 = 169 − 2 = 167。
- 兩個乘積都是整數（有理數），符合「有理化」的目的 ✔
- (b) 分子分母同乘 2 − √3：分母 = (2+√3)(2−√3) = 4 − 3 = 1；分子 = 2 − √3。
  分母為 1，答案 = 2 − √3。
- 檢核 (b)：1/(2+√3) = 1/3.7321 ≈ 0.26795；2 − √3 ≈ 2 − 1.73205 = 0.26795 ✔
- **文件答案：(a) 4 − √3（13）、13 + √2（167）　(b) 2 − √3 — 一致。**

4．化簡 1/(x−1) + 1/(x+1)，並寫出 x 的限制。

- 公分母 (x−1)(x+1) = x²−1（兩分母無公因式）。
- 通分：(x+1)/[(x−1)(x+1)] + (x−1)/[(x−1)(x+1)]。
- 分子 = (x+1) + (x−1) = 2x（+1 與 −1 相消）。
- 結果 = 2x/(x²−1)。分子 2x 與分母 (x−1)(x+1) 無公因式，不能再約。
- 限制：原式分母 x−1 與 x+1 → x ≠ 1 且 x ≠ −1。
- 檢核：x = 3 → 原式 = 1/2 + 1/4 = 3/4；2×3/(9−1) = 6/8 = 3/4 ✔
- 再檢核：x = −3 → 原式 = 1/(−4) + 1/(−2) = −0.75；2(−3)/(9−1) = −6/8 = −0.75 ✔
- **文件答案：2x/(x²−1)，x ≠ 1 且 x ≠ −1 — 一致。**

5．（a）化簡 1/(x−2) − 4/(x²−4) 並寫限制。（b）說明為何 x = 2 時原式沒有意義。

- (a) x²−4 = (x−2)(x+2)，公分母 (x−2)(x+2)。
  通分：(x+2)/[(x−2)(x+2)] − 4/[(x−2)(x+2)]。
  分子 = (x+2) − 4 = x − 2。
  結果 = (x−2)/[(x−2)(x+2)]，約去公因式 (x−2) → 1/(x+2)。
- 限制：原式分母為 x−2 與 x²−4，兩者為 0 的情況是 x = 2 與 x = −2
  → x ≠ 2 且 x ≠ −2。
- 檢核 (a)：x = 3 → 原式 = 1/1 − 4/5 = 1/5；1/(3+2) = 1/5 ✔
- 再檢核：x = 0 → 原式 = 1/(−2) − 4/(−4) = −0.5 + 1 = 0.5；1/(0+2) = 0.5 ✔
- (b) x = 2 令原式的分母 x−2 = 0（同時 x²−4 = 0），除以 0 沒有定義，
  故原式在 x = 2 不存在。化簡時約去 (x−2) 只是把那個「洞」在寫法上藏起來，
  並沒有把它補回去，所以限制必須依照**原式**寫出。
- **文件答案：(a) 1/(x+2)，x ≠ 2 且 x ≠ −2　(b) 限制來自原式分母，化簡不會令它消失 — 一致。**

6．已知 a + b = 12、ab = 22。（a）求 √(a²+b²)。（b）求 log ∛(a²+b²)。

- (a) 由 (a+b)² = a² + 2ab + b² 得 a² + b² = (a+b)² − 2ab = 12² − 2×22 = 144 − 44 = 100。
  √(a²+b²) = √100 = 10。
- 獨立檢核 (a)：a、b 是 x² − 12x + 22 = 0 的兩根，x = 6 ± √14。
  (6+√14)² + (6−√14)² = (36 + 12√14 + 14) + (36 − 12√14 + 14) = 100 ✔
  （判別式 144 − 88 = 56 > 0，兩根為實數，題目條件自洽。）
- (b) ∛(a²+b²) = ∛100 = 100^(1/3)。
  log 100^(1/3) = (1/3) log 100 = (1/3)(2) = 2/3。
- 檢核 (b)：∛100 ≈ 4.64159；log 4.64159 ≈ 0.66667 = 2/3 ✔
- **文件答案：(a) 10　(b) 2/3 — 一致。**

## 講義範例

範例A．三邊為 √20、√40、√45 的三角形周長。

- 20 = 4×5 → 2√5；40 = 4×10 → 2√10；45 = 9×5 → 3√5。
- 同類項：2√5 + 3√5 = 5√5；√10 無同類，保留。周長 = 5√5 + 2√10（厘米）。
- 檢核：4.4721 + 6.3246 + 6.7082 = 17.5049；5√5 ≈ 11.1803、2√10 ≈ 6.3246，
  和 ≈ 17.5049 ✔
- 最簡性檢核：5 與 10 皆無完全平方因數 ✔
- **文件答案：5√5 + 2√10 — 一致。**

範例B．（a）10 + √5、3 − √2 的有理化因式與乘積。（b）化簡 1/(2 + √3)。

- (a) 10 − √5，乘積 = 100 − 5 = 95；3 + √2，乘積 = 9 − 2 = 7。
- (b) 同練習第 3(b) 題：答案 2 − √3。
- 檢核：95 與 7 都是整數 ✔；1/(2+√3) ≈ 0.26795 = 2 − √3 ✔
- **文件答案：(a) 10 − √5（95）、3 + √2（7）　(b) 2 − √3 — 一致。**

範例C．計算 √(9x) + 6√(x/4) − 2x√(1/x)（x > 0）。

- 第一項：√(9x) = √9 · √x = 3√x。
- 第二項：√(x/4) = √x / 2，故 6 × (√x/2) = 3√x。
- 第三項：√(1/x) = 1/√x，故 2x · (1/√x) = 2x/√x；因 x = (√x)²，約去一個 √x 得 2√x。
- 合併（三項同類）：3√x + 3√x − 2√x = 4√x。
- 檢核：取 x = 4 → 原式 = √36 + 6√1 − 8√(1/4) = 6 + 6 − 8(0.5) = 6 + 6 − 4 = 8；
  4√4 = 4 × 2 = 8 ✔
- 再檢核：取 x = 9 → √81 + 6√(9/4) − 18√(1/9) = 9 + 6(1.5) − 18(1/3) = 9 + 9 − 6 = 12；
  4√9 = 12 ✔
- **文件答案：4√x — 一致。**

範例D．化簡 1 + x/(1−x) − 2x/(x²−1)，並寫出 x 的限制。

- x²−1 = (x−1)(x+1)；1−x = −(x−1)，故 x/(1−x) = −x/(x−1)。公分母 (x−1)(x+1)。
- 通分：1 = (x²−1)/[(x−1)(x+1)]；−x/(x−1) = −x(x+1)/[(x−1)(x+1)]；
  2x/(x²−1) = 2x/[(x−1)(x+1)]。
- 分子 = (x²−1) − x(x+1) − 2x = x² − 1 − x² − x − 2x = −3x − 1 = −(3x+1)。
- 結果 = −(3x+1)/[(x−1)(x+1)] = −(3x+1)/(x²−1)。
  分子 −(3x+1) 與分母無公因式，不能再約。
- 限制：原式分母為 1−x 與 x²−1 → x ≠ 1 且 x ≠ −1。
- 檢核：x = 2 → 原式 = 1 + 2/(−1) − 4/3 = 1 − 2 − 4/3 = −7/3；
  −(3×2+1)/(4−1) = −7/3 ✔
- 再檢核：x = 0 → 原式 = 1 + 0 − 0 = 1；−(0+1)/(0−1) = −1/−1 = 1 ✔
- **文件答案：−(3x+1)/(x²−1)，x ≠ 1 且 x ≠ −1 — 一致。**

## 驗算結論

練習 6 題（合共 10 個小問）＋ 講義 4 個範例（合共 7 個小問），全部重算一次，
與文件所載答案 **100% 一致**（QB-V2）。

三種檢核方式全部用過：
1. **數值代入**——所有分式題都代兩個不同的 x（例如第 4 題代 x = 3 與 x = −3、
   第 5 題代 x = 3 與 x = 0、範例C 代 x = 4 與 x = 9、範例D 代 x = 2 與 x = 0），
   兩次都與化簡結果相符才收貨。單代一個數字有機會碰巧吻合，代兩個才排除得了。
2. **近似值核對**——所有根式答案都取小數驗算（例如 5√2 + 5 + 5√3 ≈ 20.7314）。
3. **獨立第二解法**——第 6 題除了用恆等式 a²+b² = (a+b)² − 2ab，
   另外解出 a、b = 6 ± √14 再直接平方相加，兩種做法都得 100。

數字挑選原則（依 design-checklist.md §B「計算障礙：不要讓答案不乾淨」）：

- **根式題**：根號內的數一律含有明顯的完全平方因數（50 = 25×2、75 = 25×3、
  48 = 16×3、27 = 9×3、12 = 4×3、20 = 4×5、40 = 4×10、45 = 9×5），
  拆解的目標一眼看得出，不必試除。
- **有理化題**：共軛相乘之後刻意得整數（16−3 = 13、169−2 = 167、4−3 = 1）；
  第 3(b) 題的分母更刻意設計成 1，令答案直接就是分子，不必再約分。
- **分式題**：分母都取 (x−1)(x+1) 或 (x−2)(x+2) 這類平方差形式，
  因式分解一步到位；第 5 題刻意讓分子約掉之後剩 1，
  好讓「約掉了但限制仍在」這件事看得最清楚。
- **整合題**（第 6 題）：a+b 與 ab 選成令 a²+b² = 100 的組合，
  同時服務 √100 = 10（整數）與 log∛100 = 2/3（簡分數）兩問；
  a、b 本身是無理數 6 ± √14，正好示範「不必求出 a、b」這個要點。
- 全部 17 個小問的答案，除了必然帶根號的最簡根式之外，**沒有任何小數**。
