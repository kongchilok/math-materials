## 練習題

1．判斷下列各式是否為有意義的對數，並求出有意義者的值。
（a）log₃81　（b）log₂(−8)　（c）log₁5　（d）log₄₀1

- (a) 底數 3 > 0 且 ≠ 1 ✔；真數 81 > 0 ✔ → 合法。3⁴ = 81 → 值 = 4。
- (b) 真數 −8 < 0 → 違反特徵②。補充論證：2 的任何實數次方皆為正，故不存在 k 使 2ᵏ = −8。
- (c) 底數 = 1 → 違反特徵①。補充論證：1ᵏ = 1（對任何 k），永遠得不到 5。
- (d) 底數 40 ✔、真數 1 > 0 ✔ → 合法。40⁰ = 1 → 值 = 0。
- 檢核：改寫成指數式核對 —— 3⁴ = 81 ✔；40⁰ = 1 ✔
- **文件答案：(a) 4　(b) 違反特徵②　(c) 違反特徵①　(d) 0 — 一致。**

2．（a）log 4 + log 25　（b）log₂8 + log₂4

- (a) 運算律一：log(4 × 25) = log 100。10² = 100 → 值 = 2。
- (b) log₂(8 × 4) = log₂32。2⁵ = 32 → 值 = 5。
- 檢核 (b) 另解：log₂8 = 3、log₂4 = 2，3 + 2 = 5 ✔ 兩法一致。
- 檢核 (a) 另解：log 4 = 2log 2 ≈ 0.602、log 25 = 2log 5 ≈ 1.398，和 ≈ 2.000 ✔
- **文件答案：(a) 2　(b) 5 — 一致。**

3．（a）設 log2 = a、log3 = b，用 a、b 表示 log 12。（b）求 (log₂9)(log₃2)。

- (a) 12 = 4 × 3 = 2² × 3。
  log 12 = log 4 + log 3（律一）= 2log 2 + log 3（律三）= 2a + b。
- 檢核 (a)：log 2 ≈ 0.30103、log 3 ≈ 0.47712 → 2a + b ≈ 0.60206 + 0.47712 = 1.07918；
  直接查 log 12 ≈ 1.07918 ✔ 完全吻合。
- (b) 換底至以 10 為底：log₂9 = log9 / log2；log₃2 = log2 / log3。
  乘積 = (log9 / log2) × (log2 / log3) = log9 / log3 = 2log3 / log3 = 2。
- 檢核 (b)：log₂9 ≈ 0.95424/0.30103 ≈ 3.1699；log₃2 ≈ 0.30103/0.47712 ≈ 0.63093；
  乘積 ≈ 3.1699 × 0.63093 ≈ 2.0000 ✔
- **文件答案：(a) 2a + b　(b) 2 — 一致。**

4．解方程 log(x+3) + log x = 1。

- 合併：log[x(x+3)] = 1 → x² + 3x = 10¹ = 10 → x² + 3x − 10 = 0 → (x+5)(x−2) = 0
  → x = −5 或 x = 2。
- 驗真數：x = 2 → 真數 x+3 = 5 > 0、x = 2 > 0 → 兩者合格，保留。
  x = −5 → 真數 x+3 = −2 < 0、x = −5 < 0 → 違反特徵②，捨棄。
- 檢核：log(2+3) + log 2 = log 5 + log 2 = log 10 = 1 ✔ 與原方程右邊相同。
- **文件答案：x = 2 — 一致。**

5．解方程 4^(x+4) − 2 × 2^(x+4) = −1。

- 同底：4 = 2²，故 4^(x+4) = 2^(2(x+4)) = [2^(x+4)]²。
- 換元 t = 2^(x+4)：t² − 2t = −1 → t² − 2t + 1 = 0 → (t−1)² = 0 → t = 1（重根）。
- 代回：2^(x+4) = 1 = 2⁰ → x + 4 = 0 → x = −4。
- 檢核：x = −4 → 4^0 − 2 × 2^0 = 1 − 2 = −1 ✔ 與右邊相同。
- 唯一性：(t−1)² = 0 只有一個重根，且 2^(x+4) = 1 只有一解，故 x = −4 是唯一解。
- **文件答案：x = −4 — 一致。**

6．（a）求 log(5/9) − log(3/14) + log(27/7)。（b）把 log(3/14) 改成 log(3/7) 之後的值。

- (a) 合併：真數 = (5/9) ÷ (3/14) × (27/7) = (5/9) × (14/3) × (27/7)。
  分子 5 × 14 × 27 = 1890；分母 9 × 3 × 7 = 189；1890 ÷ 189 = 10。
  故原式 = log 10 = 1。
- 檢核 (a) 逐項數值：log(5/9) ≈ log 0.5556 ≈ −0.25527；log(3/14) ≈ log 0.21429 ≈ −0.66901；
  log(27/7) ≈ log 3.85714 ≈ 0.58637。
  −0.25527 − (−0.66901) + 0.58637 = 1.00011 ≈ 1 ✔（誤差來自四捨五入）
- (b) 真數 = (5/9) × (7/3) × (27/7)。分子 5 × 7 × 27 = 945；分母 9 × 3 × 7 = 189；
  945 ÷ 189 = 5。故值 = log 5 ≈ 0.69897。
- 判斷方向核對：3/14 → 3/7 是原值的 2 倍；該項是被減項（即除數），
  除數乘 2 → 商除以 2 → 真數由 10 變 5 ✔ 與計算相符。
- 檢核 (b)：log 5 = log(10/2) = 1 − log 2 ≈ 1 − 0.30103 = 0.69897 ✔
- **文件答案：(a) 1　(b) log 5（約 0.699）— 一致。**

## 講義範例

範例A．（a）比較 6³ 與 3⁶。（b）比較 2³² 與 4³¹。

- (a) 6³ = 216；3⁶ = 729。729 > 216 → 3⁶ 較大。
- (b) 4³¹ = (2²)³¹ = 2⁶²。同底比指數：62 > 32 → 4³¹ 較大。
- 檢核 (b) 小數驗證同一做法：4² = (2²)² = 2⁴ = 16，與直接算 4² = 16 相同，
  可見 (aᵐ)ⁿ = a^(mn) 沒有用錯 ✔
- **文件答案：(a) 3⁶ 較大　(b) 4³¹ 較大 — 一致。**

範例B．（a）log₂8　（b）log₂₅1　（c）log₄256 − log₄4

- (a) 2³ = 8 → 3。
- (b) 25⁰ = 1 → 0。
- (c) 4⁴ = 256 → log₄256 = 4；4¹ = 4 → log₄4 = 1；4 − 1 = 3。
- 檢核 (c) 另解：log₄256 − log₄4 = log₄(256/4) = log₄64，而 4³ = 64 → 3 ✔ 兩法一致。
- **文件答案：(a) 3　(b) 0　(c) 3 — 一致。**

範例C．（a）以 a = log2、b = log3 表示 log15。（b）(log₃8)(log₈3)。（c）log32 / log16。

- (a) 15 = 30 ÷ 2 = (3 × 10) ÷ 2。
  log 15 = log 30 − log 2 = (log 3 + log 10) − log 2 = b + 1 − a。
- 檢核 (a)：b + 1 − a ≈ 0.47712 + 1 − 0.30103 = 1.17609；查 log 15 ≈ 1.17609 ✔
- (b) log₃8 = log8/log3；log₈3 = log3/log8；乘積 = 1。
- 檢核 (b)：log₃8 ≈ 0.90309/0.47712 ≈ 1.89279；log₈3 ≈ 0.47712/0.90309 ≈ 0.52832；
  乘積 ≈ 1.00000 ✔（一般式：logₐb × log_b a = 1）
- (c) log 32 = log 2⁵ = 5log2；log 16 = log 2⁴ = 4log2；相除 = 5/4。
- 檢核 (c)：log32 ≈ 1.50515、log16 ≈ 1.20412；1.50515 ÷ 1.20412 = 1.25 = 5/4 ✔
- **文件答案：(a) b + 1 − a　(b) 1　(c) 5/4 — 一致。**

範例D．解方程 log(x−3) + log x = 1。

- 合併：log[x(x−3)] = 1 → x² − 3x = 10 → x² − 3x − 10 = 0 → (x−5)(x+2) = 0
  → x = 5 或 x = −2。
- 驗真數：x = 5 → x−3 = 2 > 0、x = 5 > 0 ✔ 保留。
  x = −2 → x−3 = −5 < 0 ✘ 捨棄。
- 檢核：log(5−3) + log 5 = log 2 + log 5 = log 10 = 1 ✔
- **文件答案：x = 5 — 一致。**

## 驗算結論

練習 6 題（合共 11 個小問）＋ 講義 4 個範例（合共 10 個小問），全部重算一次，
與文件所載答案 **100% 一致**（QB-V2）。凡有兩種解法的題目（先合併再求值 vs 分別求值再運算、
換底至 10 為底 vs 用 logₐb × log_b a = 1），兩種解法都各算一次並互相對照，全部吻合。
另外對所有含符號的答案（2a + b、b + 1 − a、log 5）都代入常用對數近似值
（log2 ≈ 0.30103、log3 ≈ 0.47712）做過數值驗證。

數字挑選原則（依 design-checklist.md §B「計算障礙：不要讓答案不乾淨」）：

- **定義求值型**（第 1、2 題與範例B）：真數一律取底數的整次方（81 = 3⁴、100 = 10²、
  32 = 2⁵、256 = 4⁴），令答案是整數，不必用計算機。
- **運算律型**（第 3、6 題與範例C）：拆解目標都選擇能被已知量整除的組合
  （12 = 2²×3、15 = 3×10÷2）；第 6 題三個真數刻意配成 1890/189 = 10，
  合併後剛好是 10 的整次方，令答案是整數 1。
- **方程型**（第 4 題與範例D）：二次方程都設計成可因式分解且有整數根，
  並且**一定有一個根會被真數條件淘汰**（第 4 題 x = −5、範例D x = −2）
  ——這是刻意的，驗真數這一步必須真的用得上，否則學生不會養成習慣。
- **指數方程**（第 5 題）：換元後得完全平方 (t−1)² = 0，t = 1 = 2⁰，
  指數方程只有一個整數解 x = −4，不會出現要捨根的干擾。
- 全部 21 個小問**只有第 6 題（b）的答案是無理數 log 5**，而且題目本身要求的是
  「先判斷方向再驗算」，答案保留 log 5 的形式即可，不必化成小數。
