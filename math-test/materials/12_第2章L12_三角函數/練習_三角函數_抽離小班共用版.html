一、練習A（★☆☆）
第 1 題左邊的圖已經畫好、數字也標好了，右邊那欄留空——把「對邊是哪一條」寫出來，再寫算式。第 2 題下方是那張手順卡的精簡版（只留四個動作，易錯點要自己回想）。
1．直角 \(△ABC\) 中 \(∠C = 90^{\circ}\)，\(AC = 6\)、\(BC = 8\)。（1）求 \(AB\)。　（2）求 \(\sin A\)、\(\cos A\)、\(\tan A\)。　（3）求 \(\sin B\)，並說明它為什麼等於 \(\cos A\)。
圖已經給你（左欄）把右欄填完
看 ∠A：對邊是 ＿＿＿、鄰邊是 ＿＿＿、斜邊是 ＿＿＿。先求斜邊：\(AB = \sqrt{AC^2 + BC^2}\) ＝ ＿＿＿。然後 \(\sin A\) ＝ ＿＿＿、\(\cos A\) ＝ ＿＿＿、\(\tan A\) ＝ ＿＿＿（三個都要約到最簡）。
改看 ∠B：對邊是 ＿＿＿、鄰邊是 ＿＿＿、斜邊是 ＿＿＿。\(\sin B\) ＝ ＿＿＿。最後一句：\(\sin B\) 之所以等於 \(\cos A\)，是因為 ＿＿＿＿＿＿＿＿＿＿。
▍第 1 題用卡一・六個三角比　\(\sin A = \frac{\text{對邊}}{\text{斜邊}}\)　\(\cos A = \frac{\text{鄰邊}}{\text{斜邊}}\)　\(\tan A = \frac{\text{對邊}}{\text{鄰邊}}\)　（畢氏定理：\(a^2 + b^2 = c^2\)）
▍(3) 不要重新由頭數一次。先看 ∠B 的對邊是哪一條，再對照 ∠A 的鄰邊是哪一條——你會發現是同一條。
2．（a）求 \(\cos 75^{\circ}\) 的值。　（b）求 \(\tan 15^{\circ}\) 的值（分母不可以留根號）。　（c）求 \(\sin 72^{\circ} \cos 42^{\circ} - \cos 72^{\circ} \sin 42^{\circ}\) 的值。
▍第 2 題的手順卡（精簡版：只留動作）
1. 把角拆成兩個特殊角的和或差
2. 翻卡三，揀出對應那一條公式
3. 四個特殊角的值逐個代進去
4. 通分、化簡；tan 的結果要有理化
▍第 2 題用卡三・和角差角　\(\sin (α \pm β) = \sin α \cos β \pm \cos α \sin β\)　\(\cos (α \pm β) = \cos α \cos β \mp \sin α \sin β\)　\(\tan (α \pm β) = \frac{\tan α \pm \tan β}{1 \mp \tan α \tan β}\)　特殊角：\(\sin 30^{\circ} = \frac{1}{2}\)、\(\cos 30^{\circ} = \frac{\sqrt{3}}{2}\)、\(\tan 30^{\circ} = \frac{\sqrt{3}}{3}\)、\(\sin 45^{\circ} = \cos 45^{\circ} = \frac{\sqrt{2}}{2}\)、\(\tan 45^{\circ} = 1\)、\(\sin 60^{\circ} = \frac{\sqrt{3}}{2}\)、\(\cos 60^{\circ} = \frac{1}{2}\)、\(\tan 60^{\circ} = \sqrt{3}\)
▍(a) \(75^{\circ} = 45^{\circ} + 30^{\circ}\)（或 \(30^{\circ} + 45^{\circ}\)，兩種拆法答案一樣）。▍(b) \(15^{\circ} = 45^{\circ} - 30^{\circ}\)；算到 \(\frac{\sqrt{3} - 1}{\sqrt{3} + 1}\) 之後還未完，要上下同乘 \(\sqrt{3} - 1\) 把分母的根號消掉。▍(c) 這一題是反方向用：先認出式子的形狀對應哪一條公式，再讀出括號裡應該是加還是減。

參考答案與詳解（教師用）
1．答案：（1）\(AB = 10\)　（2）\(\sin A = \frac{4}{5}\)、\(\cos A = \frac{3}{5}\)、\(\tan A = \frac{4}{3}\)　（3）\(\sin B = \frac{3}{5}\)，因為 ∠B 的對邊就是 ∠A 的鄰邊（兩銳角互餘）
【考點】直角三角形的六個三角比（卡一）。考點是「對邊／鄰邊由你看的角決定」，同一個三角形換一個角，三條邊的身份就對調。
【公式／定理】\(\sin A = \frac{\text{對邊}}{\text{斜邊}}\)、\(\cos A = \frac{\text{鄰邊}}{\text{斜邊}}\)、\(\tan A = \frac{\text{對邊}}{\text{鄰邊}}\)；畢氏定理 \(a^2 + b^2 = c^2\)
【詳細步驟】
　（1）小問 (1)：\(∠C = 90^{\circ}\) 所以 AB 是斜邊。\(AB = \sqrt{AC^2 + BC^2} = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10\)。（這是 6-8-10 三角形，即 3-4-5 的兩倍。）
　（2）小問 (2)：圈出 ∠A。∠A 在左上角，它對面那一條是底邊 \(BC = 8\)（對邊）；夾着它的另一條非斜邊是 \(AC = 6\)（鄰邊）；斜邊是 \(AB = 10\)。
　（3）小問 (2)：代進卡一。\(\sin A = \frac{8}{10} = \frac{4}{5}\)、\(\cos A = \frac{6}{10} = \frac{3}{5}\)、\(\tan A = \frac{8}{6} = \frac{4}{3}\)。三個都要約到最簡。
　（4）小問 (2) 檢查：\(\sin ^2 A + \cos ^2 A = \frac{16}{25} + \frac{9}{25} = \frac{25}{25} = 1\) ✔
　（5）小問 (3)：改圈 ∠B。∠B 在右下角，它對面那一條是 \(AC = 6\)（對邊），斜邊仍然是 10，所以 \(\sin B = \frac{6}{10} = \frac{3}{5}\)。
　（6）小問 (3)：\(\sin B = \cos A\) 的理由——∠B 的對邊（AC）剛好就是 ∠A 的鄰邊（AC），是同一條邊；而兩者的斜邊也是同一條。兩個分數的分子分母完全相同，所以相等。背後的原因是 \(∠A + ∠B = 90^{\circ}\)，兩個銳角互餘。
【易錯點提示】①把 \(\sin B\) 寫成 \(\frac{8}{10}\)：那是把「B 旁邊那條邊」當成對邊。對邊是「角對面那一條」，∠B 對面的是 AC ＝ 6。②忘記約簡，答 \(\frac{8}{10}\)——不算錯但會被扣分，養成算完就約的習慣。③(3) 只答「因為互餘」而沒有指出「是同一條邊」：本題問的是為什麼，要講得出哪兩條邊重合。
2．答案：（a）\(\frac{\sqrt{6} - \sqrt{2}}{4}\)　（b）\(2 - \sqrt{3}\)　（c）\(\frac{1}{2}\)
【考點】和角差角公式（卡三）＋手順卡四步。(a)(b) 是正方向用（拆角再代值），(c) 是反方向用（由形狀認出公式）。
【公式／定理】\(\cos (α+β) = \cos α \cos β - \sin α \sin β\)；\(\tan (α-β) = \frac{\tan α - \tan β}{1 + \tan α \tan β}\)；\(\sin (α-β) = \sin α \cos β - \cos α \sin β\)
【詳細步驟】
　（1）小問 (a) 第一步：\(75^{\circ} = 45^{\circ} + 30^{\circ}\)。第二步：求 cos、而且是和，所以中間用減號（括號加、中間減）。
　（2）小問 (a) 第三、四步：\(\cos 75^{\circ} = \cos 45^{\circ} \cos 30^{\circ} - \sin 45^{\circ} \sin 30^{\circ} = \frac{\sqrt{2}}{2} \times \frac{\sqrt{3}}{2} - \frac{\sqrt{2}}{2} \times \frac{1}{2} = \frac{\sqrt{6}}{4} - \frac{\sqrt{2}}{4} = \frac{\sqrt{6} - \sqrt{2}}{4}\)。
　（3）小問 (a) 檢查：\(≈ \frac{2.449 - 1.414}{4} ≈ 0.259\)。75° 是第一象限的角，cos 應該是正而且小於 1 ✔
　（4）小問 (b) 第一、二步：\(15^{\circ} = 45^{\circ} - 30^{\circ}\)，求 tan、而且是差，所以分子用減、分母用加。
　（5）小問 (b) 第三步：\(\tan 15^{\circ} = \frac{\tan 45^{\circ} - \tan 30^{\circ}}{1 + \tan 45^{\circ} \tan 30^{\circ}} = \frac{1 - \frac{\sqrt{3}}{3}}{1 + 1 \times \frac{\sqrt{3}}{3}}\)。上下同乘 3 清走小分數：\(= \frac{3 - \sqrt{3}}{3 + \sqrt{3}}\)。
　（6）小問 (b) 第四步（有理化）：上下同乘 \(3 - \sqrt{3}\)——\(= \frac{(3 - \sqrt{3})^2}{(3 + \sqrt{3})(3 - \sqrt{3})} = \frac{9 - 6\sqrt{3} + 3}{9 - 3} = \frac{12 - 6\sqrt{3}}{6} = 2 - \sqrt{3}\)。
　（7）小問 (b) 檢查：\(\sqrt{3} ≈ 1.732\)，所以答案 \(≈ 0.268\)。15° 很小，tan 應該接近 0 而且是正數 ✔
　（8）小問 (c)：式子的形狀是「\(\sin A \cos B - \cos A \sin B\)」，對照卡三就是 \(\sin (A - B)\)（中間減 → 括號減）。所以 \(= \sin (72^{\circ} - 42^{\circ}) = \sin 30^{\circ} = \frac{1}{2}\)。
【易錯點提示】①(a) 把中間的符號寫成加號：那是 sin 的規則，cos 相反。寫錯的話答案變成 \(\frac{\sqrt{6} + \sqrt{2}}{4} ≈ 0.966\)，而 \(\cos 75^{\circ}\) 明明應該很接近 0（75° 接近 90°）。②(b) 算到 \(\frac{3 - \sqrt{3}}{3 + \sqrt{3}}\) 就交卷——分母有根號就是未完成，一定要有理化。③(c) 誤以為要逐個查 72°、42° 的值：這一題根本不需要，而且表上也沒有這兩個角。見到「兩個乘積相加減」就先想反方向。④(c) 把括號裡寫成 \(72^{\circ} + 42^{\circ}\)：中間是減號，括號裡就是減號（sin 的規則是一樣）。
3．答案：（a）第二象限　（b）\(\sin θ = \frac{4}{5}\)、\(\tan θ = -\frac{4}{3}\)
【考點】象限符號盤（卡二）。(a) 是「兩個條件取交集」，(b) 是「先求大小、再由象限定正負」——本課最常漏的就是後面那一步。
【公式／定理】一全正、二 sin 正、三 tan 正、四 cos 正；\(\sin ^2 θ + \cos ^2 θ = 1\)；\(\tan θ = \frac{\sin θ}{\cos θ}\)
【詳細步驟】
　（1）小問 (a)：\(\sin θ \gt 0\) → 翻卡二，sin 是正的象限是第一與第二。
　（2）小問 (a)：\(\tan θ \lt 0\) → tan 是正的象限是第一與第三，所以 tan 是負的象限是第二與第四。
　（3）小問 (a)：取交集——「一或二」與「二或四」共同的只有第二象限。
　（4）小問 (b) 第一步（求大小）：\(\sin ^2 θ = 1 - \cos ^2 θ = 1 - (-\frac{3}{5})^2 = 1 - \frac{9}{25} = \frac{16}{25}\)，所以大小是 \(\frac{4}{5}\)。
　（5）小問 (b) 第二步（定正負）：\(θ ∈ (\frac{π}{2}, π)\) 就是第二象限，卡二說第二象限只有 sin 是正，所以 \(\sin θ = \frac{4}{5}\)（取正）。
　（6）小問 (b) 第三步：\(\tan θ = \frac{\sin θ}{\cos θ} = \frac{4}{5} ÷ (-\frac{3}{5}) = \frac{4}{5} \times (-\frac{5}{3}) = -\frac{4}{3}\)。
　（7）小問 (b) 檢查：算出 sin 正、cos 負、tan 負，完全對得上卡二的「第二象限只有 sin 正」✔
【易錯點提示】①(a) 只看其中一個條件就作答（答「一或二」）：題目給了兩個條件就一定要取交集，這是本題的全部考點。②(b) 開方之後直接寫 \(\sin θ = ±\frac{4}{5}\) 交卷：題目已經給了象限，答案是唯一的，不可以留 \(±\)。③(b) 忘記定正負、寫成 \(-\frac{4}{5}\)：大小對、正負反，而且會連累 tan 也錯。對策是算出大小之後先在旁邊寫「第二象限」四個字。
4．答案：（a）\(\sin 2θ = \frac{24}{25}\)　（b）\(\sin 2α = 0\)
【考點】二倍角（卡四）。(a) 要先補 cos 並用卡二定正負；(b) 考的是認不認得 \((\sin α + \cos α)^2 = 1 + \sin 2α\) 這個變形。
【公式／定理】\(\sin 2θ = 2 \sin θ \cos θ\)；\((\sin α + \cos α)^2 = 1 + \sin 2α\)；\(\sin ^2 θ + \cos ^2 θ = 1\)
【詳細步驟】
　（1）小問 (a) 第一步：\(\sin 2θ\) 需要 \(\cos θ\)，題目沒有給，要自己補。\(\cos ^2 θ = 1 - (-\frac{4}{5})^2 = 1 - \frac{16}{25} = \frac{9}{25}\)，大小是 \(\frac{3}{5}\)。
　（2）小問 (a) 第二步（定正負）：θ 在第三象限，卡二說第三象限只有 tan 正，所以 cos 是負的：\(\cos θ = -\frac{3}{5}\)。
　（3）小問 (a) 第三步：\(\sin 2θ = 2 \times (-\frac{4}{5}) \times (-\frac{3}{5}) = \frac{24}{25}\)。
　（4）小問 (a) 檢查：兩個負數相乘得正，所以 \(\sin 2θ\) 是正數 ✔ 這一題的答案是正的，不要因為題目給的 sin 是負數就以為答案一定是負數。
　（5）小問 (b)：認出這是那個變形。兩邊平方：\((\sin α + \cos α)^2 = 1^2 = 1\)。
　（6）小問 (b)：而左邊展開 \(= \sin ^2 α + 2 \sin α \cos α + \cos ^2 α = 1 + \sin 2α\)。所以 \(1 + \sin 2α = 1\)，得 \(\sin 2α = 0\)。
【易錯點提示】①(a) 跳過第二步、直接用 \(\cos θ = \frac{3}{5}\)：答案會變成 \(-\frac{24}{25}\)，大小對、正負完全相反。凡是「由一個三角值求另一個」，開方之後立刻寫下象限。②(a) 以為「sin 是負 → 答案是負」：\(\sin 2θ\) 是 \(2θ\) 這個角的 sin，跟 θ 的正負沒有直接關係。③(b) 不認得變形，去解聯立方程求 sin 與 cos 各自的值：做得出但長很多倍，而且會多出一組要排除的解。
5．答案：（a）\(\sin 105^{\circ} = \frac{\sqrt{6} + \sqrt{2}}{4}\)、\(\cos 105^{\circ} = \frac{\sqrt{2} - \sqrt{6}}{4}\)　（b）\(\sin 210^{\circ} = -\frac{1}{2}\)
【考點】同一題內換兩張卡：(a) 用卡三（和角差角）求出兩個值，(b) 用卡四（二倍角）把它們接起來——\(210^{\circ} = 2 \times 105^{\circ}\)。
【公式／定理】\(\sin (α+β) = \sin α \cos β + \cos α \sin β\)；\(\cos (α+β) = \cos α \cos β - \sin α \sin β\)；\(\sin 2α = 2 \sin α \cos α\)
【詳細步驟】
　（1）小問 (a)：\(105^{\circ} = 60^{\circ} + 45^{\circ}\)。\(\sin 105^{\circ} = \sin 60^{\circ} \cos 45^{\circ} + \cos 60^{\circ} \sin 45^{\circ} = \frac{\sqrt{3}}{2} \times \frac{\sqrt{2}}{2} + \frac{1}{2} \times \frac{\sqrt{2}}{2} = \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4} = \frac{\sqrt{6} + \sqrt{2}}{4}\)。
　（2）小問 (a)：\(\cos 105^{\circ} = \cos 60^{\circ} \cos 45^{\circ} - \sin 60^{\circ} \sin 45^{\circ} = \frac{1}{2} \times \frac{\sqrt{2}}{2} - \frac{\sqrt{3}}{2} \times \frac{\sqrt{2}}{2} = \frac{\sqrt{2}}{4} - \frac{\sqrt{6}}{4} = \frac{\sqrt{2} - \sqrt{6}}{4}\)。留意 cos 中間是減號（括號加、中間減）。
　（3）小問 (a) 檢查：105° 在第二象限 → sin 應為正、cos 應為負。\(\sqrt{6} \gt \sqrt{2}\) 所以 \(\sin 105^{\circ}\) 正、\(\cos 105^{\circ}\) 負 ✔
　（4）小問 (b)：認出 \(210^{\circ} = 2 \times 105^{\circ}\)，所以翻卡四：\(\sin 210^{\circ} = 2 \sin 105^{\circ} \cos 105^{\circ}\)。
　（5）小問 (b)：代入 (a) 的兩個結果——\(= 2 \times \frac{\sqrt{6} + \sqrt{2}}{4} \times \frac{\sqrt{2} - \sqrt{6}}{4} = \frac{2(\sqrt{6} + \sqrt{2})(\sqrt{2} - \sqrt{6})}{16}\)。
　（6）小問 (b)：分子的乘積用平方差來算會更快——\((\sqrt{6} + \sqrt{2})(\sqrt{2} - \sqrt{6}) = -(\sqrt{6} + \sqrt{2})(\sqrt{6} - \sqrt{2}) = -(6 - 2) = -4\)。所以 \(\sin 210^{\circ} = \frac{2 \times (-4)}{16} = -\frac{8}{16} = -\frac{1}{2}\)。
　（7）小問 (b) 另一個驗證方法：\(210^{\circ} = 180^{\circ} + 30^{\circ}\) 在第三象限，卡二說第三象限的 sin 是負的，而它與 30° 的參考角相同，所以 \(\sin 210^{\circ} = -\sin 30^{\circ} = -\frac{1}{2}\) ✔ 兩條路相同。
【易錯點提示】①(b) 看不出 \(210^{\circ} = 2 \times 105^{\circ}\)，於是重新拆 \(210^{\circ} = 180^{\circ} + 30^{\circ}\) 從頭算：答案一樣對，但題目明講「利用 (a) 的兩個結果」，考的就是認不認得二倍角這一步。②(a) cos 的中間符號寫成加號 → \(\cos 105^{\circ}\) 變成正數，與「105° 在第二象限」矛盾。做完 cos 順手用卡二檢查正負。③(b) 分子硬乘四項而漏了其中一項：用平方差 \((x + y)(x - y) = x^2 - y^2\) 只需兩步，但要先把 \((\sqrt{2} - \sqrt{6})\) 提一個負號變成 \(-(\sqrt{6} - \sqrt{2})\)。
6．答案：（a）\(\sin 2α = -\frac{24}{25}\)、\(\cos 2α = -\frac{7}{25}\)、\(\tan 2α = \frac{24}{7}\)　（b）\(x = nπ + (-1)^{(n+1)} \frac{π}{6}\)（n 為任意整數）
【考點】同一題內換三張卡：(a) 卡二定 \(\sin α\) 的正負 → 卡四求三個二倍角值；(b) 卡五求通解。(a) 最後還要留意 \(2α\) 落在哪個象限來覆核。
【公式／定理】\(\sin 2α = 2 \sin α \cos α\)；\(\cos 2α = 2 \cos ^2 α - 1\)；\(\tan 2α = \frac{\sin 2α}{\cos 2α}\)；\(\sin x = k → x = nπ + (-1)^n \arcsin k\)
【詳細步驟】
　（1）小問 (a) 第一步：\(\sin ^2 α = 1 - (\frac{3}{5})^2 = 1 - \frac{9}{25} = \frac{16}{25}\)，大小是 \(\frac{4}{5}\)。
　（2）小問 (a) 第二步（卡二）：α 在第四象限，只有 cos 是正，所以 sin 是負：\(\sin α = -\frac{4}{5}\)。
　（3）小問 (a) 第三步：\(\sin 2α = 2 \times (-\frac{4}{5}) \times \frac{3}{5} = -\frac{24}{25}\)。
　（4）小問 (a) 第四步：\(\cos 2α\) 揀「給 cos 用」那一條，就完全不必用到剛才那個負數——\(\cos 2α = 2 \cos ^2 α - 1 = 2 \times \frac{9}{25} - 1 = \frac{18}{25} - \frac{25}{25} = -\frac{7}{25}\)。
　（5）小問 (a) 第五步：\(\tan 2α = \frac{\sin 2α}{\cos 2α} = (-\frac{24}{25}) ÷ (-\frac{7}{25}) = \frac{24}{7}\)。
　（6）小問 (a) 檢查：\(\sin 2α\) 負、\(\cos 2α\) 負 → \(2α\) 在第三象限；卡二說第三象限的 tan 是正 —— 算出來的 \(\frac{24}{7}\) 確實是正數 ✔
　（7）小問 (b) 第一步：是 sin，翻卡五的第一條 \(x = nπ + (-1)^n \arcsin k\)。
　（8）小問 (b) 第二步：\(\arcsin (-\frac{1}{2}) = -\frac{π}{6}\)（因為 \(\sin \frac{π}{6} = \frac{1}{2}\)，取負角）。代入：\(x = nπ + (-1)^n \times (-\frac{π}{6})\)。
　（9）小問 (b) 第三步：把負號併進指數——\((-1)^n \times (-1) = (-1)^{(n+1)}\)，所以 \(x = nπ + (-1)^{(n+1)} \frac{π}{6}\)。
　（10）小問 (b) 檢查：取 \(n = 1\) 得 \(x = π + \frac{π}{6} = \frac{7π}{6}\)，即 210°；\(\sin 210^{\circ} = -\frac{1}{2}\) ✔ 取 \(n = 0\) 得 \(x = -\frac{π}{6}\)，即 −30°，\(\sin (-30^{\circ}) = -\frac{1}{2}\) ✔
【易錯點提示】①(a) 忘記第二步、把 sin 寫成正：三個答案的正負會全部連鎖出錯。②(a) \(\cos 2α\) 用 \(\cos ^2 α - \sin ^2 α\) 也對，但要先處理那個負數；揀「給 cos 用」那一條可以完全避開，這是揀公式的價值。③(a) 最後不做象限覆核：本題的三個答案彼此有關係，sin 負、cos 負卻算出 tan 負的話，一定是中間某一步錯了。④(b) 停在 \(x = nπ + (-1)^n(-\frac{π}{6})\) 就交卷：答案本身沒有錯，但選擇題的選項多數已經把負號併好，找不到自己的形狀時要先搬負號再看一次。⑤(b) 誤用 cos 的公式寫成 \(2nπ ±\)：sin 配 \((-1)^n\)、cos 才配 \(±\)。
