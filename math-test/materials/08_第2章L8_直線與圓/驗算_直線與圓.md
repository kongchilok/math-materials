**本課共用的四條公式（下面每題的驗算都回到這四條）**

| 量 | 公式 | 說明 |
|---|---|---|
| 點 P(x₀, y₀) 到 x 軸／y 軸的距離 | \|y₀\| ／ \|x₀\| | 到 x 軸看 y、到 y 軸看 x（本課最高頻的錯就是這裡對調） |
| A(x₁,y₁)、B(x₂,y₂) 兩點距離 | √((x₂−x₁)²+(y₂−y₁)²) | 差先算再平方，平方後必為正 |
| AB 中點 | ((x₁+x₂)/2, (y₁+y₂)/2) | 兩坐標各自取平均 |
| 直線 ax+by+c=0 的斜率（b≠0） | −a/b | 或化成 y=mx+k 直接讀 m |
| 點 P(x₀,y₀) 到直線 ax+by+c=0 的距離 | \|ax₀+by₀+c\|/√(a²+b²) | 判斷直線與圓位置關係的第二條路，用來檢核判別式的結果 |

## 講義範例

### 範例A・點的基本量（A(−2, 3)、B(4, −5)）

- (a) A 到 x 軸的距離 = |y| = |3| = 3；A 到 y 軸的距離 = |x| = |−2| = 2。
  幾何檢核：由 A 垂直落到 x 軸的垂足是 (−2, 0)，兩點距離 = √(0+3²) = 3 ✔；
  垂直落到 y 軸的垂足是 (0, 3)，距離 = √((−2)²+0) = 2 ✔。
- (b) |AB| = √((4−(−2))² + (−5−3)²) = √(6² + (−8)²) = √(36+64) = √100 = 10。
  檢核：6−8−10 是 3-4-5 的兩倍，直角三角形三邊 6、8、10 ✔。
- (c) 中點 M = ((−2+4)/2, (3+(−5))/2) = (2/2, −2/2) = (1, −1)。
  檢核：|AM| = √((1−(−2))² + (−1−3)²) = √(9+16) = 5 = |AB|/2 ✔；
  |MB| = √((4−1)² + (−5−(−1))²) = √(9+16) = 5 ✔（兩段相等，M 確在中點）。
- **文件答案：(a) 3 與 2　(b) 10　(c) (1, −1) — 一致。**

### 範例B・直線的斜率與截距（L: 2x + 3y − 6 = 0）

- 斜率：化成斜截式 3y = −2x + 6 → y = −(2/3)x + 2，斜率 m = −2/3。
  用公式檢核：m = −a/b = −2/3 ✔。
- y 截距：令 x = 0 → 3y − 6 = 0 → y = 2，即與 y 軸交於 (0, 2)。
- x 截距：令 y = 0 → 2x − 6 = 0 → x = 3，即與 x 軸交於 (3, 0)。
- 檢核：由 (3,0) 到 (0,2) 的斜率 = (2−0)/(0−3) = −2/3 ✔ 與上面相符。
- **文件答案：斜率 −2/3、y 截距 2（x 截距 3）— 一致。**

### 範例C・求直線方程

- (a) 過 P(−2, 3)、斜率 m = 2。點斜式：y − 3 = 2(x − (−2)) = 2(x + 2) → y = 2x + 7
  → 一般式 **2x − y + 7 = 0**。
  檢核：代 (−2, 3)：2(−2) − 3 + 7 = −4 − 3 + 7 = 0 ✔；斜率 = −a/b = −2/(−1) = 2 ✔。
- (b) 過 A(1, 3)、B(5, 1)。斜率 m = (1−3)/(5−1) = −2/4 = −1/2。
  點斜式：y − 3 = −(1/2)(x − 1) → 2y − 6 = −x + 1 → **x + 2y − 7 = 0**。
  檢核：代 A(1,3)：1 + 6 − 7 = 0 ✔；代 B(5,1)：5 + 2 − 7 = 0 ✔；
  斜率 = −1/2 ✔（與兩點算出的相同）。
- (c) 過 Q(4, 1) 且垂直於 (b) 之外的 L: 2x + 3y − 6 = 0（即範例B 那條）。
  L 的斜率 = −2/3，垂直線斜率 m′ 須滿足 (−2/3)·m′ = −1 → m′ = 3/2。
  點斜式：y − 1 = (3/2)(x − 4) → 2y − 2 = 3x − 12 → **3x − 2y − 10 = 0**。
  檢核：代 (4, 1)：12 − 2 − 10 = 0 ✔；斜率 = −3/(−2) = 3/2 ✔；
  兩斜率乘積 = (−2/3)(3/2) = −1 ✔（確為垂直）。
- **文件答案：(a) 2x−y+7=0　(b) x+2y−7=0　(c) 3x−2y−10=0 — 一致。**

### 範例D・圓方程

- (a) 圓心 C(2, −1)、半徑 3 → **(x−2)² + (y+1)² = 9**。
  檢核：圓心代進括號要變號（h=2 寫成 x−2；k=−1 寫成 y−(−1)=y+1）；
  取圓上一點 (5, −1)（圓心右移 3）：(5−2)² + (−1+1)² = 9 + 0 = 9 ✔。
- (b) 圓心 C(1, 2)、圓過 P(4, 6)。半徑 r = |CP| = √((4−1)² + (6−2)²) = √(9+16) = √25 = 5。
  → **(x−1)² + (y−2)² = 25**。
  檢核：代 P(4, 6)：(4−1)² + (6−2)² = 9 + 16 = 25 ✔。
- (c) 以 A(0, 3)、B(4, −1) 為直徑的兩端。
  圓心 = AB 中點 = ((0+4)/2, (3+(−1))/2) = (2, 1)。
  |AB| = √((4−0)² + (−1−3)²) = √(16+16) = √32 = 4√2，故 r = |AB|/2 = 2√2，r² = 8。
  → **(x−2)² + (y−1)² = 8**。
  檢核：代 A(0,3)：(0−2)² + (3−1)² = 4 + 4 = 8 ✔；代 B(4,−1)：(4−2)² + (−1−1)² = 4 + 4 = 8 ✔。
  （注意：標準式右邊要的是 r²＝8，不必先把 r 開成 2√2 再平方回去。）
- **文件答案：(a) (x−2)²+(y+1)²=9　(b) (x−1)²+(y−2)²=25　(c) (x−2)²+(y−1)²=8 — 一致。**

### 範例E・直線與圓的位置關係（圓 C: x² + y² = 10，圓心 O(0,0)，r = √10 ≈ 3.162）

判別式法與距離法兩條路都算一次，互相檢核。

- (a) L₁: x + y − 4 = 0。
  **判別式法**：y = 4 − x 代入 → x² + (4−x)² = 10 → x² + 16 − 8x + x² = 10
  → 2x² − 8x + 6 = 0 → x² − 4x + 3 = 0。Δ = (−4)² − 4·1·3 = 16 − 12 = 4 > 0 → **相交於兩點**。
  (x−1)(x−3) = 0 → x = 1 或 x = 3 → 交點 (1, 3)、(3, 1)。
  **距離法**：d = |0+0−4|/√(1²+1²) = 4/√2 = 2√2 ≈ 2.828 < √10 ≈ 3.162 ✔ 相交（兩法一致）。
  驗點：1² + 3² = 1 + 9 = 10 ✔；3² + 1² = 10 ✔（兩點都真的在圓上）。
- (b) L₂: x + 3y − 10 = 0。
  **判別式法**：x = 10 − 3y 代入 → (10−3y)² + y² = 10 → 100 − 60y + 9y² + y² = 10
  → 10y² − 60y + 90 = 0 → y² − 6y + 9 = 0。Δ = 36 − 36 = 0 → **相切（一個交點）**。
  (y−3)² = 0 → y = 3 → x = 10 − 9 = 1 → 切點 (1, 3)。
  **距離法**：d = |0+0−10|/√(1²+3²) = 10/√10 = √10 = r ✔ 相切（兩法一致）。
  驗點：1² + 3² = 10 ✔（切點在圓上）。
- (c) L₃: x + y − 6 = 0。
  **判別式法**：y = 6 − x 代入 → x² + (6−x)² = 10 → 2x² − 12x + 36 = 10
  → 2x² − 12x + 26 = 0 → x² − 6x + 13 = 0。Δ = 36 − 52 = −16 < 0 → **不相交（相離）**。
  **距離法**：d = |0+0−6|/√2 = 6/√2 = 3√2 ≈ 4.243 > √10 ≈ 3.162 ✔ 相離（兩法一致）。
- 三條線的橫向比對：L₁ 與 L₃ 平行（同為 x+y=k），只有常數項由 4 變 6，
  d 由 2.828 增到 4.243，跨過 r = 3.162，位置關係就由相交變相離——
  這正是講義左欄三張圖「直線在平移、圓不動」要看出的事。
- **文件答案：(a) 相交，交點 (1,3)、(3,1)　(b) 相切，切點 (1,3)　(c) 不相交 — 一致。**

## 練習題

1．已知 A(−4, 1)、B(2, 9)。（a）A 到 x 軸、y 軸的距離各是多少？（b）求 |AB|。（c）求 AB 的中點 M。

- (a) 到 x 軸的距離 = |y| = |1| = 1；到 y 軸的距離 = |x| = |−4| = 4。
  檢核：垂足分別是 (−4, 0) 與 (0, 1)，距離各為 1 與 4 ✔。
- (b) |AB| = √((2−(−4))² + (9−1)²) = √(6² + 8²) = √(36+64) = √100 = 10。
  檢核：6-8-10 直角三角形 ✔。
- (c) M = ((−4+2)/2, (1+9)/2) = (−2/2, 10/2) = (−1, 5)。
  檢核：|AM| = √((−1+4)² + (5−1)²) = √(9+16) = 5；|MB| = √((2+1)² + (9−5)²) = √(9+16) = 5；
  兩段相等且和為 10 ✔。
- **文件答案：(a) 1 與 4　(b) 10　(c) (−1, 5) — 一致。**

2．已知直線 L: 4x − 2y + 6 = 0。（a）求 L 的斜率。（b）求 L 的 y 截距。

- (a) 化斜截式：−2y = −4x − 6 → y = 2x + 3，斜率 m = 2。
  用公式檢核：m = −a/b = −4/(−2) = 2 ✔（兩個負號相消，別答成 −2）。
- (b) 令 x = 0 → −2y + 6 = 0 → y = 3，y 截距 = 3（交點 (0, 3)）。
  由斜截式 y = 2x + 3 直接讀常數項 3 ✔ 相符。
- 附帶檢核：x 截距（令 y=0）→ 4x + 6 = 0 → x = −3/2；
  由 (−3/2, 0) 到 (0, 3) 的斜率 = (3−0)/(0+3/2) = 3/(3/2) = 2 ✔。
- **文件答案：(a) 2　(b) 3 — 一致。**

3．求下列直線方程（答案寫成一般式 ax+by+c=0）：（a）過點 P(3, −2) 且斜率為 −1；（b）過點 A(−1, 2) 與 B(3, 10)。

- (a) 點斜式：y − (−2) = −1·(x − 3) → y + 2 = −x + 3 → **x + y − 1 = 0**。
  檢核：代 P(3, −2)：3 + (−2) − 1 = 0 ✔；斜率 = −a/b = −1/1 = −1 ✔。
- (b) 斜率 m = (10−2)/(3−(−1)) = 8/4 = 2。
  點斜式（用 A）：y − 2 = 2(x + 1) → y = 2x + 4 → **2x − y + 4 = 0**。
  檢核：代 A(−1, 2)：−2 − 2 + 4 = 0 ✔；代 B(3, 10)：6 − 10 + 4 = 0 ✔。
  換用 B 點列式檢核：y − 10 = 2(x − 3) → y = 2x + 4，同一條 ✔
  （代哪一點都得同一條，這是判斷自己有沒有做錯的好方法）。
- **文件答案：(a) x+y−1=0　(b) 2x−y+4=0 — 一致。**

4．求下列圓方程（答案寫成標準式）：（a）圓心 C(−2, 3)、半徑 4；（b）以 A(1, −2) 與 B(7, 6) 為直徑的兩端。

- (a) **(x+2)² + (y−3)² = 16**。
  檢核：h = −2 → x−(−2) = x+2；k = 3 → y−3；r² = 4² = 16 ✔。
  取圓上一點 (2, 3)（圓心右移 4）：(2+2)² + (3−3)² = 16 ✔。
- (b) 圓心 = AB 中點 = ((1+7)/2, (−2+6)/2) = (4, 2)。
  |AB| = √((7−1)² + (6−(−2))²) = √(6² + 8²) = √100 = 10 → r = 5，r² = 25。
  → **(x−4)² + (y−2)² = 25**。
  檢核：代 A(1, −2)：(1−4)² + (−2−2)² = 9 + 16 = 25 ✔；
  代 B(7, 6)：(7−4)² + (6−2)² = 9 + 16 = 25 ✔。
- **文件答案：(a) (x+2)²+(y−3)²=16　(b) (x−4)²+(y−2)²=25 — 一致。**

5．判斷直線 L: x − y + 4 = 0 與圓 C: (x−1)² + (y−2)² = 9 的位置關係，並求出交點（若有）。

- 圓心 C(1, 2)，r = 3。
- **判別式法**：y = x + 4 代入 → (x−1)² + (x+4−2)² = 9 → (x−1)² + (x+2)² = 9
  → x² − 2x + 1 + x² + 4x + 4 = 9 → 2x² + 2x + 5 = 9 → 2x² + 2x − 4 = 0 → x² + x − 2 = 0。
  Δ = 1² − 4·1·(−2) = 1 + 8 = 9 > 0 → **相交於兩點**。
  (x+2)(x−1) = 0 → x = −2 或 x = 1；代回 y = x + 4 → 交點 **(−2, 2)、(1, 5)**。
- **距離法**：d = |1 − 2 + 4|/√(1²+(−1)²) = 3/√2 = 3√2/2 ≈ 2.121 < 3 = r ✔ 相交（兩法一致）。
- 驗點：(−2−1)² + (2−2)² = 9 + 0 = 9 ✔（是圓的最左點）；
  (1−1)² + (5−2)² = 0 + 9 = 9 ✔（是圓的最上點）。兩點都真的在圓上，而且好畫。
- **文件答案：相交；交點 (−2, 2)、(1, 5) — 一致。**

6．已知直線 L₁: 2x + y − 5 = 0 與點 P(1, 4)。（a）求過 P 且垂直於 L₁ 的直線 L₂ 的方程。（b）判斷 L₂ 與圓 C: x² + y² = 5 的位置關係。

- (a) L₁ 的斜率 = −a/b = −2/1 = −2。垂直 ⇒ m₂ = −1/(−2) = 1/2。
  點斜式：y − 4 = (1/2)(x − 1) → 2y − 8 = x − 1 → **x − 2y + 7 = 0**。
  檢核：代 P(1, 4)：1 − 8 + 7 = 0 ✔；L₂ 斜率 = −1/(−2) = 1/2 ✔；
  兩斜率乘積 = (−2)·(1/2) = −1 ✔（確為垂直）。
  另註：P(1,4) 不在 L₁ 上（2+4−5 = 1 ≠ 0），本題不是求垂足，只是求過 P 的垂線。
- (b) 圓心 O(0, 0)，r = √5 ≈ 2.236。
  **距離法**：d = |0 − 0 + 7|/√(1² + (−2)²) = 7/√5 = 7√5/5 ≈ 3.130 > √5 ✔ → **相離（無交點）**。
  **判別式法檢核**：x = 2y − 7 代入 → (2y−7)² + y² = 5 → 4y² − 28y + 49 + y² = 5
  → 5y² − 28y + 44 = 0。Δ = (−28)² − 4·5·44 = 784 − 880 = −96 < 0 ✔ 無實根（兩法一致）。
- **文件答案：(a) x−2y+7=0　(b) 相離（沒有交點）— 一致。**

## 數字挑選原則（供日後出平行題參考）

1. **兩點距離一律取 3-4-5 或其倍數的坐標差**（本課用了 (6, 8)→10 三次、(3, 4)→5 一次），
   讓學生的注意力留在「先算差、再平方、最後開方」的程序上，不要被開不盡的根號分心。
2. **中點要落在整數格點**：坐標差取偶數即可（如 (−4,1)→(2,9) 的差是 (6,8)，中點 (−1,5)）。
   差為奇數會出現 .5，圖上不好標，學生也容易把 .5 抄掉。
3. **求直線方程的兩題斜率刻意不同號、不同型**（範例C 用 2 與 −1/2；練習 3 用 −1 與 2），
   避免學生用「答案好像都是 2」蒙混過去。
4. **圓方程的 r² 有意留一個開不盡的**（範例D(c) 的 r=2√2、r²=8），
   用來立「標準式右邊要的是 r²，不必把 r 開出來」這一點。
5. **直線與圓刻意排一組平行線**（範例E 的 L₁: x+y−4=0 與 L₃: x+y−6=0），
   只有常數項不同，讓「直線平移 → d 變大 → 跨過 r → 由相交變相離」在同一張圖語言裡看得見。
6. **相切的例子讓切點落在整數格點**（範例E(b) 切於 (1,3)），否則圖上畫不準、Δ=0 也看不出意義。
7. **每題都用兩條路互相檢核**：直線與圓用「判別式 vs 點到直線距離」，
   中點用「兩段長度相等」，直線方程用「兩個點分別代入」。
   單一路徑算對只是沒算錯，兩條路對得上才是真的對。
