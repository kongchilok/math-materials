參考答案與詳解（教師用）
1．答案：（a）到 x 軸 1、到 y 軸 4　（b）\(|AB|=10\)　（c）\(M(-1,5)\)
【考點】坐標平面上的三個基本量。到 x 軸的距離量的是上下高度（看 y），到 y 軸的距離量的是左右寬度（看 x）；兩點距離是把兩點補成直角三角形後的斜邊；中點是兩個坐標各自取平均。
【公式／定理】到 x 軸 \(=|y|\)、到 y 軸 \(=|x|\)；\(|AB|=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}\)；中點 \(=(\frac{x_1+x_2}{2},\frac{y_1+y_2}{2})\)。
【詳細步驟】
　（1）（a）\(A(-4,1)\)：到 x 軸的距離 \(=|1|=1\)；到 y 軸的距離 \(=|-4|=4\)。圖上檢核：由 A 往下垂到 x 軸只走 1 格，往右垂到 y 軸走 4 格 ✔
　（2）（b）水平差 \(=2-(-4)=6\)，垂直差 \(=9-1=8\)。\(|AB|=\sqrt{6^2+8^2}=\sqrt{36+64}=\sqrt{100}=10\)（又是 6-8-10 直角三角形）。
　（3）（c）\(M=(\frac{-4+2}{2},\frac{1+9}{2})=(\frac{-2}{2},\frac{10}{2})=(-1,5)\)。
　（4）檢核：\(|AM|=\sqrt{(-1+4)^2+(5-1)^2}=\sqrt{9+16}=5\)，\(|MB|=\sqrt{(2+1)^2+(9-5)^2}=\sqrt{9+16}=5\)，兩段相等且合共 10 ✔
【易錯點提示】① (a) 對調：到 x 軸用 y、到 y 軸用 x，不要反。② 距離抄成負數：\(|-4|=4\)，距離永遠是正的。③ (b) 只把坐標相減不平方，或平方後忘記開方。④ (c) 把中點寫成兩坐標相減除以 2——是相加取平均。
2．答案：（a）斜率 \(=2\)　（b）y 截距 \(=3\)
【考點】由一般式 \(ax+by+c=0\) 讀斜率有兩條路：化成斜截式 \(y=mx+k\) 直接讀，或用 \(m=-\frac{a}{b}\)。y 截距就是令 \(x=0\) 求出的 y。
【公式／定理】\(m=-\frac{a}{b}\)（\(b \ne 0\)）；斜截式 \(y=mx+k\) 中 \(k\) 即 y 截距；y 截距：令 \(x=0\)；x 截距：令 \(y=0\)。
【詳細步驟】
　（1）（a）化斜截式：\(4x-2y+6=0\) → \(-2y=-4x-6\) → \(y=2x+3\)，所以 \(m=2\)。
　（2）（a）公式檢核：\(m=-\frac{a}{b}=-\frac{4}{-2}=2\) ✔ 兩個負號相消，答案是正的。
　（3）（b）令 \(x=0\)：\(-2y+6=0\) → \(y=3\)，即交 y 軸於 \((0,3)\)，y 截距 = 3。由斜截式 \(y=2x+3\) 直接讀常數項也是 3 ✔
　（4）附帶檢核：令 \(y=0\) 得 \(4x+6=0\)，\(x=-\frac{3}{2}\)；由 \((-\frac{3}{2},0)\) 到 \((0,3)\) 的斜率 \(=\frac{3-0}{0+\frac{3}{2}}=2\) ✔
【易錯點提示】① \(m=-\frac{a}{b}\) 漏掉外面那個負號，答成 \(-2\)。② \(b=-2\) 抄成 \(2\)（一般式的 b 要連負號一起抄）。③ 把 y 截距答成點 \((0,3)\) 沒關係，但答成 \(x=3\) 就錯了——截距是那個數值 3。
3．答案：（a）\(x+y-1=0\)　（b）\(2x-y+4=0\)
【考點】求直線方程的三種給法，本題考前兩種。不論哪一種，拿到斜率之後都是代點斜式再整理成一般式。
【公式／定理】點斜式 \(y-y_1=m(x-x_1)\)；兩點求斜率 \(m=\frac{y_2-y_1}{x_2-x_1}\)。
【詳細步驟】
　（1）（a）給法①：一點＋斜率。\(y-(-2)=-1(x-3)\) → \(y+2=-x+3\) → \(x+y-1=0\)。
　（2）（a）檢核：代 \(P(3,-2)\)：\(3+(-2)-1=0\) ✔；斜率 \(=-\frac{1}{1}=-1\) ✔
　（3）（b）給法②：兩點。先求斜率 \(m=\frac{10-2}{3-(-1)}=\frac{8}{4}=2\)。代點斜式（用 A）：\(y-2=2(x+1)\) → \(y=2x+4\) → \(2x-y+4=0\)。
　（4）（b）檢核：代 \(A(-1,2)\)：\(-2-2+4=0\) ✔；代 \(B(3,10)\)：\(6-10+4=0\) ✔。改用 B 點列式也得同一條：\(y-10=2(x-3)\) → \(y=2x+4\) ✔
【易錯點提示】① (a) 負坐標代錯：\(y_1=-2\)，所以左邊是 \(y-(-2)=y+2\)，不是 \(y-2\)。② (b) 斜率上下顛倒，寫成 \(\frac{x_2-x_1}{y_2-y_1}\)。③ 停在 \(y=2x+4\) 沒有整理成一般式（題目要求一般式）。④ 兩點題只代一個點檢查——兩個都要代，才抓得出斜率算錯。
4．答案：（a）\((x+2)^2+(y-3)^2=16\)　（b）\((x-4)^2+(y-2)^2=25\)
【考點】圓標準式 \((x-h)^2+(y-k)^2=r^2\)：圓心 \((h,k)\) 代進括號要變號，等號右邊放的是 \(r^2\)。直徑兩端的題，圓心是中點、半徑是直徑的一半。
【公式／定理】\((x-h)^2+(y-k)^2=r^2\)；直徑兩端 → 圓心 = 中點、\(r=\frac{|AB|}{2}\)。
【詳細步驟】
　（1）（a）\(h=-2\)、\(k=3\)、\(r=4\)。\(x-(-2)=x+2\)，\(r^2=16\) → \((x+2)^2+(y-3)^2=16\)。檢核：取圓上一點 \((2,3)\)（圓心右移 4）：\((2+2)^2+0=16\) ✔
　（2）（b）圓心 = AB 中點 \(=(\frac{1+7}{2},\frac{-2+6}{2})=(4,2)\)。
　（3）（b）\(|AB|=\sqrt{(7-1)^2+(6-(-2))^2}=\sqrt{36+64}=10\)，所以 \(r=5\)、\(r^2=25\) → \((x-4)^2+(y-2)^2=25\)。
　（4）（b）檢核：代 \(A(1,-2)\)：\((1-4)^2+(-2-2)^2=9+16=25\) ✔；代 \(B(7,6)\)：\((7-4)^2+(6-2)^2=9+16=25\) ✔
【易錯點提示】① 圓心符號不變號：\(C(-2,3)\) 寫成 \((x-2)^2\)——應該是 \((x+2)^2\)。② 右邊寫成 \(r\) 不是 \(r^2\)：半徑 4 → 右邊是 16。③ (b) 把 \(|AB|=10\) 當成半徑——那是直徑，半徑是 5。④ (b) 圓心用了 A 或 B 的坐標——圓心是它們的中點。
5．答案：相交；交點 \((-2,2)\) 與 \((1,5)\)
【考點】直線與圓的位置關係有兩條路：代入消元算 \(\Delta \)（要求交點就走這條），或算圓心到直線的距離 d 跟 r 比（只問關係就走這條）。本題要求交點，所以走代入法，再用距離法檢核。
【公式／定理】\(\Delta =b^2-4ac\)：\(\Delta \gt 0\) 相交、\(\Delta =0\) 相切、\(\Delta \lt 0\) 相離；\(d=\frac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}\)，\(d \lt r\) 相交、\(d=r\) 相切、\(d \gt r\) 相離。
【詳細步驟】
　（1）草圖：圓心 \(C(1,2)\)、\(r=3\)；直線 \(y=x+4\) 過 \((0,4)\)、\((-4,0)\)，由左下往右上。畫出來就看得到它穿過圓。
　（2）代入法：\(y=x+4\) 代進 \((x-1)^2+(y-2)^2=9\) → \((x-1)^2+(x+2)^2=9\) → \(x^2-2x+1+x^2+4x+4=9\) → \(2x^2+2x-4=0\) → \(x^2+x-2=0\)（兩邊先除以 2，數字小些不易錯）。
　（3）\(\Delta =1^2-4(1)(-2)=1+8=9 \gt 0\) → 相交於兩點。\((x+2)(x-1)=0\) → \(x=-2\) 或 \(x=1\)；代回 \(y=x+4\) 得交點 \((-2,2)\) 與 \((1,5)\)。
　（4）距離法檢核：\(d=\frac{|1-2+4|}{\sqrt{1^2+(-1)^2}}=\frac{3}{\sqrt{2}}≈2.12 \lt 3=r\) ✔ 兩法結論一致。
　（5）驗點：\((-2-1)^2+(2-2)^2=9+0=9\) ✔（圓的最左點）；\((1-1)^2+(5-2)^2=0+9=9\) ✔（圓的最上點）。
【易錯點提示】① 沒畫圖就硬代，代錯一個括號整題報廢——本題明寫要先畫草圖。② 代入後沒有整理成「一邊為 0」就數 \(a\)、\(b\)、\(c\)。③ 求出 x 之後忘記代回求 y，只答 \(x=-2\)、\(x=1\)。④ 圓心讀錯：\((x-1)^2+(y-2)^2\) 的圓心是 \((1,2)\) 不是 \((-1,-2)\)。
6．答案：（a）\(x-2y+7=0\)　（b）相離（沒有交點）
【考點】兩步整合題：先用「垂直斜率是負倒數」求出 \(L_2\)，再用距離法（或判別式）判斷 \(L_2\) 與圓的關係。本題不必求交點，所以距離法比代入法快。
【公式／定理】垂直 ⇔ \(m_1 \times m_2=-1\)；點斜式 \(y-y_1=m(x-x_1)\)；\(d=\frac{|ax_0+by_0+c|}{\sqrt{a^2+b^2}}\)，\(d \gt r\) 相離。
【詳細步驟】
　（1）（a）\(L_1: 2x+y-5=0\) 的斜率 \(m_1=-\frac{a}{b}=-\frac{2}{1}=-2\)。垂直 → \(m_2=\frac{-1}{-2}=\frac{1}{2}\)。
　（2）（a）點斜式：\(y-4=\frac{1}{2}(x-1)\) → 兩邊乘 2：\(2y-8=x-1\) → \(x-2y+7=0\)。檢核：代 \(P(1,4)\)：\(1-8+7=0\) ✔；\(m_1 \times m_2=(-2)(\frac{1}{2})=-1\) ✔
　（3）（b）圓 \(x^2+y^2=5\) 的圓心 \(O(0,0)\)、\(r=\sqrt{5}≈2.24\)。\(d=\frac{|0-0+7|}{\sqrt{1^2+(-2)^2}}=\frac{7}{\sqrt{5}}≈3.13 \gt \sqrt{5}\) → 相離，沒有交點。
　（4）（b）判別式檢核：\(x=2y-7\) 代入 → \((2y-7)^2+y^2=5\) → \(5y^2-28y+44=0\)，\(\Delta =(-28)^2-4(5)(44)=784-880=-96 \lt 0\) ✔ 無實根，與距離法一致。
【易錯點提示】① 垂直斜率只變號不取倒數（答成 2）或只取倒數不變號（答成 \(-\frac{1}{2}\)）。② \(d\) 的分母用了點的坐標——分母是 \(\sqrt{a^2+b^2}\)，\(a\)、\(b\) 是直線方程的係數。③ 分子忘記加絕對值，算出負數就直接拿去跟 r 比。④ 把 \(r\) 讀成 5——\(x^2+y^2=5\) 的右邊是 \(r^2\)，\(r=\sqrt{5}\)。
