**本課共用的公式表（下面每題的驗算都回到這一張）**

| | 橢圓 | 雙曲線 | 拋物線 |
|---|---|---|---|
| 標準式 | x²/a² + y²/b² = 1（相**加**） | x²/a² − y²/b² = 1（相**減**） | y = ax² 或 x = ay²（一個變數是二次、另一個是一次） |
| a 是誰 | a² ＝ **較大**的分母；長軸跟着大分母那個變數走 | a² ＝ **減號前面**那一項的分母（不看大小） | 沒有 a、b、c；只看開口方向與頂點 |
| a、b、c 的關係 | c² ＝ a² − **b²**（相減） | c² ＝ a² + **b²**（相加） | — |
| 離心率 e ＝ c/a | 0 ＜ e ＜ 1 | e ＞ 1 | e ＝ 1 |
| 準線 | 到中心 a²/c，兩準線距離 ＝ 2a²/c | 同式（本課不考） | — |
| 漸近線 | 沒有 | y ＝ ±(b/a)x（橫向）／ y ＝ ±(a/b)x（縱向） | 沒有 |
| 焦點性質 | 到兩焦點距離之**和** ＝ 2a | 到兩焦點距離之差的**絕對值** ＝ 2a | — |

> 全課最容易混的兩條：橢圓 c² 是**減**、雙曲線 c² 是**加**；橢圓的 a 看**分母大小**、
> 雙曲線的 a 看**減號位置**。下面每一題都會回到這兩條檢核。

## 講義範例

### 範例A・由方程或離心率認出是哪一種曲線

- (a) x²/25 + y²/9 = 1：兩項相加等於 1，兩個分母都是正數 → **橢圓**。
  （a² = 25 > 9 = b²，大分母在 x 下面，所以長軸沿 x 軸，a = 5、b = 3。）
- (b) x²/16 − y²/9 = 1：兩項相減等於 1 → **雙曲線**（橫向，減號前面是 x，所以 a² = 16、a = 4）。
- (c) y = 2x² − 4x + 1：x 是二次、y 是一次 → **拋物線**（開口向上，x² 係數 2 > 0）。
- (d) x² + y² = 16：x²、y² 係數相同 → **圓**（半徑 4）。
  也可以看成 x²/16 + y²/16 = 1，即 a = b 的橢圓（此時 c = 0、e = 0）。
- (e) 某曲線的離心率 e = 0.6：0 < 0.6 < 1 → **橢圓**。
- 檢核（把每一題反向對回公式表）：(a) 相加 ✔ 橢圓列；(b) 相減 ✔ 雙曲線列；
  (c) 一個二次一個一次 ✔ 拋物線列；(d) 係數相同 ✔ 圓；(e) 0<e<1 ✔ 橢圓列。
- **文件答案：(a) 橢圓　(b) 雙曲線　(c) 拋物線　(d) 圓　(e) 橢圓 — 一致。**

### 範例B・橢圓的四個量（兩題只調轉分母，用來立「a 跟着大分母走」）

**(1) x²/25 + y²/9 = 1**

- 分母 25 > 9，大分母在 x 下面 → 長軸沿 **x 軸**，a² = 25 → a = 5；b² = 9 → b = 3。
- c² = a² − b² = 25 − 9 = 16 → c = 4。（焦點在長軸上，即 (±4, 0)。）
- e = c/a = 4/5 = 0.8，滿足 0 < e < 1 ✔ 確實是橢圓。
- 準線：x = ±a²/c = ±25/4 = ±6.25，兩準線間的距離 = 2a²/c = 50/4 = **12.5**。
- 檢核：a > c 一定成立（5 > 4）✔；e = 0.8 接近 1 表示比較扁，
  而 b/a = 3/5 = 0.6 確實比較扁 ✔ 兩者相符。

**(2) x²/9 + y²/25 = 1**

- 分母 25 > 9，這次大分母在 y 下面 → 長軸沿 **y 軸**，a² = 25 → a = 5；b² = 9 → b = 3。
- c² = 25 − 9 = 16 → c = 4，焦點在 (0, ±4)（在 y 軸上）。
- e = 4/5 = 0.8；準線 y = ±25/4，距離仍是 **12.5**。
- 檢核：(1)(2) 只是把圖橫放與直放，四個量的**數值完全一樣**，
  差別只在長軸與焦點的**方向**——這正是本題要立的點。
- **文件答案：(1) a=5、b=3、長軸沿 x、c=4、e=0.8、準線距離 12.5；
  (2) 同樣的數值但長軸沿 y、焦點在 (0,±4) — 一致。**

### 範例C・雙曲線 x²/16 − y²/9 = 1

- 減號前面是 x 那一項 → 橫向雙曲線，a² = 16 → a = 4；b² = 9 → b = 3。
- **c² = a² + b² = 16 + 9 = 25 → c = 5**（雙曲線是相加，跟橢圓相反）。
- e = c/a = 5/4 = 1.25 > 1 ✔ 確實是雙曲線。
- 漸近線：y = ±(b/a)x = ±(3/4)x。
- 焦半徑：P 在雙曲線上、到一個焦點的距離 d₁ = 3，求 d₂。
  由定義 |d₁ − d₂| = 2a = 8 → d₂ = 3 + 8 = 11，或 d₂ = 3 − 8 = −5（距離不能是負數，捨去）。
  所以 d₂ = **11**。
- 合理性檢核：焦點到最近那個頂點的距離 = c − a = 5 − 4 = 1，
  所以雙曲線上任何一點到焦點的距離至少是 1；d₁ = 3 ≥ 1 ✔ 題目給的值合理。
- **文件答案：a=4、b=3、c=5、e=1.25；漸近線 y=±(3/4)x；d₂=11 — 一致。**

### 範例D・拋物線草圖

- (a) y = x² − 4：x² 的係數 1 > 0 → **開口向上**；頂點 (0, −4)。
  檢核：令 y = 0 得 x² = 4，x = ±2，與 x 軸交於 (±2, 0) ✔ 圖上量得到。
- (b) x² + 8y = 0 → y = −x²/8：係數 −1/8 < 0 → **開口向下**；頂點 (0, 0)。
  檢核：取 x = 4 得 y = −2，圖上 (4, −2) 在曲線上 ✔
- (c) y² = 4x：這次是 **y** 二次、x 一次 → 開口左右；4 > 0 → **開口向右**；頂點 (0, 0)。
  檢核：取 y = 2 得 x = 1，(1, 2) 在曲線上；取 y = 4 得 x = 4，(4, 4) 在曲線上 ✔
- 三題的共同判斷法：**先看哪一個變數是二次**——x 二次就上下開口，y 二次就左右開口；
  **再看係數的正負**——正的朝正方向（上／右），負的朝負方向（下／左）。
- **文件答案：(a) 開口向上、頂點 (0,−4)　(b) 開口向下、頂點 (0,0)　
  (c) 開口向右、頂點 (0,0) — 一致。**

### 範例E・共同漸近線求雙曲線方程

求經過 P(8√2, 6)、且與 x²/16 − y²/9 = 1 有共同漸近線的雙曲線方程。

- 關鍵：把等號右邊的 1 換成待定的 k，得到**同漸近線族** x²/16 − y²/9 = k（k ≠ 0）。
  這一族的每一條，漸近線都是 y = ±(3/4)x。
- 代入 P(8√2, 6)：(8√2)²/16 − 6²/9 = 128/16 − 36/9 = 8 − 4 = 4，所以 k = 4。
- 得 x²/16 − y²/9 = 4，兩邊除以 4 化成標準式：**x²/64 − y²/36 = 1**。
- 檢核①（點在不在上面）：代 P(8√2, 6)：128/64 − 36/36 = 2 − 1 = 1 ✔
- 檢核②（漸近線是否相同）：新曲線 a² = 64 → a = 8，b² = 36 → b = 6，
  漸近線 y = ±(b/a)x = ±(6/8)x = ±(3/4)x，與原曲線的 ±(3/4)x 相同 ✔
- 附記（k 是負數時會怎樣）：若代入後得 k < 0，例如 x²/9 − y²/16 = −1，
  兩邊除以 −1 會變成 y²/16 − x²/9 = 1——**兩項換邊、分母不變**，
  雙曲線由橫向轉成縱向，但漸近線仍然是 y = ±(4/3)x。練習第 6 題就是這種。
- **文件答案：x²/64 − y²/36 = 1 — 一致。**

## 練習題

1．判斷下列各方程（或條件）代表哪一種曲線：（a）x²/36 + y²/16 = 1　（b）y² − x²/4 = 1　（c）y = 3x² + 2x − 1　（d）某曲線的離心率 e = 1.5。

- (a) 兩項相加等於 1 → **橢圓**。（36 > 16，大分母在 x 下面 → 長軸沿 x，a = 6、b = 4。）
- (b) 寫齊分母就是 y²/1 − x²/4 = 1：兩項相減等於 1 → **雙曲線**。
  減號前面是 y，所以是**縱向**雙曲線，a² = 1 → a = 1、b² = 4 → b = 2。
- (c) x 二次、y 一次 → **拋物線**（開口向上，係數 3 > 0）。
- (d) e = 1.5 > 1 → **雙曲線**。
- 檢核：四題分別對應公式表的橢圓列、雙曲線列、拋物線列、雙曲線列 ✔
  特別注意 (b)：分母是 1 不寫出來，很多人會因為看不到分母而認不出是雙曲線。
- **文件答案：(a) 橢圓　(b) 雙曲線（縱向）　(c) 拋物線　(d) 雙曲線 — 一致。**

2．已知橢圓 x²/100 + y²/64 = 1。（a）求 a、b 與長軸的方向。（b）求 c。（c）求離心率 e。

- (a) 分母 100 > 64，大分母在 x 下面 → 長軸沿 **x 軸**；a² = 100 → a = 10；b² = 64 → b = 8。
- (b) c² = a² − b² = 100 − 64 = 36 → c = 6（相減，別跟雙曲線的相加搞混）。
- (c) e = c/a = 6/10 = 3/5 = **0.6**，滿足 0 < e < 1 ✔
- 檢核：6-8-10 是 3-4-5 的兩倍，直角三角形 ✔；焦點在 (±6, 0)，
  而 6 < 10 = a，焦點確實落在橢圓內部 ✔
- **文件答案：(a) a=10、b=8、長軸沿 x 軸　(b) c=6　(c) e=0.6 — 一致。**

3．已知橢圓 25x² + 9y² = 225。（a）求半長軸 a 與長軸的方向。（b）求 c 與離心率 e。（c）求兩準線間的距離。

- 先化標準式：兩邊除以 225 → 25x²/225 + 9y²/225 = 1 → **x²/9 + y²/25 = 1**。
  （除的時候是把整條式子除以 225，不是把係數搬去分母：25x²/225 = x²/9。）
- (a) 分母 25 > 9，大分母在 **y** 下面 → 長軸沿 **y 軸**；a² = 25 → a = 5（b² = 9 → b = 3）。
- (b) c² = a² − b² = 25 − 9 = 16 → c = 4；e = c/a = 4/5 = **0.8**。焦點在 (0, ±4)。
- (c) 準線 y = ±a²/c = ±25/4 = ±6.25，兩準線間的距離 = 2a²/c = 50/4 = **12.5**。
- 檢核①：原式代點驗證——取 (0, 5)：25(0) + 9(25) = 225 ✔（(0,5) 確是長軸端點）；
  取 (3, 0)：25(9) + 0 = 225 ✔（(3,0) 確是短軸端點）。所以 a = 5 沿 y、b = 3 沿 x ✔
- 檢核②：準線一定在橢圓外面——a²/c = 6.25 > a = 5 ✔ 合理。
- **文件答案：(a) a=5、長軸沿 y 軸　(b) c=4、e=0.8　(c) 12.5 — 一致。**

4．已知雙曲線 x²/9 − y²/16 = 1。（a）求 a、b、c 與漸近線方程。（b）若 P 在雙曲線上、到一個焦點的距離是 2，求 P 到另一個焦點的距離。

- (a) 減號前面是 x → 橫向；a² = 9 → a = 3；b² = 16 → b = 4。
  **c² = a² + b² = 9 + 16 = 25 → c = 5**（雙曲線相加）。
  漸近線 y = ±(b/a)x = **±(4/3)x**。（順帶：e = 5/3 ≈ 1.67 > 1 ✔）
- (b) 由定義 |d₁ − d₂| = 2a = 6。d₁ = 2 → d₂ = 2 + 6 = 8，或 d₂ = 2 − 6 = −4（捨去）。
  所以 d₂ = **8**。
- 檢核：焦點到最近頂點的距離 = c − a = 5 − 3 = 2，剛好等於題目給的 d₁ = 2，
  即 P 就是那個頂點 (3, 0)。那麼 P 到另一個焦點 (−5, 0) 的距離 = 3 − (−5) = 8 ✔
  兩種算法完全吻合，而且 8 = c + a = 5 + 3 ✔
- **文件答案：(a) a=3、b=4、c=5、漸近線 y=±(4/3)x　(b) 8 — 一致。**

5．畫出下列曲線的草圖，並寫出曲線種類、開口方向（如果是拋物線）與頂點／中心：（a）y = −x² + 2　（b）y² = −8x　（c）x²/4 + y²/4 = 1。

- (a) x 二次、y 一次 → **拋物線**；x² 係數 −1 < 0 → **開口向下**；頂點 (0, 2)。
  檢核：令 y = 0 得 x² = 2，x = ±√2 ≈ ±1.41，與 x 軸交於 (±√2, 0) ✔
  取 x = 1 得 y = 1，(1, 1) 在曲線上 ✔
- (b) **y** 二次、x 一次 → **拋物線**，開口左右；係數 −8 < 0 → **開口向左**；頂點 (0, 0)。
  檢核：取 y = 2 → y² = 4 = −8x → x = −0.5，點 (−0.5, 2) 在曲線上；
  取 y = 4 → 16 = −8x → x = −2，點 (−2, 4) 在曲線上 ✔ 兩點都在 y 軸左邊，確是開口向左。
- (c) 兩項相加等於 1，而且**兩個分母相同**（都是 4）→ 化簡後是 x² + y² = 4，
  即**圓**，圓心 (0, 0)、半徑 2。（不是一般的橢圓；此時 a = b，c = 0，e = 0。）
  檢核：(2,0)、(0,2)、(−2,0)、(0,−2) 四點都滿足 x²+y²=4 ✔ 到原點距離都是 2 ✔
- 本題的考點在 (c)：**看到「相加等於 1」不要立刻寫橢圓，要先看兩個分母是不是相同**。
- **文件答案：(a) 拋物線、開口向下、頂點 (0,2)　(b) 拋物線、開口向左、頂點 (0,0)　
  (c) 圓、圓心 (0,0)、半徑 2 — 一致。**

6．求經過點 P(3, 4√2)、且與 x²/9 − y²/16 = 1 有共同漸近線的雙曲線方程。

- 設同漸近線族：x²/9 − y²/16 = k（k ≠ 0）。
- 代入 P(3, 4√2)：3²/9 − (4√2)²/16 = 9/9 − 32/16 = 1 − 2 = **−1**，所以 k = −1。
- 得 x²/9 − y²/16 = −1，兩邊除以 −1（**每一項都要變號**）：
  −x²/9 + y²/16 = 1，整理成標準式 → **y²/16 − x²/9 = 1**。
- 檢核①（點在不在上面）：代 P(3, 4√2)：32/16 − 9/9 = 2 − 1 = 1 ✔
- 檢核②（漸近線是否相同）：新曲線是縱向雙曲線（減號前面是 y），a² = 16 → a = 4，
  b² = 9 → b = 3，縱向的漸近線是 y = ±(a/b)x = ±(4/3)x；
  原曲線是橫向、a = 3、b = 4，漸近線 y = ±(b/a)x = ±(4/3)x ✔ 相同。
- 幾何意義：k 由正變負，雙曲線由**橫向轉成縱向**（開口由左右變上下），
  但兩條漸近線一動不動——所以答案的分母 16 與 9 只是換了邊，數值沒有變。
- **文件答案：y²/16 − x²/9 = 1 — 一致。**

## 數字挑選原則（供日後出平行題參考）

1. **a、b、c 一律取 3-4-5 家族**（本課用了 3-4-5、6-8-10、5-3-4 共六次）。
   橢圓 c² = a² − b²、雙曲線 c² = a² + b² 兩條式都能落在整數上，
   學生的注意力才留得住在「這一課到底是加還是減」，而不是被開方分心。
2. **橢圓刻意排一組只調轉分母的對照題**（範例B 的 x²/25+y²/9 與 x²/9+y²/25）：
   四個量的數值完全相同、只有長軸方向不同，這是「a 跟着大分母走」最省話的教法。
3. **準線題一定讓 a²/c 除得盡**（本課 25/4 = 6.25、兩準線距離 12.5）。
   若取 a²=7、c=√2 之類（題庫 MOCK2-086 就是），答案會出現 7√2，
   對本班而言計算負荷蓋過概念，改放教師說明頁備註即可。
4. **雙曲線焦半徑題把 d₁ 設成剛好等於 c − a**（範例C 的 3 = 5−4 不是、練習4 的 2 = 5−3 是）：
   練習4 可以用「P 就是頂點」第二條路獨立驗一次，範例C 則保持一般位置，
   兩題合起來剛好示範「答案要檢查合理性（d₁ 不能小於 c − a）」。
5. **共同漸近線題安排 k 一正一負**（範例E 的 k = 4、練習6 的 k = −1）。
   k = −1 是全部負數情形裡最漂亮的一個：兩項換邊、分母原封不動，
   一眼就看到「漸近線沒變、曲線轉了 90 度」。
6. **拋物線一定要出一題 y 是二次的**（範例D(c)、練習5(b)），
   否則學生會把「拋物線」直接等同於「開口上下」。
7. **每一組都埋一個辨識陷阱**：練習1(b) 分母是 1 不寫出來、
   練習5(c) 兩個分母相同其實是圓、練習3 要先把 25x²+9y²=225 化成標準式才看得出方向。
