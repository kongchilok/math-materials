## 0. 符號寫法（本課定案）

| 項目 | 本課寫法 | 不用的寫法 | 理由 |
|---|---|---|---|
| 首項 | `a₁`（標記 `{a_1}`） | a(1)、A₁ | 與課本、考卷一致 |
| 公差／公比 | `d`／`r` | 統一用 `d` 表示兩者 | 兩個符號分開，是本課防混淆的第一道防線 |
| 通項指數 | 一律 `n−1` | 先寫 `n+1` 再調整 | 本課最貴的錯就在這個指數，寫法不統一會更混亂 |
| 求和 | `Sₙ`（標記 `{S_n}`） | `S(n)` | 同上 |
| 負分數 | `−1/8`（標記 `-frac(1,8)`） | `frac(-1,8)` | 後者把負號塞進分子，排版像「−1 分之 8」 |

**兩條公式的指數不同，這是本課最容易連鎖出錯的地方**：
等比通項 `aₙ = a₁r^(n−1)` 的指數是 `n−1`；等比求和 `Sₙ = a₁(rⁿ−1)/(r−1)` 的指數是 `n`。
講義、練習、工具卡三份都在同一位置標了 ※ 提醒。

## 1. 講義範例逐題驗算

### 範例A・先認出是哪一種

**(a) 1/2, 1/4, 1/6, 1/8, … 的通項**

- 路徑一（判斷 → 找規律）：
  相減：1/4 − 1/2 = −1/4；1/6 − 1/4 = −1/12。兩差不同 → 不是等差。
  相除：(1/4)÷(1/2) = 1/2；(1/6)÷(1/4) = 2/3。兩商不同 → 不是等比。
  分子恆為 1，分母 2, 4, 6, 8 成等差（d=2），第 n 項分母 = 2n → **aₙ = 1/(2n)**。
- 路徑二（逐項代入檢查）：
  n=1 → 1/2 ✔　n=2 → 1/4 ✔　n=3 → 1/6 ✔　n=4 → 1/8 ✔ 四項全中。
  對照錯誤答案 (1/2)ⁿ：n=3 給 1/8 ≠ 1/6 ✘ 排除。
- **一致 ✔**　題庫對照 MATH-014／MOCK2-012（答案 C：1/(2n)）✔

**(b) −8, 4, −2, 1, … 的第 10 項**

- 路徑一：相除 4÷(−8) = −1/2；(−2)÷4 = −1/2；1÷(−2) = −1/2 → 等比，r = −1/2。
  a₁₀ = a₁r⁹ = −8 × (−1/2)⁹ = −8 × (−1/512) = 8/512 = **1/64**。
- 路徑二（逐項推）：
  −8, 4, −2, 1, −1/2, 1/4, −1/8, 1/16, −1/32, **1/64** —— 第 10 項 ✔
- 路徑三（正負自檢）：r < 0 時單數項為負、雙數項為正；第 10 項是雙數項 → 應為正 ✔
- **一致 ✔**　題庫對照 COMP1-052（答案 A：1/64）✔

### 範例B・等差數列（四數和 82、第四項比第二項大 14）

- 路徑一：a₄ − a₂ = (a₁+3d) − (a₁+d) = 2d = 14 → d = 7。
  四項和 = 4a₁ + (0+1+2+3)d = 4a₁ + 6d = 82 → 4a₁ = 82 − 42 = 40 → **a₁ = 10**。
- 路徑二（用求和公式）：S₄ = 4(a₁+a₄)/2 = 2(a₁ + a₁+3d) = 2(2a₁+3d) = 4a₁+6d，
  與路徑一同一條式 ✔ 代 d=7 得 4a₁+42 = 82 → a₁ = 10 ✔
- 路徑三（列出四項驗證）：10, 17, 24, 31。
  和 = 10+17+24+31 = 82 ✔　a₄ − a₂ = 31 − 17 = 14 ✔ 兩個條件都成立。
- **一致 ✔**　題庫對照 MATH-005／MOCK2-005（答案 A：10）✔

### 範例C・等差級數

**(a) (−15) + (−5) + 5 + … + 35**

- 路徑一：a₁ = −15、aₙ = 35、d = 10。n = (35−(−15))/10 + 1 = 5 + 1 = 6。
  S₆ = 6(−15+35)/2 = 6×20/2 = **60**。
- 路徑二（逐項相加）：−15 −5 +5 +15 +25 +35
  = (−15−5) = −20 → −15 → 0 → 25 → **60** ✔
- **一致 ✔**　題庫對照 MOCK2-073（答案 60）✔

**(b) 30 + 35 + 40 + … + 235**

- 路徑一：a₁ = 30、aₙ = 235、d = 5。n = (235−30)/5 + 1 = 41 + 1 = 42。
  S₄₂ = 42(30+235)/2 = 21 × 265 = **5565**。
- 路徑二（平均數 × 項數）：(30+235)/2 = 132.5；132.5 × 42 = **5565** ✔
- 路徑三（另一條求和公式）：S = 42[2×30 + 41×5]/2 = 21(60+205) = 21×265 = 5565 ✔
- **一致 ✔**　題庫對照 COMP1-073（答案 A：5565）✔

### 範例D・等比數列

**(a) 第三項 1、第八項 −1/32，求首項**

- 路徑一：a₈/a₃ = r⁵ = (−1/32)/1 = −1/32 = (−1/2)⁵ → r = −1/2。
  a₃ = a₁r² = a₁ × 1/4 = 1 → **a₁ = 4**。
- 路徑二（列出八項）：4, −2, 1, −1/2, 1/4, −1/8, 1/16, −1/32。
  第三項 = 1 ✔　第八項 = −1/32 ✔
- **一致 ✔**　題庫對照 MATH-023／MOCK2-020（答案 D：4）✔

**(b) 6561, 4374, 2916, …, 256 共幾項**

- 路徑一：r = 4374/6561 = 2/3（覆核 2916/4374 = 2/3 ✔）。
  6561(2/3)^(n−1) = 256 → (2/3)^(n−1) = 256/6561。
  6561 = 3⁸、256 = 2⁸ → 256/6561 = (2/3)⁸ → n − 1 = 8 → **n = 9**。
- 路徑二（逐項推）：6561, 4374, 2916, 1944, 1296, 864, 576, 384, **256** —— 數出 9 項 ✔
  （逐項：6561×2/3=4374、×2/3=2916、1944、1296、864、576、384、256 ✔）
- **一致 ✔**　題庫對照 MATH-052／MOCK2-051（答案 B：9）✔

### 範例E・數學歸納法（1·3 + 2·4 + … + n(n+2) = n(n+1)(2n+7)/6）

- 基礎步驟 n=1：左 = 1×3 = 3；右 = 1×2×9/6 = 18/6 = 3 ✔
- 歸納步驟：設 n=k 成立。加第 (k+1) 項 (k+1)(k+3)：
  k(k+1)(2k+7)/6 + (k+1)(k+3)
  = (k+1)[k(2k+7) + 6(k+3)]/6
  = (k+1)(2k² + 7k + 6k + 18)/6
  = (k+1)(2k² + 13k + 18)/6
  因式分解：(k+2)(2k+9) = 2k² + 9k + 4k + 18 = 2k² + 13k + 18 ✔
  = (k+1)(k+2)(2k+9)/6
  目標（n=k+1）：(k+1)(k+2)(2(k+1)+7)/6 = (k+1)(k+2)(2k+9)/6 ✔ **完全相同**
- 獨立數值覆核（n=1..4 直接代）：
  n=1：左 3、右 3 ✔
  n=2：左 3+8 = 11；右 2×3×11/6 = 66/6 = 11 ✔
  n=3：左 3+8+15 = 26；右 3×4×13/6 = 156/6 = 26 ✔
  n=4：左 3+8+15+24 = 50；右 4×5×15/6 = 300/6 = 50 ✔
- **一致 ✔**　題庫對照 MATH-071／MOCK2-141 ✔

### 第 1 題

(a) 相減 7−3 = 4、11−7 = 4、15−11 = 4 → 等差，d = 4。
a₂₀ = 3 + (20−1)×4 = 3 + 76 = **79**。
覆核：代 n=1 得 3 ✔；代 n=4 得 3+12 = 15 ✔（與題目第四項相符）。

(b) 相減 6−2 = 4、18−6 = 12 → 不是等差。相除 6÷2 = 3、18÷6 = 3、54÷18 = 3 → 等比，r = 3。
a₆ = 2 × 3⁵ = 2 × 243 = **486**。
覆核（逐項）：2, 6, 18, 54, 162, **486** ✔
**一致 ✔**

### 第 2 題

a₁ = 5、aₙ = 101、d = 9−5 = 4。
n = (101−5)/4 + 1 = 96/4 + 1 = 24 + 1 = **25**。
S₂₅ = 25(5+101)/2 = 25 × 106/2 = 25 × 53 = **1325**。
覆核一（平均數 × 項數）：(5+101)/2 = 53；53 × 25 = 1325 ✔
覆核二（另一條公式）：S = 25[2×5 + 24×4]/2 = 25(10+96)/2 = 25×106/2 = 1325 ✔
覆核三（末項驗算）：a₂₅ = 5 + 24×4 = 5 + 96 = 101 ✔ 項數確實是 25。
**一致 ✔**

### 第 3 題

a₄ − a₁ = 3d = 18 → d = 6。
四項之和 = 4a₁ + (0+1+2+3)d = 4a₁ + 6d = 52 → 4a₁ = 52 − 36 = 16 → a₁ = 4。
四個數：**4、10、16、22**。
覆核：和 = 4+10+16+22 = 52 ✔　a₄ − a₁ = 22 − 4 = 18 ✔ 兩條件同時成立。
覆核（用求和公式）：S₄ = 4(4+22)/2 = 2×26 = 52 ✔
**一致 ✔**

### 第 4 題

a₅/a₂ = r³ = (−1/8)/1 = −1/8 = (−1/2)³ → **r = −1/2**。
a₂ = a₁r = 1 → a₁ = 1 ÷ (−1/2) = **−2**。
覆核（列出五項）：−2, 1, −1/2, 1/4, −1/8。
第二項 = 1 ✔　第五項 = −1/8 ✔　公比為負、各項正負交替 ✔
**一致 ✔**　題庫對照 MOCK2-084（a₁ = −2）✔

### 第 5 題

**(a)** a₁ = 2、r = 6/2 = 3（覆核 18/6 = 3 ✔）。
2 × 3^(n−1) = 1458 → 3^(n−1) = 729 = 3⁶ → n − 1 = 6 → **n = 7**。
覆核（逐項）：2, 6, 18, 54, 162, 486, **1458** —— 數出 7 項 ✔

**(b)** S₇ = a₁(r⁷−1)/(r−1) = 2(3⁷−1)/(3−1) = 2(2187−1)/2 = **2186**。
覆核（逐項相加）：2+6 = 8 → +18 = 26 → +54 = 80 → +162 = 242 → +486 = 728 → +1458 = **2186** ✔
覆核（指數陷阱檢查）：若誤把求和公式的指數寫成 n−1 = 6，會得 2(729−1)/2 = 728，
剛好是前 6 項的和（2186 − 1458 = 728 ✔ 印證這正是漏了最後一項）。
此陷阱已寫入本題的【易錯點提示】①。
**一致 ✔**

### 第 6 題

**(a)** 證 1·2 + 2·3 + … + n(n+1) = n(n+1)(n+2)/3。
基礎 n=1：左 = 1×2 = 2；右 = 1×2×3/3 = 2 ✔
歸納：設 n=k 成立，加第 (k+1) 項 (k+1)(k+2)：
k(k+1)(k+2)/3 + (k+1)(k+2)
= (k+1)(k+2)[k/3 + 1]
= (k+1)(k+2)(k+3)/3
目標（n=k+1）：(k+1)(k+2)(k+3)/3 ✔ **完全相同**。
獨立數值覆核：
n=2：左 = 2+6 = 8；右 = 2×3×4/3 = 8 ✔
n=3：左 = 2+6+12 = 20；右 = 3×4×5/3 = 20 ✔
n=4：左 = 2+6+12+20 = 40；右 = 4×5×6/3 = 40 ✔
題庫對照 MOCK2-170 ✔

**(b)** 末項 20×21 對應通項 n(n+1) 的 n = 20。
S = 20×21×22/3 = 9240/3 = **3080**。
覆核（先約簡）：21/3 = 7 → 20 × 7 × 22 = 140 × 22 = 3080 ✔
覆核（遞推）：由 (a) 的公式，n=19 時 = 19×20×21/3 = 7980/3 = 2660；
再加第 20 項 20×21 = 420 → 2660 + 420 = **3080** ✔ 兩條路相同。
**一致 ✔**
