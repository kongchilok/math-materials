## 練習題

1．解方程（因式分解法）：（a）x²−7x+10=0　（b）x²−9=0。

- (a) 找兩數之積 10、之和 7 → 2 與 5：x²−7x+10=(x−2)(x−5)=0 → x=2 或 x=5。
  驗根：2²−7·2+10=4−14+10=0 ✔；5²−7·5+10=25−35+10=0 ✔。
- (b) 平方差：x²−9=(x−3)(x+3)=0 → x=3 或 x=−3。
  驗根：(±3)²−9=9−9=0 ✔。
- **文件答案：(a) x=2 或 x=5　(b) x=3 或 x=−3 — 一致。**

2．判斷下列方程根的情況（只用判別式，不必解出根）：（a）x²−4x+4=0　（b）2x²−3x+5=0。

- (a) a=1、b=−4、c=4。Δ=b²−4ac=(−4)²−4·1·4=16−16=0 → **兩個相等實根**（重根）。
  佐證：x²−4x+4=(x−2)²=0，確實只得 x=2 一個值（重根），與 Δ=0 相符。
- (b) a=2、b=−3、c=5。Δ=(−3)²−4·2·5=9−40=−31<0 → **沒有實數根**。
  佐證：2x²−3x+5 的頂點值 = c−b²/(4a)=5−9/8=31/8>0，開口向上而最低點在 x 軸上方，
  故圖像不與 x 軸相交，無實根，與 Δ<0 相符。
- **文件答案：(a) 兩個相等實根　(b) 沒有實數根 — 一致。**

3．用公式法解 x²−6x+2=0（答案化到最簡）。

- a=1、b=−6、c=2。Δ=(−6)²−4·1·2=36−8=28>0，兩相異實根。
- x=(−b±√Δ)/(2a)=(6±√28)/2。√28=√(4·7)=2√7，故 x=(6±2√7)/2=3±√7。
- 檢核（近似值）：√7≈2.6458，x≈5.6458 或 0.3542。
  代 x≈0.3542：0.3542²−6·0.3542+2≈0.1255−2.1252+2≈0.0003≈0 ✔。
  代 x≈5.6458：5.6458²−6·5.6458+2≈31.875−33.875+2=0 ✔。
- 韋達定理佐證：兩根之和 =(3+√7)+(3−√7)=6=−b/a ✔；
  兩根之積 =(3+√7)(3−√7)=9−7=2=c/a ✔。
- **文件答案：x=3±√7 — 一致。**

4．方程 x²+6x+k=0。（a）k 為何值時有兩個相等實根？（b）k 在甚麼範圍時有兩個相異實根？

- a=1、b=6、c=k。Δ=6²−4·1·k=36−4k。
- (a) 兩相等實根 ⇔ Δ=0 ⇔ 36−4k=0 ⇔ k=9。
  佐證：k=9 時 x²+6x+9=(x+3)²=0，x=−3 重根 ✔。
- (b) 兩相異實根 ⇔ Δ>0 ⇔ 36−4k>0 ⇔ 4k<36 ⇔ k<9。
  佐證：取 k=0 → x²+6x=0 → x(x+6)=0 → x=0、−6，兩相異實根 ✔（0<9，符合範圍）。
  邊界檢核：k=9 剛好相等（不算相異，故用嚴格 <）✔。
- **文件答案：(a) k=9　(b) k<9 — 一致。**

5．解二次不等式：（a）x²−x−6≤0　（b）x²−x−6>0。（提示：先求根，再看拋物線）

- 先解對應方程：x²−x−6=(x−3)(x+2)=0 → 兩根 x=−2、x=3（−2<3）。
  x² 的係數為正 → 拋物線開口向上；兩根之間圖像在 x 軸下方（值為負），
  兩根外側在 x 軸上方（值為正）。
- (a) 要 ≤0（負或零）→ 取兩根之間，含端點：−2≤x≤3。
  檢核：x=0 → 0−0−6=−6≤0 ✔（0 在 [−2,3] 內）；
  x=4 → 16−4−6=6，不 ≤0 ✔（4 在區間外）；端點 x=3 → 9−3−6=0≤0 ✔。
- (b) 要 >0（正，不含零）→ 取兩根外側，不含端點：x<−2 或 x>3。
  檢核：x=4 → 6>0 ✔；x=−3 → 9+3−6=6>0 ✔；x=0 → −6，不 >0 ✔（0 不在解集）。
- 兩小問互補檢核：(a) 的解 [−2,3] 與 (b) 的解 (−∞,−2)∪(3,∞) 恰好以兩根為界、
  併起來是整條實數線且只在端點 −2、3 重疊（因 (a) 含等號、(b) 不含），劃分正確 ✔。
- **文件答案：(a) −2≤x≤3　(b) x<−2 或 x>3 — 一致。**

6．（找錯題）某同學解 −x²+4x−3≥0 如下，圈出錯在哪一步、改正，並寫出正確解集：
　　「兩邊乘 −1：x²−4x+3≥0；因式分解 (x−1)(x−3)≥0；取兩邊：x≤1 或 x≥3。」

- 分歧步驟＝第一步。兩邊乘（或除以）**負數**，不等號必須**轉向**：
  −x²+4x−3≥0 兩邊乘 −1 應得 x²−4x+3**≤**0（把 ≥ 轉成 ≤），該同學漏了轉向。
- 改正後：x²−4x+3≤0 → (x−1)(x−3)≤0 → 兩根 1、3，開口向上，取兩根之間（含端點）
  → **1≤x≤3**。
- 檢核（回代原式 −x²+4x−3≥0，不碰乘 −1）：
  x=2 → −4+8−3=1≥0 ✔（2 在 [1,3] 內）；
  x=0 → −3，不 ≥0 ✔（0 在解集外）；
  端點 x=1 → −1+4−3=0≥0 ✔；x=3 → −9+12−3=0≥0 ✔。
  該同學的錯答「x≤1 或 x≥3」會把 x=0 判為解，但 x=0 令原式 =−3<0，可見其錯 ✔。
- **文件答案：錯在第一步（乘 −1 沒有把 ≥ 轉成 ≤）；正確解集 1≤x≤3 — 一致。**

## 講義範例

範例A・因式分解解方程：（a）x²−5x+6=0　（b）2x²+3x−2=0。

- (a) 積 6、和 5 → 2 與 3：(x−2)(x−3)=0 → x=2 或 x=3。
  驗根：2²−5·2+6=0 ✔；3²−5·3+6=0 ✔。
- (b) 首項係數不是 1，用十字交乘：2x²+3x−2=(2x−1)(x+2)。
  展開檢查：(2x−1)(x+2)=2x²+4x−x−2=2x²+3x−2 ✔。
  令每個括號為 0：2x−1=0 → x=1/2；x+2=0 → x=−2。
  驗根：2·(1/2)²+3·(1/2)−2=2·(1/4)+3/2−2=1/2+3/2−2=0 ✔；
  2·(−2)²+3·(−2)−2=8−6−2=0 ✔。
- **文件答案：(a) x=2 或 x=3　(b) x=1/2 或 x=−2 — 一致。**

範例B・公式法：解 x²−4x+1=0。

- a=1、b=−4、c=1。Δ=(−4)²−4·1·1=16−4=12>0。
- x=(4±√12)/2；√12=2√3，故 x=(4±2√3)/2=2±√3。
- 檢核（近似值）：√3≈1.7321，x≈3.7321 或 0.2679。
  代 x≈0.2679：0.2679²−4·0.2679+1≈0.0718−1.0718+1≈0 ✔。
- 韋達佐證：和 =(2+√3)+(2−√3)=4=−b/a ✔；積 =(2+√3)(2−√3)=4−3=1=c/a ✔。
- **文件答案：x=2±√3 — 一致。**

範例C・判別式判根：（a）x²−6x+9=0　（b）2x²−3x+4=0　（c）求 k 使 x²+kx+4=0 有兩個相等實根。

- (a) Δ=(−6)²−4·1·9=36−36=0 → 兩個相等實根。佐證：(x−3)²=0，x=3 重根 ✔。
- (b) Δ=(−3)²−4·2·4=9−32=−23<0 → 沒有實數根。
- (c) 兩相等實根 ⇔ Δ=0：Δ=k²−4·1·4=k²−16=0 → k²=16 → k=4 或 k=−4（**兩個值都要寫**）。
  佐證：k=4 → x²+4x+4=(x+2)²，重根 ✔；k=−4 → x²−4x+4=(x−2)²，重根 ✔。
- **文件答案：(a) 兩個相等實根　(b) 沒有實數根　(c) k=4 或 k=−4 — 一致。**

範例D・二次不等式（符號線示範）：解 x²−2x−3>0，並順帶寫出 x²−2x−3≤0 的解。

- 求根：x²−2x−3=(x−3)(x+1)=0 → 兩根 x=−1、x=3。x² 係數為正 → 開口向上。
- x²−2x−3>0：取兩根外側 → x<−1 或 x>3。
- x²−2x−3≤0：取兩根之間（含端點）→ −1≤x≤3。
- 檢核：x=0 → 0−0−3=−3。−3<0，故 x=0 屬 ≤0 的解（0 在 [−1,3] 內）✔，
  且不屬 >0 的解 ✔；x=4 → 16−8−3=5>0，屬 >0 的解（4 在兩根外側）✔。
- **文件答案：>0 的解 x<−1 或 x>3；≤0 的解 −1≤x≤3 — 一致。**

## 驗算結論

練習 6 題（合共 11 個小問）＋ 講義 4 個範例（合共 9 個小問），全部重算一次，
與文件所載答案 **100% 一致**（QB-V2）。

三種檢核方式全部用過：
1. **回代驗根／回代驗解**——每一條方程的根都代回原式確認為 0（練習 1、3，範例 A、B）；
   每一個不等式解集都代「區間內一個數＋區間外一個數＋端點」三種點確認（練習 5、6，範例 D），
   單代一個數有機會碰巧吻合，代三種點才排除得了取錯區間或漏端點。
2. **獨立第二法佐證**——公式法的根用韋達定理（和 =−b/a、積 =c/a）另行核對（練習 3、範例 B）；
   判別式的結論用「配方成完全平方」或「頂點值的正負」獨立佐證（練習 2、範例 C）。
3. **互補性檢核**——練習 5 的 (a)≤0 與 (b)>0 兩個解集必須以兩根為界互補，
   併起來覆蓋整條實數線且只在端點重疊，用這一點反查有沒有取錯區間。

數字挑選原則（依 design-checklist.md §B「計算障礙：不要讓答案不乾淨」）：

- **因式分解題**：兩根都取小整數，積與和一眼湊得出（10=2×5、6=2×3、−8=−2×… 等），
  不必試除；平方差題（x²−9）示範最快的一種分解。
- **判別式題**：刻意各放一個 Δ=0（完全平方）、一個 Δ<0（明顯負數），
  讓「相等／無根」兩種結論都出場；求參數題的 k 取到乾淨整數（k=9、k=±4）。
- **公式法題**：判別式取非完全平方但可化簡（28=4×7、12=4×3），
  答案是乾淨的 3±√7、2±√3，示範「根號要化到最簡」而不是留一堆小數。
- **二次不等式題**：兩根都取小整數（−2、3；−1、3；1、3），開口一律向上，
  好讓「大於取兩邊、小於取中間」這條規則看得最清楚；
  第 6 題刻意設計成「乘 −1 沒轉向」這個 D14 高頻錯，錯答會把區間外的點誤判為解，一驗即現形。
- 全部 20 個小問的答案，除了必然帶根號的無理根之外，**沒有任何小數**。
