一、這一課要做到的事
這一課把一元二次的兩件事一次收齊：把方程解出來（求根），以及不解出根也能判斷「有幾個實根」（判別式）；再進一步，把「等於 0」換成「大於 0／小於 0」，就是二次不等式。三件事共用同一個起手式——先把式子整理成「一邊是 0」的標準式 \(ax^2+bx+c=0\)。
和前兩課一樣，本課是多步驟的程序運算，所以主工具仍然是手順卡：三張卡分別管解方程、判別式、解不等式，每一步下面都標了那一步最容易錯的地方（※）。
但本課多了一個前兩課沒有的難點：二次不等式。多數人不是解不出根，而是求了兩根之後，不知道答案應該「取哪一段」——這不是算術問題，是看圖的問題。所以本課加一個圖文雙軌：左邊畫拋物線與符號線，右邊寫對應的代數判斷，把「要取哪一段」由背口訣變成看得見的圖。
最後把兩個每年都有人中招的錯法挑出來正誤對照：一個是把不等式當方程解、答成兩個點；一個是兩邊乘負數卻忘了把不等號轉向。看清楚這兩步分歧在哪裡，比多做十題更有用。
二、三張手順卡
三種題型的起手式相同（先化成一邊為 0），但接下來的動作不同。做題時先認出這是哪一種，再把對應那一張卡放在旁邊，用手指指住正在做的那一步。
手順卡一・解一元二次方程
什麼時候用：題目是 \(ax^2+bx+c=0\) 這種、要你「解方程」或「求 x」。
1. 先整理成標準式：一邊是 0，\(ax^2+bx+c=0\)。※ 移項要變號；不要兩邊直接除以 x——那樣會把 \(x=0\) 這個根丟掉。
2. 試因式分解：能分解成 \((px+q)(rx+s)=0\) 就令每個括號分別為 0。※ 兩個括號各給一個根，不要只解一個。\(x^2=9\) 要寫成 \((x-3)(x+3)=0\)，得 \(x=3\) 和 \(x=-3\)，不是只有 \(x=3\)。
3. 分解不到就用公式法 \(x=\frac{-b \pm \sqrt{b^2-4ac}}{2a}\)。※ 先算 \(b^2-4ac\)；\(-b\) 的負號不要漏；整條式子的分母是 \(2a\)，不是 \(a\)。
（教師）褪除：完整三步卡 → 只留關鍵詞（標準式、試分解、公式法）→ 只留「先化成一邊為 0」→ 完全移除。
手順卡二・判別式判根
什麼時候用：題目問「根的情況」「有沒有實根／有幾個實根」「k 為何值時有兩相等根」，但不要求你把根解出來。
1. 化成標準式，抄出 \(a\)、\(b\)、\(c\)（連正負號一起抄）。※ \(c\) 是常數項，符號要跟著抄；\(b\) 是一次項係數。
2. 算判別式 \(\Delta =b^2-4ac\)。※ \(b^2\) 一定是非負的（負數平方也變正）；\(-4ac\) 的正負看 \(ac\) 的乘積。
3. 看 Δ 的正負零：\(\Delta \gt 0\) 兩相異實根；\(\Delta =0\) 兩相等實根（重根）；\(\Delta \lt 0\) 無實根。※ \(\Delta =0\) 是「兩個相等」不是「沒有根」——它有一個重根，別答成無解。
（教師）褪除：完整三步卡 → 只留一句「\(\Delta =b^2-4ac\)，正兩根、零重根、負無根」→ 完全移除。
手順卡三・解二次不等式
什麼時候用：題目是 \(ax^2+bx+c \gt 0\)（或 \( \lt 0\)、\( \ge 0\)、\( \le 0\)）這種、要你求 x 的範圍。
1. 整理成一邊為 0，並讓 \(x^2\) 的係數是正的（若為負，兩邊乘 −1）。※ 兩邊乘或除以負數，不等號一定要轉向（> 變 <、≥ 變 ≤）——這是本課最高頻的錯。
2. 把它先當等式，解出兩根 \(r_1 \lt r_2\)（用因式分解或公式法）。※ 先求根才畫得出線；求不到實根時（\(\Delta \lt 0\)）另作判斷，本課題目都有實根。
3. 畫開口向上的拋物線／符號線，按不等號取區間。※ 口訣（開口向上時）：大於取兩邊、小於取中間。> / < 端點空心，≥ / ≤ 端點實心。
（教師）褪除：完整三步卡 → 只留口訣「大於取兩邊、小於取中間」→ 只留「先求根、再看拋物線」→ 完全移除。
三、範例A・因式分解解方程
【範例A・因式分解解方程】解下列方程：（a）\(x^2-5x+6=0\)　（b）\(2x^2+3x-2=0\)。
（a）第 1 步（標準式）：已經是 \(x^2-5x+6=0\)，一邊為 0，可直接分解。
（a）第 2 步（分解）：找兩數之積 6、之和 5 → 2 與 3，所以 \(x^2-5x+6=(x-2)(x-3)\)。令 \((x-2)(x-3)=0\) → \(x=2\) 或 \(x=3\)。
（b）首項係數不是 1，用十字交乘：\(2x^2+3x-2=(2x-1)(x+2)\)（展開檢查 \((2x-1)(x+2)=2x^2+4x-x-2=2x^2+3x-2\)，正確）。
（b）令每個括號為 0：\(2x-1=0\) → \(x=\frac{1}{2}\)；\(x+2=0\) → \(x=-2\)。
檢核：把 \(x=2\)、\(x=3\) 代回 (a) 都得 0；把 \(x=\frac{1}{2}\)、\(x=-2\) 代回 (b) 都得 0。
※ 令括號為 0 這一步，兩個括號各給一個根，一定有兩個答案（除非兩個括號相同，那才是重根）。只寫一個 \(x=2\) 是漏根。
四、範例B・公式法：先算判別式，根號化到最簡
【範例B・公式法】解 \(x^2-4x+1=0\)（分解不到，用公式法）。
第 1 步（抄係數）：\(a=1\)、\(b=-4\)、\(c=1\)。
第 2 步（判別式）：\(\Delta =b^2-4ac=(-4)^2-4 \times 1 \times 1=16-4=12\)，大於 0，有兩相異實根。
第 3 步（代公式）：\(x=\frac{-b \pm \sqrt{\Delta }}{2a}=\frac{4 \pm \sqrt{12}}{2}\)。把 \(\sqrt{12}\) 化到最簡：\(\sqrt{12}=\sqrt{4 \times 3}=2\sqrt{3}\)。
第 4 步（約簡）：\(x=\frac{4 \pm 2\sqrt{3}}{2}=2 \pm \sqrt{3}\)（分子兩項都要除以 2）。
所以 \(x=2+\sqrt{3}\) 或 \(x=2-\sqrt{3}\)。
檢核（韋達定理）：兩根之和 \(=(2+\sqrt{3})+(2-\sqrt{3})=4\)，等於 \(\frac{-b}{a}=4\)；兩根之積 \(=(2+\sqrt{3})(2-\sqrt{3})=4-3=1\)，等於 \(\frac{c}{a}=1\)——相符。
※ \(-b\) 的負號最容易漏：\(b=-4\)，所以 \(-b=4\)，不是 \(-4\)。還有 \(\sqrt{12}\) 一定要化成 \(2\sqrt{3}\)，再與分母的 2 約簡；停在 \(\frac{4 \pm \sqrt{12}}{2}\) 不算做完。
五、範例C・判別式判根：只看 Δ 的正負零
【範例C・判別式判根】不必解出根，只判斷根的情況：（a）\(x^2-6x+9=0\)　（b）\(2x^2-3x+4=0\)　（c）\(x^2+kx+4=0\) 有兩個相等實根，求 k。
（a）\(a=1\)、\(b=-6\)、\(c=9\)。\(\Delta =(-6)^2-4 \times 1 \times 9=36-36=0\) → 兩個相等實根。（其實 \(x^2-6x+9=(x-3)^2\)，只有 \(x=3\) 一個重根，與 \(\Delta =0\) 相符。）
（b）\(a=2\)、\(b=-3\)、\(c=4\)。\(\Delta =(-3)^2-4 \times 2 \times 4=9-32=-23 \lt 0\) → 沒有實數根。
（c）「兩個相等實根」即 \(\Delta =0\)：\(\Delta =k^2-4 \times 1 \times 4=k^2-16=0\) → \(k^2=16\) → \(k=4\) 或 \(k=-4\)（兩個值都要寫）。
檢核（c）：\(k=4\) 時 \(x^2+4x+4=(x+2)^2\)，是重根；\(k=-4\) 時 \(x^2-4x+4=(x-2)^2\)，也是重根——兩個都符合。
※ 判別式題只看 Δ 的正負零，不必真的把根解出來。求參數的題（c）常見漏了一個解——\(k^2=16\) 有 \(k=4\) 和 \(k=-4\) 兩個。
六、範例D・二次不等式：用符號線看要取哪一段
【範例D・二次不等式】用符號線解 \(x^2-2x-3 \gt 0\)，並順帶寫出 \(x^2-2x-3 \le 0\) 的解。
把三步對照下面的「拋物線／符號線」看：左邊每一格是圖上發生的事，右邊是同一步在算式上怎樣寫。
拋物線／符號線（看得見）代數上怎樣判斷（寫得出）
第 1 步（求根）：解 \(x^2-2x-3=0\) → \((x-3)(x+1)=0\) → 兩根 \(x=-1\)、\(x=3\)。\(x^2\) 的係數是正的，所以拋物線開口向上。
第 2 步（看正負）：開口向上時，兩根之間落在 x 軸下方（值為負，標 −）；兩根外側落在 x 軸上方（值為正，標 ＋）。
第 3 步（取區間）：要 \(x^2-2x-3 \gt 0\)（正），就取兩個 ＋ 的部分＝兩根外側，得 \(x \lt -1\) 或 \(x \gt 3\)。若改問 \(x^2-2x-3 \le 0\)，就取中間那一段：\(-1 \le x \le 3\)。
※ 「大於取兩邊、小於取中間」只在開口向上（\(x^2\) 係數為正）時成立。若係數是負的，先照手順卡三第 1 步兩邊乘 −1（記得轉向）變成正的再用這口訣。另外：> / < 用空心點（不含端點），≥ / ≤ 用實心點（含端點）。
七、最容易錯的兩步（正誤對照）
下面兩個錯法每年都有人中招。左欄是「很多人會這樣寫」，右欄是正確寫法，兩欄同一列對齊，只有一步不同——看清楚那一步。
錯法一・把不等式當方程解（答成兩個點）
解 \(x^2-x-6 \gt 0\)。
常見寫法（很多人會這樣）正確寫法
因式分解 \((x-3)(x+2) \gt 0\)，求出 \(x=3\)、\(x=-2\)。因式分解求根：\(x=-2\)、\(x=3\)（兩根，開口向上）。
答：\(x=3\) 或 \(x=-2\)。答：取兩根外側 \(x \lt -2\) 或 \(x \gt 3\)。
※ 差在這裡：不等式問的是「哪些 x 使式子 \( \gt 0\)」，答案是一段範圍，不是兩個點。兩個根只是分界線，真正的解在兩根的外側（開口向上、要正）。
錯法二・兩邊乘負數，不等號沒有轉向
解 \(-x^2+4x-3 \ge 0\)。
常見寫法（很多人會這樣）正確寫法
兩邊乘 −1：\(x^2-4x+3 \ge 0\)（不等號照抄）。兩邊乘 −1，不等號轉向：\(x^2-4x+3 \le 0\)。
\((x-1)(x-3) \ge 0\) → \(x \le 1\) 或 \(x \ge 3\)。\((x-1)(x-3) \le 0\) → 取中間 \(1 \le x \le 3\)。
※ 差在這裡：兩邊乘或除以負數，不等號一定要轉向（\( \ge \) 變 \( \le \)）。這一步錯，後面全部跟着錯，而且很難查出來。
