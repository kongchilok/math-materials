## A. 先做兩個判斷

### A-1. 簡報服務對象
- **共融全班簡報**（預設）：全班同一份 deck，融合生靠「分層任務頁＋視覺鷹架＋節奏設計」跟上，不做標籤化的「特製版」。
- **抽離小組簡報**（資源班／課後輔導）：頁數更少、步子更小、CRA 比重更高、每頁字量再減半、練習即時穿插。

### A-2. 調整支援 vs 課程剪裁（與 inclusive-math-worksheet-generator 同一套判準）
- 全班同一份 deck＋分層任務 ＝ **Accommodation**（內容與年級標準不變，只改接觸方式）。
- 抽離版若刪減概念、降低標準 ＝ **Modification**，須在簡報備註頁標示「本簡報為課程剪裁版」，方便記入 IEP。

## B. 障別 × 簡報設計對照表

| 障別（筆記出處） | 簡報上要做的事 |
|---|---|
| 讀寫障礙（②1.4/1.7） | 每頁字量壓到最低、關鍵字**加粗**、數字與符號留足間距（6/9、＋/× 易混）、運算順序做成步驟卡頁、多感官＋小步驟＋重複練習、圖像先行文字在後 |
| ADHD（②2.6/2.7） | 10–15 分鐘一個轉換點、指令頁一次只給一個步驟、用字正面淺白（說「要做什麼」不說「不要做什麼」）、解題六步提示卡（讀題→找關鍵字→列式→計算→檢查運算→檢查單位）、視覺提示固定同一位置 |
| ASD（②7.2/7.4） | 開場放「今日課堂流程預告頁」、轉換活動前一頁先預告、全簡報版型高度一致（可預測性）、指令明確不含糊、比喻必須解釋、可用學生特殊興趣包裝情境題 |
| 計算障礙（③4.1） | 顏色編碼標示可移動／組合的數字與變數（如分配律）、運算過程分步出現（動畫或拆頁）而非一次呈現完成式 |
| 臨界智能／智力障礙（②3.3–3.4、③4.5） | 小步子細分內容、圖表＋手勢輔助講解、新知連結生活經驗、多安排成功展示機會 |
| 感官障礙（②4A/4B） | 聽障：關鍵口述內容文字化上投影片、影片加字幕；視障：字級再放大、高對比、圖形另備口頭描述 |

| 數學焦慮（③4.6） | 入口放保底成功經驗頁（人人做得起的低門檻題）、asset-based 用語、避免倒數計時等壓力視覺 |

## C. 六類通用策略（③4.7，一次設計照顧多種需求）

| 通用策略 | 覆蓋的需求類型 |
|---|---|
| 明確指令法＋步驟拆解（chunking） | 計算障礙、ADHD、臨界智能 |
| 視覺化與具體表徵（CRA/CPA） | 讀寫障礙、計算障礙、ASD、臨界智能（最常見） |
| 降低文字／語言負荷、詞彙鷹架 | 讀寫障礙、ADHD、臨界智能、ASD |
| 版面乾淨、減少視覺雜訊 | 計算障礙、ADHD、ASD |
| 情境連結與個人興趣融入 | ASD（動機）、數學焦慮 |
| 可預期的結構化流程＋正向課堂文化 | ADHD、ASD（TEACCH 視覺化）、數學焦慮 |

**簡報實作口訣：圖像先行、文字精簡、步驟編號、留白充足、版型固定、節奏分段。**

## D. 簡報版面硬規則（BDA 失讀症友善標準・簡報適配版）

> 講義用 12–14pt；簡報投影距離遠，全面放大。此表**覆蓋**一般簡報技能的自由發揮空間，屬硬規則。

- 字型：無襯線黑體（微軟正黑體／思源黑體）；不用標楷體、斜體、底線、藝術字
- 字級：內文 ≥ 20pt，標題 ≥ 32pt
- 每頁內文 ≤ 5 行、每行 ≤ 18 個中文字；裝不下就拆頁（一頁一重點本來就是 SOIL 鐵律）
- 行距 1.3–1.5 倍
- 淺色底（米白／淺灰）配深色字，不用純白底；深色頁（封面／行動頁）用高對比白字
- 左對齊，不用兩端對齊（齊行會產生不規則字距）
- 難度／層次只用星星（★☆☆／★★☆／★★★）標示，不用顏色區分（色盲友善、黑白列印可辨）
- 不以紅綠對比傳達語意；整體配色需色盲安全
- 關鍵字強調用「加粗＋淺色塊底」，不用底線與斜體
- 圖示緊鄰對應文字／算式，不隔欄遙相呼應

## E. CRA 三階頁（數學概念頁的預設結構，①2.1）

- **具體頁**：實物／操作情境的照片或示意圖（代數磚、天平、錢幣、摺紙）
- **表徵頁**：線段圖／面積模型／天平圖（幾何圖可呼叫 jh-math-geometry 技能）
- **抽象頁**：符號算式登場，但角落保留前一階段的縮圖（並列呈現，不完全抽離視覺線索）
- 中學可整合式：同一頁三欄並列（具體｜表徵｜抽象），互相對應箭頭連結
- 每一階都要走「示範 → 引導 → 學生做」（明示教學，不是讓學生自己摸索）

## F. 分層任務頁（行動頁的融合版，③3.2/3.5）

- 三層**同一頁**呈現、全班同時發，學生自選或按晉級標準往上走，不由教師點名分派（減少標籤化）
- 練習 A ★☆☆（具體情境／半成品鷹架）／練習 B ★★☆（課本標準難度）／練習 C ★★★（開放式／一題多解）
- 三層同源同概念，只調鷹架與抽象程度，不偷換核心目標
- Low floor, high ceiling：入口人人做得起，天花板夠 2E 學生發揮

## G. 注意力節奏（②2.2 專注力長度表）

- 中學生連續專注參考上限約 **20 分鐘** → 45 分鐘一節課至少 2–3 個轉換點
- 轉換點頁型：操作活動頁／討論頁／分層任務頁／動態休息頁（伸展 30 秒）
- 轉換前一頁要有預告（ASD 需要）：「再 1 頁就進入練習」
- 長講解拆成「短講解＋立即操作」交替，不連續超過 3 頁純講述
