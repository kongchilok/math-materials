## 逐題重算

| 題 | 題型 | 題目 | 卷上答案 | 重算過程 | 一致？ |
|---|---|---|---|---|---|
| 1 | 基礎 | `3/(x−4)=2/x` 的限制條件 | C（`x≠0` 且 `x≠4`） | 兩條分母分別是 `x−4` 與 `x`，兩者都不可為 0 → `x≠4` 且 `x≠0` | ✓ |
| 2 | 基礎 | 解 `5/x=x−4` | `x₁=5` 或 `x₂=−1` | 限制 `x≠0`；乘 x：`5=x(x−4)` → `x²−4x−5=0` → `(x−5)(x+1)=0` → `x₁=5` 或 `x₂=−1`；兩根皆 ≠0 | ✓ |
| 3 | 基礎 | 解 `√(x+4)=x−2` | `x=5` | 平方：`x+4=x²−4x+4` → `x²−5x=0` → `x(x−5)=0` → `x=0` 或 `x=5`；驗根捨 0 | ✓ |
| 4 | 常見錯誤糾正 | 小明解 `3/(x−2)=(x+1)/(x−2)` 答 `x=2` | 增根，捨去；原方程無解 | 乘 `(x−2)`：`3=x+1` → `x=2`；`x=2` 令分母 `x−2=0`，分式無意義 → 增根 → 無解 | ✓ |
| 5 | 常見錯誤糾正 | 小芳解 `√(x+5)=x−1` 答兩根 | 漏驗根；正確 `x=4` | 平方：`x+5=x²−2x+1` → `x²−3x−4=0` → `(x−4)(x+1)=0` → `x₁=4` 或 `x₂=−1`；驗根捨 −1 | ✓ |

## 驗根（一律代回原方程）

| 題 | 代回驗證 |
|---|---|
| 2 | `x=5`：左 `=5/5=1`，右 `=5−4=1` ✓ 保留｜`x=−1`：左 `=5/(−1)=−5`，右 `=−1−4=−5` ✓ 保留。兩根皆 ≠0，不觸分母限制。 |
| 3 | `x=0`：左 `=√(0+4)=√4=2`，右 `=0−2=−2`，`2≠−2` ✗ **捨去**｜`x=5`：左 `=√(5+4)=√9=3`，右 `=5−2=3` ✓ **保留** |
| 4 | `x=2` 代回原方程：兩邊分母皆為 `2−2=0`，分式沒有意義，故 `x=2` 不是原方程的解。去分母後的一次方程再無其他解 → **原方程無解** ✓ |
| 5 | `x=4`：左 `=√(4+5)=√9=3`，右 `=4−1=3` ✓ 保留｜`x=−1`：左 `=√(−1+5)=√4=2`，右 `=−1−1=−2`，`2≠−2` ✗ **捨去** |
