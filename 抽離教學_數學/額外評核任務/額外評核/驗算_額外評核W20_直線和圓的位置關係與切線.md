## 逐題重算

| 題 | 題型 | 題目 | 卷上答案 | 重算過程 | 一致？ |
|---|---|---|---|---|---|
| 1 | 基礎 | `r=6`、`d=6`，直線與圓的關係 | B（相切，1 個公共點） | 判準 `d=r` → 相切，1 個公共點（切點） | ✓ |
| 2 | 基礎 | `r=5`；`d=2` 與 `d=9` 各是什麼關係、幾個公共點 | 相交 2 個；相離 0 個 | `d=2<r=5` → 相交（2 點）；`d=9>r=5` → 相離（0 點） | ✓ |
| 3 | 基礎 | PA 切 `⊙O` 於 A，`OA=9`、`PA=12`，求 `OP` | `OP=15` | 切線⊥過切點半徑 → `∠OAP=90°`；`OP²=OA²+PA²=81+144=225` → `OP=15` | ✓ |
| 4 | 常見錯誤糾正 | `r=4`、`d=3`，小明答「相離」 | 大小關係看反；正確相交，2 個公共點 | `d=3<r=4` → 相交，2 個公共點 | ✓ |
| 5 | 常見錯誤糾正 | 小芳說 `∠OPA=90°` | 直角在切點 → `∠OAP=90°`；`PA=12` | `OP` 為斜邊：`PA²=OP²−OA²=169−25=144` → `PA=12` | ✓ |

## 代回／獨立核對

| 題 | 核對 |
|---|---|
| 1 | `d=r` 時圓心到直線距離恰等於半徑，垂足即唯一公共點（切點），再無其他交點 ✓ |
| 2 | `d=2` 時弦長 `=2√(r²−d²)=2√21>0` → 確有兩個交點 ✓；`d=9` 時 `r²−d²=25−81<0`，無實數解 → 0 個交點 ✓（此式僅用於本檔內部核對，不出現在交付檔） |
| 3 | 勾股逆驗：`9²+12²=81+144=225=15²` ✓。`9–12–15` 為 `3–4–5` 的 3 倍 ✓ |
| 4 | `d=3<r=4`：弦長 `=2√(16−9)=2√7≈5.29>0` → 確為相交 ✓ |
| 5 | 勾股逆驗：`5²+12²=25+144=169=13²` ✓。`5–12–13` 為常用勾股數組 ✓ |

## 結論

5 題全部逐題重算，兩題勾股計算均以逆向平方和核對
（`9²+12²=15²`、`5²+12²=13²`），位置關係題另以弦長公式 `2√(r²−d²)` 在本檔內部驗證
（該式不出現在交付檔）。**與卷上答案完全一致，無數學錯誤**。
第 1 題三個誘答全部對應真實學生錯誤。
第 3 與第 5 題刻意設計成「求斜邊／求直角邊」的對照組：
認錯直角位置的學生會在兩題用同一條加法算式，批改時一眼可辨，這是本卷的診斷設計重點。
