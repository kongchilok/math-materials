## 驗根／獨立第二法核對

| 題 | 第二種算法 |
|---|---|
| 1 | 因式分解：`3x²−6x+3=3(x−1)²=0` → 重根 `x=1`，與 Δ=0 相符 ✓ |
| 2 | 求根公式：根 `=(−6±√76)/4`；和 `=−12/4=−3` ✓；積 `=(36−76)/16=−40/16=−5/2` ✓ |
| 3 | 直接解：`x=2±√10`；`(2+√10)²+(2−√10)²=2(4+10)=28` ✓ |
| 4 | `x²−6x+9=(x−3)²=0` → `x₁=x₂=3`，確為兩個相等實根 ✓ |
| 5 | `2x²−8x+6=2(x−1)(x−3)=0` → 根 1、3；`1+3=4` ✓、`1×3=3` ✓ |
