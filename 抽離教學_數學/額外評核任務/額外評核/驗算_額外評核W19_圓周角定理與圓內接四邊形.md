| 題 | 題型 | 題目 | 卷上答案 | 重算過程 | 一致？ |

| 1 | 基礎 | `∠AOB=110°`（圓心角），求同弧圓周角 `∠ACB` | A（55°） | 圓周角定理：圓周角＝同弧圓心角的一半 → `110÷2=55°` | ✓ |
| 2 | 基礎（逆向＋推論） | `∠ACB=28°` 求 `∠AOB`；AB 為直徑時 `∠ACB=`？ | 56°；90° | 圓心角＝圓周角 ×2 → `28×2=56°`；直徑所對圓周角為直角 → 90° | ✓ |
| 3 | 基礎 | 圓內接四邊形 `∠A=85°`、`∠B=105°`，求 `∠C`、`∠D` | `∠C=95°`、`∠D=75°` | 對角互補：`∠C=180−85=95°`；`∠D=180−105=75°` | ✓ |

| 5 | 常見錯誤糾正 | AB 為直徑、`∠A=35°`，小芳答 `∠ACB=35°` | `∠ACB=90°`；`∠ABC=55°` | 直徑所對圓周角恆為 90°，與 `∠A` 無關 → `∠ACB=90°`；三角形內角和 → `∠ABC=180−90−35=55°` | ✓ |

## 代回／獨立核對

| 題 | 核對 |
|---|---|
| 1 | 反向：`55×2=110°` ＝ 原圓心角 ✓ |
| 2 | 前半反向：`56÷2=28°` ✓。後半用定理本身核對：直徑所對圓心角為平角 180°，`180÷2=90°` ✓ 與推論一致 |
| 3 | 四邊形內角和核對：`85+105+95+75=360°` ✓（對角互補兩組必然湊成 360°） |
| 4 | 若照小明的 `∠A+∠B=180°`，則 `∠B=110°`，再由對角互補得 `∠D=70°`、`∠C=110°`，四角和 `70+110+110+70=360°` 亦成立——**故不能靠內角和否證，必須靠「對角」的位置關係**。教師卷已明寫「`∠B` 要另外給條件才求得到」，避免學生誤以為任意兩角都能互推 |
| 5 | 三角形內角和核對：`90+35+55=180°` ✓。另：`∠A=35°` 為圓周角，其所對弧的圓心角為 70°，與 `∠ACB=90°` 所對的直徑（圓心角 180°）互不相干，確認兩者無關 ✓ |
