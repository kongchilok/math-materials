## 代回／獨立核對

| 題 | 核對 |
|---|---|
| 1 | 代 `x=3`：`y=−(0)²+7=7`；代 `x=2`：`y=−1+7=6<7`；代 `x=4`：`y=−1+7=6<7` → 確為最大值 ✓ |
| 2 | 展開回原式：`−(x−7)²+49=−(x²−14x+49)+49=−x²+14x=x(14−x)` ✓。逐點試算：`x=6`→`6×8=48`；`x=7`→`7×7=49`；`x=8`→`8×6=48`。49 為最大 ✓（正方形時面積最大，與講義 §二 結論一致） |
| 3 | 旋轉為保距變換（等距同構）：`OA′=OA=7`、`OB′=OB=4` ✓；`∠AOA′=∠BOB′=` 旋轉角 `=60°` ✓ |
| 4 | 代 `x=4`：`y=2(0)²+3=3`；代 `x=5`：`y=2(1)²+3=5>3`；代 `x=3`：`y=2(1)²+3=5>3` → 最小值確為 3 ✓ |
| 5 | 另法：12:00 到 12:15 分針走了一圈的四分之一，`360÷4=90°` ✓ 與 `15×6=90°` 相符 |
