## 二、逐題驗算

### 1（原①）判別一元二次方程　答：A
- A `x² + 5x − 1 = 0`：整式、一個未知數、最高次數 2 → 是。
- B `1/x² = 1`：分母含 x → 分式方程。
- C `y² + 2x = 1`：含 x、y 兩個未知數。
- D `2x + b = 0`：關於 x 是一元一次方程。

### 2（原④）`x² − 6x − 2 = 0` 的二次項係數／一次項係數／常數項　答：B
a = 1，b = −6，c = −2 → `1，−6，−2`。

### 3（原②）`4x² + x = 5` 化一般式後的 a、b、c　答：C
移項：`4x² + x − 5 = 0` → a = 4，b = 1，c = −5。

### 4（原③）`x² + kx − 6 = 0` 一根為 2，求 k　答：B
代入：`(2)² + 2k − 6 = 0` → `4 + 2k − 6 = 0` → `2k = 2` → **k = 1**。

### 5（原⑧）`x² − x + m = 0` 一解為 x = 2，求 m　答：m = −2
代入：`(2)² − (2) + m = 0` → `2 + m = 0` → **m = −2**。
回代檢查：`x² − x − 2 = 0` → `(x − 2)(x + 1) = 0` → x = 2 或 x = −1，x = 2 確為一根 ✓

### 6（原⑦）`x² + 6x = 1` 配方，兩邊應同加　答：B
一次項係數 6 的一半再平方：`(6 ÷ 2)² = 9`。
檢查：`x² + 6x + 9 = 1 + 9` → `(x + 3)² = 10` ✓

### 7（原⑤）`x² − 4x = −1` 配方後的結果　答：B
`x² − 4x + 4 = −1 + 4` → `(x − 2)² = 3`。
（陷阱：A 的括號內取 +2，符號錯；C、D 的右邊 5 是把 −1 當成 +1 相加。）

### 8（原⑩）解方程
**(1) `x² − 4x = 0`**
`x(x − 4) = 0` → `x = 0` 或 `x − 4 = 0` → **x₁ = 0 或 x₂ = 4**
※ 不可兩邊同除以 x，會漏掉 x = 0（IEP 短期目標 1-2 的指定易錯點）。
驗根：0² − 4(0) = 0 ✓；4² − 4(4) = 16 − 16 = 0 ✓

**(2) `x² − 4x − 5 = 0`**
兩數積 −5、和 −4 → −5 與 +1 → `(x − 5)(x + 1) = 0` → **x₁ = 5 或 x₂ = −1**
驗根：25 − 20 − 5 = 0 ✓；1 + 4 − 5 = 0 ✓

### 9（原⑪）解方程
**(1) `x² − 2x = 5`**（配方法）
`x² − 2x + 1 = 5 + 1` → `(x − 1)² = 6` → `x − 1 = √6` 或 `x − 1 = −√6`
→ **x₁ = 1 + √6 或 x₂ = 1 − √6**
驗算（韋達）：兩根和 = 2 ＝ −b/a = 2 ✓；兩根積 = 1 − 6 = −5 ＝ c/a = −5 ✓
（一般式為 `x² − 2x − 5 = 0`）

**(2) `2x² − x = 2 − 4x`**
移項：`2x² − x + 4x − 2 = 0` → `2x² + 3x − 2 = 0`
`(2x − 1)(x + 2) = 0` → `2x − 1 = 0` 或 `x + 2 = 0` → **x₁ = 1/2 或 x₂ = −2**
驗根：2(1/4) − 1/2 = 0，右邊 2 − 4(1/2) = 0 ✓；2(4) + 2 = 10，右邊 2 + 8 = 10 ✓

### 10（原⑥）`x² − 4x + 2 = 0` 的判別式值　答：D
a = 1，b = −4，c = 2 → `Δ = (−4)² − 4(1)(2) = 16 − 8 = 8`。
（陷阱：C 的 −8 來自把 `(−4)²` 算成 −16。）

### 11（原⑨）`2x² + x − k = 0` 有兩個相等實根，求 k　答：k = −1/8
a = 2，b = 1，c = −k → `Δ = 1² − 4(2)(−k) = 1 + 8k`
令 Δ = 0 → `8k = −1` → **k = −1/8**。
回代檢查：`2x² + x + 1/8 = 0` → 乘 8：`16x² + 8x + 1 = 0` → `(4x + 1)² = 0`
→ x = −1/4（重根）✓
※ 書寫規範：負分數的負號寫在分數線左邊（`−1/8`，不是 `(−1)/8`），
　 OMML 用 `mr('-') + frac(...)`；已在成品 PDF 目視確認。

### 12（原⑫）`x² − (m + 2)x + 2m = 0`
**(1) 求證恆有兩實根**
a = 1，b = −(m + 2)，c = 2m
`Δ = (m + 2)² − 4(1)(2m) = m² + 4m + 4 − 8m = m² − 4m + 4 = (m − 2)²`
`(m − 2)² ≥ 0` → Δ ≥ 0 → 恆有兩個實數根 ✓
（m = 2 時 Δ = 0，為兩個相等的實數根；題目問「兩個實數根」，相等亦算，敘述無誤。）

**(2) 一根為 1，求 m 及另一根**
代入：`(1)² − (m + 2)(1) + 2m = 0` → `1 − m − 2 + 2m = 0` → `m − 1 = 0` → **m = 1**
代回：`x² − 3x + 2 = 0` → `(x − 1)(x − 2) = 0` → 另一根 **x = 2**
驗算（韋達）：兩根和 1 + 2 = 3 ＝ m + 2 = 3 ✓；兩根積 1 × 2 = 2 ＝ 2m = 2 ✓
