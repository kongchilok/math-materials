### 8 (1) `6x(5x + 2) = 7(5x + 2)`
`(5x + 2)(6x − 7) = 0` → x = −2/5 或 7/6。回代 x = 7/6：6·(7/6) = 7 ✓；x = −2/5 兩邊皆 0 ✓

### 8 (2) `x² − 2x − 35 = 0`
`(x − 7)(x + 5) = 0` → x = 7 或 −5。49 − 14 − 35 = 0 ✓；25 + 10 − 35 = 0 ✓

### 10 (1) `3x² + 5(2x + 1) = 0`
`3x² + 10x + 5 = 0`，Δ = 100 − 60 = 40，x = (−10 ± 2√10)/6 = **(−5 ± √10)/3**。
檢查：兩根和 = −10/3 = −b/a ✓；積 = (25 − 10)/9 = 5/3 = c/a ✓

### 10 (2) `4x² − 8x − 1 = 0`
Δ = 64 + 16 = 80，x = (8 ± 4√5)/8 = **(2 ± √5)/2**。
檢查：和 = 2 = 8/4 ✓；積 = (4 − 5)/4 = −1/4 = c/a ✓

### 16 `2x² + 5x − 7 = 0`
(1) −5/2　(2) −7/2　(3) (25/4) + 7 = **53/4**　(4) (53/4) ÷ (−7/2) = **−53/14**
獨立檢查：`(2x + 7)(x − 1) = 0`，兩根 1、−7/2：和 −5/2 ✓；積 −7/2 ✓；
平方和 1 + 49/4 = 53/4 ✓；x₂/x₁ + x₁/x₂ = −7/2 + (−2/7) = −(49 + 4)/14 = −53/14 ✓
