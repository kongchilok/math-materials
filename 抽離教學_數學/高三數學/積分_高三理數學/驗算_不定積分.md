## 一、基本初等函數的不定積分公式表（講義主體）

標準公式，逐條以求導驗證「d/dx(右式) = 被積函數」：

1. ∫0 dx = C — d/dx(C) = 0 ✓
2. ∫x^α dx = x^(α+1)/(α+1) + C （α≠−1） — d/dx[x^(α+1)/(α+1)] = (α+1)x^α/(α+1) = x^α ✓
3. ∫(1/x) dx = ln|x| + C — d/dx(ln|x|) = 1/x ✓
4. ∫e^x dx = e^x + C — d/dx(e^x) = e^x ✓
5. ∫a^x dx = a^x/ln a + C （a>0, a≠1） — d/dx(a^x/ln a) = a^x·ln a/ln a = a^x ✓
6. ∫cos x dx = sin x + C — d/dx(sin x) = cos x ✓
7. ∫sin x dx = −cos x + C — d/dx(−cos x) = sin x ✓

## 二、運算法則
- 常數倍：∫k·f(x) dx = k∫f(x) dx
- 和差：∫[f(x)±g(x)] dx = ∫f(x) dx ± ∫g(x) dx

（兩條均為積分線性性質，可由導數的加減法則與常數倍法則反向驗證，標準結論，不再展開。）

## 三、講義示範題（I do）

**求 ∫(6x²−4x+3) dx**

= 6·(x³/3) − 4·(x²/2) + 3x + C
= 2x³ − 2x² + 3x + C

驗算：d/dx(2x³−2x²+3x+C) = 6x²−4x+3 ✓ 與被積函數相符。

## 四、講義引導題（We do）

**求 ∫(9x²+2x−5) dx**

= 9·(x³/3) + 2·(x²/2) − 5x + C
= 3x³ + x² − 5x + C

驗算：d/dx(3x³+x²−5x+C) = 9x²+2x−5 ✓

## 五、練習A（★☆☆，2題＝正式題號1-2）

**A1＝第1題：已知 d/dx(x⁶)=6x⁵，求 ∫6x⁵ dx**
= x⁶ + C
驗算：d/dx(x⁶+C) = 6x⁵ ✓

**A2＝第2題：求 ∫x³ dx（套用公式2，α=3）**
= x⁴/4 + C
驗算：d/dx(x⁴/4+C) = x³ ✓

## 六、練習B（★★☆，2題＝正式題號3-4）

**B1＝第3題：求 ∫(3x²−2x+5) dx**
= 3·(x³/3) − 2·(x²/2) + 5x + C
= x³ − x² + 5x + C
驗算：d/dx(x³−x²+5x+C) = 3x²−2x+5 ✓

**B2＝第4題：求 ∫(4eˣ+cos x) dx**
= 4eˣ + sin x + C
驗算：d/dx(4eˣ+sin x+C) = 4eˣ+cos x ✓

## 七、練習C（★★★，2題＝正式題號5-6，降低開放度版）

**C1＝第5題：已知 F'(x)=6x²−4x+1，且 F(0)=3，求 F(x)**
一般解：F(x) = 2x³−2x²+x+C
代入 F(0)=3：2(0)−2(0)+0+C=3 → C=3
所以 F(x) = 2x³−2x²+x+3
驗算：d/dx(2x³−2x²+x+3) = 6x²−4x+1 ✓；F(0)=0−0+0+3=3 ✓

**C2＝第6題：錯誤分析——判斷以下做法錯在哪裡**
題目：某同學求 ∫x⁻¹ dx 時，直接套用公式2寫成 ∫x⁻¹ dx = x⁰/0 + C

錯誤所在：公式2「∫x^α dx = x^(α+1)/(α+1)+C」明確限定 **α≠−1**（因為 α=−1 時分母 α+1=0，除以零無意義）。
本題 α=−1 剛好落在限定條件之外，不能套用冪函數公式。

正確做法：α=−1 時被積函數是 1/x，應改用公式3：
∫x⁻¹ dx = ∫(1/x) dx = ln|x| + C

驗算：d/dx(ln|x|) = 1/x = x⁻¹ ✓
