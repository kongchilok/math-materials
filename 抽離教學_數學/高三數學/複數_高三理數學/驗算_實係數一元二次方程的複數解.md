# 驗算：實係數一元二次方程的複數解（L5，課本 10.2.2 之 3）

> 驗算方法：每題人手逐步計算，再用 Python sympy 獨立重算（2026-10-05，41 項全數一致）。
> 虛數單位 i 依課本印正體；「迷思測試」＝假設學生仍持本課最常見錯誤概念，該題會否仍答對（會→該題無篩選力）。

## 結構情況窮舉
判別式三種情況（B3 齊備：Δ＝0、Δ＜0、Δ＞0）；Δ＜0 的根：純虛數根（A1）、整數實部虛部（例二、A2）、
分數（例三）、含根號（B4）；逆向（已知一根求係數，C5）；「Δ＜0 就無解」迷思（C6）。

## 講義
| 題 | 計算 | 答案 | 驗算 |
|---|---|---|---|
| 例一 x²=−9 | √9=3 | ±3i 分兩支 | (3i)²=−9 ✓ |
| 例二 x²+2x+5=0 | Δ=4−20=−16；√16=4 | −1±2i | (−1+2i)²+2(−1+2i)+5=(−3−4i)+(−2+4i)+5=0 ✓ |
| 例三 2x²−2x+1=0 | Δ=4−8=−4；√4=2；(2±2i)/4 | ½±½i | x=(1+i)/2：2x²=i，−2x=−1−i，+1 → 0 ✓ |

## 練習
| 題號 | 答案 | 驗算 |
|---|---|---|
| 1 | (1) ±4i (2) ±√3 i | (√3 i)²=−3 ✓ |
| 2 | x²−4x+13=0：2±3i | Δ=16−52=−36；(2+3i)²−4(2+3i)+13=(−5+12i)−8−12i+13=0 ✓ |
| 3 | (1) Δ=0 (2) Δ=−7 (3) Δ=17 | 9+8=17 |
| 4 | x²−2x+4=0：1±√3 i | Δ=−12，√12=2√3；(1+√3i)²=−2+2√3i，−2−2√3i，+4 → 0 ✓ |
| 5 | 1+2i 為根：b=−2，c=5 | 另一根 1−2i：和 2＝−b，積 5＝c ✓ |
| 6 | x²+2x+2=0：實數範圍無解；複數範圍 −1±i | Δ=−4 |

**迷思測試**：C6 若持「Δ＜0 就無解」迷思 → 會認同同學 → 答錯 ✓。B4 若寫 √(−12) 不化簡 → 解法卡住或格式錯 → 有篩選力。
