# 驗算：矩陣的應用 — 求多項式的最大公因式（※16.6）

> 係數行對齊（缺項補 0）→ 行相減消最高次 → 約掉常數 = HCF；次數不同先乘 x 左移。題號對應練習檔 1–10。

## 講義範例（自驗）
- 範例1：f=x²+3x+2=(x+1)(x+2)，g=x²−1=(x+1)(x−1)。[1,3,2]−[1,0,−1]=[0,3,3]=3(x+1) → HCF=x+1 ✓
- 範例2：f=x³−1，g=x²−1。f−x·g=[0,0,1,−1]=x−1 → HCF=x−1 ✓

## 練習A（★☆☆）

1．f=x²+5x+6=(x+2)(x+3)，g=x²+2x=x(x+2)。[1,5,6]−[1,2,0]=[0,3,6]=3(x+2) → **HCF=x+2**。✓

2．f=x²+4x+3=(x+1)(x+3)，g=x²−9=(x+3)(x−3)。[1,4,3]−[1,0,−9]=[0,4,12]=4(x+3) → **HCF=x+3**。✓

3．消去後得 [0,2,6]=2x+6=2(x+3)，約掉常數 → 候選 **x+3**。✓

## 練習B（★★☆）

4．f=x²+7x+12=(x+3)(x+4)，g=x²+2x−3=(x+3)(x−1)。[1,7,12]−[1,2,−3]=[0,5,15]=5(x+3) → **HCF=x+3**。✓

5．f=x²−4=(x−2)(x+2)，g=x²−x−2=(x−2)(x+1)。[1,0,−4]−[1,−1,−2]=[0,1,−2]=x−2 → **HCF=x−2**。✓

6．f=2x²+5x+3=(2x+3)(x+1)，g=2x²−x−3=(2x−3)(x+1)。[2,5,3]−[2,−1,−3]=[0,6,6]=6(x+1) → **HCF=x+1**。✓

7．f=x²+2x−8=(x+4)(x−2)，g=x²+6x+8=(x+4)(x+2)。[1,2,−8]−[1,6,8]=[0,−4,−16]=−4(x+4) → **HCF=x+4**。✓

## 練習C（★★★）

8．f=x³−1，g=x²−1（次數不同）。f=[1,0,0,−1]，x·g=[1,0,−1,0]，f−x·g=[0,0,1,−1]=x−1。
- 再驗 g÷(x−1)=x+1（餘 0）。**HCF=x−1**。f=(x−1)(x²+x+1)、g=(x−1)(x+1) ✓

9．f=x³+2x²−x−2=(x+2)(x−1)(x+1)，g=x²−1。f=[1,2,−1,−2]，x·g=[1,0,−1,0]，f−x·g=[0,2,0,−2]=2(x²−1)=2g → 餘 0。
- **HCF=x²−1**。g=(x−1)(x+1) 完整整除 f ✓

10．（開放）設計 g 使 gcd(x²+3x+2, g)=x+1。參考解：g=x²+4x+3=(x+1)(x+3)。
- [1,3,2]−[1,4,3]=[0,−1,−1]=−(x+1) → **HCF=x+1** ✓。評分重點：g 含 (x+1) 但不含 (x+2)。
