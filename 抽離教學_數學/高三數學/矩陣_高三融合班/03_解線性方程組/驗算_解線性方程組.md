# 驗算：矩陣的應用 — 解線性方程組

> 增廣矩陣高斯消元／克拉瑪法則 x=Δx/Δ。題號對應練習檔 1–10。

## 講義範例（自驗）
- 範例1：{x+2y=5；3x−y=1} → (1,2)。檢驗 1+4=5 ✓、3−2=1 ✓
- 範例2：{x+y+z=6；2x−y+z=3；x+2y−z=2} → (1,2,3)。三式皆合 ✓
- 範例3：{2x+y=5；x−y=1}，Δ=−3、Δx=−6、Δy=−3 → (2,1) ✓

## 練習A（★☆☆）

1．（寫增廣）{2x+3y=7；x−y=1} → **[2,3|7 ; 1,−1|1]**。✓

2．（消元）{x+y=5；x−y=1}。R2−R1 → y=2，回代 x=3。**(3,2)**。檢驗 3+2=5 ✓、3−2=1 ✓

3．（克拉瑪）{x+2y=8；3x−y=3}。Δ=1·(−1)−2·3=−7；Δx=8·(−1)−2·3=−14；Δy=1·3−8·3=−21。
- x=−14/−7=**2**，y=−21/−7=**3**。檢驗 2+6=8 ✓、6−3=3 ✓

## 練習B（★★☆）

4．{3x+y=7；2x−y=3}。兩式相加 5x=10 → x=2、y=1。**(2,1)**。檢驗 6+1=7 ✓、4−1=3 ✓

5．（高斯消元）{x+y+z=2；x−y+2z=3；2x+y−z=1}。
- eq2−eq1：−2y+z=1；eq3−2eq1：−y−3z=−3。解得 z=1，y=0，x=1。**(1,0,1)**。
- 檢驗：1+0+1=2 ✓、1−0+2=3 ✓、2+0−1=1 ✓

6．（克拉瑪）{4x+3y=18；2x−y=4}。Δ=−4−6=−10；Δx=−18−12=−30；Δy=16−36=−20。
- x=−30/−10=**3**，y=−20/−10=**2**。檢驗 12+6=18 ✓、6−2=4 ✓

7．（應用）2 筆+3 簿=13；1 筆+2 簿=8。設筆 x、簿 y：2x+3y=13、x+2y=8。
- x=8−2y → 16−y=13 → y=3、x=2。**筆 2 元、簿 3 元**。檢驗 4+9=13 ✓、2+6=8 ✓

## 練習C（★★★）

8．（高斯消元）{x+2y+z=8；2x+y−z=1；x−y+2z=9}。
- eq1+eq2：x+y=3；eq3−2eq1：x+5y=7。相減 4y=4 → y=1、x=2、z=4。**(2,1,4)**。
- 檢驗：2+2+4=8 ✓、4+1−4=1 ✓、2−1+8=9 ✓

9．（三元應用）1 筆+1 尺+1 膠=12；2 筆+1 尺=11；1 尺+3 膠=17。
- x+y+z=12、2x+y=11、y+3z=17。解得 x=3、y=5、z=4。**筆 3、尺 5、膠 4 元**。
- 檢驗：3+5+4=12 ✓、6+5=11 ✓、5+12=17 ✓

10．（開放）寫解為 x=1、y=2 的方程組。參考解：{x+y=3；x−y=−1}，增廣 [1,1|3;1,−1|−1] 消元得 (1,2)。
- 檢驗：1+2=3 ✓、1−2=−1 ✓。評分重點：聯立解恰為 (1,2)。
