# 驗算：矩陣（概念與運算）練習

> 逐題親自命題＋驗算。題號對應練習檔 1–11；矩陣以 [列;列] 表示。

## 練習A（★☆☆）

1．（辨認）設 A = [[3, −1, 0], [2, 5, −4]]。A 為 2×3 階矩陣（2 列 3 行）；a₁₃ = 0；a₂₁ = 2；a₂₃ = −4。✓

2．（加法）A = [[2, 3], [1, 4]]，B = [[5, −1], [0, 6]]，A+B。
- 對位相加：[[2+5, 3+(−1)], [1+0, 4+6]] = **[[7, 2], [1, 10]]**。✓

3．（數乘）A = [[1, −2], [3, 0]]，3A。
- 每格 ×3：**[[3, −6], [9, 0]]**。✓

## 練習B（★★☆）

4．（減法）A = [[4, 1, −2], [3, 0, 5]]，B = [[−1, 2, 3], [6, −4, 1]]，A−B。
- [[4−(−1), 1−2, −2−3], [3−6, 0−(−4), 5−1]] = **[[5, −1, −5], [−3, 4, 4]]**。✓

5．（數乘＋加）A = [[2, −1], [0, 3]]，B = [[1, 4], [−2, 5]]，2A+B。
- 2A = [[4, −2], [0, 6]]；2A+B = **[[5, 2], [−2, 11]]**。✓

6．（乘法 2×2）A = [[1, 2], [3, 0]]，B = [[2, −1], [4, 5]]，AB。
- c₁₁=1·2+2·4=10；c₁₂=1·(−1)+2·5=9；c₂₁=3·2+0·4=6；c₂₂=3·(−1)+0·5=−3。
- AB = **[[10, 9], [6, −3]]**。✓

7．（乘法 2×3）A = [[2, 1], [1, 3]]（2×2），B = [[1, 0, −2], [4, 3, 1]]（2×3），AB。
- c₁₁=2·1+1·4=6；c₁₂=2·0+1·3=3；c₁₃=2·(−2)+1·1=−3
- c₂₁=1·1+3·4=13；c₂₂=1·0+3·3=9；c₂₃=1·(−2)+3·1=1
- AB = **[[6, 3, −3], [13, 9, 1]]**（2×3）。✓

8．（轉置）A = [[2, −1, 3], [0, 5, 4]]，Aᵀ = **[[2, 0], [−1, 5], [3, 4]]**（3×2）。✓

## 練習C（★★★）

9．（AB≠BA）A = [[1, 2], [0, 1]]，B = [[1, 0], [3, 1]]。
- AB：[[7, 2], [3, 1]]；BA：[[1, 2], [3, 7]]。**AB ≠ BA**，矩陣乘法不具交換律。✓

10．（求 X）A = [[3, 1], [2, 4]]，B = [[5, −1], [0, 2]]，2X = A−B。
- A−B = [[−2, 2], [2, 2]]，X = **[[−1, 1], [1, 1]]**。檢驗 2X = A−B ✓

11．（開放）設計 A、B 使 A+B = [[4, 4], [4, 4]]。
- 參考解（不唯一）：A = [[1, 2], [3, 0]]，B = [[3, 2], [1, 4]]。A+B = [[4,4],[4,4]] ✓
- 評分重點：任何對應元素相加皆為 4 的 A、B 皆正確。
