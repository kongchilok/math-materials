# 驗算：逆矩陣（反矩陣）練習

> 2×2 公式：A=[[a,b],[c,d]]，A⁻¹ = 1/(ad−bc)·[[d,−b],[−c,a]]，ad−bc=det(A)≠0。題號對應練習檔 1–10。

## 講義範例（自驗）
- 範例2：A=[[2,5],[1,3]]，det=1，A⁻¹=[[3,−5],[−1,2]]；A·A⁻¹=I ✓
- 範例3：A=[[1,2],[2,5]]，初等行變換得 A⁻¹=[[5,−2],[−2,1]]；det=1 核對 ✓
- 範例4：A=[[2,4],[1,2]]，det=0 → 不存在 ✓

## 練習A（★☆☆）

1．（行列式）A=[[3,1],[2,4]]，det = 3·4 − 1·2 = **10**（≠0，可逆）。✓

2．（公式法）A=[[4,1],[3,1]]，det = 4·1 − 1·3 = 1，A⁻¹ = **[[1,−1],[−3,4]]**。
- 檢驗 A·A⁻¹ = [[4−3,−4+4],[3−3,−3+4]] = [[1,0],[0,1]] ✓

3．（判斷可逆）P=[[2,6],[1,3]]：det=0 → **無逆矩陣**；Q=[[2,3],[2,4]]：det=2≠0 → **有逆矩陣**。✓

## 練習B（★★☆）

4．（公式，含分數）A=[[4,2],[1,1]]，det=2，A⁻¹ = 1/2·[[1,−2],[−1,4]] = **[[1/2,−1],[−1/2,2]]**。
- 檢驗 A·A⁻¹ = [[2−1,−4+4],[1/2−1/2,−1+2]] = [[1,0],[0,1]] ✓

5．（初等行變換）A=[[1,3],[2,5]]。
- [A|I]→R2−2R1→(−1)R2→R1−3R2 得 A⁻¹ = **[[−5,3],[2,−1]]**。
- formula 檢驗：det=−1，A⁻¹=1/(−1)[[5,−3],[−2,1]]=[[−5,3],[2,−1]] ✓

6．（解 AX=B）A=[[2,1],[3,2]]，B=[[5],[8]]。det=1，A⁻¹=[[2,−1],[−3,2]]。
- X = A⁻¹B = [[10−8],[−15+16]] = **[[2],[1]]**。檢驗 AX=[[5],[8]]=B ✓

7．（驗證逆矩陣）A=[[3,5],[1,2]]，B=[[2,−5],[−1,3]]。
- AB = [[6−5,−15+15],[2−2,−5+6]] = [[1,0],[0,1]] = I → **B 是 A 的逆矩陣**。✓

## 練習C（★★★）

8．（3×3 初等變換）A=[[1,1,1],[0,1,1],[0,0,1]]，A⁻¹ = **[[1,−1,0],[0,1,−1],[0,0,1]]**。
- 檢驗 A·A⁻¹ = I（逐格：(1,2)=−1+1=0、(2,3)=−1+1=0…）✓

9．（不可逆求 t）M=[[t,4],[1,t−3]] 逆矩陣不存在 → det=0：t²−3t−4=0 → (t−4)(t+1)=0 → **t=4 或 t=−1**。
- 檢驗：t=4→16−12−4=0 ✓；t=−1→1+3−4=0 ✓

10．（性質驗證）(AB)⁻¹=B⁻¹A⁻¹，取 A=[[1,1],[0,1]]、B=[[1,0],[1,1]]。
- AB=[[2,1],[1,1]]，(AB)⁻¹=[[1,−1],[−1,2]]；B⁻¹A⁻¹=[[1,0],[−1,1]]·[[1,−1],[0,1]]=[[1,−1],[−1,2]]。**兩者相等** ✓
