三、練習C（★★★）—— 極值、最值與情境應用
6．求函數 \( f(x)=x^3-27x \) 的極大值與極小值。
7．求函數 \( f(x)=x^3-27x \) 在閉區間 [−4，4] 上的最大值與最小值。（提示：把極值和兩端點 f(−4)、f(4) 一起比較）
8．某工廠某產品的日產量為 x 公噸時，獲利函數為 \( P(x)=-x^3+9x^2 \)（單位：萬元），其中 x∈[0，8]。請問日產量為多少公噸時獲利最大？最大獲利是多少萬元？
教師用：參考答案

1．B（遞減，因為 f'(x) = −2 < 0 對所有 x 成立）

2．f'(x)=2x−2；x > 1 時 f'(x) > 0 → A（遞增）

3．f'(x)=eˣ−1

4．f'(x)=6x²−12x=6x(x−2)，零點 x=0, 2。x < 0 遞增、0 < x < 2 遞減、x > 2 遞增。極大值 f(0)=7；極小值 f(2)=2(8)−6(4)+7=−1

5．f'(x)=3x²+3，對所有 x 恆正（永遠 > 0），所以 f(x) 在整個定義域 R 上都是單調遞增，沒有極值。

6．f'(x)=3x²−27=3(x−3)(x+3)，零點 x=−3, 3。極大值 f(−3)=−27+81=54；極小值 f(3)=27−81=−54

7．候選值：f(−4)=−64+108=44、f(−3)=54、f(3)=−54、f(4)=64−108=−44。最大值＝54（於 x=−3）；最小值＝−54（於 x=3）

8．P'(x)=−3x²+18x=−3x(x−6)，零點 x=0, 6（x=0為端點）。0 < x < 6 遞增、6 < x < 8 遞減，x=6為極大。候選值：P(0)=0、P(6)=108、P(8)=64。答：日產量6公噸時獲利最大，最大獲利108萬元。
