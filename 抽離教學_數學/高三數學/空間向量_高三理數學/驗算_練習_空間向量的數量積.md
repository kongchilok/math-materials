# 驗算記錄——練習_空間向量的數量積

範圍：課本 1.1.1 後半（數量積定義、性質、求夾角/模）。共 8 題，全數逐題親自演算，非抽樣。

統一設定：正方體 ABCD-A₁B₁C₁D₁，棱長視乎題目（1或2或a），DA、DC、DD₁ 三條棱互相垂直。

## 練習A（★☆☆）

1．**AB·AD（相鄰棱）**
AB⊥AD（正方體相鄰棱互相垂直），由性質④直接得 **0**。✓

2．**|a|=3，|b|=4，a⊥b，求a·b**
由性質④（垂直⟺數量積=0），直接得 **0**。✓

3．**|a|=2，|b|=5，⟨a,b⟩=60°，求a·b**
代入定義：a·b=|a||b|cosθ=2×5×cos60°=10×½=**5**。✓（cos60°=½為標準值）

## 練習B（★★☆）

4．**正方體棱長2，求AB·AC**
AC=AB+BC（三角形法則）。AB·AC=AB·(AB+BC)=AB·AB+AB·BC=|AB|²+0（AB⊥BC）=2²=**4**。✓
座標覆核：A=(2,0,0)，B=(2,2,0)，C=(0,2,0)（D原點）。AB=(0,2,0)，AC=(-2,2,0)。AB·AC=0×(-2)+2×2+0×0=4。✓相符。

5．**a·b=6，|a|=3，|b|=4，求⟨a,b⟩**
cosθ=(a·b)/(|a||b|)=6/(3×4)=6/12=½。θ=arccos(½)=**60°**。✓（標準角）

6．**若a·b=0，是否一定a=0或b=0？**
**錯**。反例：a⊥b 且兩者皆非零向量時，a·b=0 依然成立（性質④）。例如 |a|=1,|b|=1,⟨a,b⟩=90°，a·b=1×1×cos90°=1×1×0=0，但a、b都不是零向量。結論：a·b=0 只表示「a=0 或 b=0 或 a⊥b」三選一，不能推斷是前兩者。✓

## 練習C（★★★）

7．**正方體棱長2，M是BB₁中點，求AM與AC₁夾角餘弦值**

設 DA=p，DC=q，DD₁=r，三者兩兩垂直，|p|=|q|=|r|=2。
- A（位置向量，以D為原點）= p
- B = p+q，B₁ = p+q+r，M = B與B₁中點 = (2p+2q+r)/2 = p+q+r/2
- AM = M-A = q+r/2
- C₁（位置向量）= q+r，AC₁ = C₁-A = -p+q+r

AM·AC₁ = (q+½r)·(-p+q+r)
= q·(-p) + q·q + q·r + ½r·(-p) + ½r·q + ½r·r
= 0 + |q|² + 0 + 0 + 0 + ½|r|²　（p,q,r兩兩垂直，交叉項全部=0）
= 4 + ½(4) = 4+2 = **6**

|AM|² = (q+½r)·(q+½r) = |q|²+q·r+¼|r|² = 4+0+1 = 5，|AM|=√5
|AC₁|² = (-p+q+r)·(-p+q+r) = |p|²+|q|²+|r|²（交叉項全零）=4+4+4=12，|AC₁|=2√3

cosθ = 6/(√5×2√3) = 6/(2√15) = 3/√15 = 3√15/15 = **√15/5**

**座標覆核**（D=(0,0,0)，A=(2,0,0)，B=(2,2,0)，C=(0,2,0)，B₁=(2,2,2)，C₁=(0,2,2)）：
M=中點(B,B₁)=(2,2,1)。AM=M-A=(0,2,1)。AC₁=C₁-A=(-2,2,2)。
AM·AC₁=0×(-2)+2×2+1×2=6。|AM|=√(0+4+1)=√5。|AC₁|=√(4+4+4)=2√3。
cosθ=6/(√5×2√3)=6/(2√15)=√15/5≈0.7746（θ≈39.2°）。**兩種方法完全相符**。✓

8．**求證 |a+b|²=|a|²+2a·b+|b|²**
|a+b|² = (a+b)·(a+b)（模的平方=自身數量積）
= a·a+a·b+b·a+b·b（分配律展開）
= |a|²+2a·b+|b|²（a·a=|a|²，b·b=|b|²，a·b=b·a交換律合併中間兩項）
得證。✓ 這是純代數推導，每步都直接用已證明性質，無需數值驗證。

## 小結
全部 8 題答案與文件內容一致。第4、7題額外用座標系統獨立驗算，與純向量法結果一致。第6題的反例用具體角度（90°）示範，確保論證扎實而非空泛陳述。
