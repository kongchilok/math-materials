# 驗算記錄——練習_空間角的計算

範圍：課本 1.2.3+1.2.4（線面角公式sinθ、二面角公式|cosθ|+銳鈍角判斷）。共 8 題，全數逐題親自演算，非抽樣。

## 練習A（★☆☆）

1．**v=(1,1,2)，n=(0,0,1)，求線面角正弦值**
v·n=1×0+1×0+2×1=2。|v|=√(1+1+4)=√6。|n|=1。
sinθ=|2|/(√6×1)=2/√6=2√6/6=**√6/3**。✓

2．**v=(1,0,0)，n=(0,1,1)，求v·n並判斷線面角**
v·n=1×0+0×1+0×1=0。sinθ=0/(...)=0。**線面角=0°**（直線平行於平面或含於平面內）。✓

3．**n1=(1,0,0)，n2=(0,1,0)，求|cos⟨n1,n2⟩|**
n1·n2=0。|cosθ|=0。**二面角=90°**。cos為0時無銳鈍角歧義（因為90°的補角本身仍是90°，不存在二選一的問題）。✓

## 練習B（★★☆）

4．**正方體棱長2，D原點建系，求AC₁與底面ABCD所成角正弦值**
AC₁=(-2,2,2)（A=(2,0,0),C₁=(0,2,2)）。n=(0,0,1)（底面）。
AC₁·n=2。|AC₁|=√12=2√3。
sinθ=2/(2√3×1)=1/√3=**√3/3**。✓

5．**同一正方體，求AC₁與側面ABB₁A₁所成角正弦值**
側面ABB₁A₁是x=2平面，n=(1,0,0)。
AC₁·n=(-2)(1)+2(0)+2(0)=-2。|AC₁·n|=2。|AC₁|=2√3。
sinθ=2/(2√3×1)=1/√3=**√3/3**。
（與第4題數值相同——這是因為AC₁對底面z=0與對側面x=2兩者的「傾斜程度」在這個特定體對角線上恰好相等，屬於正方體的對稱性，非抄錯。可用第三個側面y=2驗證：n=(0,1,0)，AC₁·n=2，同樣得√3/3，三個結果一致，印證體對角線與正方體三組相對面的傾角在數值上全部相等，這是稱體對角線的一個對稱性質）✓

6．**n1=(1,1,0)，n2=(1,-1,0)，求|cos⟨n1,n2⟩|**
n1·n2=1×1+1×(-1)+0×0=1-1+0=0。|cosθ|=0。**二面角=90°**。✓

## 練習C（★★★）

7．**正方體棱長2，D原點建系，求二面角A-BD₁-C**

平面ABD₁的法向量：A=(2,0,0),B=(2,2,0),D₁=(0,0,2)。
BA=A-B=(0,-2,0)。BD₁=D₁-B=(-2,-2,2)。
設n1=(x,y,z)：n1·BA=0→-2y=0→y=0。n1·BD1=0→-2x-2y+2z=0，代入y=0：-2x+2z=0→x=z。
取x=1,z=1,y=0：**n1=(1,0,1)**。驗算：n1·BA=0✓；n1·BD1=-2+0+2=0✓。

平面CBD₁的法向量：C=(0,2,0),B=(2,2,0),D₁=(0,0,2)。
BC=C-B=(-2,0,0)。BD₁=(-2,-2,2)（同上）。
設n2=(x,y,z)：n2·BC=0→-2x=0→x=0。n2·BD1=0→-2x-2y+2z=0，代入x=0：-2y+2z=0→y=z。
取y=1,z=1,x=0：**n2=(0,1,1)**。驗算：n2·BC=0✓；n2·BD1=0-2+2=0✓。

|cos⟨n1,n2⟩|=|n1·n2|/(|n1||n2|)=|0+0+1|/(√2×√2)=1/2。

**判斷銳鈍角**（用嚴謹方法：找B點出發、垂直於邊BD₁、分別指向A、C方向的向量）：
邊方向 d=BD₁=(-2,-2,2)，|d|²=12。
BA=(0,-2,0)。BA在d上的投影係數=(BA·d)/|d|²=(0+4+0)/12=4/12=1/3。
BA_perp = BA - (1/3)d = (0,-2,0) - (1/3)(-2,-2,2) = (0,-2,0)-(-2/3,-2/3,2/3) = (2/3,-4/3,-2/3)。

BC=(-2,0,0)。BC在d上投影係數=(BC·d)/|d|²=(4+0+0)/12=4/12=1/3。
BC_perp = BC-(1/3)d = (-2,0,0)-(-2/3,-2/3,2/3) = (-4/3,2/3,-2/3)。

cos(實際二面角) = (BA_perp·BC_perp)/(|BA_perp||BC_perp|)
BA_perp·BC_perp = (2/3)(-4/3)+(-4/3)(2/3)+(-2/3)(-2/3) = -8/9-8/9+4/9 = -12/9 = -4/3。
|BA_perp|²=|BC_perp|²=(4+16+4)/9=24/9=8/3。
cos(實際角) = (-4/3)/(8/3) = **-1/2**。

負數 ⟹ 實際二面角是鈍角：θ=arccos(-1/2)=**120°**。✓
（此方法比「肉眼判斷」更嚴謹，直接算出帶正負號的餘弦值，不依賴看圖猜測。120°亦與|cos⟨n1,n2⟩|=1/2的補角180°-60°=120°一致，驗證通過）

8．**A₁C與平面BDD₁B₁所成角正弦值**
平面BDD₁B₁的法向量：B=(2,2,0),D=(0,0,0),D₁=(0,0,2)。
BD=D-B=(-2,-2,0)。BD₁=D₁-B=(-2,-2,2)。
設n=(x,y,z)：n·BD=0→-2x-2y=0→x=-y。n·BD1=0→-2x-2y+2z=0，代入-2x-2y=0：2z=0→z=0。
取x=1,y=-1,z=0：**n=(1,-1,0)**。驗算：n·BD=-2+2+0=0✓；n·BD1=-2+2+0=0✓。

A₁C：A₁=(2,0,2)，C=(0,2,0)。A₁C=C-A₁=(-2,2,-2)。
A₁C·n=(-2)(1)+(2)(-1)+(-2)(0)=-2-2+0=-4。
|A₁C|=√(4+4+4)=2√3。|n|=√2。
sinθ=|-4|/(2√3×√2)=4/(2√6)=2/√6=2√6/6=**√6/3**。✓

## 小結
全部8題答案與文件內容一致。第7題（二面角C-tier）額外用「投影去邊向量」嚴謹方法獨立算出帶符號的餘弦值（-1/2），比純粹憑圖判斷更可靠，確認120°鈍角結論正確、與講義的判斷方法互相印證。第5題的數值巧合已用第三個側面驗算解釋清楚（正方體體對角線對稱性），避免被誤認為抄錯。
