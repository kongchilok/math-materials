# 驗算記錄——練習_空間向量的概念與線性運算

範圍：課本 1.1.1 前半（向量的加減、數乘、中點公式）＋自編平面向量複習橋接。共 8 題，全數逐題親自演算，非抽樣。

統一設定：正方體 ABCD-A₁B₁C₁D₁，D 為參考角，DA、DC、DD₁ 三條棱互相垂直。

## 練習A（★☆☆）

1．**化簡 DA+AB**
三角形法則首尾相接：D→A→B，直接得 **DB**。✓

2．**化簡 DC+CC₁**
首尾相接：D→C→C₁，直接得 **DC₁**。✓

3．**M 是 AB 中點，DA=a，DB=b，用 a、b 表示 DM**
中點公式：DM = ½(DA+DB) = **½(a+b)**。✓（公式直接代入，講義有教）

## 練習B（★★☆）

4．**化簡 AB+BC+CC₁+C₁D₁**
逐步首尾相接：AB+BC=AC；AC+CC₁=AC₁；AC₁+C₁D₁=AD₁。
座標覆核（D=(0,0,0)，A=(2,0,0)，B=(2,2,0)，C=(0,2,0)，D₁=(0,0,2)，C₁=(0,2,2)）：
AB+BC+CC₁+C₁D₁ 逐項相加＝(B-A)+(C-B)+(C₁-C)+(D₁-C₁)＝D₁-A（望遠鏡消去）＝(0,0,2)-(2,0,0)=(-2,0,2)。
AD₁=D₁-A=(-2,0,2)。兩者相符。答案 **AD₁**。✓

5．**化簡 AB+CD**
AB=(0,2,0)（B-A）。CD=D-C=(0,0,0)-(0,2,0)=(0,-2,0)。
AB+CD=(0,0,0)=**零向量**。✓ 幾何解讀：ABCD 是正方形，AB 與 DC 是同一向量（見第1題腳注邏輯），故 CD=-AB，兩者相加抵消。

6．**DB₁ 是體對角線，M 是其中點，DA=a、DC=b、DD₁=c，表示 DM**
DB₁：D→A→B→B₁ 三段首尾相接＝DA+AB+BB₁。AB=DC=b（正方形對邊），BB₁=DD₁=c（豎棱平行且等長）。
故 DB₁=a+b+c。中點公式：DM=½DB₁=**½(a+b+c)**。
座標覆核：D=(0,0,0)，B₁=(2,2,2)（a=(2,0,0)方向，b=(0,2,0)方向，c=(0,0,2)方向，取邊長2）。DM=½(2,2,2)=(1,1,1)=½[(2,0,0)+(0,2,0)+(0,0,2)]=½(a+b+c)。✓

## 練習C（★★★）

7．**空間四邊形 ABCD（不一定共面），M、N 分別是 AC、BD 中點，求證 MN=½(AB+CD)**
設 O 為任意點（位置向量法）：
OM=½(OA+OC)，ON=½(OB+OD)
MN=ON-OM=½[(OB-OA)+(OD-OC)]=½(AB+CD)　得證。

**數值反例驗證**（確保公式方向沒有寫反，用非平行四邊形的一般四點，含z座標確保非共面）：
A=(0,0,0)，B=(2,0,0)，C=(3,2,0)，D=(0,3,1)。
M=中點AC=(1.5,1,0)，N=中點BD=(1,1.5,0.5)。
MN=N-M=(-0.5,0.5,0.5)。
AB=B-A=(2,0,0)。CD=D-C=(-3,1,1)。½(AB+CD)=½(-1,1,1)=(-0.5,0.5,0.5)。
**兩者相符**，公式方向正確（注意是 CD 不是 DC——曾經寫錯方向，用此數值反例抓出並改正）。✓

8．**正方體 ABCD-A₁B₁C₁D₁，P 是 CC₁ 中點，DA=a、DC=b、DD₁=c，表示 AP**
DP＝DC 與 DC₁ 的中點＝½(DC+DC₁)＝½[b+(b+c)]＝b+½c（DC₁=DC+CC₁=b+c）。
AP=DP-DA=(b+½c)-a=**-a+b+½c**。
座標覆核：D=(0,0,0)，A=(2,0,0)，C=(0,2,0)，C₁=(0,2,2)。P=中點(C,C₁)=(0,2,1)。
AP=P-A=(-2,2,1)。公式：-a+b+½c=-(2,0,0)+(0,2,0)+(0,0,1)=(-2,2,1)。✓ 相符。

## 小結
全部 8 題答案與文件內容一致，第7題公式方向（AB+CD 非 AB+DB 或 AB+DC）額外用數值反例覆核過。第4、6、8題均有座標系統獨立驗算，不只靠向量鏈式推導。
