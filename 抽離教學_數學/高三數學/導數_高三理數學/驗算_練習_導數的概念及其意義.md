## 練習B（★★☆）用定義求導數

3．文件答案 y'=3｜重算：Δy=[3(x+Δx)+4]−(3x+4)=3Δx，Δy/Δx=3，取極限得 y'=3｜一致 ✓
4．文件答案 f'(x)=−1/x²｜重算：Δy=1/(x+Δx)−1/x=−Δx/[x(x+Δx)]，Δy/Δx=−1/[x(x+Δx)]，Δx→0 得 −1/x²｜一致 ✓
5．文件答案 f'(x)=1/(2√x)｜重算：Δy=√(x+Δx)−√x，有理化得 Δy/Δx=1/[√(x+Δx)+√x]，Δx→0 得 1/(2√x)｜一致 ✓
6．文件答案 y'=3x²｜重算：(x+Δx)³−x³=3x²Δx+3x(Δx)²+(Δx)³，除以 Δx 得 3x²+3xΔx+(Δx)²，Δx→0 得 3x²｜一致 ✓

## 練習C（★★★）切線方程與情境應用

### 切線方程（2026-08-12 新增，源自舊《功課_導數的概念及其意義(變化率問題)》類型三第7、9題）

7．文件答案 f'(x)=2x-2；(1) f'(2)=2；(2) f(2)=3，切線方程 y=2x-1｜重算：f(x)=x²-2x+3，
   f'(x)=2x-2，f'(2)=4-2=2；f(2)=4-4+3=3，切點(2,3)；y-3=2(x-2) → y=2x-1｜一致 ✓
8．文件答案 f'(x)=2x，k=f'(2)=4，切線方程 y=4x-7｜重算：f(x)=x²-3，f'(x)=2x，k=f'(2)=4；
   f(2)=4-3=1，切點(2,1)；y-1=4(x-2) → y=4x-7｜一致 ✓
9．文件答案 斜率0、切線 y=1｜重算：f(x)=x²+1，f'(x)=2x，f'(0)=0；過 (0,1) 的水平切線為 y=1；(0,1) 為頂點，f(0)=1 確在曲線上｜一致 ✓
