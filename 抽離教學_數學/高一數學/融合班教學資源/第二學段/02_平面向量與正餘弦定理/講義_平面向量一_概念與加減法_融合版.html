一、什麼是向量？

生活中有兩種量：一種只要說「多少」就講完了，例如溫度 25°C、面積 30 平方公尺；另一種除了「多少」，還要說「往哪個方向」，例如向東走 3 公里、向下的重力。

既有大小、又有方向的量，叫做向量；只有大小、沒有方向的量，叫做數量。

提示：判斷是不是向量，只問一句話——「它有方向嗎？」位移、力、速度是向量；溫度、年齡、面積不是。

記法：以 A 為起點、B 為終點的向量記作 \(\overrightarrow{AB}\)，它的長度叫做模，記作 \(|\overrightarrow{AB}|\)。長度為 0 的向量叫零向量 \(\vec{0}\)；長度為 1 的向量叫單位向量。

長度相等且方向相同 ⇒「相等向量」；方向相同或相反的非零向量 ⇒「平行向量」（共線向量）。

二、向量加法——兩種畫法

想像走路：先從 A 走到 B（向量 a），再從 B 走到 C（向量 b），合起來跟從 A 直接走到 C 一樣——「三角形法則」，首尾相接。

圖1　三角形法則：首尾相接，「先走 a，再走 b」

兩個向量從同一點出發時，用「平行四邊形法則」：以兩向量為鄰邊畫平行四邊形，對角線就是和。

圖2　平行四邊形法則：共起點，對角線是和
口訣：\(\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\)——前一個的終點字母＝後一個的起點字母時，中間字母「相消」。
三、向量減法——共起點，指回來

把兩個向量移到同一個起點，a − b 就是「從 b 的終點指向 a 的終點」的向量。

圖3　減法：共起點，從 b 的終點指向 a 的終點
兩個常用轉換：①負號＝掉頭：\(-\overrightarrow{DC} = \overrightarrow{CD}\)　②同起點相減：\(\overrightarrow{AB} - \overrightarrow{AC} = \overrightarrow{CB}\)（箭頭指向「被減」的那個）。
四、範例（四步驟框架）
範例：化簡 \(\overrightarrow{AB} + \overrightarrow{BC} - \overrightarrow{DC}\)。
  • 找首尾相接的一對：\(\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}\)（中間字母 B 相消）
  • 把負號變掉頭：\(-\overrightarrow{DC} = +\overrightarrow{CD}\)
  • 再首尾相接一次：\(\overrightarrow{AC} + \overrightarrow{CD} = \overrightarrow{AD}\)（中間字母 C 相消）
  • 檢查：起點 A、終點 D，中途字母都消掉 ✓　答案：\(\overrightarrow{AD}\)
