## 一、平面向量（一）概念與加減法

### 講義
- 向量／數量的區分準則「有沒有方向」✓；模 |AB| ✓；零向量、單位向量 ✓
- 相等向量（等長同向）✓；平行／共線向量（同向或反向的非零向量）✓
- 三角形法則 AB + BC = AC ✓（首尾相接，中間字母相消）
- 平行四邊形法則（共起點、對角線為和）✓
- 減法：共起點，a − b 由 b 終點指向 a 終點 ✓
- −DC = CD ✓；AB − AC = CB ✓（覆核：AC + CB = AB ⟺ AB − AC = CB ✓）
- **範例** AB + BC − DC = AC + CD = **AD** ✓

### 練習
- **A-1** (1) AC ✓　(2) PR ✓
- **A-2** (1) −BA = AB ✓　(2) −DC = CD ✓
- **A-3** AB + BC = AC ✓；AC + CA = **0**（零向量）✓（繞一圈回起點 ✓）
- **B-1** BA + AC = **BC** ✓（中間字母 A 相消）
- **B-2** AC − AB = BC ✓，再 BC + CD = **BD** ✓
- **B-3** AB + CE + BC 重排為 AB + BC + CE = AC + CE = **AE** ✓（加法可交換 ✓）
- **B-4** 平行四邊形 ABCD，AB = a、AD = b：
  AC = AB + AD = **a + b** ✓；DB = DA + AB = −b + a = **a − b** ✓
- **C-1** OA + BO = OA − OB = **BA** ✓
  **以坐標覆核**：設 O 為原點、外接圓半徑 1，A、B、C、D、E、F 依次在 0°、60°、120°、
  180°、240°、300°。則 A(1, 0)、B(½, √3/2)、F(½, −√3/2)。
  BA = A − B = (½, −√3/2)；OF = F − O = (½, −√3/2) → **BA = OF ✓**，答案正確
- **C-2** 開放題，檢核重點（首尾相接、回到起點、和為 0）合理 ✓

## 二、平面向量（二）數乘與共線

### 講義
- |λa| = |λ||a| ✓；λ>0 同向、λ<0 反向、λ=0 得零向量 ✓
- 分配律 λ(a+b) = λa + λb ✓；(λ+μ)a = λa + μa ✓
- 共線定理：b 與非零向量 a 共線 ⟺ 存在唯一 λ 使 b = λa ✓
- **範例** 3(a−b) + 2(2a+b) = 3a − 3b + 4a + 2b = **7a − b** ✓
  （係數覆核：a：3+4 = 7 ✓；b：−3+2 = −1 ✓）

### 練習
- **A-1** 2(a + 3b) = 2a + **6**b ✓
- **A-2** (−3) × 4a = **−12**a ✓
- **A-3** 5a − 2a + b − 3b = **3a − 2b** ✓
- **A-4** a = −2e、b = 2e → b = **−a**（−1 倍）✓，共線且反向 ✓
- **B-1** 2(a+2b) − 3(a−b) = 2a + 4b − 3a + 3b = **−a + 7b** ✓ → 選 (1) ✓
- **B-2** 3(a+b) − 2(a−b) − a = (3−2−1)a + (3+2)b = 0a + 5b = **5b** ✓
- **B-3** c = a + 3b、d = 2a + kb，c ∥ d ⇒ d = λc：
  比較 a 係數 λ = 2 ✓；比較 b 係數 k = 3λ = **6** ✓
  （回代：d = 2a + 6b = 2(a + 3b) = 2c ✓）
- **B-4** C 在 AB 上、AC : CB = 2 : 1（全長 3 份）：
  AC = **⅔** AB ✓；CB = ⅓ AB → BC = **−⅓** AB ✓（方向相反，係數為負 ✓）
- **C-1** a = e₁ − 2e₂、b = 2e₁ + ke₂，共線 ⇒ b = λa：
  e₁ 係數 λ = 2 ✓；e₂ 係數 k = −2λ = **−4** ✓
  （回代：b = 2e₁ − 4e₂ = 2(e₁ − 2e₂) = 2a ✓）
- **C-2** AB = OB − OA = (a+2b) − (a+b) = **b** ✓；AC = OC − OA = (a+3b) − (a+b) = **2b** ✓
  → AC = 2AB，共線且共點 A → A、B、C 三點共線 ✓
- **C-3** 開放題 ✓

## 三、平面向量（三）基本定理與坐標表示

### 講義
- 平面向量基本定理（e₁、e₂ 不共線 → 任一 a 唯一表為 λ₁e₁ + λ₂e₂）✓
- 坐標表示 a = xi + yj = (x, y) ✓
- 五條運算規則：加減逐分量 ✓、數乘逐分量 ✓、AB =（終點 − 起點）✓、
  |a| = √(x₁²+y₁²) ✓、a ∥ b ⟺ x₁y₂ − x₂y₁ = 0 ✓
- **範例** A(5,3)、B(1,2)、a = (−1,1)、b = (2,−1)：
  AB = (1−5, 2−3) = **(−4, −1)** ✓；a+b = **(1, 0)** ✓；a−b = **(−3, 2)** ✓；2a = **(−2, 2)** ✓

### 練習
- **A-1** (1) (4, 1) ✓　(2) (1−3, 2+1) = (−2, 3) ✓　(3) (2, 4) ✓
- **A-2** AB = (4−2, 5−1) = **(2, 4)** ✓（與「往右 2 格、往上 4 格」的圖上檢查一致 ✓）
- **B-1** 2b = (0, −2)；2b − a = (0−3, −2−2) = **(−3, −4)** ✓ → 選 (1) ✓
- **B-2** a = (−3,1)、b = (m,2)：(−3)(2) − (m)(1) = 0 → **m = −6** ✓
  （回代：b = (−6, 2) = 2(−3, 1) = 2a ✓ 確實平行）
- **B-3** |a| = √(2²+3²) = **√13** ✓
- **B-4** 平行四邊形 ABCD，A(1,−2)、B(3,0)、C(4,3)：
  BC = (4−3, 3−0) = (1, 3) ✓；AD = BC → D = A + (1,3) = **(2, 1)** ✓
  （反向覆核：AB = (2,2)，DC = C − D = (4−2, 3−1) = (2,2)，AB = DC ✓ 確為平行四邊形）
- **C-1** A(k,5)、B(−3,3)、C(2,k−3)：
  AB = (−3−k, −2) ✓；AC = (2−k, k−8) ✓
  共線 ⇒ (−3−k)(k−8) − (−2)(2−k) = 0
  展開：(−k²+5k+24) − (−4+2k) = −k² + 3k + 28 = 0 → **k² − 3k − 28 = 0** ✓
  因式分解 (k−7)(k+4) = k² − 3k − 28 ✓ → **k = 7 或 k = −4** ✓
  **兩根逐一回代驗證**：
  - k = 7：A(7,5)、B(−3,3)、C(2,4) → AB = (−10,−2)、AC = (−5,−1)，AC = ½AB ✓ 共線
  - k = −4：A(−4,5)、B(−3,3)、C(2,−7) → AB = (1,−2)、AC = (6,−12)，AC = 6AB ✓ 共線
  **兩個答案都成立，答案給兩根正確**（無需捨根）
- **C-2** M = ((1+5)/2, (2+4)/2) = **(3, 3)** ✓
  G = ((1+5+3)/3, (2+4−6)/3) = (9/3, 0/3) = **(3, 0)** ✓

## 四、平面向量（四）數量積

### 講義
- 夾角定義（共起點，0° ≤ θ ≤ 180°）✓；a ⊥ b 記法 ✓
- 定義 a·b = |a||b| cos θ ✓，**強調結果是數不是向量** ✓
- 正負號 ↔ 夾角類型（銳角正／直角零／鈍角負）✓
- a ⊥ b ⟺ a·b = 0 ✓
- 坐標式 a·b = x₁x₂ + y₁y₂ ✓；|a| = √(x₁²+y₁²) ✓；cos θ = (a·b)/(|a||b|) ✓
- 展開式 (a+b)² = |a|² + 2a·b + |b|² ✓
- **範例** |a| = 4、|b| = 2、θ = 60°：
  a·b = 4×2×½ = **4** ✓；(a+b)² = 16 + 2(4) + 4 = **28** ✓；|a+b| = √28 = **2√7** ✓

### 練習
- **A-1** 3 × 2 × ½ = **3** ✓
- **A-2** (−2)(2) + (1)(3) = −4 + 3 = **−1** ✓
- **A-3** |a| = √(4+9) = **√13** ✓
- **B-1** 1 × 1 × cos 60° = **½** ✓ → 選 (1) ✓
- **B-2** cos θ = 5/(2×5) = ½ → **θ = 60°** ✓（在 0°–180° 內唯一 ✓）
- **B-3** (1) a·b = 1×1 + 2×(−1) = **−1** ✓
  (2) 2a + b = (2+1, 4−1) = **(3, 3)** ✓；ka − b = (k−1, 2k+1) ✓
  垂直 ⇒ 3(k−1) + 3(2k+1) = 3k − 3 + 6k + 3 = 9k = 0 → **k = 0** ✓
  （回代 k = 0：ka − b = (−1, 1)；(3,3)·(−1,1) = −3 + 3 = 0 ✓ 確實垂直）
- **C-1** a + xb = (3+2x, 4−x) ✓
  (a + xb)·b = 2(3+2x) + (−1)(4−x) = 6 + 4x − 4 + x = 2 + 5x = 0 → **x = −2/5** ✓
- **C-2** A(1,2)、B(2,3)、C(−2,5)：AB = (1,1) ✓、AC = (−3,3) ✓
  AB·AC = −3 + 3 = 0 → ∠A = 90° → **直角三角形** ✓
  （補核：|AB| = √2、|AC| = 3√2，兩邊不等長，故非等腰直角，答案只稱「直角三角形」正確 ✓）
- **C-3** 填 **2** ✓；理由（數量積交換律 a·b = b·a，展開後同一個數出現兩次）✓

## 五、解三角形（五）正弦定理與餘弦定理

### 講義
- 記號約定（大寫角、小寫對邊）✓
- 餘弦定理 c² = a² + b² − 2ab cos C ✓，及輪換兩式 ✓
- 推論 cos A = (b² + c² − a²)/(2bc) ✓（記憶提示與公式逐項對得上 ✓）
- 正弦定理 a/sin A = b/sin B = c/sin C = 2R ✓
- 選定理決策卡（兩邊夾角／三邊 → 餘弦；兩角一邊／兩邊及對角 → 正弦）✓
- 面積 S = ½ab sin C ✓
- **範例** a = 7、b = 8、c = 5：
  cos A = (64 + 25 − 49)/(2×8×5) = 40/80 = ½ → **A = 60°** ✓
  sin B = b sin A / a = 8×(√3/2)/7 = **4√3/7** ✓
  合理性覆核：4√3/7 ≈ 0.9897 < 1 ✓；b 為最長邊故 B 為最大角，
  由 cos C = (49+64−25)/(2×7×8) = 88/112 = 0.7857 → C ≈ 38.2°，
  則 B ≈ 180° − 60° − 38.2° = 81.8°，sin 81.8° ≈ 0.990 ✓ 與 4√3/7 吻合

### 練習
- **A-1** (1) cos C ✓　(2) sin B ✓　(3) sin C ✓
- **A-2** cos A = (16 + 25 − 9)/(2×4×5) = 32/40 = **4/5** ✓
- **A-3** sin B = 6×(√3/2)/9 = 3√3/9 = **√3/3** ✓
- **B-1** B = 120°、b = AC = 2√7、c = AB = 4，設 a = BC：
  b² = a² + c² − 2ac cos B → 28 = a² + 16 − 2·a·4·(−½) = a² + 16 + 4a ✓
  → a² + 4a − 12 = 0 → (a+6)(a−2) = 0 → 取正根 **a = 2** ✓
  （負根 a = −6 為邊長，必捨 ✓；回代：4 + 16 + 8 = 28 ✓）
- **B-2** cos B = (a² + c² − b²)/(2ac) = (4 + 9 − 12)/(2×2×3) = 1/12 ✓ → 選 (1) ✓
- **B-3** b = a sin B / sin A = 2×(√3/2)/(√2/2) = √3 × 2/√2 = **√6** ✓ → 選 (1) ✓
- **B-4** (1) a/sin A = 2R = **2** ✓　(2) 選 **(i)** ✓
  （(ii) 符號錯、(iii) 誤用 sin，兩個誘答都指向真實迷思 ✓）
- **C-1** a = 4、b = 5、cos C = 1/8：
  (1) c² = 16 + 25 − 2×4×5×(1/8) = 41 − 5 = 36 → **c = 6** ✓；周長 = 4+5+6 = **15** ✓
  (2) sin C = √(1 − 1/64) = √(63/64) = **3√7/8** ✓（√63 = 3√7 ✓）
  S = ½ × 4 × 5 × 3√7/8 = 30√7/8 = **15√7/4** ✓
  （三角形存在性覆核：cos C = 1/8 ∈ (−1,1) ✓；4、5、6 滿足三角不等式 ✓）
- **C-2** d² = 300² + 500² − 2×300×500×cos 60° = 90000 + 250000 − 150000 = **190000** ✓
  d = √190000 = √(10000×19) = **100√19 ≈ 436 公尺** ✓（100×4.3589 = 435.9 ✓）
  創作部分開放，檢核重點合理 ✓
