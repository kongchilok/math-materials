二、練習B（★★☆）

B-1．求值：sin(−30°) + cos 225° + tan 405°

提示：三個角分開處理：負角先變正角；225° = 180° + 45°；405° = 360° + 45°。

B-2．求值：\(\sin\dfrac{13\pi}{6} + \cos\dfrac{23\pi}{3}\)

提示：\(\dfrac{13\pi}{6} = 2\pi+\dfrac{\pi}{6}\)；\(\dfrac{23\pi}{3} = 6\pi+\dfrac{5\pi}{3}\)，再把 \(\dfrac{5\pi}{3}\) 寫成 \(2\pi-\dfrac{\pi}{3}\)。

B-3．化簡：\(\dfrac{\cos(\pi-\alpha)\cdot\sin(2\pi-\alpha)}{\sin(\pi+\alpha)\cdot\cos(-\alpha)}\)

提示：一項一項換：\(\cos(\pi-\alpha)=-\cos\alpha\)；\(\sin(2\pi-\alpha)=-\sin\alpha\)；\(\sin(\pi+\alpha)=-\sin\alpha\)；\(\cos(-\alpha)=\cos\alpha\)。換完再約分。

B-4．用五點法作出 y = 1 + sin x（0 ≤ x ≤ 2π）的圖像。先填表，再描點連線：

x：　0　　π/2　　π　　3π/2　　2π

sin x：＿＿　＿＿　＿＿　＿＿　＿＿

y = 1 + sin x：＿＿　＿＿　＿＿　＿＿　＿＿

（在格線上描出五個點，再用平滑曲線連接）

B-5．求下列函數的最小正週期：

(1) \(f(x) = \cos\!\left(2x+\dfrac{\pi}{8}\right)\)　　(2) \(g(x) = \sin\dfrac{x}{2}\)

提示：\(T = \dfrac{2\pi}{\omega}\)，ω 是 x 前面的係數。

B-6．求函數 y = 2 − sin x 的最大值和最小值，並說出各在 sin x 等於多少時取得。

提示：sin x 的範圍是 −1 到 1。sin x 前面是負號——sin x 越小，y 越大。
三、練習C（★★★）
