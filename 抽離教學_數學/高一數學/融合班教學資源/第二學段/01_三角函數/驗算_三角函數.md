## 第一份：角與三角函數的概念

### 講義
- 終邊相同角 α + k·360°（k 為整數）✓；例證 390° − 30° = 360° ✓
- 弧度制 180° = π rad ✓；度→弧度 ×π/180 ✓；弧度→度 ×180/π ✓
- 常用對照 30°=π/6、45°=π/4、60°=π/3、90°=π/2、180°=π ✓（逐個以 ×π/180 覆算）
- 扇形 l = αr ✓；S = ½lr = ½αr² ✓（由 S = ½·弧長·半徑 與 l=αr 互推一致）
- 單位圓定義 sin α = y、cos α = x、tan α = y/x (x≠0) ✓
- 非單位圓 r = √(x²+y²) ✓；sin = y/r、cos = x/r、tan = y/x ✓
- 符號口訣「一全正、二正弦、三正切、四餘弦」✓
- 平方關係 sin²α + cos²α = 1 ✓；商數關係 tan α = sin α / cos α ✓
- **範例** P(3, −4)：r = √(9+16) = √25 = 5 ✓；sin = −4/5 ✓、cos = 3/5 ✓、tan = −4/3 ✓；
  第四象限只有 cos 正，與算出的正負號一致 ✓

## 第二份：誘導公式與圖像性質

### 講義（六組共 17 條公式，逐條以單位圓對稱覆核）
- 第1組 sin/cos/tan(2kπ+α) 值不變 ✓
- 第2組 sin(π+α) = −sin α ✓、cos(π+α) = −cos α ✓、tan(π+α) = tan α ✓（原點對稱）
- 第3組 sin(−α) = −sin α ✓、cos(−α) = cos α ✓、tan(−α) = −tan α ✓（x 軸對稱）
- 第4組 sin(π−α) = sin α ✓、cos(π−α) = −cos α ✓、tan(π−α) = −tan α ✓（y 軸對稱）
- 第5組 sin(π/2−α) = cos α ✓、cos(π/2−α) = sin α ✓
- 第6組 sin(π/2+α) = cos α ✓、cos(π/2+α) = −sin α ✓
- 口訣「奇變偶不變，符號看象限」與上列六組逐組對得上 ✓
- 特殊角表：sin 0、½、√2/2、√3/2、1 ✓；cos 1、√3/2、√2/2、½、0 ✓；
  tan 0、√3/3、1、√3、不存在 ✓（tan 各格用 sin÷cos 覆算：(1/2)÷(√3/2)=1/√3=√3/3 ✓）
- 圖像性質：定義域 R ✓、值域 [−1,1] ✓、最小正週期 2π ✓、sin 奇 ✓、cos 偶 ✓
- sin 遞增 [−π/2+2kπ, π/2+2kπ] ✓、遞減 [π/2+2kπ, 3π/2+2kπ] ✓
- cos 遞增 [−π+2kπ, 2kπ] ✓、遞減 [2kπ, π+2kπ] ✓
- 週期 T = 2π/ω ✓；五點法取 0、π/2、π、3π/2、2π ✓
- **範例** cos(−120°) = cos 120°（偶）✓ = cos(180°−60°) = −cos 60° = **−½** ✓；
  第二象限 cos 為負，檢查句成立 ✓

## 第三份：公式變換與圖像變換

### 講義
- 兩角和差六條：cos(α∓β)、sin(α±β)、tan(α±β) 全部與標準式逐字相符 ✓
- 記法「cos 同名相乘、符號相反；sin 異名相乘、符號相同」與六條公式對得上 ✓
- 二倍角：sin 2α = 2sin α cos α ✓；cos 2α 三式（cos²−sin²、2cos²−1、1−2sin²）互推一致 ✓；
  tan 2α = 2tan α/(1−tan²α) ✓
- 輔助角 a sin x + b cos x = √(a²+b²)·sin(x+φ) ✓
  - sin x + cos x = √2 sin(x+π/4) ✓（A=√2、φ=π/4 覆算）
  - √3 sin x + cos x = 2 sin(x+π/6) ✓（A=√(3+1)=2、tan φ = 1/√3 → φ=π/6 覆算）
- 四參數作用（A 振幅、ω 週期 T=2π/ω、φ 左加右減、b 上下移）✓
- 提出係數的示範 sin(2x+π/3) = sin 2(x+π/6) ✓
- **範例** cos 75° = cos 45°cos 30° − sin 45°sin 30° = (√2/2)(√3/2) − (√2/2)(1/2)
  = **(√6−√2)/4** ✓；數值檢查 (2.449−1.414)/4 ≈ 0.259，講義寫 ≈ 0.26 ✓

### 練習（教師答案逐題重算）
