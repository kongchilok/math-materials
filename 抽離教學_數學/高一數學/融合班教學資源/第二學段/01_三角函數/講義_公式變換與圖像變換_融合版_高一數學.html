一、兩角和與差的公式

\(\cos(\alpha-\beta) = \cos\alpha\cos\beta + \sin\alpha\sin\beta\)

\(\cos(\alpha+\beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta\)

\(\sin(\alpha+\beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta\)

\(\sin(\alpha-\beta) = \sin\alpha\cos\beta - \cos\alpha\sin\beta\)

\(\tan(\alpha+\beta) = \dfrac{\tan\alpha+\tan\beta}{1-\tan\alpha\tan\beta}\)　　\(\tan(\alpha-\beta) = \dfrac{\tan\alpha-\tan\beta}{1+\tan\alpha\tan\beta}\)

提示：記法：cos 的展開是「同名相乘」（cos·cos、sin·sin），中間符號跟原式相反；sin 的展開是「異名相乘」（sin·cos、cos·sin），中間符號跟原式相同。

用途一：算非特殊角。例如 75° = 45° + 30°、15° = 45° − 30°。

用途二：把 sin 20° cos 40° + cos 20° sin 40° 這種展開式「收回去」變成 sin(20° + 40°) = sin 60°。

二、二倍角公式（令 β = α 就得到）

\(\sin 2\alpha = 2\sin\alpha\cos\alpha\)

\(\cos 2\alpha = \cos^2\alpha-\sin^2\alpha = 2\cos^2\alpha-1 = 1-2\sin^2\alpha\)

\(\tan 2\alpha = \dfrac{2\tan\alpha}{1-\tan^2\alpha}\)

提示：cos 2α 有三種寫法——題目給 sin α 就用「1 − 2sin²α」，給 cos α 就用「2cos²α − 1」，兩個都給才用「cos²α − sin²α」。
三、輔助角公式（a sin x + b cos x 合成一個 sin）

\(a\sin x + b\cos x = \sqrt{a^2+b^2}\,\sin(x+\varphi)\)

常用的兩個結果：\(\sin x+\cos x = \sqrt{2}\,\sin\!\left(x+\dfrac{\pi}{4}\right)\)；　\(\sqrt{3}\sin x+\cos x = 2\sin\!\left(x+\dfrac{\pi}{6}\right)\)

提示：合成之後，最大值就是前面的係數 \(\sqrt{a^2+b^2}\)，最小值是它加負號——這就是求「a sin x + b cos x 型」最值的固定套路。
四、y = A sin(ωx + φ) + b 四個參數的作用

A（振幅）：圖像縱向拉伸，最大 A、最小 −A。

ω：橫向壓縮或拉伸，週期變成 \(T=\dfrac{2\pi}{\omega}\)。

φ：左右平移——「左加右減」：x + φ 是向左移 φ，x − φ 是向右移 φ。

b：整條曲線上下平移 b。

五、範例（跟著四個步驟做）

求 cos 75° 的值。

  • 步驟1　拆角：75° 不是特殊角，把它拆成兩個特殊角：75° = 45° + 30°。
  • 步驟2　選公式：拆的是「和」，cos 的和公式中間變減號：cos(α + β) = cos α cos β − sin α sin β。
  • 步驟3　代入計算：\(\cos 75^\circ = \dfrac{\sqrt{2}}{2}\cdot\dfrac{\sqrt{3}}{2}-\dfrac{\sqrt{2}}{2}\cdot\dfrac{1}{2} = \dfrac{\sqrt{6}-\sqrt{2}}{4}\)。
  • 步驟4　檢查：75° 接近 90°，cos 應該接近 0 而且是正的。(2.45 − 1.41) ÷ 4 ≈ 0.26，合理。
