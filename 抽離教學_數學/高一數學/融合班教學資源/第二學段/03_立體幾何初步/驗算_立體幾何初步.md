## 一、講義 §二 七種立體的公式（13 條，逐條核對）

| 立體 | 表面積 | 體積 | 核對 |
|---|---|---|---|
| 正稜柱 | S＝2S底＋C·h | V＝S底·h | 直稜柱側面積＝底周長×高 ✓ |
| 圓柱 | S＝2πr²＋2πrh | V＝πr²h | 側面展開為矩形 2πr×h ✓ |
| 正稜錐 | S＝S底＋C·l/2 | V＝⅓S底·h | 側面為三角形，面積和＝½×底周長×斜高 ✓ |
| 圓錐 | S＝πr²＋πrl | V＝⅓πr²h | 側面展開為扇形，面積＝½·(2πr)·l＝πrl ✓ |
| 圓錐母線 | l＝√(r²＋h²) | — | 軸截面直角三角形，畢氏定理 ✓ |
| 正稜台 | S＝S上＋S下＋½(C上＋C下)·l斜 | V＝⅓(S上＋S下＋√(S上·S下))·h | 側面為梯形，面積和＝½(上周長＋下周長)×斜高；體積為擬柱體公式 ✓ |
| 圓台 | S＝π(R²＋r²)＋π(R＋r)l | V＝⅓πh(R²＋Rr＋r²) | 側面＝大扇形減小扇形＝π(R+r)l；體積為圓台標準式 ✓ |
| 球 | S＝4πR² | V＝⁴⁄₃πR³ | 標準式 ✓ |

**符號一致性**：全份 r＝半徑、R＝（圓台／球）較大半徑、h＝高、l＝母線或斜高、S底＝底面積、
C＝底面周長，講義已列符號說明，練習提示沿用同一套 ✓
