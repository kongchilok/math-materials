一、餘式定理：不用做除法，也知道餘式
上一課用綜合除法求餘式。如果題目只問餘式、不問商式，還有更快的方法。
▍餘式定理
什麼時候翻我：題目只問「餘式」，不問商式
\(f(x)\div (x-a)\) 的餘式 ＝ \(f(a)\)
為什麼：由除法原理 \(f(x)=(x-a)\cdot q(x)+r\)，把 \(x=a\) 代入，\((a-a)\) 是 0，前面整項消失，只剩下 \(r\)。
推論：\(f(x)\div (ax-b)\) 的餘式 ＝ \(f(\frac{b}{a})\)（\(a\ne 0\)）。
用餘式定理求餘式　四步
什麼時候用：題目只問餘式、不問商式
1. 令除式 ＝ 0，解出要代入的 x※ \(x+3\) 要代 \(-3\)；\(2x-1\) 要代 \(\frac{1}{2}\)
2. 把這個數代入 \(f(x)\)，負數和分數都加括號※ 先算次方，再乘係數
3. 逐項算出每一項的值※ 一項一項寫，不要心算一整條
4. 加起來就是餘式※ 答案是一個數；算出含 x 就是錯了
（教師）褪除：完整四步卡 → 只留「令除式 ＝ 0 → 代入 → 逐項算」→ 只問「要代哪個數」→ 移除
二、範例一：除式是 x − a
★ 範例一：設 \(f(x)=x^{3}-4x^{2}+3x-5\)，求 \(f(x)\) 除以 \(x-2\) 的餘式。
算式這一步在做什麼
\(x-2\)\(=\)\(0\)第 1 步：令除式 ＝ 0
\(x\)\(=\)\(2\)要代入的數是 2
\(f(2)\)\(=\)\(2^{3}-4(2)^{2}+3(2)-5\)第 2 步：代入
\(f(2)\)\(=\)\(8-16+6-5\)第 3 步：逐項算
\(f(2)\)\(=\)\(-7\)第 4 步：加起來
\(\therefore\) 餘式為 \(-7\)作答：最後一行用「∴」寫出答案
\(2\)\(1\)\(-4\)\(3\)\(-5\)
\(2\)\(-4\)\(-2\)
\(1\)\(-2\)\(-1\)\(-7\)
商式係數餘式
兩個方法，同一個餘式
用綜合除法核對：最後一格也是 \(-7\)。
餘式定理只是跳過了前面那幾格。
兩個方法答案一樣——可以用其中一個檢查另一個。
三、範例二：除式是 ax − b
★ 範例二：設 \(f(x)=2x^{4}-3x^{3}+x-2\)，求 \(f(x)\) 除以 \(2x-1\) 的餘式。
算式這一步在做什麼
\(2x-1\)\(=\)\(0\)第 1 步：令除式 ＝ 0
\(x\)\(=\)\(\frac{1}{2}\)要代入的數是 \(\frac{1}{2}\)
\(f(\frac{1}{2})\)\(=\)\(2(\frac{1}{2})^{4}-3(\frac{1}{2})^{3}+\frac{1}{2}-2\)第 2 步：代入，分數加括號
\(f(\frac{1}{2})\)\(=\)\(\frac{1}{8}-\frac{3}{8}+\frac{4}{8}-\frac{16}{8}\)第 3 步：逐項算，化成同分母
\(f(\frac{1}{2})\)\(=\)\(-\frac{7}{4}\)第 4 步：加起來
\(\therefore\) 餘式為 \(-\frac{7}{4}\)作答：最後一行用「∴」寫出答案
\(f(a)\) 有兩個身份：它是函數在 \(x=a\) 的值，也是 \(f(x)\) 除以 \((x-a)\) 的餘式。
四、反過來用：已知餘式，求未知數
★ 範例三：\(3x^{4}+x^{3}+2x^{2}-ax+6\) 除以 \(x+1\) 的餘式為 1，求 \(a\) 的值。
算式這一步在做什麼
令 \(x+1=0\)，要代入 \(x=-1\)第 1 步
\(f(-1)\)\(=\)\(3(-1)^{4}+(-1)^{3}+2(-1)^{2}-a(-1)+6\)第 2 步：代入，負數加括號
\(f(-1)\)\(=\)\(3-1+2+a+6\)第 3 步：逐項算
\(10+a\)\(=\)\(1\)第 4 步：餘式 ＝ 1，寫成方程
\(a\)\(=\)\(-9\)移項
\(\therefore\) \(a=-9\)作答：最後一行用「∴」寫出答案
五、除以兩個一次式的乘積
如果除式是 \((x+1)(x-2)\) 這種二次式，餘式最多是一次式，要先設成 \(px+q\)。
求除以 (x − a)(x − b) 的餘式　四步
什麼時候用：題目給兩個一次式的餘式，問除以它們乘積的餘式
1. 除式是二次，餘式最多一次：設餘式為 \(px+q\)※ 不可以只設一個常數
2. 寫出 \(f(x)=(x-a)(x-b)\cdot Q(x)+px+q\)※ \(Q(x)\) 是商式，不用求
3. 分別代入 \(x=a\)、\(x=b\)，前面那項變 0，得兩條方程※ \(f(a)\) 就是題目給的第一個餘式
4. 聯立解出 \(p\)、\(q\)，寫出餘式 \(px+q\)※ 答案是一條式子，不是兩個數
（教師）褪除：完整四步卡 → 只留「設 px ＋ q → 代兩個數 → 聯立」→ 移除
★ 範例四：\(f(x)\) 除以 \(x+1\) 的餘式為 4，除以 \(x-2\) 的餘式為 \(-2\)。求 \(f(x)\) 除以 \((x+1)(x-2)\) 的餘式。
算式這一步在做什麼
設 \(f(x)=(x+1)(x-2)\cdot Q(x)+px+q\)第 1、2 步：餘式設為 \(px+q\)
\(f(-1)\)\(=\)\(-p+q\)第 3 步：代入 \(x=-1\)，前面那項變 0
\(-p+q\)\(=\)\(4\)題目說除以 \(x+1\) 的餘式是 4，記作 ①
\(f(2)\)\(=\)\(2p+q\)代入 \(x=2\)
\(2p+q\)\(=\)\(-2\)題目說除以 \(x-2\) 的餘式是 \(-2\)，記作 ②
\(3p\)\(=\)\(-6\)第 4 步：② − ①
\(p\)\(=\)\(-2\)
\(q\)\(=\)\(2\)代回 ①：\(2+q=4\)
\(\therefore\) 餘式為 \(-2x+2\)作答：最後一行用「∴」寫出答案
