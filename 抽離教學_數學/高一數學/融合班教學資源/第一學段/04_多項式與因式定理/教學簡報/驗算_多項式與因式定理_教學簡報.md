## L2　綜合除法

| 例題一 | (x²+3x+6) ÷ (x+1) | c=−1；1, 2 \| 4 | 商 x+2，餘 4 | (x+1)(x+2)+4 = x²+3x+2+4 = **x²+3x+6** ✓ |
| 例題二 | (4x³+4x²−x−3) ÷ (2x+1) | c=−½；4, 2, −2 \| −2 | 商 2x²+x−1（4,2,−2 各除 2），餘 −2 | (2x+1)(2x²+x−1)−2 = 4x³+2x²−2x+2x²+x−1−2 = **4x³+4x²−x−3** ✓ |

| 練習 B | (2x³−3x²+x−5) ÷ (x−2) | c=2；2, 1, 3 \| 1 | 商 2x²+x+3，餘 1 | (x−2)(2x²+x+3)+1 = 2x³+x²+3x−4x²−2x−6+1 = **2x³−3x²+x−5** ✓ |

## L5　牛頓定理（整係數一次因式檢驗法）

例題：f(x)=x³−2x²−5x+6，首項係數 1（因數 ±1）、常數項 6（因數 ±1, ±2, ±3, ±6）

| 試 x = | f(x) 計算 | 結果 |
|---|---|---|
| 1 | 1−2−5+6 | **0** → (x−1) 是因式 ✓ |
| −1 | −1−2+5+6 | 8 → 不是 ✓ |
| 2 | 8−8−10+6 | −4 → 不是 ✓ |
| −2 | −8−8+10+6 | **0** → (x+2) 是因式 ✓ |
| 3 | 27−18−15+6 | **0** → (x−3) 是因式 ✓ |

回代驗證：(x−1)(x+2)(x−3) = (x²+x−2)(x−3) = x³−3x²+x²−3x−2x+6 = **x³−2x²−5x+6** ✓
（三次式最多 3 個一次因式，已足數，投影片標明可停 ✓）

| 練習 | 題目 | 答案 | 驗證 |
|---|---|---|---|
| A | f(x)=x²−5x+6，列 6 的因數；試 f(2) | ±1, ±2, ±3, ±6；f(2)=4−10+6=**0** ✓ | x²−5x+6=(x−2)(x−3) ✓ |
| B | f(x)=x³−6x²+11x−6，找一個一次因式 | f(1)=1−6+11−6=**0** → (x−1) ✓ | =(x−1)(x−2)(x−3) ✓ |
| C | f(x)=2x³−x²−5x−2（首項係數 2，需試分數） | f(−1)=−2−1+5−2=**0** →(x+1)；f(2)=16−4−10−2=**0** →(x−2)；f(−½)=−¼−¼+5/2−2=**0** →(2x+1) | (x+1)(x−2)(2x+1) = (x²−x−2)(2x+1) = 2x³+x²−2x²−x−4x−2 = **2x³−x²−5x−2** ✓ |

## L7　二次函數與判別式

| 項目 | 題目 | a, b, c | Δ = b²−4ac | 結論 |
|---|---|---|---|---|
| 例題 | x²−5x+6=0 | 1, −5, 6 | 25 − 24 = **1 > 0** | 兩個不等實根 x=2, 3 ✓（(x−2)(x−3)=x²−5x+6 ✓） |
| 對照表 | x²−4x+4=0 | 1, −4, 4 | 16 − 16 = **0** | 一個重根 x=2 ✓（(x−2)²） |
| 對照表 | x²+x+1=0 | 1, 1, 1 | 1 − 4 = **−3 < 0** | 無實根 ✓ |
| 練習 A | x²−6x+5=0 | 1, −6, 5 | 36 − 20 = **16 > 0** | 兩個根（x=1, 5）✓ |
| 練習 B① | x²−2x+1=0 | 1, −2, 1 | 4 − 4 = **0** | 一個重根 x=1 ✓ |
| 練習 B② | x²+2x+5=0 | 1, 2, 5 | 4 − 20 = **−16 < 0** | 無實根 ✓ |
| 練習 C | x²+kx+9=0 有兩個相等實根 | 1, k, 9 | k² − 36 = 0 | **k = ±6** ✓（k=6 →(x+3)²；k=−6 →(x−3)²，皆為重根 ✓） |

圖示驗證（第 7 頁三格）：三格用同一條開口向上拋物線，只移動 x 軸高度 —— 與「Δ 改變 = 圖象相對
x 軸上下平移」的數學事實一致，交點數 2／1／0 正確 ✓

## L8　一元二次不等式

| 項目 | 題目 | 根 | 解集 | 抽點驗證 |
|---|---|---|---|---|
| 例題 | x²−5x+6 > 0 | 2, 3 | **{x \| x<2 或 x>3}** | x=0：6>0 ✓（在解集）；x=2.5：−0.25<0 ✓（不在）；x=4：2>0 ✓（在） |
| 對照 | x²−5x+6 < 0 | 2, 3 | **{x \| 2<x<3}** | x=2.5：−0.25<0 ✓ |
| 對照 | x²−5x+6 ≥ 0 | 2, 3 | **{x \| x≤2 或 x≥3}**（實心圈） | x=2：0≥0 ✓（含端點） |
| 慢鏡例題 | −x²+4x−3 > 0 | 乘 −1 反向 → x²−4x+3 < 0；根 1, 3 | **{x \| 1<x<3}** | x=2：−4+8−3=1>0 ✓（在解集）；x=0：−3<0 ✓（不在） |
| 練習 A | (x−1)(x−4) > 0 | 1, 4 | **{x \| x<1 或 x>4}** | x=0：(−1)(−4)=4>0 ✓；x=2：(1)(−2)=−2<0 ✓（不在） |
| 練習 B | x²−x−6 < 0 | (x−3)(x+2) → −2, 3 | **{x \| −2<x<3}** | x=0：−6<0 ✓；x=4：16−4−6=6>0 ✓（不在） |
| 練習 C | −x²+4x−3 > 0 | 同慢鏡例題 | **{x \| 1<x<3}** | x=2：1>0 ✓ |

口訣驗證：a>0 時「大於取兩邊、細過取中間」，上表六列全部符合 ✓
