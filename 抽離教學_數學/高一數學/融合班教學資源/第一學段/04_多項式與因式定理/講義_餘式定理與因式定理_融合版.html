一、餘式定理：不用做除法，也知道餘式
上一份講義用綜合除法求餘式。如果題目只問餘式、不問商式，還有更快的方法。
▍餘式定理
什麼時候翻我：題目只問「餘式」，不問商式
\(f(x)\div (x-a)\) 的餘式 ＝ \(f(a)\)
為什麼：由除法原理 \(f(x)=(x-a)\cdot q(x)+r\)，把 \(x=a\) 代入，\((a-a)\) 是 0，前面整項消失，只剩下 \(r\)。
二、用餘式定理求餘式的手順卡
用餘式定理求餘式　四步
什麼時候用：題目只問餘式、不問商式
1. 令除式 ＝ 0，解出要代入的 x※ \(x+2\) 要代 \(-2\)；\(2x-1\) 要代 \(\frac{1}{2}\)
2. 把這個數代入 \(f(x)\)，負數和分數都加括號※ 先算次方，再乘係數
3. 逐項算出每一項的值※ 一項一項寫，不要心算一整條
4. 加起來就是餘式※ 答案是一個數；算出含 x 就是錯了
（教師）褪除：完整四步卡 → 只留「令除式 ＝ 0 → 代入 → 逐項算」→ 只問「要代哪個數」→ 移除
三、範例一
★ 範例一：\(f(x)=x^{3}-3x^{2}+2x-5\)，求 \(f(x)\) 除以 \((x-2)\) 的餘式。
算式這一步在做什麼
\(x-2\)\(=\)\(0\)第 1 步：令除式 ＝ 0
\(x\)\(=\)\(2\)要代入的數是 2
\(f(2)\)\(=\)\(2^{3}-3(2)^{2}+2(2)-5\)第 2 步：代入
\(f(2)\)\(=\)\(8-12+4-5\)第 3 步：逐項算
\(f(2)\)\(=\)\(-5\)第 4 步：加起來
\(\therefore\) 餘式為 \(-5\)作答：最後一行用「∴」寫出答案
\(2\)\(1\)\(-3\)\(2\)\(-5\)
\(2\)\(-2\)\(0\)
\(1\)\(-1\)\(0\)\(-5\)
商式係數餘式
兩個方法，同一個餘式
用綜合除法核對：最後一格也是 \(-5\)。
餘式定理只是跳過了前面那幾格。
兩個方法答案一樣——考試時可以用其中一個檢查另一個。
四、除式是 ax − b 的情形
除式是 \(ax-b\) 時，一樣令除式 ＝ 0：\(ax-b=0\)，所以要代入 \(x=\frac{b}{a}\)。
★ 範例二：\(g(x)=2x^{3}-x^{2}+3x-1\)，求 \(g(x)\) 除以 \((2x-1)\) 的餘式。
算式這一步在做什麼
\(2x-1\)\(=\)\(0\)第 1 步：令除式 ＝ 0
\(x\)\(=\)\(\frac{1}{2}\)要代入的數是 \(\frac{1}{2}\)
\(g(\frac{1}{2})\)\(=\)\(2(\frac{1}{2})^{3}-(\frac{1}{2})^{2}+3(\frac{1}{2})-1\)第 2 步：代入，分數加括號
\(g(\frac{1}{2})\)\(=\)\(\frac{1}{4}-\frac{1}{4}+\frac{3}{2}-1\)第 3 步：逐項算
\(g(\frac{1}{2})\)\(=\)\(\frac{1}{2}\)第 4 步：加起來
\(\therefore\) 餘式為 \(\frac{1}{2}\)作答：最後一行用「∴」寫出答案
\(f(a)\) 有兩個身份：它是函數在 \(x=a\) 的值，也是 \(f(x)\) 除以 \((x-a)\) 的餘式。
五、因式定理：餘式剛好是 0
▍因式定理
什麼時候翻我：題目說「\((x-c)\) 是因式」或「能被 \((x-c)\) 整除」
\((x-c)\) 是 \(f(x)\) 的因式 \(\Leftrightarrow \) \(f(c)=0\)
因式定理就是餘式定理中「餘式剛好是 0」的情形。反過來用，可以求多項式裡的未知係數。
用因式定理求未知係數　四步
什麼時候用：題目說「\((x-c)\) 是因式」或「能被 \((x-c)\) 整除」
1. 每個因式寫一條「代入 ＝ 0」的式※ \((x+2)\) 要代 \(-2\)：令括號內 ＝ 0
2. 代入第一條，化簡成方程 ①※ 整理到只剩未知數和常數
3. 代入第二條，化簡成方程 ②※ 有幾個未知數，就要幾條方程
4. 聯立 ①、② 解出未知數，再代回檢查※ 代回後應該得 0
（教師）褪除：完整四步卡 → 只留「一個因式一條式」→ 只問「要列幾條式」→ 移除
六、範例三
★ 範例三：設 \(f(x)=x^{3}+px^{2}+qx-6\) 有因式 \((x-1)\) 及 \((x-2)\)，求 \(p\)、\(q\) 的值。
算式這一步在做什麼
\(f(1)=0\)，\(f(2)=0\)第 1 步：兩個因式，各寫一條「代入 ＝ 0」
\(1+p+q-6\)\(=\)\(0\)第 2 步：代入 \(f(1)=0\)
\(p+q\)\(=\)\(5\)化簡，記作 ①
\(8+4p+2q-6\)\(=\)\(0\)第 3 步：代入 \(f(2)=0\)
\(4p+2q\)\(=\)\(-2\)移項
\(2p+q\)\(=\)\(-1\)兩邊除以 2，記作 ②
\(p\)\(=\)\(-6\)第 4 步：② − ①
\(q\)\(=\)\(11\)代回 ①：\(-6+q=5\)
\(\therefore\) \(p=-6\)，\(q=11\)作答：最後一行用「∴」寫出答案
檢查：代回得 \(f(x)=x^{3}-6x^{2}+11x-6\)。\(f(1)\)：\(1-6+11-6\)，得 0；\(f(2)\)：\(8-24+22-6\)，也得 0。✓
