一、由「等於 0」走到「大於 0」
上一課解過方程 \(x^2-5x+6=0\)，答案是 \(x_1=2\) 或 \(x_2=3\)——兩個數。
這一課問的是不等式 \(x^2-5x+6 \gt 0\)。答案不再是幾個數，而是一整段範圍。
解一元二次不等式 ＝ 看二次函數的圖象落在 x 軸的哪一邊。
圖象在 x 軸上方　→　\(y \gt 0\)
圖象在 x 軸下方　→　\(y \lt 0\)
圖象碰到 x 軸　　→　\(y = 0\)（那一點就是根）
二、草圖怎麼畫、怎麼讀
草圖只要三樣東西：一條 x 軸、一條拋物線、軸上的根。不用畫 y 軸、不用畫格線、不用算頂點——三秒畫得完才有用。
以 \(y=x^2-5x+6\) 為例（根是 2 和 3，\(a=1 \gt 0\) 所以開口向上）：
草圖上看到什麼寫成什麼
\(x \lt 2\) 或 \(x \gt 3\) 這兩段，線在 x 軸上方
所以 \(y \gt 0\)
\(2 \lt x \lt 3\) 這一段，線在 x 軸下方
所以 \(y \lt 0\)
所以同一幅草圖可以回答兩種問題：問 ＞ 0 就取兩邊，問 ＜ 0 就取中間。
三、根有幾個？判別式 Δ 決定草圖長什麼樣
待會手順卡的第 3 步要「數清楚有幾個根」，靠的就是判別式 \(\Delta=b^2-4ac\)（此處 \(a \gt 0\)）：
判別式草圖長這樣問 ＞ 0 時問 ＜ 0 時
\(\Delta \gt 0\)
取兩邊
\(\{x \mid x \lt x_1\) 或 \(x \gt x_2\}\)
取中間
\(\{x \mid x_1 \lt x \lt x_2\}\)
\(\Delta = 0\)
除了那一點，全部都是解
\(\{x \mid x \ne x_0\}\)
無解
（圖象沒有一段在 x 軸下方）
\(\Delta \lt 0\)
全部實數都是解
\(\{x \mid x\) 是任何實數\(\}\)
無解
（整條都在 x 軸上方）
Δ ＝ 0 和 Δ ＜ 0 這兩欄，答案常常是「全部實數」或「無解」，不要以為一定要寫出兩個數才叫答案。
四、手順卡：解一元二次不等式五步
解一元二次不等式　五步
什麼時候用：題目是 \(ax^2+bx+c \gt 0\)（或 \(\lt\)、\(\ge\)、\(\le\)）這種二次不等式
1. 把所有項搬到一邊，讓右邊變成 0※ 過等號要變號；右邊不是 0 就不能往下做
2. 看二次項係數 a 的正負；a 是負數就整條乘 −1※ 乘負數，不等號一定要反向——這一步最易漏
3. 把不等號換成等號，解方程求根，數清楚有幾個根※ 因式分解或用公式；\(\Delta\) 決定有 2 個、1 個還是 0 個根
4. 畫草圖：開口向上，在 x 軸標出根※ 只畫 x 軸和拋物線，不用畫 y 軸、不用畫格線
5. 對照草圖挑範圍，用「∴」寫成解集※ 大於取兩邊，小於取中間
五、範例
★ 範例一：解 \(x^2-5x+6 \gt 0\)
算式這一步在做什麼
\(x^2-5x+6\)\(\gt\)\(0\)第 1 步：右邊已經是 0，不用搬
第 2 步：\(a=1\)，是正數，不用乘 −1
\(x^2-5x+6\)\(=\)\(0\)第 3 步：把不等號換成等號，先求根
\((x-2)(x-3)\)\(=\)\(0\)因式分解
\(x-2\)\(=\)\(0\)或\(x-3\)\(=\)\(0\)分成兩支寫，中間寫「或」
\(x_1\)\(=\)\(2\)或\(x_2\)\(=\)\(3\)兩個不相等的根
第 4 步：畫草圖，標出兩個根
第 5 步：問的是 ＞ 0，取 x 軸上方那兩段（粗線）
\(\therefore\) 解集為 \(\{x \mid x \lt 2\) 或 \(x \gt 3\}\)作答：最後一行用「∴」寫出解集
★ 範例二：解 \(-x^2+4x-3 \gt 0\)（二次項係數是負數）
算式這一步在做什麼
\(-x^2+4x-3\)\(\gt\)\(0\)第 1 步：右邊已經是 0
\(a=-1\)第 2 步：a 是負數 → 整條乘 −1，而且不等號要反向。這一步最易漏
\(x^2-4x+3\)\(\lt\)\(0\)乘 −1 之後：＞ 變成 ＜
\(x^2-4x+3\)\(=\)\(0\)第 3 步：把不等號換成等號，先求根
\((x-1)(x-3)\)\(=\)\(0\)因式分解
\(x-1\)\(=\)\(0\)或\(x-3\)\(=\)\(0\)分成兩支寫，中間寫「或」
\(x_1\)\(=\)\(1\)或\(x_2\)\(=\)\(3\)兩個不相等的根
第 4 步：畫的是乘 −1 之後那條的草圖
第 5 步：現在問的是 ＜ 0，取 x 軸下方那一段（粗線）
\(\therefore\) 解集為 \(\{x \mid 1 \lt x \lt 3\}\)作答：只有一段，不用寫「或」
