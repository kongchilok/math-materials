9．一個球向上拋出，\(t\) 秒後的高度是 \(h=16t-t^2\)（公尺）。問在哪一段時間內，球的高度超過 60 公尺？
練習C 做完，先自己核對一次
☐ a 是負數的題目，已經乘 −1 並反向；草圖畫的是乘完之後那一條
☐ 應用題的答案有寫回一段時間，不是只留一個不等式
教師用參考答案
A1　\((x-1)(x-4)=0\) → \(x_1=1\) 或 \(x_2=4\)；\(a \gt 0\) 開口向上，問 ＞ 0 取兩邊
∴ 解集為 \(\{x \mid x \lt 1\) 或 \(x \gt 4\}\)
A2　\(x^2-x-6=(x+2)(x-3)\)；令它等於 0 → \(x_1=-2\) 或 \(x_2=3\)；問 ＜ 0 取中間
∴ 解集為 \(\{x \mid -2 \lt x \lt 3\}\)
A3　\(x^2-7x+10=(x-2)(x-5)\)；令它等於 0 → \(x_1=2\) 或 \(x_2=5\)；問 ＞ 0 取兩邊
∴ 解集為 \(\{x \mid x \lt 2\) 或 \(x \gt 5\}\)
B4　\(\Delta=36-36=0\)，重根 \(x=3\)（即 \((x-3)^2 \le 0\)）；開口向上，只有頂點碰到 x 軸
\((x-3)^2\) 永遠 \(\ge 0\)，所以「\(\le 0\)」只在頂點成立
∴ 解集為 \(\{x \mid x=3\}\)
B5　\(\Delta=4-20=-16 \lt 0\)，沒有實根；\(a=1 \gt 0\) 開口向上，整條在 x 軸上方
∴ 解集為 \(\{x \mid x\) 是任何實數\(\}\)
B6　\(2x^2-3x-2=(2x+1)(x-2)\)；令它等於 0 → \(x_1=-\frac{1}{2}\) 或 \(x_2=2\)；\(a=2 \gt 0\)，問 ＜ 0 取中間
∴ 解集為 \(\{x \mid -\frac{1}{2} \lt x \lt 2\}\)
C7　\(a=-1 \lt 0\)，整條乘 −1 並把不等號反向：\(x^2-3x-4 \lt 0\)
\((x+1)(x-4)=0\) → \(x_1=-1\) 或 \(x_2=4\)；問 ＜ 0 取中間
∴ 解集為 \(\{x \mid -1 \lt x \lt 4\}\)
C8　\(\Delta=16-16=0\)，重根 \(x=2\)（即 \((x-2)^2 \gt 0\)）；開口向上，只有頂點碰到 x 軸
除了 \(x=2\) 那一點之外，其餘每一點都在 x 軸上方
∴ 解集為 \(\{x \mid x \ne 2\}\)
C9　\(16t-t^2 \gt 60\) → 搬到一邊：\(-t^2+16t-60 \gt 0\) → 乘 −1 並反向：\(t^2-16t+60 \lt 0\)
\((t-6)(t-10)=0\) → \(t_1=6\) 或 \(t_2=10\)；問 ＜ 0 取中間
∴ 解集為 \(\{t \mid 6 \lt t \lt 10\}\)，即第 6 秒到第 10 秒之間
