## 一、多項式除法（長除法與綜合除法）

### 講義
- 引例 17 ＝ 5×3＋2 ✓；「餘數比除數小」的類比正確 ✓
- 除法原理 f(x) ＝ g(x)·q(x) ＋ r(x)，deg r ＜ deg g ✓
- **範例一（長除法）** (x³+2x²+3x+1) ÷ (x−1)
  四個步驟逐步覆算：x³÷x=x² → 餘 3x²+3x+1 ✓；3x²÷x=3x → 餘 6x+1 ✓；6x÷x=6 → 餘 7 ✓
  結果 商 x²+3x+6、餘 7；**回乘覆核**：(x−1)(x²+3x+6)+7 = x³+2x²+3x+1 ✓
- **範例二（綜合除法，除式 x 係數為 1）** (x²+3x+6) ÷ (x+1)，c = −1
  1 → 1×(−1)=−1，3+(−1)=2 → 2×(−1)=−2，6+(−2)=4，與表中 1 | +2 | 4 完全一致 ✓
  商 x+2、餘 4；**回乘覆核**：(x+1)(x+2)+4 = x²+3x+6 ✓
- **範例三（除式 x 係數不為 1）** (4x³+4x²−x−3) ÷ (2x+1)，c = −½
  4 → −2，4−2=2 → −1，−1−1=−2 → +1，−3+1=−2，與表中 4 | +2 | −2 | −2 一致 ✓
  商係數 4,2,−2 再除以 2 得 2,1,−1 → 商 2x²+x−1、餘 −2（餘式不再除，正確）✓
  **回乘覆核**：(2x+1)(2x²+x−1) − 2 = 4x³+4x²−x−3 ✓

### 練習（教師答案逐題重算，每題皆回乘覆核）
1．A1 (x²+5x+6)÷(x+2)，c=−2：1 → −2，5−2=3 → −6，6−6=0
　　商 **x+3**、餘 **0** ✓　回乘：(x+2)(x+3) = x²+5x+6 ✓
　　A2 (2x²+3x−2)÷(x+2)，c=−2：2 → −4，3−4=−1 → +2，−2+2=0
　　商 **2x−1**、餘 **0** ✓　回乘：(x+2)(2x−1) = 2x²+3x−2 ✓
　　A3 (x²−x−6)÷(x−3)，c=3：1 → 3，−1+3=2 → 6，−6+6=0
　　商 **x+2**、餘 **0** ✓　回乘：(x−3)(x+2) = x²−x−6 ✓
2．B1 (3x³−2x²+5x−4)÷(x−2)，c=2：3 → 6，−2+6=4 → 8，5+8=13 → 26，−4+26=22
　　商 **3x²+4x+13**、餘 **22** ✓　回乘：(x−2)(3x²+4x+13)+22 = 3x³−2x²+5x−4 ✓
　　B2 同講義範例三 → 商 **2x²+x−1**、餘 **−2** ✓
　　B3 (2x³+x²−4x−5)÷(2x−3)，c=3/2：2 → 3，1+3=4 → 6，−4+6=2 → 3，−5+3=−2
　　商係數 2,4,2 除以 2 得 1,2,1 → 商 **x²+2x+1**、餘 **−2** ✓
　　回乘：(2x−3)(x²+2x+1) − 2 = 2x³+x²−4x−5 ✓
3．C1 (2x⁴−7x³+0x²+14x+4)÷(x+2)，c=−2（**注意補 x² 項係數 0**）：
　　2 → −4，−7−4=−11 → 22，0+22=22 → −44，14−44=−30 → 60，4+60=64
　　商 **2x³−11x²+22x−30**、餘 **64** ✓
　　**餘式定理交叉覆核**：f(−2) = 2(16) − 7(−8) + 14(−2) + 4 = 32+56−28+4 = 64 ✓ 與綜合除法一致
　　C2 被除式 − 餘式 = 2x³−4x²+x−4+5 = 2x³−4x²+x+1
　　除以商式 2x²−2x−1：2x³÷2x²=x → 餘 −2x²+2x+1；−2x²÷2x²=−1 → 餘 0
　　除式 A ＝ **x−1** ✓　回乘：(x−1)(2x²−2x−1) + (−5) = 2x³−4x²+x−4 ✓

## 二、餘式定理與因式定理

### 講義
- 餘式定理：f(x) ÷ (x−a) 的餘數 ＝ f(a) ✓
  所附證明（把 x=a 代入 f(x)=(x−a)q(x)+r 得 f(a)=r）邏輯完整 ✓
- **範例一** f(x)=x³−3x²+2x−5，f(2) = 8 − 12 + 4 − 5 = **−5** ✓
- **推論**（除式 (ax−b) 時代入 b/a）✓
  例 g(x)=2x³−x²+3x−1，g(½) = 2(⅛) − ¼ + 3/2 − 1 = ¼ − ¼ + ½ = **½** ✓
- 「f(a) 的雙重意義」說明正確 ✓
- 因式定理三者等價（(x−c) 是因式 ⟺ 整除 ⟺ f(c)=0）✓
- **範例二** f(x)=x³+px²+qx−6 有因式 (x−1)、(x−2)：
  f(1)=0 → p+q=5 ✓；f(2)=0 → 8+4p+2q−6=0 → 2p+q=−1 ✓
  相減得 −p=6 → **p=−6**、**q=11** ✓
  **回代覆核**：f(x)=x³−6x²+11x−6 → f(1)=0 ✓、f(2)=8−24+22−6=0 ✓

### 練習（教師答案逐題重算）
1．A1 f(x)=x²−4x+1 → f(3) = 9−12+1 = **−2** ✓
　　A2 f(x)=x³−2x+3 → f(−2) = −8+4+3 = **−1** ✓（x+2=0 → x=−2，代入點正確）
2．B1 x²+kx+9 有因式 (x−3) → f(3)=9+3k+9=0 → **k=−6** ✓
　　（回代：x²−6x+9=(x−3)² ✓ 確有因式 (x−3)）
　　B2 x²−5x+a 有因式 (x+2) → f(−2)=4+10+a=0 → **a=−14** ✓
　　（回代：x²−5x−14=(x+2)(x−7) ✓）
　　B3 x²−6x+a 有因式 (x+3) → f(−3)=9+18+a=0 → **a=−27** ✓
　　（回代：x²−6x−27=(x+3)(x−9) ✓）
3．C1 設餘式 ax+b（除式二次，餘式最多一次，設法正確 ✓）
　　a+b=5、4a+b=2 → 3a=−3 → a=−1、b=6 → 餘式 **−x+6** ✓
　　（覆核：x=1 → −1+6=5 ✓；x=4 → −4+6=2 ✓，兩個條件都對得上）
　　C2 f(x)=x³+ax²+bx+4：f(−1)=−1+a−b+4=0 → a−b=−3；f(2)=8+4a+2b+4=0 → 2a+b=−6
　　相加 3a=−9 → a=−3、b=0 → **a+b=−3** ✓
　　**回代覆核**：f(x)=x³−3x²+4 → f(−1)=−1−3+4=0 ✓、f(2)=8−12+4=0 ✓

## 三、牛頓定理與多項式基本定理

### 講義
- 牛頓定理敘述（(ax−b) 為因式，a、b 互質 → a 整除首項係數、b 整除常數項）✓
- **範例** f(x)=x³−2x²−5x+6，候選 8 個，逐一代入：
  f(1)=1−2−5+6=**0** ✓／f(−1)=−1−2+5+6=**8** ✓（非零，排除正確）／
  f(2)=8−8−10+6=**−4** ✓／f(−2)=−8−8+10+6=**0** ✓／f(3)=27−18−15+6=**0** ✓
  → 因式 (x−1)、(x+2)、(x−3) ✓
  **展開覆核**：(x−1)(x+2)(x−3) = (x−1)(x²−x−6) = x³−2x²−5x+6 ✓
  「找到 3 個就可以停」的理由（三次多項式最多 3 個一次因式）正確 ✓
- 多項式基本定理一、二敘述與白話解釋皆正確 ✓
- **範例** f(1)=f(4)=0、f(2)=−6 → f(x)=a(x−1)(x−4)；a(1)(−2)=−6 → **a=3**
  → f(x)=3x²−15x+12 ✓（展開覆核：3(x²−5x+4) = 3x²−15x+12 ✓）

### 練習（教師答案逐題重算）
1．A1 f(x)=x³−4x²+x+6：f(−1)=−1−4−1+6=**0** ✓／f(2)=8−16+2+6=**0** ✓／f(3)=27−36+3+6=**0** ✓
　　→ 因式 **(x+1)、(x−2)、(x−3)** ✓
　　展開覆核：(x+1)(x−2)(x−3) = (x+1)(x²−5x+6) = x³−4x²+x+6 ✓
　　A2 f(0)=f(−5)=0 → f(x)=a·x(x+5)；f(1)=6a=9 → a=3/2
　　→ f(x) = **(3/2)x² + (15/2)x** ✓（覆核 f(1)=3/2+15/2=18/2=9 ✓）
2．B1 f(x)=2x⁴+x³−x²+8x−4：
　　f(−2)=32−8−4−16−4=**0** ✓／f(½)=1/8+1/8−1/4+4−4=**0** ✓
　　→ 整係數一次因式 **(x+2)、(2x−1)** ✓
　　**剩餘二次因式覆核**：(2x²+3x−2)(x²−x+2) = 2x⁴+x³−x²+8x−4 ✓
　　x²−x+2 的 Δ = 1−8 = −7 ＜ 0，**確實沒有實數根**，答案的附註正確 ✓
　　B2 f(x)=a(x−1)(x+2)(x−3)；f(0)=a(−1)(2)(−3)=6a=12 → a=2
　　→ f(x)=**2x³−4x²−10x+12** ✓（展開覆核：2(x³−2x²−5x+6) ✓）
3．C1 f(x)=x⁴−x³−7x²+x+6：
　　f(1)=1−1−7+1+6=**0** ✓／f(−1)=1+1−7−1+6=**0** ✓／
　　f(−2)=16+8−28−2+6=**0** ✓／f(3)=81−27−63+3+6=**0** ✓
　　→ 因式 (x−1)、(x+1)、(x+2)、(x−3)；根 **x = 1, −1, −2, 3** ✓
　　展開覆核：(x²−1)(x²−x−6) = x⁴−x³−7x²+x+6 ✓
　　「四次多項式恰有 4 個根」的收斂理由正確 ✓
　　C2 設 h(x)=g(x)−5，則 h(1)=h(2)=h(3)=0（三次、三個零點）
　　→ h(x)=a(x−1)(x−2)(x−3)；h(4)=11−5=6=6a → a=1
　　→ g(x)=(x−1)(x−2)(x−3)+5 = x³−6x²+11x−6+5 = **x³−6x²+11x−1** ✓
　　**回代覆核**：g(1)=1−6+11−1=5 ✓、g(2)=8−24+22−1=5 ✓、g(3)=27−54+33−1=5 ✓、
　　g(4)=64−96+44−1=11 ✓ —— 四個條件全部成立
