## L1 集合的概念與表示法

| 頁 | 題目 | 答案 | 驗算 |
|---|---|---|---|
| P11 | 描述法 {x ∈ N \| x < 5} 轉列舉法 | {0, 1, 2, 3, 4} | N 含 0；0,1,2,3,4 皆 < 5；5 不 < 5，故不入 ✓ |
| P12 A | 3 ___ {1, 2, 3} | ∈ | 3 是該集合元素 ✓ |
| P12 A | 4 ___ {1, 2, 3} | ∉ | 4 不是其元素 ✓ |
| P12 B | 列舉法寫「細過 6 嘅正整數」 | {1, 2, 3, 4, 5} | 正整數不含 0；1–5 皆 < 6；6 不 < 6 ✓ |
| P12 C | 描述法寫「所有偶數」 | {x ∈ Z \| x = 2k, k ∈ Z} | 開放題，多解。亦可寫 {x \| x 是 2 的倍數} ✓ |

| 頁 | 題目 | 答案 | 驗算 |
|---|---|---|---|
| P11 | {1, 2} 的所有子集 | ∅、{1}、{2}、{1, 2}（共 4 個） | 2² = 4 ✓ |
| P11 | 上列何者為真子集 | 前 3 個（{1,2} 不是） | 真子集須 ≠ 原集合；{1,2} = 原集合，故不是 ✓ |
| P12 A | {1, 2} ⊆ {1, 2, 3} | 真 | 1、2 皆在右集合內 ✓ |
| P12 A | {3} ⊆ {1, 2} | 假 | 3 ∉ {1, 2}，故不成立 ✓ |
| P12 B | {a, b} 的所有子集 | ∅、{a}、{b}、{a, b} | 2² = 4 個 ✓ |
| P12 C | {1, 2, 3} 有幾多個子集 | 8 個；規律 2ⁿ | ∅,{1},{2},{3},{1,2},{1,3},{2,3},{1,2,3} 共 8 = 2³ ✓ |

## L3 交集與並集

給定 A = {1, 2, 3}，B = {2, 3, 4}（P8、P10）

| 頁 | 題目 | 答案 | 驗算 |
|---|---|---|---|
| P8 | A ∪ B | {1, 2, 3, 4} | 合併去重：1,2,3,4 ✓ |
| P8 | A ∩ B | {2, 3} | 兩集合共有：2、3 ✓ |
| P8 | A ∪ ∅ | {1, 2, 3} | 併空集不變 ✓ |
| P8 | A ∩ ∅ | ∅ | 與空集無共同元素 ✓ |
| P10 | 淨係喺 A（不在 B） | {1} | A 去掉 A∩B={2,3}，剩 {1} ✓ |
| P11 | 全班 20，籃球 12，羽毛球 9，兩樣都打 5 → 淨係打籃球 | 7 人 | 12 − 5 = 7 ✓（延伸：淨打羽毛球 9−5=4；至少打一樣 12+9−5=16；兩樣都不打 20−16=4） |
| P12 A | A={1,2,3}, B={3,4} → A ∪ B | {1, 2, 3, 4} | 合併去重 ✓ |
| P12 A | 同上 → A ∩ B | {3} | 只有 3 共有 ✓ |
| P12 B | A = 細過 6 的正整數 = {1,2,3,4,5}，B={2,4,6} → A ∩ B | {2, 4} | 6 ∉ A（6 不 < 6）；2、4 兩邊都有 ✓ |
| P12 C | A ∩ B = {2}，A = {1,2}，寫兩個可能的 B | 例：{2}、{2, 3} | B 必含 2；且 1 ∉ B（否則 1 會落入交集）；其餘元素自由 ✓ |

## L5 充分條件與必要條件

| 頁 | 題目 | 答案 | 驗算 |
|---|---|---|---|
| P8–9 | p：x = 2，q：x² = 4。p 是 q 的什麼條件？ | 充分不必要條件 | p⇒q：2² = 4 成立，真。q⇒p：反例 x = −2，(−2)² = 4 但 x ≠ 2，假。故 p 充分、不必要 ✓ |
| P11 | 充分不必要之例 | p：x=2，q：x²=4 | 同上 ✓ |
| P11 | 必要不充分之例 | p：x²=4，q：x=2 | q⇒p：x=2 ⇒ x²=4 真；p⇒q：x²=4 ⇏ x=2（x=−2）假。故 p 是 q 的必要不充分條件 ✓ |
| P11 | 充要之例 | p：x−1=0，q：x=1 | x−1=0 ⇔ x=1，兩方向皆成立 ✓ |
| P12 A | x = 3 ⇒ x² = 9 真定假 | 真 | 3² = 9 ✓ |
| P12 B | p：x=1，q：x²=1。p 是 q 的什麼條件？ | 充分不必要條件 | p⇒q：1²=1 真；q⇒p：反例 x=−1，(−1)²=1 但 x≠1，假 ✓ |
| P12 C | 找 p 使 p ⇔ x > 2 | 例：x − 2 > 0 | x−2>0 ⇔ x>2，兩方向等價 ✓（開放題，2x>4 亦可） |

## L6 全稱量詞與存在量詞

| 頁 | 題目 | 答案 | 驗算 |
|---|---|---|---|
| P8–9 | 「所有素數都係奇數」真定假 | 假 | 反例：2 是素數但為偶數。全稱命題有一反例即假 ✓ |
| P11 | ∃x ∈ R, x² < 0 真定假 | 假 | 任何實數平方 ≥ 0，無 x 滿足；存在命題須有一例才真 ✓ |
| P12 A | ∀x ∈ R, x² ≥ 0 | 真 | 實數平方恆非負（x=0 時 =0）✓ |
| P12 B | ∃x ∈ R, x + 1 = 0 | 真，x = −1 | (−1)+1 = 0 ✓ |
| P12 C | ∀x ∈ N, x² > x | 假 | 反例 x = 0：0² = 0，0 > 0 不成立。（x = 1 亦為反例：1 > 1 不成立）✓ |

## L7 命題的否定

| 頁 | 題目 | 答案 | 驗算 |
|---|---|---|---|
| P6 | x > 3 的否定 | x ≤ 3 | 需含等號，否則漏 x = 3 ✓ |
| P6 | x < 3 的否定 | x ≥ 3 | 同理 ✓ |
| P6 | x = 2 的否定 | x ≠ 2 | ✓ |
| P7–8 | 「∀x ∈ 素數, x 係奇數」的否定 | ∃x ∈ 素數, x 唔係奇數 | 換量詞 ∀→∃，結論取反；此否定為真（x = 2）✓ |
| P10 | ∀x ∈ R, x² ≥ 0 的否定 | ∃x ∈ R, x² < 0 | 換量詞，≥ 取反為 < ✓ |
| P10 | ∃x ∈ R, x + 1 = 0 的否定 | ∀x ∈ R, x + 1 ≠ 0 | 換量詞 ∃→∀，= 取反為 ≠ ✓ |
| P10 | ∀x ∈ N, x > 0 的否定 | ∃x ∈ N, x ≤ 0 | 換量詞，> 取反為 ≤ ✓（此否定為真，因 0 ∈ N） |
| P11 | 原命題與其否定可否同時為真 | 不可 | 例：∀x∈R, x²≥0 真；否定 ∃x∈R, x²<0 假。必一真一假 ✓ |
| P12 A | ∀x ∈ R, x > 0 的否定 | ∃x ∈ R, x ≤ 0 | 換量詞 + 結論取反 ✓ |
| P12 B | ∃x ∈ N, x² = 4 的否定，並判真假 | 否定：∀x ∈ N, x² ≠ 4；否定為**假** | 原命題真（x = 2，2²=4），故其否定必假 ✓ |
| P12 C | ∀x ∈ R, x² > x 的否定，並判真假 | 否定：∃x ∈ R, x² ≤ x；否定為**真** | 原命題假（x = 0.5：0.25 > 0.5 不成立），故否定為真；x = 0.5 即為證例 ✓ |
