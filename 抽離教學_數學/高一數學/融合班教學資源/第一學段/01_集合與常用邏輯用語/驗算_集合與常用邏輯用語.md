## 一、集合的概念與基本關係

### 講義
- 三要素：確定性／互異性／無序性 ✓（三者定義與標準表述一致）
- 元素關係 a ∈ A、a ∉ A ✓
- 數集符號 N（含 0）、N⁺／N*、Z、Q、R ✓（N 含 0 與本教材體系一致）
- 表示法：列舉法 {1,2,3} ✓；描述法 {x ∈ R | x > 1} ✓
- 關係：A ⊆ B ✓；A ⊊ B 定義為 A ⊆ B 且 A ≠ B ✓；A = B ⟺ A ⊆ B 且 B ⊆ A ✓；
  ∅ 是任何集合的子集 ✓
- **範例** A = {x ∈ N | x < 4} → 列舉 {0, 1, 2, 3} ✓（N 含 0，故含 0 正確）；
  B = {0,1,2,3,4}；A ⊆ B 且 B 多出元素 4 → **A ⊊ B** ✓

### 練習（教師答案逐題重算）
1．(1) 能 ✓　(2) 不能——「聰明」無明確判準，違反確定性 ✓　(3) 能 ✓
2．{x ∈ N⁺ | x < 5} = **{1, 2, 3, 4}** ✓
3．(1) 3 ∈ {1,2,3,4} → ✓　(2) 0 ∈ ∅ → ✗（∅ 無任何元素）✓　(3) {1,2} ⊆ {1,2,3} → ✓
4．(1) {x ∈ Z | x 是 3 的倍數} ✓
  (2) x² − 5x + 6 = 0 → (x−2)(x−3) = 0 → x = 2 或 3 → 解集 **{2, 3}** ✓
  （展開核對：(x−2)(x−3) = x² − 5x + 6 ✓）
5．N = {x ∈ Z | −3 < x < 3} = **{−2, −1, 0, 1, 2}** ✓（端點 −3、3 嚴格不等號排除 ✓）；
  M = {−2, 0, 2} 每個元素都在 N ✓，N 另有 −1、1 不在 M ✓ → **M ⊊ N** ✓
6．{a, b} 的子集：∅、{a}、{b}、{a,b} 共 **4 個** ✓（＝2² ✓）
7．x² − 3x + 2 = 0 → (x−1)(x−2) = 0 → A = **{1, 2}** ✓；
  A = B 且 B = {1, a} → **a = 2** ✓（互異性亦排除 a = 1 ✓）
8．開放題，評分說明合理 ✓
9．(1) 猜想 **2ⁿ** ✓
  (2) {1,2,3,4} 的 16 個子集逐個核點：空集 1 個＋單元素 4 個＋雙元素 6 個＋三元素 4 個＋
  全集 1 個 ＝ **16** ✓；答案所列 16 個逐一比對，無重複無遺漏 ✓（與 2⁴ = 16 相符 ✓）

## 二、集合的基本運算

### 講義
- 並集 A ∪ B = {x | x ∈ A 或 x ∈ B} ✓；交集 A ∩ B = {x | x ∈ A 且 x ∈ B} ✓
- 補集 ∁ᵤA ✓
- 運算性質六條：A∪A=A ✓、A∪∅=A ✓、A∩A=A ✓、A∩∅=∅ ✓、A∪∁ᵤA=U ✓、A∩∁ᵤA=∅ ✓
- **範例** U={1,…,6}、A={1,2,3}、B={2,3,4}：
  A∪B = **{1,2,3,4}** ✓（重複元素只算一次 ✓）；A∩B = **{2,3}** ✓；
  ∁ᵤ(A∪B) = U − {1,2,3,4} = **{5,6}** ✓

### 練習（教師答案逐題重算）
1．A∪B = **{1,2,3,4,5}** ✓
2．A={2,4,6,8}、B={4,8,12} → A∩B = **{4,8}** ✓
3．U={1,…,5}、A={2,4} → ∁ᵤA = **{1,3,5}** ✓
4．A={x|−1<x<2}、B={x|1<x<3}：
  A∪B = **{x | −1 < x < 3}** ✓（兩區間重疊於 (1,2)，聯集連續 ✓）
  A∩B = **{x | 1 < x < 2}** ✓
5．∁ᵤA = {4,5} ✓；(∁ᵤA) ∩ B = {4,5} ∩ {2,3,4} = **{4}** ✓
6．屬於 A 但不屬於 B：{1,2,3} 扣掉 {2,3} = **{1}** ✓（與 Venn 圖灰區一致 ✓）
7．A = {x | x<1 或 x>4}，其補集為 [1,4]；A∩B = ∅ ⟺ B ⊆ [1,4]
  → a ≥ 1 且 a+2 ≤ 4 → **1 ≤ a ≤ 2** ✓
  （邊界覆核：a=1 → B=[1,3] ⊆ [1,4] ✓；a=2 → B=[2,4] ⊆ [1,4] ✓；
  a=0.9 → B=[0.9,2.9]，0.9 < 1 落入 A，交集非空 ✓ 排除正確）
8．開放題；示例 A={x|x>2}、B={x|x<3} → A∩B = {x|2<x<3} ✓ 確實符合要求
9．A∪B = A ⟺ **B ⊆ A** ✓；示例 A={1,2,3}、B={1,2} → A∪B={1,2,3}=A ✓ 且 B⊆A ✓

## 三、充分條件與必要條件

### 講義
- 命題「若 p 則 q」、p 條件 q 結論 ✓
- p ⇒ q ⟺ p 是 q 的充分條件、q 是 p 的必要條件 ✓（方向正確，未寫反）
- p ⇏ q 的舉反例判準 ✓
- p ⇔ q 充要條件 ✓
- 集合圖解：p ⇒ q 對應 **P ⊆ Q** ✓（方向正確：條件較「強」者集合較小）
- **範例** p:「x = 2」、q:「x² = 4」
  p ⇒ q ✓（2² = 4）；q ⇏ p ✓（反例 x = −2：(−2)² = 4 但 x ≠ 2）
  → **p 是 q 的充分不必要條件** ✓

### 練習（教師答案逐題重算；本份答案頁以轉圖目視覆核）
1．成立；p 是 q 的充分條件（正方形一定是矩形）✓
2．p⇒q 成立；q⇏p（a = −3 時 a² = 9 但 a ≠ 3）→ **充分不必要** ✓
3．(1) ✓　(2) ✓
4．(1) 是（三邊成比例 ⇒ 三角形相似，判定定理）✓
  (2) 是（等式性質：a = b ⇒ a² = b²）✓
  (3) 不是（反例 x = √2、y = −√2，兩者皆無理數但 x + y = 0 為有理數）✓
5．充分不必要：a>0 且 b>0 ⇒ a+b>0 ✓（充分）；
  反向反例 a = 3、b = −1 → a+b = 2 > 0 但 b < 0 ✓（不必要）
6．必要不充分：菱形 ⇒ 對角線互相垂直 ✓（必要）；
  反向反例 風箏形對角線垂直但非菱形 ✓（不充分）
7．A ⊆ B ⇒ (x∈A ⇒ x∈B) ⇒ p⇒q 為真 → **p 是 q 的充分條件** ✓
8．示例「若 x>2，則 x>1」：p⇒q 真 ✓；q⇏p（x = 1.5 > 1 但不 > 2）✓ → 充分不必要 ✓
9．p 是 q 的必要不充分 ⟺ q⇒p 且 p⇏q ✓；q 是 r 的充要 ⟺ q⇔r ✓
  合併 r ⇒ q ⇒ p → **r ⇒ p，即 p 是 r 的必要條件** ✓
  示例覆核：q「x 是 4 的倍數」、r「x = 4k, k∈Z」（與 q 等價 ✓）、p「x 是偶數」
  → q⇒p ✓（4 的倍數必為偶數）、p⇏q ✓（x = 2 是偶數但非 4 的倍數）、q⇔r ✓
  → r⇒p 成立 ✓，與推論一致

## 四、全稱量詞與存在量詞

### 講義
- 全稱量詞 ∀、一般形式 ∀x ∈ M, p(x) ✓
- 存在量詞 ∃、一般形式 ∃x ∈ M, p(x) ✓
- 真假判準：全稱要全部成立才真、一個反例即假 ✓；存在只需一個成立即真、全部不成立才假 ✓
- **否定規則** ¬(∀x∈M, p(x)) ⟺ ∃x∈M, ¬p(x) ✓；¬(∃x∈M, p(x)) ⟺ ∀x∈M, ¬p(x) ✓
  （「換量詞、否定結論」的口訣與兩條規則對得上 ✓）
- **範例**「所有的素數都是奇數」：反例 2（2 是素數且為偶數）→ 假命題 ✓；
  否定為「存在一個素數不是奇數」，且為真 ✓

### 練習（教師答案逐題重算）
1．所有的→全稱 ✓／有一個→存在 ✓／任意一個→全稱 ✓
2．「所有的」實數 x，|x| 都「大於等於」0 ✓
3．「所有的正方形都是四邊形」→ **真** ✓
4．(1) ∀x ∈ R, x² ≥ 0 → **真** ✓
  (2) ∃x ∈ Z, 2x + 1 = 0 → 解得 x = −½ 非整數 → **假** ✓
5．(1) y = x² + a 對任意 a 都關於 y 軸對稱 → **真** ✓
  （驗證：f(−x) = (−x)² + a = x² + a = f(x)，偶函數，與 a 無關 ✓）
  (2) 「所有無理數平方後都是無理數」→ **假**，反例 √2：(√2)² = 2 為有理數 ✓
6．∃x ∈ Z, x² = 2 → **假** ✓（1² = 1、2² = 4，無整數平方為 2；負整數同理 ✓）
  否定：**∀x ∈ Z, x² ≠ 2**，為真 ✓（形式與 §五 否定規則一致 ✓）
7．x² − 2x + m = **(x−1)² + (m−1)** ✓
  （展開覆核：(x−1)² + m − 1 = x² − 2x + 1 + m − 1 = x² − 2x + m ✓）
  ∀x 恆 ≥ 0 ⟺ 最小值 (m−1) ≥ 0 ⟺ **m ≥ 1** ✓
  （邊界覆核：m = 1 時 f(x) = (x−1)² ≥ 0 恆成立 ✓；m = 0.9 時 x = 1 處 f = −0.1 < 0 ✓ 排除正確）
8．開放題；兩個示例真假判斷皆正確 ✓
9．一定為真 ✓——命題與其否定必為一真一假，原命題假 → 否定真 ✓
  （與 §五 否定規則自洽 ✓）
