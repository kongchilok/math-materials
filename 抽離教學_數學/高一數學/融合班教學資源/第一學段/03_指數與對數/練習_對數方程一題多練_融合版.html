一、練習A（★☆☆）
\(\log_a(...)=b\)　⟹　(...)=\(a^b\)　　　鷹架：先找出 a、b，再把(...)那一整塊當成未知數解出來。
1．\(\log_2(x+5)=3\)
2．\(\log_5(4x-3)=2\)
3．\(\log_3(5x-1)=1\)
4．\(\log_2(2x+1)=2\)
二、練習B（★★☆）
提示：同底的 log 先合併成一個；換底時把底數大的那個換成底數小的。合併/換底完別忘了檢驗。
1．\(\log_3(2x+1)+\log_34=3\)
2．\(\log_5(10x)-\log_52=2\)
3．\(\log_6(x-3)+\log_6(x-2)=1\)
4．\(\log_4(x-1)+\log_4(x+2)=1\)
5．\(\log_3x=\log_925\)
三、練習C（★★★）
提示：出現 \((\log_ax)^2\) 和 \(\log_ax\) 時，設 t=logₐx 轉成二次方程；底數含未知數（如 log_x2）時，先用換底公式把它變成 1/t。
1．\((\log_2x)^2-\log_2x=2\)
2．\((\log_2x)^2-4\log_2x+3=0\)
3．\(\log_2x-4\log_x2+3=0\)
4．\(\log_9(x+5)=\log_{27}125\)
5．綜合題：\(9^x-3^x-6=0\)（提示：這題要先設 \(t=3^x\)，因為 \(9^x=(3^x)^2\)）

練習A 參考答案
1．x+5=8 ⟹ x=3（檢驗：x+5=8>0 ✓）
2．4x-3=25 ⟹ x=7（檢驗：4x-3=25>0 ✓）
3．5x-1=3 ⟹ x=4/5（檢驗：5x-1=3>0 ✓）
4．2x+1=4 ⟹ x=3/2（檢驗：2x+1=4>0 ✓）
練習B 參考答案
1．合併：\(\log_3[4(2x+1)]=3\) ⟹ 4(2x+1)=27 ⟹ x=23/8（檢驗：2x+1=27/4>0 ✓）
2．合併：\(\log_5(5x)=2\) ⟹ 5x=25 ⟹ x=5（檢驗：10x=50>0、5x=25>0 ✓）
3．合併：(x-3)(x-2)=6 ⟹ x²-5x=0 ⟹ x=0 或 x=5。定義域要求 x>3，所以 x=0 捨去，只留 x=5。
4．合併：(x-1)(x+2)=4 ⟹ x²+x-6=0 ⟹ (x+3)(x-2)=0 ⟹ x=-3 或 x=2。定義域要求 x>1，x=-3 捨去，只留 x=2。
5．換底：\(\log_925=\log_{3^2}5^2=\log_35\)，所以 log₃x=log₃5 ⟹ x=5（檢驗：x=5>0 ✓）
練習C 參考答案
1．設t=log₂x：t²-t-2=0 ⟹ (t-2)(t+1)=0 ⟹ t=2 或 t=-1。log₂x=2⟹x=4；log₂x=-1⟹x=1/2。兩個都是x>0，都合法。
2．設t=log₂x：t²-4t+3=0 ⟹ (t-1)(t-3)=0 ⟹ t=1 或 3 ⟹ x=2 或 x=8。
3．設t=log₂x，則log_x2=1/t：t-4/t+3=0 ⟹ t²+3t-4=0 ⟹ (t+4)(t-1)=0 ⟹ t=-4 或 1。log₂x=-4⟹x=1/16；log₂x=1⟹x=2。定義域x>0且x≠1，兩個都合法。
4．換底：\(\log_{27}125=\log_{3^3}5^3=\log_35\)；log₉(x+5)=(1/2)log₃(x+5)。所以(1/2)log₃(x+5)=log₃5 ⟹ log₃(x+5)=2log₃5=log₃25 ⟹ x+5=25 ⟹ x=20（檢驗：x+5=25>0 ✓）
5．設t=3ˣ(t>0)：t²-t-6=0 ⟹ (t-3)(t+2)=0 ⟹ t=3 或 t=-2（捨去，t必須>0）。t=3 ⟹ 3ˣ=3 ⟹ x=1。
