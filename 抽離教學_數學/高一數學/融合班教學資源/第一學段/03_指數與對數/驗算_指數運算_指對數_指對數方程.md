## 一、4.1 指數運算（n 次方根與分數指數冪）

### 講義
- n 次方根定義 xⁿ = a ⟹ x = ⁿ√a ✓
- 奇數次：a>0 → x>0；a<0 → x<0，且唯一 ✓
- 偶數次：a>0 → x = ±ⁿ√a（兩個）✓；a<0 → 無偶次方根 ✓；0 的任何次方根為 0 ✓
- 根式性質：(ⁿ√a)ⁿ = a ✓；n 奇 ⁿ√(aⁿ) = a ✓；**n 偶 ⁿ√(aⁿ) = |a|** ✓（絕對值不可省，正確）
- 分數指數冪 a^(m/n) = ⁿ√(aᵐ) ✓；a^(−m/n) = 1/ⁿ√(aᵐ) ✓；條件 a>0、n>1 齊備 ✓
- **範例** 8^(2/3)：8 = 2³ → (2³)^(2/3) = 2^(3×2/3) = 2² = **4** ✓

### 練習（教師答案逐題重算）
1．A 組五題：x²=9 → n 偶、**x=±3** ✓／x³=8 → n 奇、**x=2** ✓／x³=−8 → **x=−2** ✓／
　　x⁵=−1 → **x=−1** ✓／x⁵=0 → **x=0** ✓（奇偶判定與講義規則逐條對應）
2．B1 (√5)² = **5** ✓；(∛−5)³ = **−5** ✓；√((a−b)²) = **|a−b|** ✓（偶次取絕對值，正確）
　　B2 ∛(a²) = **a^(2/3)** ✓；√a = **a^(1/2)** ✓
3．B3 (4/9)^(1/2) = **2/3** ✓
4．B4 ⁴√a × ¹²√a = a^(1/4) · a^(1/12) = a^(3/12+1/12) = a^(4/12) = **a^(1/3)** ✓
5．B5 √(a³) = **a^(3/2)** ✓；1/∛(a⁵) = **a^(−5/3)** ✓
6．B6 指數 1/6 + 2/3 − 1/3 = 1/6 + 1/3 = **1/2**；4^(1/2) = **2** ✓
7．C1 正解 **(B)**：a^(2/3) ÷ a^(1/3) = a^(1/3) ✓
　　(A) 錯：3a⁻² = 3/a²，係數 3 不進分母 ✓ 說明正確
　　(C) 錯：⁶√((−8)⁶) = |−8| = 8 ✓ 說明正確（呼應講義偶次絕對值規則）
　　(D) 錯：∛(2⁴) = 2^(4/3)，根指數作分母、被開方指數作分子 ✓ 說明正確
　　C2 係數 4 ÷ (−2/3) = **−6** ✓；a 指數 2/3 − (−1/3) = **1** ✓；b 指數 −1/3 − (−1/3) = **0** ✓
　　→ **−6a** ✓
　　C3 開放題；所附示例 a=8：∛(8²) = ∛64 = 4，8^(2/3) = (2³)^(2/3) = 2² = 4，兩邊相等 ✓

## 二、指對數運算（轉換、化簡、定義域值域）

### 講義
- 互換 a^b = N ⟺ log_a N = b（a>0、a≠1、N>0）✓
- 運算性質 log_a(MN)、log_a(M/N)、log_a Mⁿ = n log_a M ✓；恆等式 a^(log_a N) = N ✓
- **範例**（本次修復後恢復）log₂√2：√2 = 2^(1/2) → log₂2^(1/2) = ½·log₂2 = **½** ✓

### 練習（教師答案逐題重算）
1．A1 32^(2/5) = 4 → **log₃₂4 = 2/5** ✓
2．A2 log₃(1/9) = −2 → **3⁻² = 1/9** ✓
3．A3 log_(1/2)32 = −5 → **(1/2)⁻⁵ = 32** ✓（(1/2)⁻⁵ = 2⁵ = 32 覆核 ✓）
4．A4 3^(log₃5) = **5** ✓；log₃(log₃3) = log₃1 = **0** ✓
5．B1 (4/9)^(−1/2) = (9/4)^(1/2) = **3/2** ✓；(8/27)^(2/3) = (2/3)² = **4/9** ✓
　　B2 log₃x = 2 → **x = 9** ✓
　　B3 log₅3 + log₅(1/3) = log₅(3 × 1/3) = log₅1 = **0** ✓
6．B4 正解 **(A)** ✓；(B) 係經過乘 2 加 3 的變換、(C) 底數含變數 x —— 兩個排除理由都正確 ✓
　　B5 a^b = 2 → **log_a 2 = b** ✓
　　B6 y = log₅(x−3)：定義域 **x>3** ✓（真數 >0）；值域 **R** ✓
7．B7 f(x) = aˣ 過 (3,8) → a³ = 8 → a = 2 → **f(x) = 2ˣ** ✓
　　C1 y = log₂(x²+1)：x²+1 ≥ 1 > 0 恆成立 → 定義域 **R** ✓；
　　x²+1 ≥ 1 → log₂(x²+1) ≥ 0 → 值域 **[0, +∞)** ✓（下界在 x=0 取到 ✓）
　　C2 log₂√2 = ½ ✓；log₉27 = log_(3²)(3³) = 3/2 ✓；3^(log₃16) = 16 ✓
　　→ 總和 ½ + 3/2 + 16 = **18** ✓
　　C3 log₂5 × log₃2 × log₅3 = (ln5/ln2)(ln2/ln3)(ln3/ln5) = **1** ✓（三個分式循環相消 ✓）
　　C4 y = 3ˣ 的反函數為 f(x) = log₃x ✓ → f(½) = log₃(½) = **−log₃2** ✓
　　C5 log₁₀x + log₁₀(9−2x) = 1 → x(9−2x) = 10 → **2x² − 9x + 10 = 0** ✓
　　(2x−5)(x−2) 展開 = 2x²−9x+10 ✓ → x = 5/2 或 x = 2
　　**兩根逐一檢驗**：x=5/2 → 9−2x = 4 > 0 ✓；x=2 → 9−2x = 5 > 0 ✓ ——**兩個都是解** ✓
　　定義域 0 < x < 4.5 的推導正確 ✓；所附「不檢驗會把不合法的根當答案」的說明成立 ✓

## 三、指數方程一題多練

### 講義
- **範例**（本次修復後恢復）2^(2x) − 2ˣ − 6 = 0：
  設 t = 2ˣ（t>0）→ t² − t − 6 = 0 → (t−3)(t+2) = 0 → t = 3 或 t = −2 ✓
  t = −2 不合（2ˣ 恆正）→ 捨 ✓；2ˣ = 3 → **x = log₂3** ✓

### 練習（教師答案逐題重算）
1．A 組六題：2ˣ=16 → **4** ✓／2ˣ=64 → **6** ✓／3ˣ=81 → **4** ✓／4ˣ=64 → **3** ✓／
　　2^(x+2)=32=2⁵ → x+2=5 → **3** ✓／9ˣ=3 → 3^(2x)=3¹ → **1/2** ✓
2．B1 2ˣ = √8 = (2³)^(1/2) = 2^(3/2) → **x = 3/2** ✓
3．B2 9ˣ = √27 = 3^(3/2)，而 9ˣ = 3^(2x) → 2x = 3/2 → **x = 3/4** ✓
4．B3 3ˣ+3ˣ = 2·3ˣ = 54 → 3ˣ = 27 → **x = 3** ✓
　　B4 4ˣ+5·4ˣ = 6·4ˣ = 96 → 4ˣ = 16 → **x = 2** ✓
5．B5 5^(x+1)−5ˣ = 5ˣ(5−1) = 4·5ˣ = 100 → 5ˣ = 25 → **x = 2** ✓
　　B6 3^(x+1)+3ˣ = 3ˣ(3+1) = 4·3ˣ = 4 → 3ˣ = 1 → **x = 0** ✓
6．C1 t = 2ˣ：t²−6t+8 = 0 → (t−2)(t−4) = 0 → t = 2、4 **兩個都 >0，都保留** ✓
　　→ **x = 1 或 x = 2** ✓（與範例「一根要捨」形成對照，設計合理）
　　C2 2^(x+2)+2ˣ = 4·2ˣ+2ˣ = 5·2ˣ = 5 → 2ˣ = 1 → **x = 0** ✓
　　C3 t = 2ˣ：2^(2x+1) = 2t²、2^(x+3) = 8t → 2t²−8t = 64 → t²−4t−32 = 0
　　→ (t−8)(t+4) = 0 → t = 8（t = −4 捨）→ 2ˣ = 8 → **x = 3** ✓
　　**回代覆核**：2^(2·3+1) − 2^(3+3) = 2⁷ − 2⁶ = 128 − 64 = **64** ✓
　　C4 開放題；「2 的任何次方都是正數，t=−2 是假根」的說明正確 ✓

## 四、對數方程一題多練

### 講義
- **範例**（本次修復後恢復）log₂(3x) − log₂(x−1) = 3：
  合併 log₂(3x/(x−1)) = 3 ✓ → 3x/(x−1) = 8 ✓ → 3x = 8x−8 → **x = 8/5** ✓
  檢驗 3x = 24/5 > 0、x−1 = 3/5 > 0 ✓
  **回代覆核**：log₂(24/5) − log₂(3/5) = log₂8 = 3 ✓

### 練習（教師答案逐題重算，全部含真數檢驗）
1．A1 x+5 = 2³ = 8 → **x = 3**；檢驗 x+5 = 8 > 0 ✓
2．A2 4x−3 = 5² = 25 → **x = 7**；檢驗 25 > 0 ✓
3．A3 5x−1 = 3¹ = 3 → **x = 4/5**；檢驗 3 > 0 ✓
4．A4 2x+1 = 2² = 4 → **x = 3/2**；檢驗 4 > 0 ✓
5．B1 log₃[4(2x+1)] = 3 → 4(2x+1) = 27 → 8x = 23 → **x = 23/8**；
　　檢驗 2x+1 = 27/4 > 0 ✓
　　B2 log₅(10x/2) = log₅(5x) = 2 → 5x = 25 → **x = 5**；檢驗 10x = 50 > 0 ✓
　　B3 (x−3)(x−2) = 6 → x²−5x+6 = 6 → x²−5x = 0 → x = 0 或 5；
　　定義域 x>3 → **只留 x = 5** ✓（x=0 令 x−3 = −3 < 0，捨去正確）
　　B4 (x−1)(x+2) = 4 → x²+x−6 = 0 → (x+3)(x−2) = 0 → x = −3 或 2；
　　定義域 x>1 → **只留 x = 2** ✓
　　B5 log₉25 = log_(3²)(5²) = (2log₃5)/2 = log₃5 → log₃x = log₃5 → **x = 5** ✓
6．C1 t = log₂x：t²−t−2 = 0 → (t−2)(t+1) = 0 → t = 2 或 −1
　　→ **x = 4 或 x = 1/2**，兩者皆 >0，都合法 ✓
　　C2 t²−4t+3 = 0 → t = 1 或 3 → **x = 2 或 x = 8** ✓
　　C3 log_x2 = 1/log₂x = 1/t → t − 4/t + 3 = 0，乘 t 得 t²+3t−4 = 0
　　→ (t+4)(t−1) = 0 → t = −4 或 1 → **x = 1/16 或 x = 2** ✓
　　定義域 x>0 且 x≠1（因作了 log_x2，底數限制）——兩根都合法 ✓，答案的定義域說明正確
　　C4 log₂₇125 = log_(3³)(5³) = (3log₃5)/3 = log₃5 ✓；log₉(x+5) = ½log₃(x+5) ✓
　　→ ½log₃(x+5) = log₃5 → log₃(x+5) = log₃25 → **x = 20**；檢驗 x+5 = 25 > 0 ✓
　　C5 9ˣ = (3ˣ)²，設 t = 3ˣ（t>0）：t²−t−6 = 0 → (t−3)(t+2) = 0
　　→ t = 3（t = −2 捨）→ **x = 1** ✓

## 發現與修正（2026-08-21）

**三份講義 docx 的「範例」整段變成「wwwww」，已修。**

- **症狀**：`講義_指對數運算`、`講義_指數方程`、`講義_對數方程` 三份 **.docx** 的
  「三、範例」標題下面，四個步驟全部消失，只剩五個字母 **`wwwww`**。
  **HTML／PDF 版完全正常**（範例四步齊全）——所以只看 PDF 或 NotebookLM 發現不了，
  只有打開 .docx 才看得到。
- **成因**：三個建置腳本都把**已砌好的 `para()` 段落清單**直接傳給 `shaded_box()`。
  `shaded_box()` 只接受「平坦的 segment 清單」並且只組一個段落，
  收到 `'<w:p …>'` 這種字串時每段靜靜地塌成它的第 2 個字元，也就是 `w`——五段就是 `wwwww`。
  **共用底層 `omml_docx.py` 早在 2026-08-08 就記錄了這個坑並提供 `shaded_multi_box()`**
  （註解裡寫明就是在本資料夾的 4.1指數運算 發現的），但 topic2／3／4 三個腳本一直沒跟著改。
- **修正**：`_scripts/build_topic2.py`／`build_topic3.py`／`build_topic4.py` 各一處，
  `shaded_box([...paras...], kind='example')` → `shaded_multi_box([...paras...])`，重出 docx。
  重出後逐檔比對：**三份講義各多回一段完整範例，三份練習零差異**；
  docx 內連續 `w` 殘留 0 處，`步驟①` 三份都在，OMML 數 13／19／17。
- **順帶修好輸出路徑**：三個腳本的 `OUT` 是 `os.path.dirname(__file__)`，
  腳本搬進 `_scripts/` 之後會把交付檔寫進 `_scripts/` 裡。改為上一層（交付檔資料夾）。
- **PDF 未動**：這三份的 PDF 走 HTML→Chromium 管線，內容本來就正確（已核對範例四步齊全），
  故本次只重出 .docx。
