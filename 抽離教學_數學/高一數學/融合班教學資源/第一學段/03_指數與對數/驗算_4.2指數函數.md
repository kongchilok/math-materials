### 範例一：比較 2^0.5 與 2^0.3

```
底數 2 > 1 → y = 2^x 遞增
0.5 > 0.3
∴ 2^0.5 > 2^0.3
```
**數值核對**：2^0.5 ＝ 1.41421…，2^0.3 ＝ 1.23114…　→ 1.41421 > 1.23114 ✅

### 範例二：y = a^x 過 (2, 9)，求 a

```
把點 (2, 9) 代入
a^2 = 9
a = 3     或   a = −3      （右欄：底數不能是負數，−3 捨去）
a > 0                      （右欄：所以 a = −3 要捨去）
3 > 1                      （右欄：對照第三節第三列，a > 1 型 → 遞增）
∴ a = 3，圖由左下升到右上
```
**回代核對**：3^2 ＝ 9 ✅　底數檢查：a ＝ 3 滿足 a > 0 且 a ≠ 1 ✅

## 二、練習逐題驗算

### 練習A（★☆☆）——圖已給，讀圖填答

**第 1 題**　右圖 y ＝ 3^x
- (a) 與 y 軸交點：x ＝ 0 → y ＝ 3^0 ＝ 1 → **(0, 1)** ✅
- (b) 底數 3 > 1 → 遞增 → **升** ✅
- (c) 遞增 → x 越大，y **越大** ✅

**第 2 題**　右圖 y ＝ (1/3)^x
- (a) f(0) ＝ (1/3)^0 ＝ **1** ✅
- (b) (1/3)^x > 0 對所有實數 x 成立，x → +∞ 時趨 0 但不等於 0 → **不會碰到** ✅
- (c) 值域 **y > 0** ✅

### 練習B（★★☆）——只給算式，圖由學生畫

**第 3 題**　y ＝ 2^x
| x | −1 | 0 | 1 | 2 |
|---|---|---|---|---|
| y | 1/2 | 1 | 2 | 4 |

- 2^−1 ＝ 1/2^1 ＝ **1/2** ✅
- 2^0 ＝ **1** ✅　2^1 ＝ **2** ✅　2^2 ＝ **4** ✅
- (c) 定點 **(0, 1)** ✅（四點中 x ＝ 0 那點）
- (b) 描點連線後應為由左下升到右上的平滑曲線 ✅（與 `p_blank` 空白坐標格的 x∈[−2.4, 2.6]、y∈[−1, 5] 範圍相容：四點 y 值 0.5～4 全部落在格內）

**第 4 題**　比大小
- (a) 底數 3，屬 a > 1（遞增）。指數 1.2 > 0.7 → 3^1.2 **>** 3^0.7
  **數值核對**：3^1.2 ＝ 3.73719…，3^0.7 ＝ 2.15767… → 3.737 > 2.158 ✅
- (b) 底數 1/2，屬 0 < a < 1（遞減）。指數 1.5 > 0.9 → 值反而細 → (1/2)^1.5 **<** (1/2)^0.9
  **數值核對**：(1/2)^1.5 ＝ 0.35355…，(1/2)^0.9 ＝ 0.53589… → 0.354 < 0.536 ✅
- (c) 草圖：(a) 畫升型、(b) 畫跌型，各標出兩個指數對應的高度 ✅（開放作答）

### 練習C（★★★）——圖與式皆不給

**第 5 題**　y ＝ a^x 過 (3, 8)
- (a) a^3 ＝ 8 → **a ＝ 2**
  **檢查**：立方根在實數中唯一，故不需分兩支；且 2 > 0、2 ≠ 1，合定義 ✅
  **回代**：2^3 ＝ 8 ✅
- (b) 2 > 1 → 屬 a > 1 型 → **升（遞增）** ✅
- (c) 遞增且 0.4 < 0.6 → **a^0.4 < a^0.6**，即 2^0.4 < 2^0.6
  **數值核對**：2^0.4 ＝ 1.31951…，2^0.6 ＝ 1.51572… → 1.320 < 1.516 ✅

**第 6 題**　「y ＝ a^x 一定由左下升到右上」是否同意
- 標準答案：**不同意**。當 0 < a < 1 時圖由左上跌到右下。
- 反例：y ＝ (1/2)^x。核對：(1/2)^−1 ＝ 2、(1/2)^0 ＝ 1、(1/2)^1 ＝ 0.5 → x 增而 y 減 ✅
- 草圖要件：過 (0, 1)、全線在 x 軸上方、由左上跌向右下 ✅

**根因（第 2 輪那兩個「無關」的回歸）**：第 1 輪為修版面而加的 CSS 用了後代選擇器
`.toolcards svg { display:block; margin:auto }` 與 `.aside-side svg { width:100% }`。
MathJax 的輸出是 `<mjx-container><svg>…</svg></mjx-container>`，所以這兩條把**每一條公式**
一齊命中：公式被迫變成獨立置中的 block、又被撐到側欄闊度。表面症狀是「MathJax 跑了
display 模式」，實際上公式一直是 inline，是 CSS 蓋過它。改用 `>` 子選擇器並加
`mjx-container > svg` 保險條後一次解決，且無反噬。已寫入 house-style.md 與跨 session 記憶。
