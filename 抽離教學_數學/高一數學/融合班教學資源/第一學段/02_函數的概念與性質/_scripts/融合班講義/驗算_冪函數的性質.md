# 驗算_冪函數的性質（逐題重算，命題者親算）

單元：高一數學 3.3 冪函數的性質　｜　命題＋驗算：本次產出

## 講義範例
- 範例一：判斷 (1) y=x³ (2) y=2x² (3) y=x^(1/2) 是否冪函數。
  - (1) 係數1、指數3常數 → 是。 (2) 係數2≠1 → 否。 (3) 係數1、指數1/2常數 → 是（=√x）。✓
- 範例二：求 ³√(8²)。
  - ³√(8²)=8^(2/3)=(³√8)²=2²=4。✓

## 性質表（表3.3-1，逐格核對）
| 函數 | 定義域 | 值域 | 奇偶 | 單調 |
|---|---|---|---|---|
| y=x | R | R | 奇 | R遞增 ✓ |
| y=x² | R | [0,+∞) | 偶 | (-∞,0]減、[0,+∞)增 ✓ |
| y=x³ | R | R | 奇 | R遞增 ✓ |
| y=x^(1/2) | [0,+∞) | [0,+∞) | 非奇非偶 | [0,+∞)增 ✓ |
| y=x^(-1) | x≠0 | y≠0 | 奇 | (-∞,0)、(0,+∞)各自遞減 ✓ |
（五者皆過 (1,1)：1^α=1 恆成立 ✓）

## 練習A
- **1**（單選）：冪函數形式 y=x^α、係數1。(A)y=2x² 係數2✗；(B)y=x⁴ ✓；(C)y=3^x 指數函數✗。**答：B** ✓
- **2**（填空）：
  - (1) y=x²：定義域 **R**，值域 **[0,+∞)** ✓
  - (2) y=x³ 是 **奇** 函數 ✓
  - (3) 五冪函數共同點 **(1,1)** ✓
- **3**（求值）：
  - (1) 9^(1/2)=√9=**3** ✓
  - (2) 8^(1/3)=³√8=**2** ✓
  - (3) 4^(-1)=**1/4** ✓

## 練習B
- **4**（化簡，a>0）：
  - (1) ³√(x²)=**x^(2/3)** ✓
  - (2) 16^(3/4)=(⁴√16)³=2³=**8** ✓（16=2⁴，⁴√16=2）
  - (3) (a^(1/2))⁴=a^(1/2×4)=**a²** ✓
- **5**（比大小，y=x³在R遞增）：
  - (1) 1.5>1.4 → 1.5³>1.4³（3.375>2.744）✓
  - (2) -1.5<-1.4 → (-1.5)³<(-1.4)³（-3.375<-2.744）✓
- **6**（過點求α）：過(2,8)，2^α=8=2³ → **α=3** ✓

## 練習C
- **7**（過點求解析式＋判性質）：過(3, 1/9)，3^α=1/9=3^(-2) → α=-2，**f(x)=x^(-2)=1/x²**。
  - 定義域 x≠0；f(-x)=1/(-x)²=1/x²=f(x) → **偶函數**；
  - (0,+∞)上 x↑則x²↑則1/x²↓ → **遞減**；(-∞,0)上 x↑（趨0⁻）則x²↓則1/x²↑ → **遞增**。✓
- **8**（定義證明 f(x)=√x 在[0,+∞)增）：
  - 取值 0≤x₁<x₂；作差有理化 √x₁-√x₂=(x₁-x₂)/(√x₁+√x₂)；
  - x₁-x₂<0，√x₁+√x₂>0（x₂>0）→ 差<0 → f(x₁)<f(x₂) → **增函數** ✓
- **9**（建模）：Q與r四次方成正比。
  - (1) **Q=k·r⁴** ✓
  - (2) r→2r：Q'=k(2r)⁴=16kr⁴=16Q → **16倍** ✓
