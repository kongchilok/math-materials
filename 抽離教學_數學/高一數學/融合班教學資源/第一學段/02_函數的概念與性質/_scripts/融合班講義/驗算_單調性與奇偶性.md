## 講義範例自驗

**範例一（單調性）：證明 f(x)=2x+1 在R上是增函數**
- ①取值：設 x₁,x₂∈R，x₁<x₂
- ②作差：f(x₁)-f(x₂) = (2x₁+1)-(2x₂+1) = 2x₁-2x₂
- ③變形：= 2(x₁-x₂)
- ④定號：x₁<x₂ → x₁-x₂<0 → 2(x₁-x₂)<0 → f(x₁)-f(x₂)<0
- ⑤結論：f(x₁)<f(x₂)，增函數 ✓

**範例二（奇偶性）：判斷 f(x)=x+1/x 的奇偶性**
- 定義域 {x|x≠0}
- f(-x) = -x + 1/(-x) = -x - 1/x = -(x+1/x) = -f(x)
- 結論：奇函數 ✓（與課本例6(3)一致）

## 練習B（中階，★★☆）

**1．y=(k-1)x+b 在R上遞增，求k範圍**
一次函數遞增 ⟺ 一次項係數>0 → k-1>0 → **k>1**

**2．證明 f(x)=-2x+5 在R上為減函數**
- ①取值：x₁,x₂∈R，x₁<x₂
- ②作差：f(x₁)-f(x₂) = (-2x₁+5)-(-2x₂+5) = -2x₁+2x₂
- ③變形：= -2(x₁-x₂)
- ④定號：x₁<x₂ → x₁-x₂<0 → -2(x₁-x₂)>0（負×負＝正）→ f(x₁)-f(x₂)>0
- ⑤結論：f(x₁)>f(x₂)，**減函數** ✓
（驗算：取 x₁=0,x₂=1，f(0)=5，f(1)=3，5>3 符合 f(x₁)>f(x₂) ✓）

**3．判斷奇偶性（涵蓋偶／奇／非奇非偶三種結果）**
- (a) f(x)=x⁶-2x²+1，定義域R。f(-x)=(-x)⁶-2(-x)²+1=x⁶-2x²+1=f(x) → **偶函數**
- (b) f(x)=x³-x，定義域R。f(-x)=-x³+x=-(x³-x)=-f(x) → **奇函數**
- (c) f(x)=x²+x，定義域R。f(-x)=x²-x。
  - 與f(x)=x²+x比較：x²-x=x²+x ⟺ x=0，非恆等 → 不是偶函數
  - 與-f(x)=-x²-x比較：x²-x=-x²-x ⟺ 2x²=0 ⟺ x=0，非恆等 → 不是奇函數
  - 結論：**非奇非偶函數**

## 練習C（高階，★★★）

**1．證明 y=x+4/x 在(2,+∞)上單調遞增**
- ①取值：x₁,x₂∈(2,+∞)，x₁<x₂
- ②作差：y₁-y₂ = (x₁-x₂) + (4/x₁-4/x₂)
- ③變形：= (x₁-x₂) + 4(x₂-x₁)/(x₁x₂) = (x₁-x₂)[1-4/(x₁x₂)] = (x₁-x₂)(x₁x₂-4)/(x₁x₂)
- ④定號：x₁,x₂>2 → x₁x₂>4 → x₁x₂-4>0；x₁x₂>0；x₁-x₂<0 → 整體（負×正／正）<0
- ⑤結論：y₁<y₂，**單調遞增** ✓
（驗算：取x₁=3,x₂=4，y₁=3+4/3=13/3≈4.33，y₂=4+4/4=5，13/3<5 符合遞增 ✓）

**2．f(x)=x²-mx+m-1，f(0)=f(2)，求m及[-2,2]上最小值**
- f(0)=m-1；f(2)=4-2m+m-1=3-m
- f(0)=f(2)：m-1=3-m → 2m=4 → **m=2**
- 代入：f(x)=x²-2x+2-1=x²-2x+1=(x-1)²
- 對稱軸x=1 ∈ [-2,2]，開口向上 → 最小值在x=1：f(1)=(1-1)²=**0**
（驗算：f(-2)=(-2-1)²=9，f(2)=(2-1)²=1，兩端點都比0大，頂點確實是最小值 ✓）

**3．f為偶函數，[0,+∞)上遞增，比較f(-3)與f(2)**
- 偶函數：f(-3)=f(3)
- 遞增且3>2 → f(3)>f(2)
- 結論：**f(-3)>f(2)**
（驗算用具體函數 f(x)=x² 檢查邏輯：f(-3)=9，f(2)=4，9>4 符合結論 ✓）
