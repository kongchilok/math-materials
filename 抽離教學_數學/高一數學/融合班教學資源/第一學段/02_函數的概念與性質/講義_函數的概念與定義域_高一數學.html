留意到：不論包裹落在哪一段重量範圍，公司都只會給出「唯一一個」收費金額——這正是函數的核心精神：對於某個範圍（區間）內的每一個 x，都有唯一確定的一個值與它對應。而「暫不議價」的重量（例如 \(x=0\) 或 \(x>3\)）就不在這個計費函數的定義域之內。
一、函數的定義
設 A、B 是兩個非空的數集，如果按照某個確定的對應關係 f，使得對於集合 A 中的任意一個數 x，在集合 B 中都有唯一確定的數 y 和它對應，那麼就稱 f：A→B 為從集合 A 到集合 B 的一個函數，記作 \(y=f(x)\)，\(x\in A\)。
其中：x 叫自變量；x 的取值範圍 A 叫函數的定義域；與 x 對應的 y 值叫函數值；函數值的集合 \(\{f(x) \mid x \in A\}\) 叫函數的值域。
二、函數的三要素
函數有三個要素：定義域、對應關係、值域。判斷兩個函數是否為「同一函數」，要同時檢查：①定義域是否相同；②對應關係是否完全一致——兩項都相同，才是同一函數。化簡前後式子看起來一樣，不代表就是同一函數，定義域也要對得上。
三、區間的概念
你已經懂得用「\(\{x \mid a \le x \le b\}\)」這種集合寫法表示一段數的範圍，區間記號是它的簡寫，換個寫法會更精簡，數線上的實心點●／空心圈○可以幫助記憶：
閉區間 \([a,b] = \{x \mid a \le x \le b\}\)——兩端點都取，數線上用實心點●表示
開區間 \((a,b) = \{x \mid a < x < b\}\)——兩端點都不取，數線上用空心圈○表示
半開半閉 \([a,b) = \{x \mid a \le x < b\}\)；\((a,b] = \{x \mid a < x \le b\}\)——一端實心、一端空心
無窮區間：\([a,+\infty) = \{x \mid x \ge a\}\)；\((a,+\infty) = \{x \mid x > a\}\)；\((-\infty,b] = \{x \mid x \le b\}\)；\((-\infty,b) = \{x \mid x < b\}\)
實數集：\(R = (-\infty,+\infty)\)（正負無窮都取不到，兩端永遠用空心／不寫端點）
圖：實心點●＝端點取得到（closed）；空心圈○＝端點取不到（open）
四、求函數定義域的四步驟
求函數定義域　手順卡
什麼時候用：題目要求「求函數的定義域」，且式子中出現根號或分母時
1. 看式子裡有沒有根號：被開方數必須「≥0」，把這個條件寫出來。※ 等於 0 也可以，不是嚴格大於 0。
2. 看式子裡有沒有分母：分母必須「≠0」，把這個條件另外寫出來。※ 只看分母本身，不要把分子一起限制進去。
3. 兩個條件都寫出來後，在數線上取「交集」——兩個條件要同時成立的部分。※ 是交集，不是聯集；只保留兩個條件都滿足的 x。
4. 把交集的結果用區間記號寫出來，就是函數的定義域。※ 端點是實心●還是空心○，要對照原本是「≥／≤」還是「＞／＜／≠」。

五、範例
「我做」——老師先示範一次完整的解題過程，並且把心裡想的話說出來：
題目：已知 \(f(x)=\sqrt{x+5}+\dfrac{1}{x-1}\)，求 f(x) 的定義域，並求 f(4) 的值。
算式這一步在做什麼
\(x+5\)\(\ge\)\(0\) 「我先看式子裡有什麼：有根號，也有分母，所以有兩個條件要處理。先看根號這邊——根號裡面的式子不能是負數，所以我要求它 ≥ 0。」
\(x\)\(\ge\)\(-5\) 「把 5 移到右邊，範圍就出來了：\([-5,+\infty)\)。」
①的解集：\([-5,+\infty)\)
\(x-1\)\(\ne\)\(0\) 「再看分母：分母不可以是 0，所以要求 x−1≠0。」
\(x\)\(\ne\)\(1\) 「移項後：x 不能是 1。」
②的解集：\((-\infty,1)\cup(1,+\infty)\)
「兩個條件都要同時成立，所以要取交集——把 x=1 從 \([-5,+\infty)\) 挖走。」
③交集：\([-5,+\infty) \cap (-\infty,1)\cup(1,+\infty) = [-5,1)\cup(1,+\infty)\)
\(\therefore\) 定義域是 \([-5,1)\cup(1,+\infty)\)作答：最後一行用「∴」寫出結論
「附帶一問：求 f(4)，只要把 x=4 代入原式就可以。」
\(f(4)\)\(=\)\(\sqrt{4+5}+\dfrac{1}{4-1}\) 代入 x=4
\(f(4)\)\(=\)\(\sqrt{9}+\dfrac{1}{3}\) 化簡根號
\(\therefore f(4) = \dfrac{10}{3}\)作答：最後一行用「∴」寫出結論
