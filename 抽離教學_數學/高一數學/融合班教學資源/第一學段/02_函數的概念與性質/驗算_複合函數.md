# 驗算_複合函數（逐題重算，命題者親算）

單元：高一數學 補充．複合函數（課本無此節，全套自行設計；題型參照測驗卷 Q22 f(g(x)) 原型）
命題＋驗算：本次產出

## 講義範例
- 範例一：f(x)=x²+3x+2，g(x)=x+1，f(g(x))=(x+1)²+3(x+1)+2=x²+2x+1+3x+3+2=**x²+5x+6** ✓
  （另驗：f(x)=(x+1)(x+2)，f(g(x))=(x+2)(x+3)=x²+5x+6 ✓）
- 範例二：f(x)=2x，g(x)=x+3。f(g(x))=2(x+3)=2x+6；g(f(x))=2x+3。**兩者不同** ✓
- 範例三：f(x)=√x，g(x)=x−3，f(g(x))=√(x−3)，定義域 x−3≥0 → **x≥3** ✓

## 練習A
- **1**：f(x)=2x+1，g(x)=x²。
  - (1) f(g(1))：g(1)=1，f(1)=2·1+1=**3** ✓
  - (2) g(f(1))：f(1)=3，g(3)=3²=**9** ✓（兩答不同，示範順序影響結果）
- **2**（單選）：f(x)=x² → f(x+1)=(x+1)²。**答：B** ✓
- **3**：f(g(x))=g(x)+3=**2x+3** ✓

## 練習B
- **4**：f(g(x))=(x+1)²+3(x+1)+2=**x²+5x+6** ✓
- **5**：f(x)=3x−1，g(x)=x²+2。
  - (1) f(g(x))=3(x²+2)−1=**3x²+5** ✓
  - (2) g(f(x))=(3x−1)²+2=9x²−6x+1+2=**9x²−6x+3** ✓
  - (3) 兩式不同 → **不一樣** ✓
- **6**：f(g(x))=√(x−3)；根號裡 x−3≥0 → 定義域 **x≥3** ✓

## 練習C
- **7**：f(x)=1/(x+1)，g(x)=x²。f(g(x))=1/(x²+1)；x²+1≥1>0 恆不為0 → 定義域 **R** ✓
- **8**（反推）：f(x+1)=x²+2x+3。設 t=x+1，x=t−1，
  f(t)=(t−1)²+2(t−1)+3=t²−2t+1+2t−2+3=t²+2 → **f(x)=x²+2** ✓
  （驗算：f(x+1)=(x+1)²+2=x²+2x+3 ✓）
- **9**：f(x)=2x−1。
  - (1) f(f(x))=2(2x−1)−1=**4x−3** ✓
  - (2) f(0)=−1，f(−1)=2(−1)−1=−3，f(−3)=2(−3)−1=−7 → **f(f(f(0)))=−7** ✓

全部 9 題 + 3 範例，答案數字乾淨、逐題重算一致，無錯。
