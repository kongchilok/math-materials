1. y−4 = 2(x−1)
2. y = 3x + (−1)，即 y=3x−1
3. x/5 + y/(−2) = 1
4. k = −3/(−2) = 3/2
練習B（★★☆）參考答案
1. y−2=−3(x+1) → y=−3x−1 → 3x+y+1=0
2. 斜率=(−2−4)/(3−1)=−3；兩點式：(y−4)/(−6)=(x−1)/2；斜截式：y=−3x+7
3. x/4+y/(−3)=1，兩邊乘12：3x−4y=12，即 3x−4y−12=0
4. 5y=−2x+10 → y=−2/5 x+2，斜率=−2/5，y 軸截距=2

練習C（★★★）參考答案
1. l₂ 斜率=−4/(−2)=2。l₁ 斜率=−2/a。垂直：(−2/a)×2=−1 → a=4
2. l₁ 斜率=1（y=x−3）。過(1,2)且斜率為1：y−2=x−1 → y=x+1 → x−y+1=0
3. 開放題。範例：取 A(0,0)。(a) 平行（斜率−2）：y=−2x，即 2x+y=0。(b) 垂直（斜率1/2）：y=(1/2)x，即 x−2y=0
