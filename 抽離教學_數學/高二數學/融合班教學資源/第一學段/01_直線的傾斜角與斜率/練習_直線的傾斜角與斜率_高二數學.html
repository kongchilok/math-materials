練習A（★☆☆）參考答案
1. k = tan45° = 1
2. k = tan60° = √3
3. k = (5−5)/(6−2) = 0/4 = 0
4. k₁ = k₂，所以 l₁ 與 l₂ 平行
5. k₁×k₂ = 5×(−1/5) = −1，所以 l₁ 與 l₂ 垂直
練習B（★★☆）參考答案
1. k = (−5−2)/(−4−3) = (−7)/(−7) = 1 > 0，傾斜角為銳角
2. k₁ = (9−3)/(5−2) = 2；k₂ = (10−4)/(2−(−1)) = 2。k₁=k₂ 且兩線不重合（l₁: y=2x−1，l₂: y=2x+6），所以 l₁ // l₂
3. l₂ 斜率 = (−2−1)/(4−0) = −3/4。k₁×k₂ = (−3/4)×(−3/4) = 9/16 ≠ −1，所以不垂直（事實上 k₁=k₂，兩線是平行關係）
4. 直線 CD 斜率 = (−1−0)/(1−0) = −1。設直線 AB 斜率為 k，由垂直關係 k×(−1)=−1，得 k=1。又 k=(1−m)/(5−2)=1，解得 1−m=3，所以 m=−2

練習C（★★★）參考答案
1. kAB=(5−1)/(3−1)=2；kAC=(−1−1)/(0−1)=2。kAB=kAC 且兩線段有共同點 A，所以 A、B、C 三點共線
2. kAB=(0−1)/(4−1)=−1/3；kCD=(4−3)/(2−5)=−1/3，所以 AB//CD。kBC=(3−0)/(5−4)=3；kDA=(1−4)/(1−2)=3，所以 BC//DA。兩組對邊分別平行，故 ABCD 為平行四邊形
3. 開放題，答案不唯一。範例：取 (0,0) 和 (1,−2)，斜率 = (−2−0)/(1−0) = −2 ✓
