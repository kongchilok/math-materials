一、分式不等式

解分式不等式的關鍵：先把式子整理成「右邊等於 0」，左邊通分成一個分式 \(\dfrac{P(x)}{Q(x)}\)，再把它轉成整式（多項式）不等式來看符號：

  • •　\(\dfrac{P(x)}{Q(x)} \gt 0\) 等價於 \(P(x)\cdot Q(x) \gt 0\)；　\(\dfrac{P(x)}{Q(x)} \lt 0\) 等價於 \(P(x)\cdot Q(x) \lt 0\)。
最重要提醒：分母不可以為 0！所以分母的根一定「空心」（不可取）。若是 \(\ge 0\) 或 \(\le 0\)，分子的根可取（實心），但分母的根仍然不可取。
範例1：解 \(\dfrac{x-1}{x+2} \le 0\)。
① 轉成整式：\(\dfrac{x-1}{x+2} \le 0\) 等價於 \((x-1)(x+2) \le 0\)（且 \(x+2 \ne 0\)）。
② \((x-1)(x+2) \le 0\) 得 \(-2 \le x \le 1\)；但 \(x=-2\) 令分母為 0，必須排除。
③ 所以 \(x=1\) 可取（實心）、\(x=-2\) 不可取（空心），如下方數線。

解集：\(\{\,x \mid -2 \lt x \le 1\,\}\)。

二、絕對值不等式

絕對值不等式的兩條基本規則（設 \(a \gt 0\)）：

  • •　\(|x| \lt a\) 等價於 \(-a \lt x \lt a\)（「小於取中間」）。
  • •　\(|x| \gt a\) 等價於 \(x \lt -a\) 或 \(x \gt a\)（「大於取兩邊」）。

把 \(x\) 換成一個式子也一樣：\(|f(x)| \lt a\) 即 \(-a \lt f(x) \lt a\)；\(|f(x)| \gt a\) 即 \(f(x) \lt -a\) 或 \(f(x) \gt a\)。

遇到兩個以上絕對值相加（例如 \(|x-1|+|x+2|\)），用「零點分段法」：在每個絕對值為 0 的點把數線分段，逐段去掉絕對值符號後再解。
範例2：解 \(|2x-1| \lt 3\)。
① 依「小於取中間」：\(|2x-1| \lt 3\) 即 \(-3 \lt 2x-1 \lt 3\)。
② 三邊各加 1：\(-2 \lt 2x \lt 4\)；再各除以 2：\(-1 \lt x \lt 2\)，如下方數線。

解集：\(\{\,x \mid -1 \lt x \lt 2\,\}\)。
