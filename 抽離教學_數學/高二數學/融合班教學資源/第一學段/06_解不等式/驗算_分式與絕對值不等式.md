# 驗算紀錄：分式與絕對值不等式（練習）

逐題親自命題並重算（QB-V2）。分式：分母根永遠排除。

## 練習A
1．(x+1)/(x−2)>0 ⟺ (x+1)(x−2)>0 → x<−1 或 x>2（x=2 本在範圍外）。驗：x=0→1/(−2)=−0.5，不>0，0 不在解內 ✓。✓

2．|x−3|≤2 ⟺ −2≤x−3≤2 ⟺ 1≤x≤5。✓

## 練習B
3．(2x+1)/(x−1)≥1 → (2x+1)/(x−1)−1≥0 → (x+2)/(x−1)≥0 ⟺ (x+2)(x−1)≥0 且 x≠1。→ x≤−2 或 x>1（x=−2 分子零可取；x=1 分母零排除）。驗：x=−2→(−3)/(−3)=1≥1 ✓；x=2→5/1=5≥1 ✓。✓

4．|2x+1|>5 ⟺ 2x+1<−5 或 2x+1>5 ⟺ 2x<−6 或 2x>4 ⟺ x<−3 或 x>2。✓

## 練習C
5．(x−4)/(x+1)≤2 → (x−4)/(x+1)−2≤0 → (−x−6)/(x+1)≤0；同乘 −1（不等號變向）→ (x+6)/(x+1)≥0 ⟺ (x+6)(x+1)≥0 且 x≠−1 → x≤−6 或 x>−1。驗：x=0→−4/1=−4≤2 ✓；x=−7→−11/−6≈1.83≤2 ✓；x=−3→−7/−2=3.5≤2 假，−3∈(−6,−1) 排除 ✓。✓

6．|x−1|+|x+2|≤5，零點 −2、1，分三段：x<−2：−(x−1)−(x+2)=−2x−1≤5 → x≥−3 → −3≤x<−2；−2≤x<1：−(x−1)+(x+2)=3≤5 恆真 → −2≤x<1；x≥1：(x−1)+(x+2)=2x+1≤5 → x≤2 → 1≤x≤2。合併 −3≤x≤2。驗端點：x=−3→4+1=5≤5 ✓；x=2→1+4=5≤5 ✓。✓
