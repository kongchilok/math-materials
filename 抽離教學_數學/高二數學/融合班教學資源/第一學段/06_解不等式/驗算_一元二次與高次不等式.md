# 驗算紀錄：一元二次與高次不等式（練習）

逐題親自命題並重算（QB-V2）。

## 練習A
1．x²−5x+6>0。因式 (x−2)(x−3)>0，根 2、3，a>0 取兩根之外 → x<2 或 x>3。✓

2．(x−1)(x−2)(x−4)>0。根 1,2,4；符號由右到左 +,−,+,−（x>4:+；2<x<4:−；1<x<2:+；x<1:−）。>0 取正區間 → 1<x<2 或 x>4。✓

## 練習B
3．(a) x²−2x−8≤0：(x−4)(x+2)≤0 → −2≤x≤4。(b) x²+x+1>0：Δ=1−4=−3<0，a=1>0，拋物線恆在 x 軸上方 → 全體實數。✓

4．x(x+3)(x−2)≤0。根 −3,0,2；符號右到左 +,−,+,−（x>2:+；0<x<2:−；−3<x<0:+；x<−3:−）。≤0 取負區間含根 → x≤−3 或 0≤x≤2。✓

## 練習C
5．(x+1)(x−2)²(x−3)<0。根 −1、2(偶,不穿)、3。(x−2)²≥0，正負由 (x+1)(x−3) 定；(x+1)(x−3)<0 → −1<x<3；扣除令原式為 0 的 x=2 → −1<x<3 且 x≠2。（核：x=2 代入原式=0，不符 <0，須排除。）✓

6．解集 {x|−1<x<3} ⇒ −1、3 為 x²+bx+c=0 兩根。和：−1+3=2=−b → b=−2；積：(−1)(3)=−3=c → c=−3。驗算：x²−2x−3=(x+1)(x−3)<0 解集確為 −1<x<3。✓
