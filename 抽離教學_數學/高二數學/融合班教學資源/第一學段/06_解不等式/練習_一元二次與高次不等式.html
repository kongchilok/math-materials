提示：一元二次「大於零取兩邊，小於零取中間」；高次用穿線法「右上起、蛇形穿根、奇穿偶不穿」。

一、練習A（★☆☆）
1．解 \(x^2-5x+6 \gt 0\)。
鷹架：因式分解 \(x^2-5x+6=(x-2)(x-3)\)，兩根為（　）、（　）；因 \(a \gt 0\) 且要 \(\gt 0\)，取兩根之外。解集 \(\{\,x \mid x \lt\)（　）\(\text{ 或 } x \gt\)（　）\(\}\)。
2．解 \((x-1)(x-2)(x-4) \gt 0\)。
鷹架：三根 \(1\)、\(2\)、\(4\) 標在數線上；由右上穿線；要 \(\gt 0\) 取上方區間。
二、練習B（★★☆）
3．解下列一元二次不等式：
（a）\(x^2-2x-8 \le 0\)　　（b）\(x^2+x+1 \gt 0\)
4．解 \(x(x+3)(x-2) \le 0\)。
三、練習C（★★★）
5．解 \((x+1)(x-2)^2(x-3) \lt 0\)。
提示：\((x-2)^2\) 是偶次，用「偶不穿」——碰到根 \(x=2\) 不變號。
6．（逆向題）已知一元二次不等式 \(x^2+bx+c \lt 0\) 的解集為 \(\{\,x \mid -1 \lt x \lt 3\,\}\)，求 \(b\)、\(c\) 的值。
參考答案與解析

練習A

1．\((x-2)(x-3) \gt 0\)，兩根 \(2\)、\(3\)；取兩根之外。解集 \(\{\,x \mid x \lt 2 \text{ 或 } x \gt 3\,\}\)。

2．三根 \(1\)、\(2\)、\(4\)；由右到左符號 \(+,-,+,-\)，要 \(\gt 0\) 取上方（正）區間。解集 \(\{\,x \mid 1 \lt x \lt 2 \text{ 或 } x \gt 4\,\}\)。

練習B

3．（a）\(x^2-2x-8=(x-4)(x+2) \le 0\)，取兩根之間：\(-2 \le x \le 4\)。（b）\(\Delta=1-4=-3 \lt 0\) 且 \(a=1 \gt 0\)，故 \(x^2+x+1 \gt 0\) 恆成立，解為全體實數。

4．三根 \(-3\)、\(0\)、\(2\)；符號由右到左 \(+,-,+,-\)；要 \(\le 0\) 取下方區間並含根。解集 \(\{\,x \mid x \le -3 \text{ 或 } 0 \le x \le 2\,\}\)。

練習C

5．根 \(-1\)、\(2\)（重根，偶不穿）、\(3\)。因 \((x-2)^2 \ge 0\)，式子的正負由 \((x+1)(x-3)\) 決定；\((x+1)(x-3) \lt 0\) 得 \(-1 \lt x \lt 3\)，再扣除令原式為 0 的 \(x=2\)。解集 \(\{\,x \mid -1 \lt x \lt 3 \text{ 且 } x \ne 2\,\}\)。

6．由解集 \(\{\,x \mid -1 \lt x \lt 3\,\}\) 知 \(-1\)、\(3\) 是方程 \(x^2+bx+c=0\) 的兩根。兩根和 \(-1+3=2=-b\)，得 \(b=-2\)；兩根積 \((-1)\times3=-3=c\)，得 \(c=-3\)。
