# 驗算紀錄：二元一次不等式與平面區域（練習）

逐題親自命題並重算（QB-V2）。判斷區域一律：界線改等號 → 取測試點代入 → 定側。

## 練習A
1．不等式 x+y>2，界線 x+y=2（虛線，因 >）。測試點 (0,0)：0+0=0，0>2 不成立 → 取不含原點一側（右上方半平面）。✓（2(a)、2(b) 見下）

2．(a) x−y≥1：含「≥」→ 界線實線；界線 x−y=1 通過 (1,0)、(0,−1)。(b) 3x+2y<6：含「<」→ 界線虛線；界線 3x+2y=6 通過 (2,0)、(0,3)。✓

## 練習B
3．x−2y+2≥0，界線 x−2y+2=0 即 x−2y=−2（實線，含「≥」）。x=0→y=1 得 (0,1)；y=0→x=−2 得 (−2,0)。測試點 (0,0)：0−0+2=2≥0 成立 → 取含原點側（界線下方）。✓

4．3x+2y<6，界線 3x+2y=6（虛線）。通過 (2,0)、(0,3)。測試點 (0,0)：0<6 成立 → 取含原點側（界線左下方）。✓

5．y>2x，界線 y=2x（虛線）。通過 (0,0)、(1,2)。界線過原點，改用測試點 (1,0)：0>2 不成立 → 取不含 (1,0) 一側（界線左上方，y 軸正向側）。✓

## 練習C
6．不等式組 x+y≤4, x≥0, y≥0。頂點：(0,0)、(4,0)、(0,4)。公共區域＝三角形 (0,0)(4,0)(0,4)，含三邊。✓

7．（開放題，答案不唯一）示例①x≥0, y≥0, x+y≤4 → 頂點 (0,0)(4,0)(0,4)。示例②x≥1, y≥1, x+y≤5 → 頂點 (1,1)(4,1)(1,4)。皆為三角形。✓
