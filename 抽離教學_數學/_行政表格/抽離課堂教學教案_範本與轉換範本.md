## 二、教學計劃 → 教案 轉換範本

三份已完成的 26/27 抽離課堂教學計劃（初三乙丙班、高一甲戊班、高三甲丙班），每份都有「週次 × 內容」的表格。以下是欄位對應規則：

| 教學計劃欄位（來源） | → | 教案欄位（目標） | 轉換說明 |
|---|---|---|---|
| 計劃標題（如「高一戊班」） | → | 班級 | 直接抄班級全名 |
| 你本人 | → | 任教抽離課堂之老師 | 固定值 |
| 計劃裡的單元大標題（如「01 集合與常用邏輯用語」） | → | 學習目標/單元 | 換教學單元時更新，一份教案可涵蓋同一單元的多堂課 |
| 週次表格「週」欄＋校曆日期 | → | 上課日期 | 需對照學校正式校曆換算實際日期（本計劃的日期是預測值） |
| 「本週錨點」／「內容」欄 | → | 課堂重點/發展 | 直接搬字過紙，可視乎堂上實際教學調整措辭 |
| 錨點課固定流程「對答＋修正」環節 | → | 總結及鞏固 | 若計劃無明確寫這格，用「對答＋修正，標出錯處」等固定句式 |
| 「帶走的卡」／練習冊指定題 | → | 功課/練習 | 錨點課設計的手順卡本身也可寫在教材欄，視乎是「發還是帶走」 |
| 對應講義檔名 | → | 教材 | 寫講義全名，方便日後追查 |
| （堂上／堂後填寫，計劃無法預先提供） | → | 學生掌握情況 | 這欄**教學計劃給不到**，必須實際上課後才填 |

> ⚠️ **教材欄與功課/練習欄容易混淆**：手順卡若是「當堂發、學生帶走做記憶輔助」算教材；若是「額外指定練習題」算功課/練習。視實際情況判斷，沒有絕對規則。
