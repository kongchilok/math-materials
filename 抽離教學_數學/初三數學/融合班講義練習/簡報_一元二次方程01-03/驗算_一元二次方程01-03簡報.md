## 站① 四種解法（2026-08-05 重算）

### 方法一概念：x² = p 三情況
- p>0 → x=±√p 兩不等實根 ✓；p=0 → x=0 兩相等實根 ✓；p<0 → 無實數根（實數平方恆 ≥0）✓

### 範例（逐條代回原方程驗根）
- 方法一 (x−4)²−9=0：→(x−4)²=9→x−4=±3→x=4±3→x=7 或 1
  代回 x=7：(7−4)²−9=9−9=0 ✓；x=1：(1−4)²−9=9−9=0 ✓
- 方法二 x²+6x−1=0：→x²+6x=1；加 (6÷2)²=9 →(x+3)²=10→x=−3±√10
  代回 x=−3+√10：(19−6√10)+(−18+6√10)−1=0 ✓（x=−3−√10 同理對稱成立 ✓）
- 方法三 2(x²−1)=3x+3：展開 2x²−2=3x+3 → 2x²−3x−5=0；a=2,b=−3,c=−5
  Δ=(−3)²−4(2)(−5)=9+40=49 ✓；x=(3±7)/4 → x=10/4=5/2 或 x=−4/4=−1
  代回 x=−1：左 2(1−1)=0、右 3(−1)+3=0 ✓；x=5/2：左 2(25/4−1)=21/2、右 15/2+3=21/2 ✓
- 方法四 x²+2x−35=0：7×(−5)=−35、7+(−5)=+2 → (x+7)(x−5)=0 → x=−7 或 5
  代回 x=−7：49−14−35=0 ✓；x=5：25+10−35=0 ✓

### CRA 三階頁
- x²+2x−35：相乘=−35、相加=+2 → 7 和 −5；(x+7)(x−5)=0 → x=−7 或 5 ✓（與方法四同題同解）

## 站② 判別式與根與係數
- Δ 範例：x²−3x+1 Δ=9−4=5>0 ✓；4x²−4x+1 Δ=16−16=0 ✓；x²+x+1 Δ=1−4=−3<0 ✓
- 韋達 x²−5x+6：和=−(−5)/1=5、積=6/1=6；根 2,3 → 2+3=5、2×3=6 ✓
- A1 x²−6x+5：Δ=36−20=16>0 兩相異 ✓
- A2 x²−7x+10：和=7、積=10 ✓
- B3 x²−4x+k 重根：Δ=16−4k=0 → k=4 ✓
- B4 x²−5x+m 一根=2：4−10+m=0 → m=6；兩根積=6，一根2 → 另一根=3 ✓
- C5 x²−2x+k：Δ=4−4k → k<1 兩相異 / k=1 重根 / k>1 無實根 ✓
- C6 反例 x²+1=0：Δ=−4<0 無實根 ✓（故「任何二次方程都有兩實根」為錯）

## 站③ 一元二次方程的應用
- 範例一 面積：x(x+2)=24 → x²+2x−24=0 → (x+6)(x−4)=0 → x=4（−6 捨）；寬4長6，4·6=24 ✓
- 範例二 降價：100(1−x)²=81 → (1−x)²=0.81 → 1−x=0.9 → x=0.1=10% ✓
- A1 連續整數：x(x+1)=56 → x²+x−56=0 → (x+8)(x−7)=0 → x=7；7,8，7·8=56 ✓
- A2 增長率：100(1+x)²=144 → (1+x)²=1.44 → 1+x=1.2 → x=20% ✓
- B3 矩形：x(x+7)=60 → x²+7x−60=0 → (x+12)(x−5)=0 → x=5；寬5長12，5·12=60 ✓
- B4 靠牆籬笆：x(32−2x)=120 → x²−16x+60=0 → (x−6)(x−10)=0 → x=6 或 10（兩解皆合理）✓
- C5 傳染病：(1+x)²=121 → 1+x=11 → x=10 ✓
- C6 找錯：連續偶數相差 2，應列 x(x+2)=48 → (x+8)(x−6)=0 → x=6；6,8，6·8=48 ✓
  （小明誤列 x(x+1)=48）

## 分數原生渲染補修（2026-08-05 第二輪，使用者指出）

**問題**：初版所有分數用「/」斜線寫法（如 `x = 5/2`、`x = (3±7)/4`、`−b/a`），不符合數學書寫規範
（CLAUDE.md 鐵律 1：數學式必須原生，禁止純文字硬湊）。pptxgenjs 無 OMML／MathJax 支援，需自建
「分子／橫線／分母」直式疊字渲染。

**做法**：沿用本工作區 `簡報_概率初步12/build_deck.js` 已驗證嘅 `frac()`／`seg()` 疊字寫法慣例，
在本檔新增 `frac()`／`fracRow()`／`fracW()` 共用函式，改寫以下 6 處：

| 位置 | 舊寫法 | 新寫法 |
|---|---|---|
| S11 公式法範例第5行 | `x = (3 ± 7) / 4` | 原生疊字分數 |
| S11 公式法範例第6行 | `x = 5/2 或 x = −1` | 原生疊字分數 |
| S18 韋達定理步驟1 | `−b / a = −(−5) / 1 = 5` | 簡化去除 ÷1 冗餘，`−b/a` 原生疊字 |
| S18 韋達定理步驟2 | `c / a = 6 / 1 = 6` | 同上，`c/a` 原生疊字 |
| S18 公式徽章 | `和 = −b/a　積 = c/a` | 兩個原生疊字分數並列 |
| S19 視覺鷹架③策略算式 | `和 = −b/a\n積 = c/a` | 兩行各一個原生疊字分數 |
| S11 手順卡第4步 | `代入 x = (−b±√Δ)/(2a)` | 窄欄改文字敘述「代入求根公式（見右邊範例）」，
避免在 4.5in 窄欄硬塞分數；實際公式已在右側範例欄以原生疊字呈現 |

**除錯過程**：首輪實作分子分母框高度（`hh`）計算過小，令文字溢出鄰行、與相鄰列重疊；
文字框亦無 `margin:0`／`wrap:false`，令較長分子（如「3 ± 7」）在預設內邊距下換行錯位。
兩者修正後，用 PyMuPDF 局部放大截圖核對，分子／橫線／分母三層清晰置中，逐頁掃描全 37 頁
確認無遺漏、無連帶版位溢出。
