先判斷「用哪種方法最快」，再解出答案。

參考答案（教師用）
方法一：直接開平方法
1．\(x_1=4\) 或 \(x_2=-4\)
2．\(x_1=1\) 或 \(x_2=-5\)
3．\(x^2=4\)；\(x_1=2\) 或 \(x_2=-2\)
4．\((x-1)^2=6\)；\(x_1=1+\sqrt6\) 或 \(x_2=1-\sqrt6\)
5．\(9x^2=-4\)，\(x^2=-\dfrac{4}{9}\)——右邊是負數，無實數根
6．小華漏了先判斷右邊的正負。−9 < 0，負數不能開平方，所以 \(x^2=-9\) 無實數根，不是 \(x=\pm3\)
方法二：配方法
7．\((x+2)^2=7\)；\(x_1=-2+\sqrt7\) 或 \(x_2=-2-\sqrt7\)
8．\((x-2)^2=6\)；\(x_1=2+\sqrt6\) 或 \(x_2=2-\sqrt6\)
9．\((x+5)^2=16\)；\(x_1=-1\) 或 \(x_2=-9\)
10．先除以 2 得 \(x^2+4x-1=0\)，\((x+2)^2=5\)；\(x_1=-2+\sqrt5\) 或 \(x_2=-2-\sqrt5\)
11．\(\left(x+\dfrac{5}{2}\right)^2=\dfrac{17}{4}\)，\(x_1=\dfrac{-5+\sqrt{17}}{2}\) 或 \(x_2=\dfrac{-5-\sqrt{17}}{2}\)
12．錯在右邊：原方程常數是 +5，移項後變 −5，加 9 之後是 4，不是 14。正確：\((x+3)^2=4\)；\(x_1=-1\) 或 \(x_2=-5\)
方法三：公式法
13．\(\Delta=1\)；\(x_1=2\) 或 \(x_2=1\)
14．\(\Delta=9\)；\(x_1=2\) 或 \(x_2=\dfrac{1}{2}\)
15．\(\Delta=16\)；\(x_1=\dfrac{1}{3}\) 或 \(x_2=-1\)
16．\(\Delta=0\)；重根 \(x_1=x_2=2\)
17．\(\Delta=-8\)，小於 0，無實數根
18．展開得 \(3x^2-5x+3=0\)，\(\Delta=-11\)，小於 0，無實數根
方法四：因式分解法
19．\((x-2)(x-3)=0\)；\(x_1=2\) 或 \(x_2=3\)
20．\((x+3)(x-3)=0\)；\(x_1=3\) 或 \(x_2=-3\)
21．\((2x-1)(x-3)=0\)；\(x_1=\dfrac{1}{2}\) 或 \(x_2=3\)
22．\((x-4)(x+3)=0\)；\(x_1=4\) 或 \(x_2=-3\)
23．先移項成 \(x^2-5x=0\)，\(x(x-5)=0\)；\(x_1=0\) 或 \(x_2=5\)
※ 第 23 題重點：兩邊都有 x 時不可以除以 x，否則會漏掉 \(x=0\) 這個根。
24．\(x^2+4x-12=0\)（答案不唯一，兩根是 2 和 −6 即可）
五、四種方法怎麼選
25．直接開平方法（已是 \(x^2=p\) 型）；\(x_1=7\) 或 \(x_2=-7\)
26．因式分解法（一眼看出），\((x-2)(x-4)=0\)；\(x_1=2\) 或 \(x_2=4\)
27．公式法（分解不出），\(\Delta=13\)；\(x_1=\dfrac{-3+\sqrt{13}}{2}\) 或 \(x_2=\dfrac{-3-\sqrt{13}}{2}\)
28．直接開平方法（已是平方形式）；\(x_1=2+2\sqrt3\) 或 \(x_2=2-2\sqrt3\)
