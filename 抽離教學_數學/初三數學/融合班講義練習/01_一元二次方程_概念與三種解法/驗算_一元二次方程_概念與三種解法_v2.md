# 驗算紀錄 v2 — 一元二次方程・概念與三種解法（改版：降次→配方→公式→因式分解）

範圍：講義 4 個範例＋練習 28 題（4 方法各 A/B/C 2 題共 24 題＋綜合選法 4 題）逐題重算。

## 講義範例（源自歷屆大測第一段大測一，去識別化）
- 方法一 (x−4)²−9=0：(x−4)²=9 → x−4=±3 → x=7 或 1 ✓
- 方法二 x²+6x−1=0：x²+6x=1，+9 → (x+3)²=10 → x=−3±√10 ✓
- 方法三 2(x²−1)=3x+3：展開 2x²−3x−5=0，Δ=9+40=49 → x=(3±7)/4 → x=5/2 或 −1 ✓
- 方法四 x²+2x−35=0：(x+7)(x−5)=0 → x=−7 或 5 ✓

## 方法一：直接開平方法
- A1 x²=16 → x=±4 ✓
- A2 (x+2)²=9 → x+2=±3 → x=1 或 −5 ✓
- B3 2x²−8=0 → x²=4 → x=±2 ✓
- B4 (x−1)²−6=0 → x=1±√6 ✓
- C5 9x²+5=1 → 9x²=−4 → x²=−4/9<0 → 無實數根 ✓
- C6 找錯：x²=−9 判無實數根（負數不能開方），非 x=±3 ✓

## 方法二：配方法
- A1 x²+4x−3=0 → x²+4x=3，+4 → (x+2)²=7 → x=−2±√7 ✓
- A2 x²−4x−2=0 → +4 → (x−2)²=6 → x=2±√6 ✓
- B3 x²+10x+9=0 → +25 → (x+5)²=16 → x=−1 或 −9 ✓
- B4 2x²+8x−2=0 → ÷2: x²+4x−1=0 → +4 → (x+2)²=5 → x=−2±√5 ✓
- C5 x²+5x+2=0 → +25/4 → (x+5/2)²=17/4 → x=(−5±√17)/2 ✓
- C6 找錯：小美「5+9=14」應為「−5+9=4」→ (x+3)²=4 → x=−1 或 −5 ✓

## 方法三：公式法
- A1 x²−3x+2=0 → Δ=9−8=1 → x=(3±1)/2 → x=2 或 1 ✓
- A2 2x²−5x+2=0 → Δ=25−16=9 → x=(5±3)/4 → x=2 或 1/2 ✓
- B3 3x²+2x−1=0 → Δ=4+12=16 → x=(−2±4)/6 → x=1/3 或 −1 ✓
- B4 x²−4x+4=0 → Δ=0 → x=2（重根） ✓
- C5 x²+2x+3=0 → Δ=4−12=−8<0 → 無實數根 ✓
- C6 3(x²+1)=5x → 展開 3x²−5x+3=0 → Δ=25−36=−11<0 → 無實數根 ✓

## 方法四：因式分解法
- A1 x²−5x+6=0 → (x−2)(x−3)=0 → x=2 或 3 ✓
- A2 x²−9=0 → x=±3 ✓
- B3 2x²−7x+3=0 → (2x−1)(x−3)=0，驗證 2x²−6x−x+3=2x²−7x+3 ✓ → x=1/2 或 3 ✓
- B4 x²−x−12=0 → (x−4)(x+3)=0 → x=4 或 −3 ✓
- C5 x²=5x → 移項 x²−5x=0 → x(x−5)=0 → x=0 或 5（不可兩邊除以x） ✓
- C6 自編：兩根 2、−6 → (x−2)(x+6)=x²+4x−12=0（驗證：展開 x²+6x−2x−12=x²+4x−12 ✓）

## 綜合選法練習
- 25．x²=49 → 直接開平方法最快，x=±7 ✓
- 26．x²−6x+8=0 → 因式分解法最快，(x−2)(x−4)=0，x=2 或 4 ✓
- 27．x²+3x−1=0 → 不易因式分解，公式法：Δ=9+4=13 → x=(−3±√13)/2 ✓
- 28．(x−2)²=12 → 已是平方形式，直接開平方法：x=2±2√3（√12=2√3） ✓

結論：以上 4 範例＋28 題全部一致，無矛盾。逐題重算通過（100%）。
