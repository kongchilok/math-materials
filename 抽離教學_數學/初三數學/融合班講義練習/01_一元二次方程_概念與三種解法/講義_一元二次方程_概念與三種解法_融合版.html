一、認識一元二次方程
只含一個未知數，而且未知數的最高次數是 2 的方程，叫做「一元二次方程」。一般式（標準式）：\(ax^2+bx+c=0\)（其中 a≠0）。
辨識 a、b、c 的方法：先把式子整理成「＝0」的一般式，\(x^2\) 前面的數是 a，x 前面的數是 b，剩下的常數是 c。若 \(x^2\) 的係數是 0，那是一元一次方程，不是二次。
例：\(2x^2+3x-1=0\) 中，a＝2，b＝3，c＝−1。
本課會學習解一元二次方程的四種方法，教學順序是：① 直接開平方法（降次）→ ② 配方法 → ③ 公式法 → ④ 因式分解法。前三種方法一步步建立在上一種之上，因式分解法最後教是因為它是「看得出來就可以抄捷徑」的快速做法。
二、方法一：直接開平方法（降次）
「降次」的意思：把二次方程（有 \(x^2\)）轉化成兩個一次方程（沒有平方），這樣就能用我們已經會解的方法完成。
對於 \(x^2=p\)：
(1) 當 \(p>0\) 時，方程有兩個不等的實數根 \(x_1=-\sqrt{p}\)、\(x_2=\sqrt{p}\)；
(2) 當 \(p=0\) 時，方程有兩個相等的實數根 \(x_1=x_2=0\)；
(3) 當 \(p<0\) 時，因為任意實數 x，都有 \(x^2\ge0\)，所以方程無實數根。
★ 範例（來自歷屆大測）：解 \((x-4)^2-9=0\)
  1. 移項，把方程化成 \((x+k)^2=c\) 的形式：\((x-4)^2=9\)
  2. 判斷 c 的正負：9 ＞ 0，可以開方
  3. 兩邊開平方：\(x-4=\pm3\)
  4. 移項解出兩個 x 值：\(x=4+3=7\) 或 \(x=4-3=1\)
手順卡①　直接開平方法
什麼時候用：方程可以化成 \(x^2=p\) 或 \((x+k)^2=c\)（沒有單獨的一次項 x，或已經是完全平方的形式）時最快
1. 化成 \(x^2=p\) 或 \((x+k)^2=c\) 的形式（未是這個形式先移項）※ 常數要移到等號另一邊，符號要跟著變
2. 判斷右邊的數是正、零還是負※ 負數不能開平方——這代表方程無解，不是計錯
3. 若右邊 ＞ 0，兩邊開平方，寫成 ±※ 別漏寫 ±，只寫一個根會漏解
4. 若左邊有 +k，最後移項解出兩個 x 值※ \(x-4=\pm3\) 要分別加 4，不要只加一次
三、方法二：配方法
配方法的作用：把任何一元二次方程，都轉化成方法一「\((x+k)^2=c\)」的形式，這樣就能用已經學過的「降次」技巧解出來。
★ 範例（來自歷屆大測）：解 \(x^2+6x-1=0\)
  1. 移項，把常數移到右邊：\(x^2+6x=1\)
  2. 兩邊加上「一次項係數一半的平方」：一次項係數是 6，一半是 3，平方是 9 → \(x^2+6x+9=1+9\)
  3. 左邊配成完全平方，右邊算出結果：\((x+3)^2=10\)
  4. 套用方法一「降次」：\(x+3=\pm\sqrt{10}\)，即 \(x=-3\pm\sqrt{10}\)
手順卡②　配方法
什麼時候用：方程無法輕易因式分解，但想理解公式法「從何而來」時用；也是公式法的推導基礎
1. 若 \(x^2\) 前面的係數不是 1，兩邊先除以那個係數※ 除法要連常數項一起除，不要漏掉
2. 把常數移到等號右邊，只留 \(x^2\) 和 x 項在左邊※ 移項變號——常見漏做這一步就直接加數字
3. 兩邊加上「一次項係數一半的平方」，即 \((b/2)^2\)※ 一次項係數是「x 前面那個數」，不是移項後的常數
4. 左邊寫成 \((x+b/2)^2\)，套用手順卡①「降次」解出 x※ 別忘記开方後要 ±，再移項兩次分別得到 \(x_1\)、\(x_2\)
四、方法三：公式法
公式法是把配方法的過程一般化：對任何 \(ax^2+bx+c=0\)（a≠0），直接代入求根公式 \(x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}\)，不用每次重新配方。
★ 範例（來自歷屆大測）：解 \(2(x^2-1)=3x+3\)
  1. 先展開、移項，化成一般式：\(2x^2-2=3x+3\) → \(2x^2-3x-5=0\)
  2. 寫出 a、b、c：\(a=2\)，\(b=-3\)，\(c=-5\)
  3. 算判別式 \(\Delta=b^2-4ac=(-3)^2-4(2)(-5)=9+40=49\)
  4. 代入公式：\(x=\dfrac{3\pm\sqrt{49}}{4}=\dfrac{3\pm7}{4}\)，即 \(x=\dfrac{5}{2}\) 或 \(x=-1\)
手順卡③　公式法
什麼時候用：方程不能輕易看出因式分解（係數不是整數倍關係、或嘗試因式分解失敗）時，公式法一定解得出
1. 化成一般式 \(ax^2+bx+c=0\)，寫出 a、b、c※ 若方程有括號或分母，先展開/去分母才能寫出正確的 a、b、c
2. 算判別式 \(\Delta=b^2-4ac\)※ \(b^2\) 記住是先平方再代負號的結果，\((-3)^2=9\) 不是 −9
3. 判斷 Δ 的正負：Δ<0 無解；Δ=0 一個重根；Δ>0 兩個不同根※ 這一步先做，可以避免白算一堂
4. 代入公式 \(x=\dfrac{-b\pm\sqrt{\Delta}}{2a}\) 算出結果※ 分母 2a 要連同 \(\pm\sqrt{\Delta}\) 一起除，不要只除其中一項
五、方法四：因式分解法
因式分解法是最快的捷徑——但只在能一眼看出因式的情況下才好用。學完前三種方法後，你已經知道方程「一定解得出」，因式分解法就是在有把握時抄捷徑。
★ 範例（來自歷屆大測）：解 \(x^2+2x-35=0\)
  1. 化成一般式，右邊等於 0（本題已經是）：\(x^2+2x-35=0\)
  2. 把左邊因式分解：找兩個數，相乘 = −35，相加 = 2 → 7 和 −5 → \((x+7)(x-5)=0\)
  3. 令每個因式分別 = 0：\(x+7=0\) 或 \(x-5=0\)
  4. 解出兩個 x 值，並驗根：\(x=-7\) 或 \(x=5\)
手順卡④　因式分解法
什麼時候用：方程的左邊「一眼看出」能分解（例如常數項不大、係數簡單）時最快
1. 化成一般式，右邊等於 0※ 若右邊不是 0，因式分解法不能直接用
2. 把左邊因式分解成兩個一次式的乘積※ 找兩數之積＝c、之和＝b；係數不是 1 時用十字相乘
3. 令每個因式分別等於 0※ 兩個因式都要令它等於 0，不能只做一個
4. 解出兩個 x 值，代回原方程驗根※ 若方程兩邊都有 x（如 \(x^2=5x\)），不能直接兩邊除以 x——要先移項再分解，否則會漏解 x=0
六、四種方法怎麼選？
① 方程已經是 \(x^2=p\) 或 \((x+k)^2=c\) 型 → 用直接開平方法（最快）
② 一眼看出能因式分解 → 用因式分解法（最快）
③ 想不到怎麼因式分解，但係數不複雜 → 用配方法（幫助理解過程）
④ 係數複雜、或配方會出現分數很麻煩 → 用公式法（一定解得出）
