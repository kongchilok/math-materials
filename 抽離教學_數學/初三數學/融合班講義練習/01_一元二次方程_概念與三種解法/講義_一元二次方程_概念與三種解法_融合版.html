一、認識一元二次方程

只含一個未知數，而且未知數的最高次數是 2 的方程，叫做「一元二次方程」。

一般式（標準式）
\(ax^2+bx+c=0\)　　（其中 \(a \ne 0\)）
怎樣找出 a、b、c？
第一步先把式子整理成「＝ 0」的一般式
第二步對照 \(ax^2+bx+c=0\) 讀出係數：\(x^2\) 前面的數是 a，x 前面的數是 b，剩下的常數是 c
特別注意a 不能是 0。若 \(x^2\) 的係數是 0，那是一元一次方程，不是二次

例：\(2x^2+3x-1=0\) 中，a ＝ 2，b ＝ 3，c ＝ −1。

本課會學四種解一元二次方程的方法，教學順序是：

① 直接開平方法（降次）　→　② 配方法　→　③ 公式法　→　④ 因式分解法

前三種方法一步步建立在上一種之上；因式分解法排最後，因為它是「看得出來就可以抄捷徑」的快速做法。

每種方法後面都有一張手順卡；完整版（連每一步的易錯提醒）在《工具卡》，可以剪下放在桌面邊做邊看。

寫算式的三條規矩（四種方法都一樣）
規矩一一行只寫一個等號，等號上下對齊成一條直線
規矩二開平方或因式分解之後，分成兩支寫，中間一定要寫「或」
規矩三最後一行用「∴」寫出答案：\(\therefore x_1 = \) …　或　\(x_2 = \) …
二、方法一：直接開平方法（降次）
「降次」的意思：把二次方程（有 \(x^2\)）變成兩個一次方程（沒有平方），就能用我們已經會解的方法完成。
對於 \(x^2=p\)，右邊的 p 決定有沒有根：
①當 \(p>0\)：有兩個不等的實數根 \(x_1=\sqrt{p}\)　或　\(x_2=-\sqrt{p}\)
②當 \(p=0\)：有兩個相等的實數根 \(x_1=x_2=0\)
③當 \(p<0\)：沒有實數根（因為任何實數的平方都 ≥ 0）
★ 範例：解 \((x-4)^2-9=0\)
算式這一步在做什麼
\((x-4)^2-9\)\(=\)\(0\) 原方程
\((x-4)^2\)\(=\)\(9\) 移項：−9 過等號變 +9※ 先看右邊：9 ＞ 0，可以開平方
\(x-4\)\(=\)\(3\) 或\(x-4\)\(=\)\(-3\) 兩邊開平方，分成兩支寫※ 中間一定要寫「或」；只寫一支會漏解
\(x\)\(=\)\(3+4\) 或\(x\)\(=\)\(-3+4\) 兩支各自移項：−4 過等號變 +4
\(x_1\)\(=\)\(7\) 或\(x_2\)\(=\)\(1\) 兩支各自算出；左支叫 \(x_1\)，右支叫 \(x_2\)
\(\therefore x_1 = 7\)　或　\(x_2 = 1\) 作答：最後一行用「∴」寫出兩個根
手順卡①　直接開平方法
什麼時候用：方程已經是（或可以化成）\(x^2=p\)、\((x+k)^2=c\) 的形式時最快
1. 化成 \(x^2=p\) 或 \((x+k)^2=c\) 的形式
2. 看右邊的數是正、零還是負
3. 右邊 ＞ 0 就兩邊開平方，分兩支寫，中間寫「或」
4. 兩支各自移項，解出 \(x_1\) 和 \(x_2\)
5. 最後一行用「∴」寫答句
三、方法二：配方法
配方法的作用：把任何一元二次方程，都變成方法一「\((x+k)^2=c\)」的形式，就能用已經學過的「降次」解出來。
★ 範例：解 \(x^2+6x-1=0\)
算式這一步在做什麼
\(x^2+6x-1\)\(=\)\(0\) 原方程
\(x^2+6x\)\(=\)\(1\) 移項：−1 過等號變 +1
\(x^2+6x+9\)\(=\)\(1+9\) 兩邊同時加 9※ 9 是「一次項係數一半的平方」，即 (6 ÷ 2) 的平方
\((x+3)^2\)\(=\)\(10\) 左邊配成完全平方，右邊算出 10
\(x+3\)\(=\)\(\sqrt{10}\) 或\(x+3\)\(=\)\(-\sqrt{10}\) 兩邊開平方，分成兩支寫（回到方法一的降次）※ 中間一定要寫「或」
\(x_1\)\(=\)\(-3+\sqrt{10}\) 或\(x_2\)\(=\)\(-3-\sqrt{10}\) 兩支各自移項：+3 過等號變 −3
\(\therefore x_1 = -3+\sqrt{10}\)　或　\(x_2 = -3-\sqrt{10}\) 作答：最後一行用「∴」寫出兩個根
手順卡②　配方法
什麼時候用：方程不易因式分解，或想理解公式法「從何而來」時用
1. \(x^2\) 前面的係數不是 1，兩邊先除以它
2. 把常數移到等號右邊
3. 兩邊同時加「一次項係數一半的平方」
4. 左邊配成 \((x+k)^2\)，套用手順卡①分兩支解
5. 最後一行用「∴」寫答句
四、方法三：公式法
公式法是把配方法的過程一般化：任何 \(ax^2+bx+c=0\)（\(a \ne 0\)）都直接代公式，不用每次重新配方。
求根公式
\(x=\dfrac{-b\pm\sqrt{b^2-4ac}}{2a}\)
判別式　\(\Delta=b^2-4ac\)
※ 公式本身用 ± 記法寫；一落到解題步驟，就要把 ± 拆成兩支，中間寫「或」。
★ 範例：解 \(2(x^2-1)=3x+3\)
算式這一步在做什麼
\(2(x^2-1)\)\(=\)\(3x+3\) 原方程
\(2x^2-2\)\(=\)\(3x+3\) 展開左邊括號
\(2x^2-3x-5\)\(=\)\(0\) 移項，化成一般式※ 有括號或分母的，一定要先整理成一般式才寫 a、b、c
a ＝ 2，b ＝ −3，c ＝ −5 對照一般式讀出三個係數（這一行不是方程，不參與等號對齊）
\(\Delta\)\(=\)\(b^2-4ac\) 先寫判別式公式
\(\Delta\)\(=\)\((-3)^2-4(2)(-5)\) 代入 a、b、c※ \((-3)^2=9\)，先平方再算，不是 −9
\(\Delta\)\(=\)\(49\) 算出判別式※ 49 ＞ 0，所以有兩個不同的實數根
\(x_1\)\(=\)\(\dfrac{-b+\sqrt{\Delta}}{2a}\) 或\(x_2\)\(=\)\(\dfrac{-b-\sqrt{\Delta}}{2a}\) 照抄公式，同時把 ± 拆成兩支※ 左支取「＋」、右支取「−」，中間寫「或」
\(x_1\)\(=\)\(\dfrac{3+7}{4}\) 或\(x_2\)\(=\)\(\dfrac{3-7}{4}\) 代入：−b ＝ 3、\(\sqrt{\Delta}=7\)、2a ＝ 4※ −b 是 −(−3) ＝ 3，不是 −3
\(x_1\)\(=\)\(\dfrac{10}{4}\) 或\(x_2\)\(=\)\(\dfrac{-4}{4}\) 兩支各自算出分子
\(x_1\)\(=\)\(\dfrac{5}{2}\) 或\(x_2\)\(=\)\(-1\) 約簡
\(\therefore x_1 = \dfrac{5}{2}\)　或　\(x_2 = -1\) 作答：最後一行用「∴」寫出兩個根
手順卡③　公式法
什麼時候用：看不出怎樣因式分解時用——公式法一定解得出
1. 化成一般式，寫出 a、b、c
2. 算判別式 \(\Delta=b^2-4ac\)
3. 看 Δ：Δ<0 無解、Δ=0 一個重根、Δ>0 兩個根
4. 照抄公式，再把 ± 拆成兩支，中間寫「或」
5. 兩支各自算出，最後用「∴」寫答句
五、方法四：因式分解法
因式分解法是最快的捷徑——但只在「一眼看得出因式」時才好用。學完前三種方法，你已經知道方程一定解得出，這一種是在有把握時抄捷徑。
★ 範例：解 \(x^2+2x-35=0\)
算式這一步在做什麼
\(x^2+2x-35\)\(=\)\(0\) 原方程，右邊已經是 0
\((x+7)(x-5)\)\(=\)\(0\) 左邊因式分解※ 找兩個數：相乘 ＝ −35，相加 ＝ +2 → 7 和 −5
\(x+7\)\(=\)\(0\) 或\(x-5\)\(=\)\(0\) 令每個因式分別等於 0※ 中間一定要寫「或」；兩個因式都要做
\(x_1\)\(=\)\(-7\) 或\(x_2\)\(=\)\(5\) 兩支各自解出
\(\therefore x_1 = -7\)　或　\(x_2 = 5\) 作答：最後一行用「∴」寫出兩個根
手順卡④　因式分解法
什麼時候用：方程的左邊「一眼看出」能分解（常數項不大、係數簡單）時最快
1. 化成一般式，右邊等於 0
2. 把左邊分解成兩個一次式的乘積
3. 令每個因式分別等於 0，中間寫「或」
4. 兩支各自解出，代回原方程驗根
5. 最後一行用「∴」寫答句
六、四種方法怎麼選？

先看方程長成什麼樣子，再決定用哪一種——不要每題都從頭試。

方程長成這樣…就用這個方法
已經是 \(x^2=p\) 或 \((x+k)^2=c\)① 直接開平方法（最快）
一眼看出能因式分解④ 因式分解法（最快）
分解不出，但係數簡單② 配方法
係數複雜、配方會出現分數③ 公式法（一定解得出）
無論用哪一種方法，寫算式的三條規矩都一樣：一行一個等號、分兩支寫「或」、最後用「∴」寫答句。
