### 概念對照表（拋物線位置 ↔ 不等式）
| 拋物線的位置 | 對應的式子 |
|---|---|
| 在 x 軸上方 | ax²+bx+c ＞ 0 |
| 剛好在 x 軸上（兩個交點） | ax²+bx+c ＝ 0 |
| 在 x 軸下方 | ax²+bx+c ＜ 0 |

驗算：定義層面，無數值。與 §一「拋物線與 x 軸交點的橫坐標＝方程的根」直接銜接，

### D2 手順卡四步
① 畫草圖（把不等號換成等號求兩根）→ ② 標兩交點（由小到大）→ ③ 看開口（看 a 的正負）
→ ④ 讀區間（要 y＞0 讀上方，要 y＜0 讀下方）。

### 範例一：解 x²−2x−3 ＞ 0（延續 §一 已用過的 y＝x²−2x−3）

**代數部分（worked_example_table，含「把不等號換成等號」單獨佔一行）**
- 因式分解核對：(x−3)(x+1) ＝ x²＋x−3x−3 ＝ x²−2x−3 ✓
- 兩根：x₁ ＝ 3、x₂ ＝ −1（左支 x₁ 取 (x−3)＝0，與 §一 原有範例的分支順序完全一致 ✓）
- Δ ＝ (−2)²−4(1)(−3) ＝ 4＋12 ＝ 16 ＞ 0，與 §一 原有算式一致 ✓

**讀圖部分（D5 圖文雙軌，四列對應四步）**
- a ＝ 1 ＞ 0 → 開口向上 ✓
- 解集 x ＜ −1 或 x ＞ 3。逐點代入驗算：
  - x ＝ −2：4＋4−3 ＝ 5 ＞ 0 ✓（落在 x＜−1，應成立）
  - x ＝ 0：0−0−3 ＝ −3，不 ＞ 0 ✓（落在兩根之間，應不成立）
  - x ＝ 4：16−8−3 ＝ 5 ＞ 0 ✓（落在 x＞3，應成立）
  - x ＝ −1、x ＝ 3：y ＝ 0，不合嚴格 ＞ 0 → 圖上端點畫**空心圈**，答案不含端點 ✓

### 範例二：同一條拋物線，解 x²−2x−3 ＜ 0
- 解集 −1 ＜ x ＜ 3。逐點代入：
  - x ＝ 0：−3 ＜ 0 ✓（應成立）
  - x ＝ −2：5，不 ＜ 0 ✓（應不成立）
  - x ＝ 4：5，不 ＜ 0 ✓（應不成立）
- 與範例一互補：兩個解集聯集 ∪ 兩個根 ＝ 全體實數，無遺漏無重疊 ✓

### 決策表：不等號方向與開口的關係（p ＜ q 為兩根）
| 開口 | 不等式 | 解集 |
|---|---|---|
| a＞0 向上 | ＞0 | x ＜ p 或 x ＞ q（取兩邊） |
| a＞0 向上 | ＜0 | p ＜ x ＜ q（取中間） |
| a＜0 向下 | ＞0 | p ＜ x ＜ q（取中間） |
| a＜0 向下 | ＜0 | x ＜ p 或 x ＞ q（取兩邊） |

四格各用一條具體式子驗算（取 p ＝ −1、q ＝ 1）：
1. x²−1 ＞ 0：x＝2 → 3 ＞ 0 ✓；x＝0 → −1，不成立 ✓　→ 取兩邊 ✓
2. x²−1 ＜ 0：x＝0 → −1 ＜ 0 ✓；x＝2 → 3，不成立 ✓　→ 取中間 ✓
3. −x²+1 ＞ 0：x＝0 → 1 ＞ 0 ✓；x＝2 → −3，不成立 ✓　→ 取中間 ✓
4. −x²+1 ＜ 0：x＝2 → −3 ＜ 0 ✓；x＝0 → 1，不成立 ✓　→ 取兩邊 ✓

講義寫的核對記法「向上配 ＞0、向下配 ＜0 → 取兩邊；配不起來 → 取中間」與上表四行完全吻合 ✓
（表下已註明本節只處理與 x 軸有兩個交點的情況，Δ ≤ 0 不在範圍內，與教案範圍一致。）

### 4-A（★☆☆）由圖讀解集
**第 9 題**　y ＝ x²+x−2，圖已給並標交點 −2、1；求 x²+x−2 ＜ 0 的解集
- 因式分解核對：(x+2)(x−1) ＝ x²−x+2x−2 ＝ x²+x−2 ✓ → 兩根 −2、1
- a ＝ 1 ＞ 0 開口向上，要 y ＜ 0 → 取兩根之間
- **答：−2 ＜ x ＜ 1**。代入驗算：x＝0 → −2 ＜ 0 ✓；x＝−3 → 9−3−2 ＝ 4，不成立 ✓；
  x＝2 → 4+2−2 ＝ 4，不成立 ✓

**第 10 題**　y ＝ x²−5x+4，圖已給並標交點 1、4；求 x²−5x+4 ＞ 0 的解集
- 因式分解核對：(x−1)(x−4) ＝ x²−5x+4 ✓ → 兩根 1、4
- a ＝ 1 ＞ 0 開口向上，要 y ＞ 0 → 取兩根之外
- **答：x ＜ 1 或 x ＞ 4**。代入驗算：x＝0 → 4 ＞ 0 ✓；x＝2 → 4−10+4 ＝ −2，不成立 ✓；
  x＝5 → 25−25+4 ＝ 4 ＞ 0 ✓

### 4-B（★★☆）
**第 11 題**　y ＝ −x²+2x+3，圖已給（開口向下）並標交點 −1、3
- 核對：−x²+2x+3 ＝ −(x²−2x−3) ＝ −(x−3)(x+1) ✓ → 兩根 −1、3；a ＝ −1 ＜ 0 開口向下
- (1) ＞ 0 → 取兩根之間　**答：−1 ＜ x ＜ 3**
  代入：x＝0 → 3 ＞ 0 ✓；x＝−2 → −4−4+3 ＝ −5，不成立 ✓；x＝4 → −16+8+3 ＝ −5，不成立 ✓
- (2) ＜ 0 → 取兩根之外　**答：x ＜ −1 或 x ＞ 3**
  代入：x＝−2 → −5 ＜ 0 ✓；x＝4 → −5 ＜ 0 ✓；x＝0 → 3，不成立 ✓
- (1)(2) 兩個解集聯集 ∪ 兩根 ＝ 全體實數 ✓

**第 12 題**　解 x²−x−6 ＞ 0（教案原文指定的例子；只給虛線空框自畫草圖）
- 因式分解核對：(x−3)(x+2) ＝ x²+2x−3x−6 ＝ x²−x−6 ✓ → 兩根 −2、3
- a ＝ 1 ＞ 0 開口向上，要 y ＞ 0 → 取兩根之外
- **答：x ＜ −2 或 x ＞ 3**。代入：x＝−3 → 9+3−6 ＝ 6 ＞ 0 ✓；x＝0 → −6，不成立 ✓；
  x＝4 → 16−4−6 ＝ 6 ＞ 0 ✓

### 4-C（★★★）
**第 13 題**　解 −x²+4x−3 ＞ 0（只給虛線空框，無任何提示）
- 兩邊乘 −1：x²−4x+3 ＝ 0 → (x−1)(x−3) ＝ x²−4x+3 ✓ → 兩根 1、3
- a ＝ −1 ＜ 0 開口向下，要 y ＞ 0 → 取兩根之間
- **答：1 ＜ x ＜ 3**。代入：x＝2 → −4+8−3 ＝ 1 ＞ 0 ✓；x＝0 → −3，不成立 ✓；
  x＝4 → −16+16−3 ＝ −3，不成立 ✓
- **迷思測試**：學生若抱住「＞0 一定取兩邊」這個迷思，會答「x ＜ 1 或 x ＞ 3」——與正解相反，
  本題有篩選力 ✓。反向保險：第 12 題正是「a＞0 配 ＞0 真的取兩邊」，盲目反轉的學生一樣會錯 ✓
