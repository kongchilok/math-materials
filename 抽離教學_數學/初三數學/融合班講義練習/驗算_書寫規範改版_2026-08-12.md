## 逐條驗算

### 02 §一 判別式（Δ＝b²−4ac）
- ① `x²−3x+1=0`，a＝1、b＝−3、c＝1
  `Δ=(−3)²−4(1)(1)=9−4=5`　→　5＞0，兩個相異實根 ✅（與舊版結論相同）
- ② `4x²−4x+1=0`，a＝4、b＝−4、c＝1
  `Δ=(−4)²−4(4)(1)=16−16=0`　→　重根 ✅
- ③ `x²+x+1=0`，a＝1、b＝1、c＝1
  `Δ=(1)²−4(1)(1)=1−4=−3`　→　−3＜0，沒有實根 ✅

### 02 §二 韋達定理（x²−5x+6=0，a＝1、b＝−5、c＝6）
- 兩根和 `−b/a = −(−5)/1 = 5` ✅
- 兩根積 `c/a = 6/1 = 6` ✅
- 反向核對：兩根為 2、3 → 2＋3＝5、2×3＝6，對得上 ✅
- **另修**：通則行原寫 `frac(−b, a)`（負號縮在分子），與新範例的 `−frac(b, a)`
  打架，已統一為負號寫在分數線左邊（house-style §8、§7）。

### 05 §五 配方（y＝x²−4x+3）
- `x²−4x+3 = (x²−4x+4)−4+3 = (x−2)²−1` ✅
- 反向展開核對：`(x−2)²−1 = x²−4x+4−1 = x²−4x+3` ✅
- 補回舊版略去的「加 4 再減 4」那一步（融合班最易斷片處）。

### 06 §一 拋物線與 x 軸交點（y＝x²−2x−3）
- `Δ=(−2)²−4(1)(−3)=4+12=16`＞0，兩個交點 ✅
- `x²−2x−3=(x−3)(x+1)` ✅（展開：x²+x−3x−3＝x²−2x−3）
- 左支 `x−3=0 → x₁=3`；右支 `x+1=0 → x₂=−1` ✅
  （已核對「因式分解左右次序要與 x₁／x₂ 對得上」這條踩坑：左支對左解）
- 交點 (−1, 0)、(3, 0) ✅（與舊版相同）

### 06 §二 最值應用（籬笆 20 米）
- 長＋寬＝20÷2＝10；設寬 x，長 10−x
- `y = x(10−x) = 10x−x² = −(x²−10x) = −(x²−10x+25)+25 = −(x−5)²+25` ✅
  逐步核對：−(x²−10x+25)+25 ＝ −x²+10x−25+25 ＝ −x²+10x ＝ 10x−x² ✅
- 頂點 (5, 25) → x＝5 時最大面積 25 平方米 ✅
- 反向核對：x＝5 時長寬皆 5，面積 5×5＝25 ✅（正方形，與舊版註記一致）

### 08 §二 垂徑定理（r＝5，弦 AB＝8）
- 半弦 AM＝8÷2＝4
- `d² = 5²−4² = 25−16 = 9` → `d = 3` ✅
- **教學判斷**：幾何長度開平方只取正根，**不套**「開平方分兩支」那條規矩
  （house-style 規範 3 管的是解方程 x²＝p），右欄已註明「長度取正」。

### 08 §四 圓內接四邊形（∠A＝80°）
- `∠C = 180°−80° = 100°` ✅

### 09 §三 切線性質（OA＝3、PA＝4）
- 切線 ⊥ 半徑 → ∠OAP＝90°
- `OP² = 3²+4² = 9+16 = 25` → `OP = 5` ✅（3–4–5 直角三角形）

### 10 §一 相交弦定理（PA＝2、PB＝6、PC＝3）
- `PA·PB = PC·PD` → `2×6 = 3×PD` → `12 = 3PD` → `PD = 4` ✅

### 10 §二 切割線定理（PA＝2、PB＝8）
- `PT² = PA·PB = 2×8 = 16` → `PT = 4` ✅（長度取正）

### 11 §三 弧長與扇形面積（R＝6，n＝120°）
- 弧長 `l = (120/360)×2π×6 = (1/3)×12π = 4π` ✅
- 面積 `S = (120/360)×π×6² = (1/3)×36π = 12π` ✅
- 交叉核對（用 S＝½ l R）：`½ × 4π × 6 = 12π` ✅ 兩式一致

### 12 §一 擲骰子
- 全部 6 種等可能；偶數 3 種（2、4、6）
- `P = 3/6 = 1/2` ✅

### 12 §二 拋兩枚硬幣
- 全部 4 種：正正、正反、反正、反反
- 兩正：`P = 1/4` ✅
- 一正一反：2 種（正反、反正）→ `P = 2/4 = 1/2` ✅
