## 二、簡報獨有內容的核對

### S5 辨識題（四選二）

| 式子 | 是否分式方程 | 理由核對 |
|---|---|---|
| `3/x = x − 2` | ✓ | 分母 `x` 含未知數 ✓ |
| `x/2 + 1 = 5` | ✗ | 分母是常數 2，屬一元一次方程 ✓ |
| `1/(x−1) = 3/(x+2)` | ✓ | 兩邊分母都含未知數 ✓ |
| `x² − 5x + 6 = 0` | ✗ | 無分母，屬一般一元二次方程 ✓ |

判斷準則一致：**分母裡面有沒有未知數**。四題準則套用無矛盾。✓

### S11 為何平方會生假根（`2 = −2` 反例）

- 原命題：`2 = −2` 為假 ✓
- 兩邊平方：`2² = (−2)²` → `4 = 4` 為真 ✓
- 結論成立：平方把假命題變成真命題，故平方後的解集**包含**原方程的解集但可能更大，
  多出來的即假根。✓
- 補充判準「根號算出來一定不是負數」：對實數 `a ≥ 0`，`√a ≥ 0` ✓，
  故右邊為負時必無解，可不代入直接捨。此判準在範例二 `x₂ = −1` 與練習 A2、B5 均成立。✓

### S22 決策表

| 方程長成這樣 | 用哪張卡 | 最後一步 | 核對 |
|---|---|---|---|
| 分母裡有未知數 | 分式方程四步 | 去分母 → 驗根（怕增根） | ✓ 與手順卡措辭逐字一致 |
| 未知數被關在根號裡 | 無理方程四步 | 兩邊平方 → 驗根（怕假根） | ✓ 同上 |
| 兩條方程、兩個未知數 | 方程組四步 | 代入消元 → 回代 | ✓ 同上 |

三行涵蓋本單元全部題型，無遺漏、無重疊。✓

### S23 驗根總表

| 方程 | 驗根動作 | 判準 | 核對 |
|---|---|---|---|
| 分式方程 | 代入原方程的**分母** | 分母為 0 → 增根捨去 | ✓ 與範例一、D14 框一致 |
| 無理方程 | 代入原方程，左右各算一次 | 左右不相等 → 假根捨去 | ✓ 與範例二一致 |
| 方程組 | 每一對 (x, y) 代入兩條方程 | 兩條都成立才算對 | ✓ 與範例三一致 |

三種驗根動作各自對應其「放出未知數」的手段，邏輯自洽。✓
