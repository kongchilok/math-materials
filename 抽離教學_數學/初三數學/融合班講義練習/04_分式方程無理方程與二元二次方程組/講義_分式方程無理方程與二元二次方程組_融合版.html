這一課要學三種新方程
前面學過的一元二次方程，未知數都是「光著身」的。這一課的三種方程，未知數分別被關在三個地方：
分母裡　→　分式方程　　例：\(\dfrac{3}{x}=x-2\)
根號裡　→　無理方程　　例：\(\sqrt{x+2}=x\)
另一條方程裡　→　二元二次方程組　　例：\(y=x+1\) 與 \(x^2+y^2=25\)
三種方程的做法都是同一個念頭：
想辦法把未知數「放出來」，變回會解的一元二次方程。
但放出來是有代價的——
去分母、平方，這兩個動作都可能多生出「假的解」。所以這一課每一題最後都要驗根。
一、分式方程
分式方程 四步
什麼時候用：方程裡有分母，而且分母含有未知數
1. 把每個分母因式分解，找出最簡公分母※ 分母是 \(x^2-4\) 要先拆成 \((x+2)(x-2)\)
2. 兩邊同乘最簡公分母，去分母※ 每一項都要乘，包括沒有分母的那一項
3. 解這條整式方程※ 照一元二次方程的做法：移項、因式分解、分兩支
4. 驗根：把每個解代回原方程的分母※ 令分母等於 0 的叫增根，一定要捨去
★ 範例一：解 \(\dfrac{3}{x}=x-2\)
算式這一步在做什麼
\(\dfrac{3}{x}\)\(=\)\(x-2\)原方程。分母有 \(x\)，所以先寫低 \(x \neq 0\)
最簡公分母是 \(x\)分母只有一個，最簡公分母就是它
\(3\)\(=\)\(x(x-2)\)兩邊同乘 \(x\)，去分母
\(3\)\(=\)\(x^2-2x\)展開右邊
\(x^2-2x-3\)\(=\)\(0\)移項，化成一般式
\((x-3)(x+1)\)\(=\)\(0\)因式分解
\(x-3\)\(=\)\(0\)或\(x+1\)\(=\)\(0\)兩個因式各自等於 0，分兩支寫
\(x_1\)\(=\)\(3\)或\(x_2\)\(=\)\(-1\)兩支各自解出
驗根 \(x_1=3\)：代入分母 \(x\) 得 \(3\)不等於 0，保留
驗根 \(x_2=-1\)：代入分母 \(x\) 得 \(-1\)不等於 0，保留
\(\therefore\) \(x_1 = 3\)　或　\(x_2 = -1\)作答：最後一行用「∴」寫出兩個根
二、無理方程
無理方程 四步
什麼時候用：未知數被關在根號裡面
1. 移項，讓根號單獨留在一邊※ 根號要孤立，才能一次平方掉
2. 兩邊平方，去根號※ 右邊是整體平方：\((x-3)^2\) 不等於 \(x^2-9\)
3. 解這條整式方程※ 照一元二次方程的做法：移項、因式分解、分兩支
4. 驗根：把每個解代回原方程※ 平方會多出假根；左右不相等的一定要捨去
★ 範例二：解 \(\sqrt{x+2}=x\)
算式這一步在做什麼
\(\sqrt{x+2}\)\(=\)\(x\)原方程。根號已經單獨在左邊，可以直接平方
\(x+2\)\(=\)\(x^2\)兩邊平方，去根號
\(x^2-x-2\)\(=\)\(0\)移項，化成一般式
\((x-2)(x+1)\)\(=\)\(0\)因式分解
\(x-2\)\(=\)\(0\)或\(x+1\)\(=\)\(0\)兩個因式各自等於 0，分兩支寫
\(x_1\)\(=\)\(2\)或\(x_2\)\(=\)\(-1\)兩支各自解出
驗根 \(x_1=2\)：左邊 \(\sqrt{2+2}=2\)，右邊 \(2\)左右相等，保留
驗根 \(x_2=-1\)：左邊 \(\sqrt{-1+2}=1\)，右邊 \(-1\)根號算出來一定不是負數，左右不相等，捨去
\(\therefore\) \(x = 2\)作答：只有一個根通過驗根，就只寫一個
三、二元二次方程組
二元二次方程組 四步
什麼時候用：兩條方程、兩個未知數，其中一條是二次
1. 找出那條一次方程※ 一次方程才好用來「用一個字母表示另一個」
2. 從一次方程解出一個未知數※ 例如寫成 \(y=x+1\)，準備代入
3. 代入二次方程，解出第一個未知數※ 代入後只剩一個字母，就變回熟悉的一元二次方程
4. 每個解都要回代，求出另一個未知數※ 答案要成對寫：有幾個 \(x\) 就有幾對 \((x,y)\)
★ 範例三：解方程組 \(y=x+1\)　與　\(x^2+y^2=25\)
算式這一步在做什麼
已知：\(y=x+1\)（一次）　與　\(x^2+y^2=25\)（二次）一次那條已經解好 \(y\)，可以直接代入
\(x^2+(x+1)^2\)\(=\)\(25\)把 \(y\) 換成 \(x+1\)，代入二次方程
\(x^2+x^2+2x+1\)\(=\)\(25\)展開 \((x+1)^2\)
\(2x^2+2x-24\)\(=\)\(0\)移項，合併同類項
\(x^2+x-12\)\(=\)\(0\)兩邊除以 2，數字變細
\((x-3)(x+4)\)\(=\)\(0\)因式分解
\(x-3\)\(=\)\(0\)或\(x+4\)\(=\)\(0\)兩個因式各自等於 0，分兩支寫
\(x_1\)\(=\)\(3\)或\(x_2\)\(=\)\(-4\)兩支各自解出 \(x\)
\(y_1\)\(=\)\(4\)或\(y_2\)\(=\)\(-3\)回代 \(y=x+1\)：這一步最容易漏
\(\therefore\) \((x_1,y_1)=(3,4)\)　或　\((x_2,y_2)=(-4,-3)\)作答：方程組的答案要成對寫
四、這一課最容易錯的一步
下面兩欄，前三行一模一樣，分歧在第四行。
題目：解 \(\dfrac{2}{x-3}=\dfrac{x-1}{x-3}\)
常見寫法正確寫法
兩邊乘 \((x-3)\)，去分母兩邊乘 \((x-3)\)，去分母
\(2=x-1\)\(2=x-1\)
\(x=3\)\(x=3\)
答：\(x=3\)※ 驗根：\(x=3\) 令分母 \(x-3=0\)，分式沒有意義 → 增根，捨去
∴ 原方程無解
※ 差在這裡：解出來的數字一定要代回分母檢查。令分母等於 0 的數叫「增根」，它不是原方程的解。
