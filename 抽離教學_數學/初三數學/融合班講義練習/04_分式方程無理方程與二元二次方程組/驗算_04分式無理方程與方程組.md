> 逐題親自命題、親自驗算。每題把根代回**原方程**核對，不是代回化簡後的方程。

## 一、講義範例

### 範例一（分式方程）：解 3/x = x − 2

| 步驟 | 算式 |
|---|---|
| 原方程 | 3/x ＝ x − 2　（x ≠ 0） |
| 最簡公分母 | x |
| 去分母 | 3 ＝ x(x − 2) |
| 展開 | 3 ＝ x² − 2x |
| 移項 | x² − 2x − 3 ＝ 0 |
| 因式分解 | (x − 3)(x + 1) ＝ 0 |
| 分兩支 | x − 3 ＝ 0 或 x + 1 ＝ 0 |
| 解 | x₁ ＝ 3 或 x₂ ＝ −1 |
| 驗根 | x₁ ＝ 3 ≠ 0 ✓；x₂ ＝ −1 ≠ 0 ✓ |
| 答 | ∴ x₁ ＝ 3 或 x₂ ＝ −1 |

**代回原方程核對**
- x ＝ 3：左 ＝ 3/3 ＝ 1；右 ＝ 3 − 2 ＝ 1。左 ＝ 右 ✓
- x ＝ −1：左 ＝ 3/(−1) ＝ −3；右 ＝ −1 − 2 ＝ −3。左 ＝ 右 ✓

✅ 兩根皆合格。此題選來示範「四步走完、兩根都保留」的乾淨情況。

---

### 範例二（無理方程）：解 √(x+2) = x

| 步驟 | 算式 |
|---|---|
| 原方程 | √(x + 2) ＝ x |
| 兩邊平方 | x + 2 ＝ x² |
| 移項 | x² − x − 2 ＝ 0 |
| 因式分解 | (x − 2)(x + 1) ＝ 0 |
| 分兩支 | x − 2 ＝ 0 或 x + 1 ＝ 0 |
| 解 | x₁ ＝ 2 或 x₂ ＝ −1 |
| 驗根 | 見下 |
| 答 | ∴ x ＝ 2 |

**代回原方程核對**
- x ＝ 2：左 ＝ √(2+2) ＝ √4 ＝ 2；右 ＝ 2。左 ＝ 右 ✓ **保留**
- x ＝ −1：左 ＝ √(−1+2) ＝ √1 ＝ 1；右 ＝ −1。1 ≠ −1 ✗ **捨去**

✅ 天然示範捨根，且左右代入直觀（根號值必為非負，右邊卻是負數）。

### 範例三（二元二次方程組）：y = x + 1；x² + y² = 25

| 步驟 | 算式 |
|---|---|
| 一次方程已解出 y | y ＝ x + 1 |
| 代入二次方程 | x² + (x + 1)² ＝ 25 |
| 展開 | x² + x² + 2x + 1 ＝ 25 |
| 整理 | 2x² + 2x − 24 ＝ 0 |
| 兩邊除以 2 | x² + x − 12 ＝ 0 |
| 因式分解 | (x − 3)(x + 4) ＝ 0 |
| 分兩支 | x − 3 ＝ 0 或 x + 4 ＝ 0 |
| 解 x | x₁ ＝ 3 或 x₂ ＝ −4 |

> ⚠ 因式的左右次序必須跟下一行的 x₁／x₂ 對得上：左支 `x − 3 ＝ 0` → `x₁ ＝ 3`。
> 初版寫成 `(x + 4)(x − 3)` 卻接 `x₁ ＝ 3`，左欄由上而下讀變成「x + 4 ＝ 0 ⇒ x ＝ 3」，
> 是教錯（QA 驗出，已修）。
| **回代求 y** | x₁ ＝ 3 → y₁ ＝ 4；x₂ ＝ −4 → y₂ ＝ −3 |
| 答 | ∴ (x₁, y₁) ＝ (3, 4) 或 (x₂, y₂) ＝ (−4, −3) |

**代回原方程組核對**
- (3, 4)：y ＝ x+1 → 4 ＝ 3+1 ✓；x²+y² ＝ 9+16 ＝ 25 ✓
- (−4, −3)：y ＝ x+1 → −3 ＝ −4+1 ＝ −3 ✓；x²+y² ＝ 16+9 ＝ 25 ✓

✅ 舊版此題省略了「回代求 y」一步（subagent 驗出），本版補回並獨立成行。

## 二、D14 錯誤分析對比框（增根）

**題目**：解 2/(x−3) = (x−1)/(x−3)

| 常見寫法（錯） | 正確寫法 |
|---|---|
| 兩邊乘 (x−3)：2 ＝ x − 1 | 兩邊乘 (x−3)：2 ＝ x − 1 |
| x ＝ 3 | x ＝ 3 |
| 答：x ＝ 3 | ※ 驗根：x ＝ 3 令分母 x − 3 ＝ 0，分式無意義 → 增根，捨去 |
| — | ∴ 原方程無解 |

**核對**：x ＝ 3 代入原方程，兩邊分母皆為 3 − 3 ＝ 0，分式沒有意義，故 x ＝ 3 不是原方程的解；除此之外去分母後的一次方程再無其他解，因此原方程無解。✓

✅ 符合 D14 規範：左欄是真實高頻錯誤（非自編）、只標一個分歧步驟、正確欄灰底佔視覺優勢、排在範例段之後（不是全新概念的第一次教學）。

## 三、練習 A ★☆☆（半成品鷹架）

### A1（分式方程）：解 4/x = x − 3

去分母：4 ＝ x(x − 3) → 4 ＝ x² − 3x → x² − 3x − 4 ＝ 0
因式分解：(x − 4)(x + 1) ＝ 0
分兩支：x − 4 ＝ 0 或 x + 1 ＝ 0
解：x₁ ＝ 4 或 x₂ ＝ −1
驗根：4 ≠ 0 ✓；−1 ≠ 0 ✓
**∴ x₁ ＝ 4 或 x₂ ＝ −1**

**代回原方程**
- x ＝ 4：左 ＝ 4/4 ＝ 1；右 ＝ 4 − 3 ＝ 1 ✓
- x ＝ −1：左 ＝ 4/(−1) ＝ −4；右 ＝ −1 − 3 ＝ −4 ✓

---

### A2（無理方程）：解 √(x+3) = x − 3

兩邊平方：x + 3 ＝ (x − 3)² ＝ x² − 6x + 9
移項：x² − 7x + 6 ＝ 0
因式分解：(x − 1)(x − 6) ＝ 0
分兩支：x − 1 ＝ 0 或 x − 6 ＝ 0
解：x₁ ＝ 1 或 x₂ ＝ 6

**驗根（代回原方程）**
- x ＝ 1：左 ＝ √(1+3) ＝ √4 ＝ 2；右 ＝ 1 − 3 ＝ −2。2 ≠ −2 ✗ **捨去**
- x ＝ 6：左 ＝ √(6+3) ＝ √9 ＝ 3；右 ＝ 6 − 3 ＝ 3 ✓ **保留**

**∴ x ＝ 6**

---

### A3（方程組）：y = x − 1；x² + y² = 13

代入：x² + (x − 1)² ＝ 13 → x² + x² − 2x + 1 ＝ 13 → 2x² − 2x − 12 ＝ 0
除以 2：x² − x − 6 ＝ 0
因式分解：(x − 3)(x + 2) ＝ 0
分兩支：x − 3 ＝ 0 或 x + 2 ＝ 0
解 x：x₁ ＝ 3 或 x₂ ＝ −2
回代 y ＝ x − 1：x₁ ＝ 3 → y₁ ＝ 2；x₂ ＝ −2 → y₂ ＝ −3
**∴ (x₁, y₁) ＝ (3, 2) 或 (x₂, y₂) ＝ (−2, −3)**

**代回原方程組**
- (3, 2)：2 ＝ 3 − 1 ✓；9 + 4 ＝ 13 ✓
- (−2, −3)：−3 ＝ −2 − 1 ✓；4 + 9 ＝ 13 ✓

## 四、練習 B ★★☆（課本標準難度）

### B4（分式方程）：解 x/(x−2) − 3/x = 1

最簡公分母 x(x − 2)，限制 x ≠ 0 且 x ≠ 2
兩邊乘 x(x − 2)：x·x − 3(x − 2) ＝ x(x − 2)
展開：x² − 3x + 6 ＝ x² − 2x
消去 x²：−3x + 6 ＝ −2x
移項：6 ＝ x，即 x ＝ 6
驗根：6 ≠ 0 ✓；6 − 2 ＝ 4 ≠ 0 ✓
**∴ x ＝ 6**

**代回原方程**
左 ＝ 6/(6−2) − 3/6 ＝ 6/4 − 1/2 ＝ 1.5 − 0.5 ＝ 1；右 ＝ 1 ✓

> 註：此題去分母後 x² 項自動消去，降為一次方程、只有一個解——刻意選來破除
> 「分式方程一定有兩個根」的錯誤預期。

---

### B5（無理方程）：解 √(2x+1) = x − 1

兩邊平方：2x + 1 ＝ (x − 1)² ＝ x² − 2x + 1
移項：x² − 4x ＝ 0
因式分解：x(x − 4) ＝ 0
分兩支：x ＝ 0 或 x − 4 ＝ 0
解：x₁ ＝ 0 或 x₂ ＝ 4

**驗根（代回原方程）**
- x ＝ 0：左 ＝ √1 ＝ 1；右 ＝ 0 − 1 ＝ −1。1 ≠ −1 ✗ **捨去**
- x ＝ 4：左 ＝ √9 ＝ 3；右 ＝ 4 − 1 ＝ 3 ✓ **保留**

**∴ x ＝ 4**

---

### B6（方程組）：x + y = 5；xy = 6

從第一式解出 y：y ＝ 5 − x
代入第二式：x(5 − x) ＝ 6 → 5x − x² ＝ 6 → x² − 5x + 6 ＝ 0
因式分解：(x − 2)(x − 3) ＝ 0
分兩支：x − 2 ＝ 0 或 x − 3 ＝ 0
解 x：x₁ ＝ 2 或 x₂ ＝ 3
回代 y ＝ 5 − x：x₁ ＝ 2 → y₁ ＝ 3；x₂ ＝ 3 → y₂ ＝ 2
**∴ (x₁, y₁) ＝ (2, 3) 或 (x₂, y₂) ＝ (3, 2)**

**代回原方程組**
- (2, 3)：2 + 3 ＝ 5 ✓；2 × 3 ＝ 6 ✓
- (3, 2)：3 + 2 ＝ 5 ✓；3 × 2 ＝ 6 ✓

> 註：舊版同型題的參考答案用韋達定理（「x、y 是 t²−5t+6＝0 的根」），
> 但講義只教過代入消元，對三層學生都超綱（subagent 驗出）。本版改回代入消元。

## 五、練習 C ★★★（應用／找錯／自出題）

### C7（分式方程應用題）

**題目**：甲、乙兩地相距 30 公里。小明騎單車從甲地到乙地，比開車多用 1 小時。
已知開車速度是單車速度的 3 倍，求單車的速度。

設單車速度為 x km/h（x > 0），則開車速度為 3x km/h
單車用時 30/x 小時，開車用時 30/(3x) 小時
列式：30/x − 30/(3x) ＝ 1
最簡公分母 3x
兩邊乘 3x：90 − 30 ＝ 3x
60 ＝ 3x
x ＝ 20
驗根：20 ≠ 0 ✓，且 x ＝ 20 > 0 合乎情境 ✓
**∴ 單車的速度是 20 km/h**

**代回題目情境核對**
- 單車：30 ÷ 20 ＝ 1.5 小時
- 開車：30 ÷ 60 ＝ 0.5 小時
- 相差 1.5 − 0.5 ＝ 1 小時 ✓ 與題目「多用 1 小時」相符

> 數字挑選說明：單車 20 km/h、開車 60 km/h 皆為現實合理速度；時間為 1.5 與 0.5
> 小時，學生心算可驗。

### C8（找錯題）

**題目**：小美解無理方程 √(x+6) = x，過程如下——
兩邊平方，得 x + 6 ＝ x²；整理，得 x² − x − 6 ＝ 0；
因式分解，得 (x − 3)(x + 2) ＝ 0；所以 x ＝ 3 或 x ＝ −2。
（一）小美漏了哪一步？（二）正確答案是什麼？請寫出完整過程。

**參考答案**
（一）漏了**驗根**。兩邊平方是不可逆運算，可能多出不合原方程的根，
每個解都必須代回**原方程**檢查。

（二）驗根：
- x ＝ 3：左 ＝ √(3+6) ＝ √9 ＝ 3；右 ＝ 3 ✓ **保留**
- x ＝ −2：左 ＝ √(−2+6) ＝ √4 ＝ 2；右 ＝ −2。2 ≠ −2 ✗ **捨去**

**∴ x ＝ 3**

**核對**：小美前四步的代數運算全部正確，唯一缺失是驗根——符合 D14「只標一個
分歧步驟」的要求。✓

### C9（自出一題）

**題目**：請你自己出一條分式方程，要求：解整式方程後會得到兩個數，
但其中一個是增根、必須捨去。
（一）寫出你的方程　（二）寫出完整解法（包括驗根）　（三）用一句話說明那個數為什麼要捨去

**參考答案（其中一種，學生答案只要符合要求即可）**

方程：x²/(x−1) ＝ 1/(x−1)

兩邊乘 (x − 1)：x² ＝ 1
移項：x² − 1 ＝ 0
因式分解：(x − 1)(x + 1) ＝ 0
分兩支：x − 1 ＝ 0 或 x + 1 ＝ 0
解：x₁ ＝ 1 或 x₂ ＝ −1

驗根：
- x ＝ 1：分母 1 − 1 ＝ 0，分式無意義 → **增根，捨去**
- x ＝ −1：分母 −1 − 1 ＝ −2 ≠ 0 ✓ **保留**

**∴ x ＝ −1**

（三）x ＝ 1 會令原方程的分母等於 0，分式在該處無意義，所以它不是原方程的解。

**代回原方程核對**（x ＝ −1）
左 ＝ (−1)²/(−1−1) ＝ 1/(−2) ＝ −0.5；右 ＝ 1/(−2) ＝ −0.5 ✓
