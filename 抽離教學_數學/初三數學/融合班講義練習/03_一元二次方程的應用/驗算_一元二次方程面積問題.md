**註 A（第 7 題設法改動）**：原稿參考答案設平行於牆的邊為 x，列 x·(35−x)/2=150 → x²−35x+300=0 → 15, 20，捨 20。
本版改設垂直於牆的邊為 x，與第 6 題、《練習_一元二次方程的應用_融合版》第 5 題同一模型。SymPy 兩種設法：
[15/2, 10] 對應平行邊 [20, 15]；原稿設法 [15, 20]。兩者最終答案同為長 15 m、寬 10 m。

**註 B（第 8 題歧義）**：原文「使花壇的面積增加原來的 2 倍」。
讀法 (A) 大＝小×3：(x+5)²=3x² → x≈6.830（原稿參考答案採此讀法）；
讀法 (B) 大＝小×2：(x+5)²=2x² → x=5(√2+1)≈12.071。
兩種讀法答案都是無理數，「答案形態」無法分辨原意，故跟參考答案。
使用者 2026-09-27 裁決採 (A)，題幹改寫為「使大花壇的面積比小花壇多出小花壇面積的 2 倍（即大花壇的面積是小花壇的 3 倍）」，標 ★★★ 挑戰題。

## 附錄：SymPy 腳本

```python
from sympy import *
x, c, r = symbols('x c r')
solve((c-1)**2+(c-8)**2-c**2, c)            # [5, 13]
solve(x*(x+1)-110, x)                        # [-11, 10]
solve(Rational(1,2)*x*(x-2)-4, x)            # [-2, 4]
solve(4*(x+5)**2-9*x**2, x)                  # [-2, 10]
solve(pi*r**2-2*pi, r)                       # [-sqrt(2), sqrt(2)]
expand(2*(Rational(1,2)*x*(x-3)-9))          # x**2 - 3*x - 18
expand((x**2+(2*x)**2-25)/5)                 # x**2 - 5
solve(x*(16-2*x)-30, x)                      # [3, 5]  → 平行邊 [10, 6]
solve(x*(35-2*x)-150, x)                     # [15/2, 10] → 平行邊 [20, 15]
solve(x*(35-x)/2-150, x)                     # [15, 20]（原稿設法）
solve((x+5)**2-3*x**2, x)                    # 5/2 ± 5*sqrt(3)/2 ≈ -1.830, 6.830
solve((x+5)**2-2*x**2, x)                    # 讀法 (B)：≈ -2.071, 12.071
solve((20-x)*(16-x)-252, x)                  # [2, 34]
solve((60-x)*(32-x)-1740, x)                 # [2, 90]
```
