## 一、逐題驗算

| 題 | 設法 | 方程 | 手算根 | SymPy | 捨根判斷 | 題意回代 | 一致？ |
|---|---|---|---|---|---|---|---|
| 1 | 較小數 x，較大 x+1 | x²+x−90=0 | (x+10)(x−9)=0 → 9, −10 | [−10, 9] | 捨 −10（x 須為正整數） | 9×10=90 ✓；9、10 相差 1 ✓ | ✓ |
| 2 | 較小偶數 x，較大 x+2 | x²+2x−168=0 | (x+14)(x−12)=0 → 12, −14 | [−14, 12] | 捨 −14（須為正偶數） | 12×14=168 ✓；同為偶數且相差 2 ✓ | ✓ |
| 3 | 較小奇數 x，較大 x+2 | x²+2x−35=0 | (x+7)(x−5)=0 → 5, −7 | [−7, 5] | 捨 −7（須為正奇數） | 5²+7²=25+49=74 ✓；同為奇數且相差 2 ✓ | ✓ |
| 4 | 一數 x，另一數 15−x | x²−15x+56=0 | (x−7)(x−8)=0 → 7, 8 | [7, 8] | **兩根都保留**（見註 A） | 7+8=15 ✓；7×8=56 ✓ | ✓ |
| 5 | 較小正數 x，較大 x+4 | x²+4x−96=0 | (x+12)(x−8)=0 → 8, −12 | [−12, 8] | 捨 −12（兩數皆為正） | 12−8=4 ✓；8×12=96 ✓ | ✓ |
| 6 | 該正整數 x | x²−5x−14=0 | (x−7)(x+2)=0 → 7, −2 | [−2, 7] | 捨 −2（須為正整數） | 7²=49；5×7+14=49 ✓ | ✓ |
| 7 | 該正數 x，倒數 1/x | 12x²−25x+12=0 | (3x−4)(4x−3)=0 → 4/3, 3/4 | [3/4, 4/3] | **兩根都保留**（見註 B） | 4/3+3/4=16/12+9/12=25/12 ✓ | ✓ |
| 8 | 該正數 x | 2x²+3x−27=0 | (2x+9)(x−3)=0 → 3, −9/2 | [−9/2, 3] | 捨 −9/2（須為正數） | 2×3+3=9；9×3=27 ✓ | ✓ |
| 9 | 個位 x，十位 x+2 | x²+2x−15=0 | (x+5)(x−3)=0 → 3, −5 | [−5, 3] | 捨 −5（數位數字須為 0–9 整數） | 5−3=2 ✓；5×3=15 ✓；兩位數＝5×10+3=53 | ✓ |
| 10 | 較小奇數 x，較大 x+2 | 4x+4=40（**一次方程**，見註 C） | x=9 | [9] | 無捨根（只有一個根） | 11²−9²=121−81=40 ✓；同為奇數且相差 2 ✓ | ✓ |

**結論：10 題全部兩種算法一致，零數學錯誤。**

### 註 A（第 4 題）：兩根不是兩組答案
x=7 時另一數為 15−7=8；x=8 時另一數為 15−8=7。兩個根指向**同一對數 {7, 8}**，
只是「先設哪一個」不同。既不能捨一個，也不能寫成兩組答案。
教師版第 4 題與「三、易錯點」第 ③ 條已寫明。

### 註 B（第 7 題）：兩根互為倒數，都成立
4/3 與 3/4 互為倒數。題目只說「一個正數與它的倒數之和為 25/12」，沒有額外限制，
故兩個都是合法答案，必須兩個都寫。
驗算：4/3 + 3/4 = 25/12 ✓；3/4 + 4/3 = 25/12 ✓。

### 註 C（第 10 題）：原稿此題實為一元一次方程
(x+2)² − x² = x²+4x+4 − x² = 4x+4。**二次項互相抵消**，方程化為 4x+4=40，x=9，唯一解。
即此題放在「一元二次方程應用題」中，實際不需解二次方程。

原文：「一個正數的 2 倍與它加 3 後的積為 27」

| 讀法 | 方程 | 根 |
|---|---|---|
| (A)　[2 倍] × [它加 3] | 2x(x+3)=27 → 2x²+6x−27=0 | Δ=252，x=(−3+3√7)/2 ≈ 2.469（無理數） |
| (B)　[2 倍加 3] × [它] | x(2x+3)=27 → 2x²+3x−27=0 | x=3 或 −9/2 |

判斷依據：其餘九題答案全部是整數或簡分數（最複雜的是第 7 題的 4/3、3/4），
只有讀法 (A) 會冒出無理數，與本卷「(基礎)」標示不符。判定原意為 (B)。

### 問題 2：第 3 題原稿提示寫到一半（已補完）

## 附錄：SymPy 覆核腳本

```python
from sympy import symbols, solve, Rational, Eq
x = symbols('x')
cases = [
 ("Q1",  Eq(x*(x+1), 90)),          # [-10, 9]
 ("Q2",  Eq(x*(x+2), 168)),         # [-14, 12]
 ("Q3",  Eq(x**2+(x+2)**2, 74)),    # [-7, 5]
 ("Q4",  Eq(x*(15-x), 56)),         # [7, 8]
 ("Q5",  Eq(x*(x+4), 96)),          # [-12, 8]
 ("Q6",  Eq(x**2, 5*x+14)),         # [-2, 7]
 ("Q7",  Eq(x + 1/x, Rational(25,12))),  # [3/4, 4/3]
 ("Q8",  Eq(x*(2*x+3), 27)),        # [-9/2, 3]
 ("Q9",  Eq(x*(x+2), 15)),          # [-5, 3]
 ("Q10", Eq((x+2)**2 - x**2, 40)),  # [9]
]
for name, eq in cases:
    print(name, solve(eq, x))
```
