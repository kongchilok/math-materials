## 站① 二次函數的圖像與性質（單元 05）

- 辨識（S4）：y=x²−4x+3 最高次 2 → 是 ✓；y=2x² 只有 x² 項（a=2）→ 是 ✓；y=3x+1 最高次 1 → 不是 ✓
- 一般式（S5）：y=x²−4x+3 → a=1、b=−4、c=3 ✓
- 開口（S6）：a>0 向上、a<0 向下、|a| 越大越窄；圖 y=x²（上）、y=−x²（下）對稱於原點 ✓
- 頂點式（S7）：y=a(x−h)²+k 頂點 (h,k)、軸 x=h；例 y=2(x−1)²+3 → 頂點 (1,3)、軸 x=1 ✓
- 配方步驟卡（S8）：y=x²−4x+3；(−4)/2=−2，(−2)²=4；x²−4x+4=(x−2)²；y=(x−2)²−4+3=(x−2)²−1 → 頂點 (2,−1)、軸 x=2 ✓；驗 −b/2a=−(−4)/2=2 ✓
- 圖像對照（S9）：y=x²−4x+3=(x−2)²−1；開口上(a=1)；頂點 (2,−1)；軸 x=2；x 軸 (x−1)(x−3)=0→(1,0)(3,0)；y 軸 (0,3) ✓（展開 (x−1)(x−3)=x²−4x+3 ✓）
- 分層題（S12）解答核對：
  - A1：y=2(x−1)²+3 → 上、x=1、(1,3) ✓；y=−(x+2)²−1 → 下、x=−2、(−2,−1) ✓
  - A2：y=x²−6x+5；(−6)/2=−3，9；(x−3)²；y=(x−3)²−9+5=(x−3)²−4 → 頂點 (3,−4) ✓
  - B3：y=x²+2x−3=(x+1)²−4；上；軸 x=−1；頂點 (−1,−4)；x 軸 (x+3)(x−1)=0→(−3,0)(1,0)；y 軸 (0,−3) ✓
  - B4：讀圖 → 頂點 (1,4)、軸 x=1、x 軸約 (−1,0)(3,0) ✓
  - C5：頂點 (1,−4) 且過 (3,0)：y=a(x−1)²−4，4a−4=0→a=1；y=x²−2x−3 → a=1、b=−2、c=−3 ✓
  - C6：找錯——(x−2)²=x²−4x+4，需 −4+3=−1，故正確為 (x−2)²−1；原式 (x−2)²+3 漏補常數 ✓

## 站② 二次函數與方程、應用（單元 06）

- 判別式（S16）：Δ=b²−4ac；Δ>0 兩交點、Δ=0 一交點（相切）、Δ<0 無交點 ✓
- 算 Δ 三例（S17）：x²−4x+1 → Δ=16−4=12>0（2 個）✓；x²−6x+9 → Δ=36−36=0（1 個）✓；x²+x+1 → Δ=1−4=−3<0（0 個）✓
- 圖像對照（S18）：y=x²−2x−3；Δ=(−2)²−4·1·(−3)=4+12=16>0（兩交點）；(x−3)(x+1)=0→x=3,−1→交點 (−1,0)(3,0)；頂點 (x−1)²−4→(1,−4) ✓
- 最值範例籬笆（S20）：長 20 不靠牆 → 長+寬=10；設寬 x，長 10−x；y=x(10−x)=−(x−5)²+25；頂點 (5,25)；x=5 面積最大 25 平方米（邊長 5 正方形）✓
- 分層題（S23）解答核對：
  - A1：Δ=12>0（2）、Δ=0（1）、Δ=−3<0（0）✓
  - A2：y=x²−x−6=(x−3)(x+2)→交點 (3,0)(−2,0) ✓
  - B3：y=−x²+4x−3=−(x−2)²+1；頂點 (2,1)；最大值 1；x 軸 (1,0)(3,0)；y 軸 (0,−3) ✓
  - B4：長+寬=12；y=x(12−x)=−(x−6)²+36；x=6（邊長 6 正方形），最大面積 36 平方米 ✓
  - C5：利潤 y=(x−40)(100−x)=−(x−70)²+900；售價 70 元最大利潤 900 元 ✓（展開 −x²+140x−4000 ✓）
  - C6：y=ax²−4x+c 過 (0,−1)→c=−1；最小值 c−b²/4a=−1−16/4a=−1−4/a=−5→a=1；答 a=1、c=−1 ✓
