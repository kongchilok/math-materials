## 改動清單

### ✅ 改 1：第 4 題條件式讀取教師實施說明頁

**位置**：SKILL.md 第 67-76 行

**改動內容**：
- 原本：硬性假設有 worksheet-generator 輸出的教師實施說明頁
- 新版：「無論來源，有教師實施說明頁就讀、沒有就跳過」
- 效果：支援其他來源教材、不卡流程

**新版文字**：
```markdown
> 4. **呢一課有冇同步出緊融合班講義／練習？**（無論來源——可以是 inclusive-math-worksheet-generator 或其他教材）
>    - 如果有教師實施說明頁（含設計代號），請提供：主設計是什麼（D1–D14，見講義末頁）
>    - 如果冇教師實施說明頁、或唔確定：無需提供，deck 用自己一套融合角色照常進行
```

### ✅ 改 2：資源班最佳實踐子項

**位置**：SKILL.md 第 2 題決定路線後

**新增內容**：「🔧 資源班最佳實踐」子節

**包含**：
- 轉換點密度：45 分鐘 3–4 個（練習講解密集，vs 全班共融 2–3 個）
- 分層任務：一層或兩層（vs 全班共融 A/B/C 三層）
- 新增頁面角色：「練習講解頁」
- 預告頁：課堂流程 + 練習順序預告

**效果**：選擇「抽離小組（資源班）」時自動套用資源班設置，不需另外問

## 使用場景

### 場景 1：math-test 資源班（主要使用場景）
```
第 2 題選「抽離小組（資源班）」
  → 自動套用資源班最佳實踐
  → 引擎二、三會自動排 3–4 個轉換點
  → 可加「練習講解頁」呈現講義截圖 + 詳解
  → 不強求 A/B/C 三層分層
```

### 場景 2：初中全班共融
```
第 2 題選「全班共融」
  → 保持原有設置（2–3 個轉換點、A/B/C 三層）
  → 不受影響
```

### 場景 3：輸入來源多元
```
教材來自任何地方（不只 worksheet-generator）
  → 第 4 題回答「沒有教師實施說明頁」
  → skill 不追問，用自己的融合角色照常進行
  → 流程順暢
```
